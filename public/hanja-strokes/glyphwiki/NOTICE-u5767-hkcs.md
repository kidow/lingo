# 坧 원본 형상 출처

GlyphWiki Project and contributors. [원본](https://glyphwiki.org/wiki/hkcs_m5767@1), [라이선스](https://glyphwiki.org/wiki/GlyphWiki:データ・記事のライセンス@18).

고정 제공자 hkcs_m5767@1의 완성형 3기록과 실제 full5·9raw·9draw·15P를 보존한다. 원문24·정적8쌍에 따라 raw1/2/3/4/5/6/(7+8)/9를 정상8획·9mask로 연결한다. 원P·Q·폭·weight·원본 raw 내부 순서를 바꾸지 않는다. 두 source-bound 초기캡과 y49 중심의 선행H 접촉 band를 사용하고, 완료 시 원P를 그대로 표시한다. ROOT 실제21·자연6·새 전체8획을 별도 확인했다. 초기21 보고 당시17이었던 점은 마지막4의 실제 확인 후 정정했다. 픽셀 수 0·모든 시점·원문 microtiming·시험 주관기관·AppUI 승인은 주장하지 않는다.
