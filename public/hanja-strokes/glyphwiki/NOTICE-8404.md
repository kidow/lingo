# 萄 source geometry

GlyphWiki contributors, under the [GlyphWiki data license revision18](https://glyphwiki.org/wiki/GlyphWiki:データ・記事のライセンス@18).

Pinned whole-glyph records: `u8404-k@8`, `u8404-ue0102@9`, `ufa5e-03@8`.
Editable source records and drawing calls are in `8404.json`.

The selected output uses the original engine-defined `new Kage(1)` and
`k.kShotai = k.kGothic` preset. Engine revision:
`49232bac0348fe815f4200d4116ab7917e0db47f`, exact file hashes in the asset.
The constructor preset and style constants are declared in that engine's kage.js.
Its COPYING is GPL-3.0; engine code is fetched into RAM for verification, not embedded in this app or asset.

Modifications: original polygons scaled 200 to 100; grass 3/4 reordered; outer
勹 moved before 缶; original shared endpoints grouped at two corners. The hook
follows both original engine quadratics. No source point, component or custom
width parameter was edited. Default and size1 Mincho outputs were rejected
because they connect the first grass vertical with the outer falling stroke.

Domestic e-hanja crosscheck, not exam-body approval. Private graphics are not distributed.
