# 濩 원본 형상 출처

GlyphWiki Project and contributors. [원본](https://glyphwiki.org/wiki/hkcs_m6fe9@2), [라이선스](https://glyphwiki.org/wiki/GlyphWiki:データ・記事のライセンス@18).

고정 hkcs_m6fe9@2의 공개 3기록과 실제 full5 21raw·21draw·41P를 보존하여 정상17획에 대응한다. 원문 새48·기존水3과 정적17·새m 전체 자형을 구분해 검토했다. 논리3의 원P9(3+4+2)는 각 nonzero로 독립 채우며 원Q 문자열·폭을 유지한 역방향 측정과 원본 전용 초기P3·몸통·상승 표시정책을 사용한다. 나머지6캡도 source-bound이다. 원P/Q 좌표·폭·무게를 바꾸거나 연결선을 추가하지 않는다. 정규화 p1 요청의 raw부분값을 exact완료로 승격하지 않고 phase done의 실제progress1/statuscomplete/P9 복원을 별도로 확인했다. 모든 프레임·픽셀0·원문 미세시계 동등성·시험기관·제품 전체자동재생 승인은 주장하지 않는다.
