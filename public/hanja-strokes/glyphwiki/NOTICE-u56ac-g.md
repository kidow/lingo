# 嚬 원본 형상 출처

GlyphWiki Project and contributors. [원본](https://glyphwiki.org/wiki/u56ac-g@2), [라이선스](https://glyphwiki.org/wiki/GlyphWiki:データ・記事のライセンス@18).

고정 u56ac-g@2의 공개 5기록과 실제 full5 21raw·21draw·36P를 보존하여 정상19획에 대응한다. 동일 원문 SVG의 기존1..12 방향 관찰과 새13..19 CSS21·새G 정적19를 구분해 사용한다. 옛 소스8의 갈고리 불일치는 새 G의 보류 근거로 전이하지 않는다. source-bound 초기 캡5와 H→V band2는 원P/Q 좌표·폭·무게를 바꾸거나 새 연결선을 추가하지 않는다. 실제 재생 승인 범위는 별도 native 기록에 고정하며 모든 프레임·픽셀0·원문 미세시계 동등성·시험기관·제품 전체자동재생 승인은 주장하지 않는다.
