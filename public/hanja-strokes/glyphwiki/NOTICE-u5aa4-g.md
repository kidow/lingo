# 媤 원본 형상 출처

GlyphWiki Project and contributors. [원본](https://glyphwiki.org/wiki/u5aa4-g@2), [라이선스](https://glyphwiki.org/wiki/GlyphWiki:データ・記事のライセンス@18).

고정 u5aa4-g@2의 공개 3기록과 실제 full5 14raw·16draw·28P를 보존하여 정상12획에 대응한다. 동일 원문 SVG의 기존12 방향·누적 관찰과 새 핵심1/10 CSS6·새G 정적12를 구분해 사용한다. 옛 여변 소스의 궤적 불연속을 새 G에 전이하지 않는다. source-bound 초기 캡5·원P 축 prefix3·H→V band1은 원P/Q 좌표·폭·무게를 바꾸거나 새 연결선을 추가하지 않으며 心 끝의 원래 serif도 보존한다. 실제 재생 승인 범위는 별도 native 기록에 고정하고 모든 프레임·픽셀0·원문 미세시계 동등성·시험기관·제품 전체자동재생 승인은 주장하지 않는다.
