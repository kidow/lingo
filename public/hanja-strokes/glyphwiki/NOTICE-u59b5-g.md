# 妵 원본 형상 출처

GlyphWiki Project and contributors. [원본](https://glyphwiki.org/wiki/u59b5-g@2), [라이선스](https://glyphwiki.org/wiki/GlyphWiki:データ・記事のライセンス@18).

고정 u59b5-g@2의 공개 3기록과 실제 full5 9raw·9draw·16P를 보존하여 정상8획에 대응한다. 같은 원문 SVG의 기존8획 방향·누적·완성형과 새G 정적8을 사용하며 옛 소스 첫획 불연속·가로 접촉 보류를 G에 전이하지 않는다. source-bound 초기 캡3과 여변 첫 꺾임 원P DOWN prefix1은 원P/Q 좌표·폭·무게를 바꾸거나 새 연결선을 추가하지 않는다. 실제 재생 승인 범위는 별도 native 기록에 고정하며 모든 프레임·픽셀0·원문 미세시계 동등성·시험기관·제품 전체자동재생 승인은 주장하지 않는다.
