# 蕃 원본 형상 출처

GlyphWiki Project and contributors. [원본](https://glyphwiki.org/wiki/u8543-t@1), [라이선스](https://glyphwiki.org/wiki/GlyphWiki:データ・記事のライセンス@18).

고정 u8543-t@1의 공개 4기록과 실제 full5 17raw·17draw·29P를 보존하여 정상16획에 대응한다. 원문 CSS48·정적16으로 13획 H→V 합획과 14H/15V 순서를 대조했다. source-bound 초기 캡7과 13m2 H→V band1은 원P/Q 좌표·폭·무게를 바꾸거나 새 연결선을 추가하지 않는다. 실제 재생 승인 범위는 별도 native 기록에 고정하며 모든 프레임·픽셀0·원문 미세시계 동등성·시험기관·제품 전체자동재생 승인은 주장하지 않는다.
