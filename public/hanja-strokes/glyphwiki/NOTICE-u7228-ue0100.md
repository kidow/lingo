# 爨 원본 형상 출처

GlyphWiki Project and contributors. [원본](https://glyphwiki.org/wiki/u7228-ue0100), [라이선스](https://glyphwiki.org/wiki/GlyphWiki:License@18).

고정 보존 원본 u7228-ue0100 body3의 34raw·34calls·60P를 30논리획·34mask로 연결한다. 카탈로그29는 유지하고 사전30 재생 변형 하나만 허용한다. 원P·원guide·width·weight는 변경하지 않는다. 캡15는 원Q/ML 완성마스크를 보존하며 초기 면적0에서 성장한다. 11/15 복합 캡과 6/9 접촉 Y대는 실제 완료 원본 H를 엄격히 확인한다. ROOT 신규114 및 자연8 PASS, 기존 독립 cardinal51·actual whole30 한 화면·원문90·정적30 근거를 재사용한다. 잔여17 화면은 520 전체에서 육안 백색이며 pixel0·모든시점·원문 microtiming 등가는 주장하지 않는다.
