# 塚 원본 출처와 사전 필순 표시

GlyphWiki Project and contributors의 공개 자형 자료를 사용합니다.

- 원본: https://glyphwiki.org/wiki/u585a
- 라이선스: https://glyphwiki.org/wiki/GlyphWiki:License@18
- 고정 아카이브: https://github.com/tomcumming/glyphwiki-database/tree/a7dd7f3d911936770fa742e8c37d16bee7e2173c
- 사용한 closure 3개: u585a, u571f-01, u51a2-02-var-001.
- 편집 가능한 공개 원본: [u585a.json](u585a.json)

고정 actual-full5의 13개 원시 행·14개 그리기 호출·26개 원래 폴리곤을 사전 필순 12획으로 연결합니다. 카탈로그의 13획 표기는 유지합니다. 원래 P·Q 가이드·폭·weight를 바꾸거나 연결선을 추가하지 않습니다. 시작 캡 9개와, 완료된 8획 첫 마스크에 접촉하는 원본 P의 왼쪽 진행 prefix를 표시합니다.

사전 필순 근거는 e-hanja 출판사 SVG이며 시험 주관기관의 승인을 뜻하지 않습니다. 과거 11획의 오른쪽 가로 진행이라는 서술은 원문 3프레임 재확인에 따라 짧은 좌하향 획으로 정정했습니다. 새 실제 화면 66프레임·자연 재생 18스냅샷·완료된 전체 자형 1스냅샷과 기존 원문·정적 대응·전체 자형 기록을 구분합니다. 모든 순간의 래스터 동일성이나 출판사 애니메이션과 같은 시간 배분을 주장하지 않습니다.
