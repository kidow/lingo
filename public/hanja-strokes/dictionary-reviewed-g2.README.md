# Grade 2 dictionary-crosschecked geometry

`dictionary-reviewed-g2.json` contains 44 modified characters / 506 centerline
strokes, prepared for Lingo on 2026-09-15. The full modified source is the JSON
bundle, distributed under the [Arphic Public License](ARPHICPL.txt), without
warranty. Attribution and copyright notices are preserved in [COPYING.txt](COPYING.txt).

The bundle records the pinned URL, SHA-256 and byte size for each geometry
corpus: Make Me a Hanzi `graphics.txt` and AnimCJK `graphicsJa.txt`. Each
character identifies the actual corpus through `geometrySource`; Korean
dictionary verification is separate from this licensed geometric origin.

Original median coordinates, source hashes, complete review observations,
correction recipes, final paths and the read-only compiler are retained in
`docs/hanja-g2-batch1-2026-09-15/`. The runtime serves 35 unchanged normalized
candidates and nine corrected candidates. 憾·傀·槐·掘·珪 reorder existing
strokes; 坑·炅·圈·購 contain five locally corrected centerlines. Locally
corrected strokes carry null `sourceStrokeIndices`; recipes retain the
source stroke from which their bounds were derived.

All 581 strokes in the 50-character batch were visually compared with the
e-hanja Korean dictionary. Six forms (迦·甄·雇·膠·絞·窟, 75 strokes) remain
unpublished. Matching counts or shared radicals alone never approve playback.
`ehanja-crosschecked` denotes this dictionary comparison, not exam-body
certification, exact font-outline matching or handwriting grading.

No proprietary e-hanja paths, masks, centerlines, scripts or screenshots are
redistributed. Source SVG data were used only in memory for visual review.
