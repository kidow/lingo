# 僝 14획 검토 완료

전체 원본 2종과 국내 사전의 14획 순서·방향을 브라우저 패널에서 대조했다. 원본 43개 다각형은 좌표 변경 없이 각각 한 번 사용하며 14획·17마스크로 재생한다.

126개 진행 프레임, 곡선 10획의 520px 99.99→100% 경계, 7·10·13획의 동일 획 갈고리 전이, 6·13획의 실제 재생을 확인했다. 원본 고정 아카이브·엔진 8개·국내 메타데이터 검증과 변경 대상 테스트 3개가 통과했다. 빌드·전체 테스트·모바일 검증은 실행하지 않았다.

적용 5,420/5,978자, 미적용 558자. 다음 후보는 欌 22획이다. 사전 대조 결과이며 시험 주관 기관의 공식 승인을 의미하지 않는다. 비공개 SVG와 검토 화면은 저장하지 않았다.
