- [비상교육 고등 한문](https://text.vivasam.com/detail/186)의 [교재 뷰어](https://viewer.vivasam.com/qrviewer/viewer.html?qrcode=106502_171p_25_ST&teacher=false) 원본을 기준으로 했다.
