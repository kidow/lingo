# 弊 14획 전체 경로·방향 검토

검토일: 2026-09-13. **弊 14획 애니메이션을 승인·반영했다.**

## 근거

- [한국어문회 후속 답변](https://www.hanja.re.kr/klea/counsel/hanjaDetail.do?id=16424)은 㡀를 7획으로 계산하는 기준을 弊 등에도 적용하도록 설명한다. 앞선 [획수 검토](../hanja-g3ii-pye-count-2026-09-13/README.md)에서 앱의 弊를 14획으로 보정했고, 배정표 원문 15획은 보존했다.
- [e-hanja의 弊 필순 원문](http://img.e-hanja.kr/hanjaSvg/aniSVG/5F00/5F0A.svg)을 브라우저에서 1획부터 14획까지 직접 대조했다. 각 획의 재생 시간 20%·80%·완료 시점과 후보 누적 자형의 시작·끝 표시를 비교했다. CSS 애니메이션의 색 변화와 실제 그려지는 방향을 함께 확인했다.
- 이전 비상교육 교과서 영상 검토에서도 14획과 연속된 가운데 세로가 관찰되었다. 그 기록은 보조 근거로 참조했으며 이번에 영상을 다시 검수했다고 주장하지 않는다.

공식 설명은 **획수의 근거**, 사전 원문은 **전체 필순·방향의 근거**, 로컬 후보는 **앱이 재생할 중심선 경로**다. 사전이나 한국어문회가 이 SVG 경로를 인증했다는 뜻은 아니다.

## 보정과 검수

Make Me a Hanzi의 고정된 원본에서 弊의 14개 중심선을 확보했다. 원본 9·12획은 유지하고 나머지 12개 중심선은 국내 자형과 실제 선 두께에 맞게 보정했다.

| 구간 | 확인한 동작과 보정 |
|---|---|
| 1·2 | 왼쪽 삐침과 오른쪽 점. 원본 후보의 반대 방향을 바로잡았다. |
| 3–7 | 바깥 세로, 한 번에 꺾이는 가로·세로·갈고리, 끊기지 않는 중앙 세로, 분리된 안쪽 두 획. 선 두께 5에서도 안쪽 획과 갈고리가 중앙·외곽에 붙지 않도록 간격을 보정했다. |
| 8–11 | 오른쪽 삐침과 가로의 연결, 가로에서 시작하는 긴 왼쪽 삐침, 그와 교차하는 오른쪽 파임. 11획 시작점을 위쪽 연결부로 보정했다. |
| 12–14 | 廾의 가로, 왼쪽 삐침, 오른쪽 세로. 위쪽 敝와는 떨어져 있고 아래 가로와는 교차한다. |

보정 후 14개의 누적 상태를 다시 대조했다. 선분 사이의 정확한 거리 검사에서 발견한 1·3획의 미세한 접촉은 추가 보정하고 1획과 완성된 14획 자형을 재확인했다. 떨어져 있어야 할 17쌍은 중심선 거리 최소 약 5.8로, 선 두께 5를 제외해도 간격이 남는다. 연결되어야 할 8쌍과 주요 실제 교차도 검사했다.

자형의 비례·붓 외곽까지 그대로 복사한 것이 아니라, 검토한 순서·방향·연속성·연결 관계를 표현하는 중심선이다. 외부 사전의 경로·이미지를 런타임에 가져오지 않았다. 수정한 기하 데이터와 원본 중심선에는 기존 [Arphic 라이선스·저작권 고지](../../public/hanja-strokes/dictionary-reviewed.README.md)를 적용한다.

## 파일과 재현

- `sources.json`: 출처·수집 해시·획수 정정 연결.
- `observations.json`, `review.json`: 실제 관찰 내용과 이 글자에 한정한 승인.
- `originals.json`, `corrections.json`, `candidate-paths.json`: 원본 중심선, 보정식, 최종 경로.
- `review.html`, `serve.mjs`: 로컬 대조 화면. 외부 SVG·재생 자원은 해시를 확인한 뒤 메모리에만 보관한다.
- `verification.json`: 최종 검사 결과.

```sh
rtk proxy node docs/hanja-g3ii-pye-2026-09-13/serve.mjs
rtk proxy node --test 'lib/hanja*.test.ts'
rtk proxy pnpm exec next build
```

검토 서버가 출력한 루프백 주소를 열면 각 획의 원문 정지 화면과 후보를 비교할 수 있다. 서버는 임의의 파일 경로를 제공하지 않는다. 브라우저의 자동 화면 복원으로 아래쪽이 보이면 페이지 맨 위로 이동한다.
