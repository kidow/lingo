1. **笛·蹟·稚 3자 42획의 후보 경로 검토**를 먼저 진행한다. 고정된 공개 코퍼스의 순서·시작점·끝점·꺾임·접점을 확인하고, 출처 공백이 남으면 검토 후보로 보관한다.
