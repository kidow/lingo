## 획 순서 교환 8자

| 부수 | 글자 | 교환 |
| --- | --- | --- |
| 糸 | 絏·繻 | 가운데 세로를 왼쪽 점보다 먼저 (4·5획) |
| 艹 | 藹 | 두 十을 가로 먼저 (두 쌍) |
| 角 | 觫 | 안쪽 세로를 가로 둘 사이에 (6·7) |
| 王 | 瑣 | 둘째 가로를 세로보다 먼저 (2·3) |
| 聿 | 贐 | 가운데 긴 세로를 아래 가로보다 먼저 (11·12) |
| 黑의 里 | 黯 | 안쪽 가로를 세로보다 먼저 (6·7) |
| **艹 + 肅** | 蠨 | 艹 두 쌍에 더해 肅 본체 **열세 자리** 재배열 |

**蠨이 이번 회차에서 가장 멀리 움직인 글자다.** 사전은 肅의 긴 세로 둘을 맨 뒤로 미루는데
MM은 가운데 세로를 肅의 첫 획으로, 오른쪽 세로를 그다음으로 그린다.
열세 자리가 움직이지만 **획 하나하나는 허가된 경로 그대로**고, 스물세 획이 빠짐없이 한 번씩 쓰인다.

## 국소 보정 8획 5자

| 보정 | 글자 | 내용 |
| --- | --- | --- |
| 亠의 첫 점 | 蟀 | 세로로 (7) |
| 隹의 짧은 획 | 售·濉 | 오른쪽 위 획을 왼쪽 아래로 반전 (售 3, 濉 11) |
| **屯의 첫 가로** | 肫 | **역방향으로** (5) |
| **羽 안쪽 넷** | 熠 | 점 둘(6·9)은 반전, 올려 긋는 획 둘(7·10)은 역방향으로 |

**肫이 처음 나온 자리다.** 사전은 屯의 첫 가로를 **오른쪽에서 왼쪽으로** 긋는다(178°).
색으로 나눈 진행 구간에서 파란 시작점이 오른쪽 끝에 있는 것을 확인했고,
역방향으로 맞추면 허가된 점을 하나도 버리지 않는다.
나머지 보정은 모두 선례대로다 — 隹의 짧은 획은 霍·雞·雒·售,
羽 안쪽은 [5차](../hanja-special-batch5-2026-09-20/README.md)의 翻과 [4차](../hanja-special-batch4-2026-09-20/README.md)의 僇,
亠의 첫 점은 稟·廡와 같다.

藹은 사전 그림이 `translate(12, -830)`로 가로 오프셋을 가진다.
검토 시트·검사 스크립트가 모두 `translate(x, -y)`를 받으므로 대조에는 영향이 없다.

부수 유사성으로 승인하지 않았다. 쉰 글자의 사전 전체 필순을 순서대로 보고,
색으로 나눈 25% 진행 구간에서 방향·펜 떼기·획 경계·완성 자형을 대조했다.
[direction-probe.mjs](direction-probe.mjs)의 60° 초과 표시는 후보 교체·교환·보정으로 모두 해소했고,
각도 검사가 놓친 絏·繻의 糸 순서와 蠨의 肅 재배열은 끝점 배정 검사가 잡았다.
공개한 순서·경로로 다시 재면 60°를 넘는 획이 없다.
45~60° 구간은 다섯 획(愫 8, 竦 1, 鶉 1, 啻 1, 黯 13)이고, 이전 회차와 같은 기준으로 그대로 뒀다.
