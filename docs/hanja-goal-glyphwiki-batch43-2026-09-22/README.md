# 芭8획 — 원본 윤곽 순차 재생 적용

GlyphWiki 원본4건과 고정 KAGE 엔진8파일로 전체 윤곽 및 실제 line/curve 호출을 재현했다. 국내 사전의 전체8획 방향과 후보의72개 중간 상태·누적·완성형을 대조했다. 한국어문회 공식 승인으로 표시하지 않는다.

`draw-trace.json`과 `progressive.mjs`가 각 원본 도형을 재생 구간으로 연결한다. 직선은 원본 윤곽의 진행 방향으로, 꺾인 모서리는 원래 quadratic 명령으로 드러낸다. 마지막 위쪽 갈고리는 원본 다각형을 아래에서 위로 드러내며 새 중심선을 만들지 않았다. 전체 획을 페이드하는 방식이 아니다.

앱의 `StrokeOutlines`는 기존 플레이어 시계·1.5배 속도·일시정지·다시 재생을 공유한다. 매 프레임 갱신은 SVG 하위 컴포넌트에 한정한다. 완료/수동 재생에서는 전체 윤곽을 표시하며, 다시 재생 시 이전 진행률을 초기화한다. 기존 중심선 데이터의 재생 방식은 보존했다.

검증: 원본4건 재조회, 엔진8파일 해시 및 draw trace 재현, 한자 테스트869개, 관련 회귀12개, TypeScript 포함 프로덕션 빌드 및7페이지 내보내기 통과. 격리 작업 트리의16개 파일과 출력 자산3개가 원본 작업 트리와 일치한다. 모바일430×932에서 소개/쓰기 자동재생·다시 재생·완료·일시정지/이어 재생·수동1~8획/재시작을 확인했다. 캔버스0→1→0획 입력 중 시트 위치/스크롤이 유지되고 SVG1개·정적 이미지0개, 콘솔 오류/경고0건이다.

재현: `node docs/hanja-goal-glyphwiki-batch43-2026-09-22/verify.mjs --engine --sources`. `serve-progressive.py`는51897에서 RAM 대조 화면을 제공한다. 엔진 구현과 비공개 사전 그래픽을 제품에 복제하지 않았다. 공개 원본·라이선스 고지는 `public/hanja-strokes/glyphwiki/82ad.json`과 `NOTICE-82ad.md`에 포함된다.
