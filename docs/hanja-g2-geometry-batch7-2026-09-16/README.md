## 확보·대조

- 사전 상세 페이지의 실제 애니메이션 iframe을 다시 확인했다. 표시 획수, 애니메이션 수, 외곽선 수는 각각 10·6·13으로 일치했다.

- 고정 커밋의 Ko·Ja·MM 자료를 다시 받아 해시를 검사하고 NFKC 호환 글자까지 조사했다. Ko 후보는 없고 Ja·MM은 각각 9·5·12획이다. 목록과 정확히 같은 획수의 대체 후보는 없었다. 이번에는 MM 후보를 사용했다.
- 29개 누적 단계와 각 획의 25·50·75·100% 진행 구간을 브라우저에서 대조했다. 보정 경로 27개와 완성 자형 3개를 다시 확인했다.
- 원본 접점·간격 36쌍을 RAM에서 외곽선으로 확인했다. 곡선당 30개 구간으로 근사한 최소 간격과 교차 여부를 기록했다. 애니메이션 중심선 29획의 이동 방향도 대조했다.
- 사전 SVG·외곽선·스크린샷은 디스크에 저장하지 않았다. 라이선스 원후보, 자체 보정 경로, 원본 URL·해시·검토 결과만 기록했다.

## 글자별 보정

**荀:** 초두의 통가로를 분리해 네 획으로 만들고 두 세로를 곧게 보정했다. 아래 삐침은 왼쪽 초두 밑에서 시작한다. 바깥 지붕 가로는 이 삐침에 닿고 오른쪽에서 내려와 왼쪽 갈고리로 끝난다. 원후보의 비스듬한 왼쪽 위 마무리를 보정했다. 안쪽 日은 바깥 勹과 떨어지며, 가운데·아래 가로가 양쪽 세로에 모두 닿도록 보정했다.

**艾:** 네 획 초두 아래, 오른쪽에서 왼쪽 아래로 그리는 삐침을 먼저 쓴다. 다음 파임은 왼쪽에서 시작해 오른쪽 아래로 교차한다. 두 획의 역방향 진입을 없애고 각각의 진행 방향을 유지했다. 두 시작점은 초두 세로와 떨어진다.

**惹:** 초두 아래 삐침이 5획, 긴 가로가 6획이다. 가로를 먼저 쓰는 원후보의 순서를 바꿨다. 口의 왼세로와 지붕 가로는 삐침에 닿고, 윗가로와는 떨어진다. 아래 心의 긴 획은 세로로 내린 뒤 둥근 모서리를 거쳐 가로로 진행하고 오른쪽에서 위로 마무리한다. 원후보의 비스듬한 그릇 모양과 왼쪽 위 갈고리를 보정했다. 왼쪽 점과 안쪽 점은 원후보를 유지하고, 마지막 점은 오른쪽 아래로 옮겨 口·갈고리와 분리했다. 口 밑가로와 안쪽 점 사이의 작은 간격도 별도 검사한다.

보정 결과는 학습용 중심선이다. 정적 Noto 글꼴이나 사전 서체의 외곽선을 그대로 재현한 데이터는 아니다.
