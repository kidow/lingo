# 秊 8획 적용

국내 사전의 전체 8획 방향·누적·완성 자형과 공개 백업의 완성 원본 `u79ca`를 대조했다. 8개 원본 그룹을 동일 순서로 사용하고 네 이차곡선과 모든 외곽선 정점을 보존했다. 새 점·연결선·자르기·좌표 변경·부수 교체는 없다.

- 정확한 원본 3레코드 및 고정 엔진 8파일 재현 검증 통과.
- 8획 × 9단계, 총 72개 중간 프레임 직접 검토. 禾·千의 교차, 방향, 최종 형태 확인.
- 한자 테스트 201파일·949개 및 격리 빌드·타입 검사·정적 7페이지 생성 통과. 검사한 17파일과 공개 출력 3파일이 작업 트리와 일치.
- 430×932 모바일 소개/쓰기 진입 자동재생·다시 재생·8/8완료 확인. 입력 0→1→0, 드래그 전후 시트 위치·스크롤 동일, 정적 이미지 중첩 0, 경고/오류 0.

전체 **5,001/5,978자(83.7%) 적용**, 미적용 **977자**. 남은 수: 1급 65·2급 1·특급II 286·특급 625. 다른 급수는 100% 적용.

다음은 昑(특급II·8획). 완성 원본 4레코드는 확보했고 국내 자형·방향과 원본 엔진 대조는 아직 하지 않았다. 사전 그래픽은 RAM에서만 검토했으며 서버 52003–52005는 종료했다. 모바일 탭은 닫았고 검토 탭은 연결 해제로 자동 정리에 맡겼다. 국내 사전 교차검토이며 시험기관의 공식 승인이 아니다.
