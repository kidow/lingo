## 전체 획 검토

브라우저에서 원본 36단계와 보정 후 36단계를 모두 확인했다.
각 단계에서 마스크의 25·50·75·100% 구간으로 시작점·진행 방향·끝점을 대조했다.

| 글자 | 보정한 주요 지점 |
| --- | --- |
| 湜 | 물수변의 불필요한 진입 꺾임을 없애고 세 획을 분리했다. 日의 중간·아래 가로획을 양쪽에 연결하고, 아래 세로와 마지막 오른쪽 획의 접점을 유지했다. |
| 珣 | 王의 가로·세로·올림획 접점, 勹의 아래 꺾임과 왼쪽 위 갈고리, 안쪽 日의 폐합을 맞췄다. |
| 瑢 | 머리 점을 사전에서 확인한 아래 방향으로 바꿨다. 지붕의 연결과 아래 두 획의 분리를 맞추고, 王의 마지막 획이 가운데 왼쪽 삐침에 닿지 않도록 보정했다. 입 구(口) 부분의 위쪽 연결과 내부 가로획 간격도 대조했다. |

공개 중앙 경로를 바탕으로 36개 경로를 보정했다. 곡선은 자체 보정 제어점에서
폴리라인으로 변환했다. 사전의 외곽선이나 마스크 경로를 복사하지 않았다.

모든 획 쌍 202개를 원문 외곽선으로 RAM에서 대조했다. 곡선당 30개 표본을
사용한 근사 거리·교차 검사이며 시각 검토를 보조한다. 재생 선폭 5에서
원문의 연결·분리 관계가 모두 유지된다. 초안의 湜 2/3획과 瑢 4/10획이
가까운 문제를 수정하고 해당 단계를 다시 확인했다.

## 구현과 검증

- 별도 배치 모듈·런타임 JSON을 추가하고 기존 한자 등록부에 연결했다.
- `dictionaryLocalGeometry`는 이번 세 글자만 명시적으로 추가한다.
  출처·증빙 해시·원본 중앙 경로·보정 경로를 검증한 뒤에만 공개 후보 조회를 대체한다.
- 원본 복원, 순서 뒤바꿈, 출처 변조, 증빙 바이트 수정, 범위 밖 경로 및 미검토 한자 승인을 거부한다.
- 한자 테스트 67개 파일 **419개 통과**, 실패·건너뜀 0.
- `pnpm exec tsc --noEmit --incremental false` 통과.
- 획 단계 및 방향을 시각 검토했다. 실제 경과 시간에 따른 재생 속도나 전체 앱 빌드를 새로 검사한 것은 아니다.
