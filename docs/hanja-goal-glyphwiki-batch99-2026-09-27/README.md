- 국내 사전의 6획 방향·누적·완성 자형과 54개 진행 화면을 직접 대조했다. 시험 주관 기관의 공식 승인을 뜻하지 않는다.
- 일반 u9099는 亡 세로획이 가로획 왼쪽 끝에 붙어 제외했다. 별도 전체 한국형 u9099-k가 국내 접합 형태와 일치한다.

- 공개 백업6레코드(선택3개와 제외 원본의 합집합), 엔진8파일 해시·원본 재현 통과. 비공개 사전 그림은 RAM에서만 처리했다.
- 한자 테스트209파일973개, 배포 빌드, 정적 산출물3개와 소유 파일23개 일치 통과.
- 모바일430×932: 소개/쓰기 자동·다시 재생, 오버레이 중복 없음, 입력0→1→0, 시트/캔버스 위치 유지, 콘솔 경고·오류0.
