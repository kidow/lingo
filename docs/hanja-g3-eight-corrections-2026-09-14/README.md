## 근거와 검토 범위

[비상교육 고등 한문](https://text.vivasam.com/detail/186)의 [교재 QR 뷰어](https://viewer.vivasam.com/qrviewer/viewer.html?qrcode=106502_171p_25_ST&teacher=false)와 고정된 1,800자 목록을 사용했다. **출판사 원문과 대조한 결과이며 한국어문회 인증이 아니다.** 정확한 영상 URL·SHA-256·바이트 수는 `review.json`에 보관했다.

- 8개 영상 전체를 2fps **286개 표본**으로 재열람했다. 繫의 8.5~11.0초는 10fps **26개 표본**, 矯의 최종 자형은 **840px**로 추가 확인했다.
- 실제 `textbookGeometry` 출력의 109개 누적 경로와 420px 최종 자형을 모두 확인했다. 굵기 5, 둥근 선 끝과 이음을 사용했다.
- 첫 보정본에서 발견한 絹 오른쪽 점의 접촉, 矯 위 口와 오른쪽 삐침의 접촉을 추가 보정하고 다시 열람했다. 矯의 두 내부 공간과 주변 획 간격은 수치 검사로도 고정했다.
- 繫 8~10획의 완료 상한을 상세 관찰에 맞춰 **10.2·11.0·12.0초**로 보완했다. 모든 시각은 표본에서 확인한 보수적 완료 상한이며 정확한 펜 이탈 시각이 아니다.
- 기하 원본은 고정 커밋의 Make Me a Hanzi 중심선이다. 원본 좌표·해시·일대일 대응을 보존하고, 원문에서 확인한 차이에 한해 표시 좌표를 수정했다. 기존 `public/hanja-strokes`의 Arphic 라이선스 고지를 유지한다.
- 검토자는 Codex root 1명이다. 자동 검증은 기록·기하·출처 연결의 일관성을 검사한다.
- 출판사 동영상·원문 이미지·디코딩한 프레임은 RAM에서만 처리했으며 제품이나 문서에 복사하지 않았다.

## 파일과 재현

- `prior-review.json`, `prior-candidate-paths.json`: 이전 보류 판정과 후보 경로. 현재 승인 목록이 아니다.
- `originals.json`: 고정된 라이선스 원본 중심선 8자와 해시.
- `corrections.json`: 8자 보정 레시피. `sourceStroke`는 원본 대응이며 명시적 `points`만 표시 좌표 보정이다.
- `candidate-paths.json`: 최종 열람 경로. 실제 생성기 및 제품 경로와 일치한다.
- `review.json`, `observations.json`: 전체 필순 관찰, 변경 획, 출처, 완료 시각, 최종 판정.
- `baseline.json`: 작업 전 등록부·레시피·제품 번들의 기존 기록 해시.
- `verification.json`: 테스트·빌드·원본 재생성 결과와 현재 적용 수.
- `serve.py`: 루프백 전용 RAM 검토 서버. `?glyph=矯&final=1&native=1`로 원문 고해상도 비교를 재현한다. 출처 해시가 바뀌면 중단한다.

```sh
node --test --test-reporter=spec lib/hanja-stroke-g3-eight.test.ts
node --test --test-reporter=spec 'lib/hanja*.test.ts'
node scripts/hanja-stroke-textbook-build.ts --check
node docs/hanja-g3-batch1-2026-09-14/verify.mjs
pnpm run build
python3 -B docs/hanja-g3-eight-corrections-2026-09-14/serve.py
```

한자 테스트 **226/226**, 교재 번들 **1,016자 원본 재생성 일치**, Next.js 16.3.3 빌드와 TypeScript 검사가 통과했다. 이전 모든 승인 기록·레시피·제품 항목은 보존했다.
