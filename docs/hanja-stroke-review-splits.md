# 5급까지 500자 필순 적용 완료

적용일: 2026-09-07. 成·萬·草·花·藥·苦·英·敬·觀·舊·落·葉의 12자 보정을 마쳤다. 5급까지 누적 500자 전체와 상위 급수 回·瓦·臼 3자를 합쳐 총 503자가 재생된다. 전체 5,978자 중 나머지 5,475자는 미제공 상태다.

## 공식 근거와 개별 대조

한국어문회 [「필순 정정 및 500자 필순」](https://www.hanja.re.kr/kccpt/exam/otherData.do?search_option=subject&search_text=%ED%95%84%EC%88%9C), 2010-03-22 판본의 `f37.hwp`를 다시 내려받아 해시를 확인했다. SHA-256은 `4e191bbee54edd6db595f16fc83a15b9929eba0e3e01095da1e828c70e10760c`다.

[成 공식 답변](https://www.hanja.re.kr/klea/counsel/hanjaDetail.do?id=4349)은 내부 丁 변형을 2획으로 계산한다고 설명한다. [초두머리 공식 답변](https://www.hanja.re.kr/klea/counsel/hanjaDetail.do?id=10723)은 본자 4획과 가로를 이어 쓴 속자 3획을 구분한다. 순서와 분할은 이 설명뿐 아니라 아래 각 글자의 모든 누적 도해로 확인했다.

## 재현 가능한 수정

원본은 [AnimCJK graphicsKo.txt](https://github.com/parsimonhi/animCJK/blob/ec5e17cca76c87587790bcbce5ea0b4d4fb753d6/graphicsKo.txt), SHA-256 `7e703f34df54080281252a5c87a7106b85034b81fdbf93d37c07009a1448202e`다. 먼저 기존 정규화(Y축 반전, 80단위 균일 배율, 중앙 정렬, 소수 첫째 자리)를 적용하고 다음 수정만 수행한다.

- 成: 원본 2획을 1획보다 먼저 쓴다. 원본 3획의 세 번째 점을 공통 끝점·시작점으로 삼아 가로와 이후 꺾인 획을 분리한다. 원본의 모든 점을 보존한다. 획 대응은 `[2,1,3,3,4,5,6]`이다.
- 초두머리 11자: 원본 1획의 가로 연결부를 위 표의 구간에서 제거한다. 새 끝점은 기존 선분 위에서 보간해 소수 첫째 자리로 반올림한다. 출력은 왼쪽 가로·왼쪽 세로·오른쪽 가로·오른쪽 세로 순이다. 이후의 원본 경로는 바꾸지 않는다. 앞부분 원본 획 대응은 `[1,2,1,3]`이다.

`public/hanja-strokes/splits-reviewed.json`에 글자별 보정 방법, 공식 위치, 원본·결과 해시, 수정 전후 획 대응, APL·저작권·변경 내역을 보존한다. `sourceStrokeIndices`에서 같은 번호가 반복되면 그 원본 획의 서로 다른 분할 부분이다. 결과 해시는 UTF-8 `JSON.stringify(paths)`의 SHA-256이다. 공식 이미지는 배포하지 않는다.

`scripts/hanja-stroke-splits.ts`는 정확히 이 12자의 보정만 허용한다. 감사 도구는 원본 해시, 글자, 공식 위치, 원본 획수, 보정 ID, 분할 결과, 획 대응과 최종 해시를 확인한다. 경로를 임의로 수정하고 해시만 다시 계산해서는 통과하지 못한다. 기존 두 점 보정과 性 순서 보정의 검사도 유지한다.

## 검증 및 범위

급수별 최초 배정 글자의 재생 수는 8급 50/50, 7급II 50/50, 7급 50/50, 6급II 75/75, 6급 75/75, 5급II 100/100, 5급 100/100이다.

- 전체 테스트 156개, 타입 검사 통과. 5급까지 500자 집합과 등록 경로를 정확히 비교하며 누락·중복·다른 획수·유사 문자 치환을 검사한다.
- 원본을 다시 내려받은 `node scripts/hanja-stroke-audit.ts`: Ko 기반 482자 + Ja 3자 + 별도 자체 중심선 18자 = 503자.
- 앱 찾기 상세에서 成 7/7, 萬 13/13, 觀 25/25 완주와 다시 재생 시 1획으로 돌아가는 동작을 확인했다. 미검증 상위 급수 警에는 재생 버튼이 나타나지 않는다. `git diff --check`도 통과했다.
- Ko 원본 후보 집계는 기존과 같이 획수 불일치 15자다. 그중 14자는 보정 후 재생하며, 상위 급수 警은 미승인이다. 후보 자체와 보정된 재생 데이터를 구분한다.
- 읽기 전용 대조 도구 `scripts/hanja-stroke-review.py --port 5865`의 `/split/成`처럼 글자를 지정하면 공식 원문과 실제 배포 경로를 비교할 수 있다(Pillow·xlrd 필요).

이 결과는 공식 도해와의 필순·획 구성 대조다. 공식 앱 인증, Noto 윤곽과의 픽셀 일치 또는 손글씨 자동 채점을 의미하지 않는다. 이전 485·489·491자 보고서는 각 적용 시점의 이력으로 보존한다.
