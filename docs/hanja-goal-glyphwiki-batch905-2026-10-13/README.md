# 纘 25획 보류

브라우저 패널에서 국내 자형과 전체 원본3종을 대조했으며 자형은 호환된다. 세 원본 모두29raw·31draw·62다각형이고 정확 경계는 [21,26]·[22,23]뿐이다. 비연속 貝폐합[21,26]을 제외하면 연속 경계 한 곳으로 최소28획이며 국내25획과 다르다. 비연속 폐합을 허용한 수치27도25와 맞지 않는다. 경로·윤곽을 새로 만들거나 임의로 연결하지 않으며 국내 방향·진행·확대·재생은 미검토다.

브라우저 패널에서 전체 원본 3종과 전체 자형을 대조했다. 국내 방향은 미검토다. 완료하지 않은 진행 프레임·확대 경계·재생은 승인하지 않았다. 고정 원본·엔진·국내 메타데이터 검증은 통과했으며, 기존 런타임에 이 후보가 포함되지 않음을 확인했다.

적용 5459/5,978자, 미적용 519자. 빌드·전체 테스트·모바일 검증을 실행하지 않았다. 다음 후보 爨 29획.
