# 枏 8획 적용

국내 사전 전체8획의 방향·누적·완성 자형을 고정 공개 백업의 완성 원본 `u678f`와 대조했다. 원본10그룹 중 빈 제어 항목4에는 그리기 호출과 외곽선이 없다. 실제 그려지는 모든 그룹을 유지하며 그룹6·7을 국내6획의 가로→세로→왼쪽 갈고리로 재생한다. 내부 경로 끝점은 정확히 이어진다.

- 정확한 원본5레코드와 고정 엔진8파일을 검증했다. 원래 세 이차곡선과 모든 외곽선 정점을 보존했으며 새 점·연결선·자르기·좌표 변경·부수 교체는 없다.
- 8획 × 9단계, 총72개 점진 재생 장면을 직접 검토했다.
- 한자 테스트200파일·946개 통과. 격리 빌드·타입 검사·정적7페이지 생성 통과. 검사한17파일과 공개 출력3파일이 현재 작업과 일치한다.
- 430×932 모바일에서 소개/쓰기 진입 자동재생, 다시 재생,8/8완료를 확인했다. 캔버스 입력0→1→0, 드래그 전후 시트 위치·스크롤 동일, 정적 이미지 중첩0, 브라우저 경고/오류0.

전체5,000/5,978자(83.6%) 적용, 미적용978자. 남은 수: 1급65·2급1·특급II287·특급625. 다른 급수는 모두 적용됐다.
