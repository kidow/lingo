## 전체 획 대조

각 획마다 누적 상태와 마스크가 0·25·50·75·100% 드러난 상태를 시각적으로 대조했다. 이는 경로의 노출 비율이며 시간의 비율이 아니다. 원본 CSS는 선언된 재생 시간의 75%에 노출을 완료한다. SVG의 클립 참조를 짝지은 뒤 CSS 시작 시간으로 정렬했다.

- **隷:** XML과 시간순 1–16이 일치한다. 모든 후보 경로의 순서·방향·경계를 유지했다. 왼쪽 土/示의 가로선들, 6·12획 갈고리, 14획 왼쪽 아래→오른쪽 위, 15획 오른쪽 위→왼쪽 아래, 16획 파임을 포함해 확인했다.
- **隣:** 시간순 XML 번호는 **13·14·15·1–12**다. 처음 세 획이 왼쪽 阜이고, 그 뒤 오른쪽 부분을 그린다. 후보의 14·15획은 사전에서 **세로 아래→가로 오른쪽으로 이어지는 한 획**이다. 연결 경로 한 개를 작성해 출력 14획으로 바꾸고, 원본 16획을 출력 15획으로 사용했다.

제품의 기하 자료는 고정 리비전 [AnimCJK Ja](https://github.com/parsimonhi/animCJK/tree/ec5e17cca76c87587790bcbce5ea0b4d4fb753d6)의 Arphic 라이선스 경로다. 30개 경로는 그대로 유지했고, 연결한 1획은 원본 대응을 `null`로 명시했다. 원본 두 경로를 그대로 잇는 과정에서 역주행하지 않도록 아래→오른쪽의 중심선을 작성했다. 보정한 15개 누적 경로도 다시 대조했다.

사전 SVG의 윤곽·마스크 경로와 출판사 영상은 RAM에서만 열람했다. 제품이나 저장소로 복사하지 않았다. 부수 유사성만으로 필순을 추정하지 않았다.
