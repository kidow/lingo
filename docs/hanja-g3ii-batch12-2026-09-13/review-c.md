## 원문과 경계

[비상교육 고등학교 한문](https://text.vivasam.com/detail/186)의 원문 목록은 **戱**, 실제 영상은 虍 아래 豆가 있는 **戲**다. raw sourceGlyph를 그대로 보존하고 행1799 한정 `vivasam-1799-rendered-hui-v1`에 연결했다. 실제 `validateTextbookSourceForm` 검증이 통과했다.

## 원본 경로와 최종 기하

Ko·Ja·Make Me a Hanzi 전체 자료를 새로 조회하고 기존 고정 SHA를 검증했다. Ko에는 정확한 戲가 없고 Ja·MM에는 각각17획이 있다. 영상은 상부 가로꺾음3을 먼저, 긴 왼삐침4를 다음에 쓰므로 MM의17획 identity 매핑을 선택했다. Ja는3·4 순서 교환이 필요하다. 후보 자료는 기하의 출발점이며 한국 필순의 권위로 사용하지 않았다.

선택한 MM 원본 좌표를 변경 없이 JSON에 보존했다. 원본 SHA-256은 `f4a43a8c766933f6250dbfe77e34861817276cf5c107be4ad5aa22e8b6e23c09`다. 각 획의 원본 번호, 완료 시각, 경계 근거, 보정 이유와 실제 출력 경로를 `strokeMap`에 적었다.

실제 `textbookGeometry`와 `textbookCorrectionSha256`를 사용해 생성했다. 최종17누적 상태와420px 최종을 굵기5·round cap·round join으로 모두 열람했다.42개 명명한 전체 선분 접점·간격검사가 통과했다.

고정 대상·원문 영상·원본 좌표·실제 생성 함수·출력 경로·행 한정 자형 관찰·기하 감사의 일치 여부를 검증했다. 저자 검토 상태는 일치이며, 최종 독립 peer 결과는 별도 파일에 고정한다.
