목록 원문 **凉·戱는 그대로 보존**했다. 해당 행·영상의 실제 자형이 涼·戲라는 관찰을 [자형 등록부](../../scripts/hanja-stroke-source-forms.json)에 따로 추가하고, 관찰 ID·해시를 검토 기록과 배포 데이터에 연결했다. 일반적인 이체자 동등 관계를 추가한 것은 아니다.

## 원문과 실제 렌더링 검토

- 저자는 전체 원문을 2fps와 10fps로 열람했다. 10fps 표본은 涼 110장, 戲 220장이다.
- 독립 검토자와 root는 전체 2fps 66장, 28개 완료 표본, 확대 최종 자형을 실제 열람했다. 완료 시각은 관찰 표본의 상한이며 정확한 펜 이탈 시각이 아니다.
- `textbookGeometry`가 만든 모든 28개 누적 상태와 각 420px 최종을 앱과 같은 굵기 5·둥근 끝/모서리로 확인했다.
- 독립 기하 검사 191쌍(涼 55 / 戲 136)을 통과했다. 戲의 6–14획은 확대 원문에서 상단 틈 아래 회색 연결부가 확인되어 접촉을 유지했다. 13–16획도 접촉한다.
- 원본 영상은 메모리에서 읽고 해독했다. 원본 영상이나 원본 프레임 파일을 저장소에 복사하지 않았다.

이는 출판사 자료를 이용한 Codex의 시각 비교 기록이며 한국어문회 인증이나 인간 전문가 감수 결과를 뜻하지 않는다.
