# 2급 경로 보정 5회차 — 縫·蓬·芬

2026-09-16. **3자·40획 검토·보정·적용 완료.** 국내 민간 사전의 글자별 전체 필순과 대조한 결과이며 시험 주관기관의 인증을 의미하지 않는다. 런타임 출처는 `ehanja-crosschecked`다.

완성된 40획 가운데 27개 경로를 보정·분리했고, 13개는 라이선스 원후보를 유지했다. 부수의 유사성만으로 승인하지 않았다.

## 확보·대조

- 사전 상세 페이지의 실제 애니메이션 iframe을 다시 확인했다. 표시 획수, 애니메이션 수, 외곽선 수는 각각 17·15·8로 일치했다.
- 원본 파일의 XML 나열 순서와 실제 재생 순서는 다르다. 지연시간으로 정렬한 재생 순서를 사용했다. 縫은 XML 인덱스 12–17→1–11, 蓬은 12–15→1–11, 芬은 5–8→1–4다.
- 고정 커밋의 Ko·Ja·MM 데이터를 다시 받아 해시를 검사하고 NFKC 호환 글자까지 조사했다. Ko 후보는 없고, 縫의 Ja·MM은 16획, 蓬의 Ja는 14획·MM은 13획, 芬의 Ja·MM은 7획이다. 목록과 정확히 같은 획수의 대체 후보는 없었다.
- 40개 누적 단계와 각 획의 25·50·75·100% 진행 구간을 브라우저에서 대조했다. 보정 경로 27개 및 최종 자형 3개를 다시 확인했다.
- 원본의 접점·간격 15쌍을 RAM에서 외곽선으로 확인하고, 애니메이션 중심선 13획의 이동 방향을 추가 대조했다.
- 사전 SVG·외곽선·스크린샷은 디스크에 저장하지 않았다. 라이선스 원후보, 자체 보정 경로, 원본 URL·해시·검토 결과만 기록했다.

## 글자별 보정

**縫:** 실사변 첫 획은 왼쪽 아래→왼쪽 위→오른쪽 아래 순서로 보정했다. 2획 올림가로는 3획 점과 4획 세로에 닿고, 4획은 긴 세로, 5획은 왼삐침, 6획은 오른쪽 점이 된다. 원후보의 4·5획 대응을 바꿨다. 오른쪽 위 8·9획은 7획의 같은 접점에서 출발한다. 13획 세로는 가로 세 개를 지나되 위 교차부와 마지막 받침에서 떨어진다. 책받침 점을 두 획으로 분리하고, 원후보의 굽이진 16획을 가로→세로 내려긋기로 보정했다. 마지막 획은 오른쪽 위로 들어가 앞 획 끝을 지난 뒤 오른쪽 아래로 흘러간다. 실사변 3획과 책받침 16획의 원본 외곽선 간격은 18단위다. 보정본도 두 획을 떨어뜨리고 다시 확인했다.

**蓬:** 초두의 통가로를 1·3획으로 분리하고 오른쪽 세로 끝을 줄여 아래 부분과 분리했다. 5획은 왼삐침, 6·7획은 5획의 같은 접점에서 출발한다. 11획 세로는 위 교차부와 아래 책받침에서 떨어진다. 원후보에 이미 있는 두 점은 유지했다. 14획은 가로→세로 내려긋기로, 15획 진입부는 오른쪽 위로 올라가 앞 획 끝을 거치는 경로로 보정했다.

**芬:** 초두를 네 획으로 분리했다. 5획의 불필요한 오른쪽 아래 진입선을 제거했다. 6획은 짧은 가로에서 시작해 오른쪽 아래로 내려가며 초두와 분리된다. 7획 지붕 가로는 5획에 닿고, 오른쪽으로 간 뒤 내려가 왼쪽 갈고리로 끝난다. 8획은 7획 지붕에서 시작해 왼쪽 아래로 휜다.

보정 결과는 학습용 중심선이다. 정적 Noto 글꼴이나 사전 서체의 외곽선을 그대로 재현한 데이터는 아니다.

- `originals.json`: 고정 라이선스 후보·대체 후보·사전 자료 식별 정보.

- `prepare.mjs`, `verify.mjs`: 읽기 전용 재구성과 검증.
