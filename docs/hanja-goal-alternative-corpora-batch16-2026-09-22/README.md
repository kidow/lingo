국내 사전과 AnimCJK Hans/Hant의 **3자·37획** 전체 경로·누적 상태·완성 자형을 대조했다. 신규 적용은 **0자**, 3자 모두 보류다.

- **兕(배정 8 / 사전 7획)**: 6획이 5획에서 떨어져 시작하고 시작부에 꺾임이 있다.
- **牖(15획)**: 국내 5획의 긴 왼쪽 방향 가로획이 Hans에서는 오른쪽 아래 점이다. 내부 가로획 접속도 다르다. 이전 Ja 보류를 해제하지 못했다.
- **瘦(배정 14 / 사전 15획)**: 첫 획의 세로·가로 접속과 마지막 획 시작부 접속이 다르다.

획수 차이를 맞추는 임의 분할·병합·새 경로는 적용하지 않았다. 시험 주관기관의 공식 승인이라고 주장하지 않으며 국내 사전 교차검토 결과다.

## 조사 범위

HanziVG의 현재 미적용 목록에 해당하는 새 폴더 자료는 **瘦·适·摸·猫·离 5개**였고, 모두 국내 재생 획수와 달랐다. AnimCJK Hant/Hans에서는 201자·202레코드를 대조하여 국내 획수 일치 11레코드를 찾았다. 최근 보류 목록 밖 3레코드가 이번 시각 검토 대상이다. 이는 과거 전체 검토 이력이 없다는 의미가 아니다. 牖는 이전 Ja 검토 이력을 확인했다.

HanziVG `kanji/`의 **287파일**도 내려받아 Git blob 해시와 획수를 확인했다. 국내 획수 일치는 **25자·45파일**로 모두 최근 보류 글자였다. 다음은 이 45파일과 기존 고정 KanjiVG 경로의 실질적인 차이를 비교한다. 복제 경로는 독립 근거로 세지 않는다.
