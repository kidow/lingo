# 1급 狐~洽 50자 검토 — 50자·559획 반영

2026-09-20 · **50자 반영, 보류 없음**

[1급 20차 疋~弧](../hanja-g1-batch20-2026-09-20/README.md)의 `next-batch.json`에 고정한 후보 50자를
같은 방식으로 대조했다. 첫 대조에서 44자가 일치했고, 6자는 보정 후 전체 획을 다시 확인했다.
허가된 중간선 559획을 그대로 유지했고 국소 보정한 획은 없다. 6자의 획 순서만 바꿨다.
MM 원본 47자, Ja 원본 3자에서 출발했다.

## 보정

| 보정 대상 | 변경 |
| --- | --- |
| 猾 | 骨 冎의 안쪽 가로를 안쪽 세로보다 먼저 (6·7획 교환) |
| 遑 | 王의 둘째 가로를 긴 세로보다 먼저 (7·8획 교환) |
| 賄 | 有의 삐침을 가로보다 먼저 (8·9획 교환) |
| 誨·晦 | 每 아래쪽 안쪽 획을 긴 아래 가로보다 먼저 (誨 13·14, 晦 10·11획 교환) |
| 繪 | 糸의 긴 가운데 세로를 왼쪽 점보다 먼저 (4·5획 교환) |

같은 회차의 膾처럼 會의 순서가 그대로 맞는 글자와, 鰥·闊·諱처럼 획이 많아도 어긋남이 없는 글자는 손대지 않았다.

부수 유사성으로 승인하지 않았다. 각 글자의 사전 전체 필순을 순서대로 보고,
색으로 나눈 25% 진행 구간에서 방향·펜 떼기·획 경계·완성 자형을 대조했다.
보정 6자는 변경 획뿐 아니라 전체 획을 재대조했다.

[direction-probe.mjs](direction-probe.mjs)가 60°를 넘는 획 7개(4자)를 표시했고,
猾·遑·賄·誨 4자가 보정으로 이어졌다. 표시만 되고 그대로 둔 획은 없다.
획 끝점 대응 검사가 여기에 晦·繪 2자를 더했다. 방향은 같고 순서만 어긋나 프로브에는 걸리지 않는 자리다.
재배열 뒤 50자 559획의 대응을 다시 계산해 60°를 넘는 획이 남지 않음을 확인했다.
45~60° 구간의 방향 차이는 보정 뒤 6개였다. 모두 사전이 세로로 긋고 허가 원본이 기울여 쓰는 짧은 점(宦·麾·痕·歆)과
恢·彙의 짧은 획으로, 이전 회차와 같은 기준으로 임계 아래는 허가된 중간선을 그대로 뒀다.
이번 회차 원문에는 가로 이동 변환이 없었다.

## 근거와 재현

- [observations.json](observations.json): 50자 판정, 6자의 첫 판정·보정·재대조 기록, 8방향 코드
- [source-checks.json](source-checks.json): 50자의 원문 해시·획별 시간·XML 참조·좌표 변환
- [originals.json](originals.json): 고정한 라이선스 원본의 중간선과 정규화 경로
- [proposals.json](proposals.json), [corrections.json](corrections.json): 획별 원본 대응과 국소 보정 이유 (이번 회차의 국소 보정은 없다)
- [candidate-paths.json](candidate-paths.json), [review.json](review.json): 승인 경로와 증거 해시
- [prepare.mjs](prepare.mjs): 읽기 전용 승인 데이터 재현 (50자 승인을 검사)
- [verify.mjs](verify.mjs): 재현 결과·공개 데이터·적용 수·다음 후보 검증. 1급 회차의 보류 글자는 큐에서 뺀다
- [checks.json](checks.json), [progress.json](progress.json): 이번 검증과 전체 진행 현황
- [next-batch.json](next-batch.json): 마지막 恰·犧·詰 3자·42획 후보
- [acquire.mjs](acquire.mjs), [source-checks.mjs](source-checks.mjs), [serve.py](serve.py): 원본 고정·원문 확인·검토 시트

필순 근거는 e-hanja 사전이며, **한국어문회 인증으로 표시하지 않는다.**
재생 중간선은 Arphic Public License의 고정 MM·Ja 원본에서 출발했다.
사전의 경로·마스크·영상·스크린샷을 파일에 저장하거나 배포하지 않았다.
자형의 구조와 진행 방향을 비교한 것으로 폰트 외곽선의 픽셀 일치나 필기 채점이 아니다.

```bash
node docs/hanja-g1-batch21-2026-09-20/verify.mjs
node --test lib/hanja*.test.ts
pnpm build
```

위 데이터 재현 검증, **한자 테스트 655개**, **타입 검사**, **프로덕션 빌드**가 통과했다.
전체 **4,191/5,978자(70.1%)**, 남은 **1,787자**.
1급 **1,035/1,145자(90.4%)**, 남은 **110자**. 검토 가능한 미검토 1급은 **3자**뿐이다.
다음 권장 작업은 **恰·犧·詰 3자·42획**이며, 그 3자를 넣으면 검토 가능한 1급 큐가 빈다.
남는 107자는 사전 출처나 후보 원본이 없어 큐에 들어오지 않는다. 그다음 급수로는 특급II 345자와 2급 4자가 남아 있고, 특급 1,328자는 아직 조사 전이다.
