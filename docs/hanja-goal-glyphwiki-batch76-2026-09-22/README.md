# 扤 6획 적용

국내 사전의 전체6획·방향·누적·완성 자형과54개 중간 장면을 공개 백업의 완성 글자 `u6264`와 대조했다. 한국어문회 공식 필순 승인으로 표시하지 않는다.

- 원본의 모든 이차곡선·외곽점을 유지했다. 손변 왼쪽 갈고리와 마지막 위쪽 갈고리는 원본이 정의한 외곽선 그대로 몸통 뒤에 재생한다.
- 세로→곡선 및 마지막 곡선→가로의 원본 접속점을 확인했다. 새 연결선·좌표 보정·부수 교체는 없다.
- 백업SHA256·3개 정확한 의존 레코드·엔진8파일 재현 통과. 전체193파일925테스트, 프로덕션 빌드·타입검사·정적7페이지 통과. 최초 실행은 응답 전달이 끊겨 원래 검사 프로세스 종료를 확인한 뒤 결과를 다시 확보했다.
- 실제 모바일430×932 학습·쓰기 자동재생 및 다시 재생1/6→6/6, 입력0→1→0, 캔버스 드래그 중 시트 위치·스크롤 불변을 확인했다. 정적이미지0, 애니메이션1, 콘솔 경고·오류0. 속도 코드는 변경하지 않았다.
- 실제 적용4,993/5,978자(83.5%), 미적용985자. 남은 수는1급65,2급1,특급II288,특급631이며 다른 급수는 모두 적용됐다.

다음 吪(특급7획)은 완성 원본6개 의존 레코드와 엔진 재현까지 확보했다. 전체 시각 대조·런타임 등록은 아직 하지 않았다.

비공개 사전 그래픽은 RAM에서만 사용했다. 비교/UI 탭·서버와 격리 워크트리는 정리했고 공개 백업 RAM조회 서버51967만 다음 후보를 위해 유지했다.
