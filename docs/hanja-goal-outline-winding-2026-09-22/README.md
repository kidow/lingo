# 芍·菽 윤곽 채움 보완

6자의 원본 독립 다각형·기존 합친 SVG 경로·방향 정규화 결과를 전체 자형과 확대 화면으로 대조했다. 실제 빈틈이 확인된 **芍 5획 첫 구간, 菽 9획 첫 구간**만 수정했다. 芭·苛·萌·慌은 변경하지 않았다.

원인은 겹친 다각형의 반대 감김 방향이 SVG nonzero 채움에서 상쇄되는 것이다. 원본 KAGE는 각 다각형을 독립적으로 채운다. 수정은 음의 방향 다각형의 순회 순서를 뒤집되 첫 꼭짓점과 모든 좌표를 유지한다. 새 경로·연결선·좌표·필순을 만들지 않았다.

- [검토 기록](findings.json): 6자 대조, 수정 2구간과 변경하지 않은 4자의 근거.
- [정규화](normalize.mjs): 원본 꼭짓점 보존.
- [검증](verify.mjs): 51,200개 표본점에서 원본 합집합과 일치. 기존 빈틈 147개 표본점 재현, 수정 후 0개. 각 곡선 재생 경로와 첫 꼭짓점도 고정한다.
- [결과](validation.json): Node 한자 테스트 892개·182파일 통과, 격리 빌드/TypeScript/7개 정적 페이지 통과. 소스 리비전 각 6개와 엔진 8파일 재생 일치.
- 2획을 각각 9단계로 재검토했다. 실제 430×932 소개·쓰기 화면 자동재생/다시 재생/완료 상태 및 정적 SVG 비중첩 확인. 芍 캔버스 입력·취소 시 시트 위치/스크롤 유지.
- 최초 테스트 호출은 컨텍스트 도구의 Bun 실행 파일을 상속해 중단됐다. 명시적 Node 실행으로 전체 검사를 통과했다.

공개 소스·라이선스는 기존 batch45/batch47에 유지하고 수정 내용·자산/검토 해시를 갱신했다. 국내 사전 교차검토 범위이며 시험 주관 기관의 새 승인이 아니다. 비공개 사전 그래픽은 RAM에서만 대조했다.
