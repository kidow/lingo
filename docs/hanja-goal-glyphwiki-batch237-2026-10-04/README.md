브라우저 패널에서 국내 12획 방향·누적·완성형과 기본·대체 전체 자형을 대조했다. 기본 자형은 艹가 3획으로 연결되어 국내 4획과 다르다. 실제 전체 자형 u6e36-ue0102가 선언한 u82f1-02-var-001@3 → ufa5e-03@3를 정확한 과거 리비전으로 확보해 艹 4획 문제를 해소했다. 부수를 임의로 이식하지 않았다.
