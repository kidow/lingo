## 출처와 범위

필순·방향 대조 자료는 국내 민간 사전 [e-hanja](http://www.e-hanja.kr/)다. **한국어문회 등 시험 주관기관의 인증을 뜻하지 않는다.** 모든 글자의 출처는 `ehanja-crosschecked`로 유지한다.

배포 경로의 원형은 Make Me a Hanzi 5자, AnimCJK Ja 2자(憙·禧)다. 커밋과 SHA-256을 고정한 Arphic Public License 자료를 사용했으며, 관찰된 한국 사전 자형에 맞춰 Lingo 경로를 보정했다. 사전의 윤곽선·SVG·스크린샷은 저장하거나 배포하지 않았다.

| Make Me a Hanzi | `bddc96d41bef78427ed0e034e9f7e31d71fd1b92` | `a28c478b5178e98f67f510b2d52fde08a69dc664654ef43498253b9b764d46ee` |

`source-checks.json`에는 제목·바이트 수·해시·변환 행렬·획별 재생 순서를 기록했다. 사전 원본은 메모리에서만 렌더링하며, 진행 방향과 누적 자형을 허가된 후보 경로 옆에서 관찰했다.

## 주요 보정

- 欽: 金 오른쪽 짧은 획의 우상향과 欠 마지막 획의 시작점 연결.
- 噫: 立의 첫 세로획, 日의 두 가로획 접점, 心 마지막 점의 우하향과 간격.
- 熹·憙·嬉·禧: 喜의 口를 닫고, 그 아래 두 짧은 획의 방향·간격을 보정. 사전에 보이는 접점과 떨어진 부분을 각각 유지했다.
- 羲: 羊의 중앙 세로획을 첫 가로획부터 연결하고, 아래 戈의 시작점과 서로 다른 끝점을 분리.
- 禧: 示 좌우의 긴 획과 喜 가운데 가로획 사이 간격을 보정.
- 획 경계·순서·방향의 판단 근거는 각 글자의 전체 자료다. 부수 유사성이나 획수 일치만으로 승인하지 않았다.

## 검증

한자 테스트 **48개 파일·287개 테스트 통과**. 이번 묶음의 5개 테스트는 전체 경로 재현, 원본 복귀 거부, 방향·연결점, 재생 선폭에서의 분리, 증거·번들 변조 거부를 확인한다. 연결점은 1단위 미만 오차, 짧은 획의 가로획 연결은 선폭 반지름 2.5단위 미만, 분리점은 선폭 5단위보다 큰 간격을 요구한다.

`pnpm run build` 통과: Next.js 16.3.3, TypeScript 검사와 정적 페이지 7개 생성 완료.

```sh
node docs/hanja-g2-batch10-2026-09-16/verify.mjs
node --test lib/hanja-stroke-dictionary-g2-batch10.test.ts
node --test "lib/hanja*.test.ts"
pnpm run build
```

`prepare.mjs`는 파일을 쓰지 않는 컴파일러다. 검토 기록·원본·레시피의 해시를 고정하고, `verify.mjs`가 컴파일 결과와 배포 JSON을 비교한다.
