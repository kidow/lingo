## 검토 근거와 재현

각 사전 SVG의 URL·바이트 수·SHA-256을 확인하고, clip-path 참조로 획을
연결한 뒤 CSS 지연 시각으로 재생 순서를 정렬했다. 문서의 XML 순서를 필순으로
가정하지 않았다. 매 획의 누적 상태와 25% 단위 마스크 진행을 나란히 표시해
순서·방향·획 경계·자형을 시각 대조했다. 25% 구간은 경로 진행률이며 시간 비율이 아니다.

사전 영상과 일치 여부는 자체 교차검토 결과이다. 시험 주관 기관의 인증을 뜻하지 않는다.
배포 경로는 라이선스가 있는 Make Me a Hanzi / AnimCJK 원본과 기록된 로컬 보정에서
재구성한다. 사전의 원본 경로·마스크·영상·스크린샷은 저장하거나 배포하지 않았다.

- [originals.json](originals.json): 두 코퍼스의 원본 중간선 및 사전 출처 메타데이터
- [source-checks.json](source-checks.json): 전체 581획의 시간·XML 참조 확인 기록
- [observations.json](observations.json): 50자 전체의 방향·판정·보정 재검토 기록
- [proposals.json](proposals.json), [corrections.json](corrections.json): 순서 및 경로 보정
- [review.json](review.json), [candidate-paths.json](candidate-paths.json): 확정 검토와 배포 경로
- [prepare.mjs](prepare.mjs): 파일을 쓰지 않는 재현용 컴파일러
- [verify.mjs](verify.mjs): 재구성·출처·보류 배제·현재 적용 수 검사

출처·보정·완료 판정 파일의 해시를 빌드에서 확인한다. 런타임은 승인된 44자만
받으며, 기존 사전 검증 경로도 두 코퍼스를 실제 출처별로 확인한다.
