# 杇 7획 적용

실시간API 확보 실패였던 杇을 고정 공개 백업의 완성 원본 `u6747`로 다시 검토했다. 국내 사전의 전체7획·방향·누적·완성 자형과63개 중간 장면을 대조했다. 한국어문회 공식 필순 승인으로 표시하지 않는다.

- 기본 크기 명조의 마지막 꺾임 끝장식이 크게 돌출되어 엔진 기본설정4종을 재현했다. 전체 재검토한 소형 명조 `Kage(1)`를 선택했다. 임의 설정값·좌표 수정은 없다.
- 마지막 획은 원래 비스듬한 직선→가로→두 이차곡선→왼쪽 갈고리 순서다. 각 접속점이 정확히 일치하며 모든 외곽점을 보존했다. 원래 직선으로 만든 마스크가 끝장식 전체를 덮는지도 계산했다(최대거리6.0717,마스크반경7).
- 백업SHA256·4개 의존 레코드·엔진8파일과 선택한 설정 재현 통과. 한자195파일931테스트, 프로덕션 빌드·타입검사·정적7페이지 통과. 변경19파일과 공개3파일의 빌드 산출물 일치 확인.
- 모바일430×932 학습·쓰기 자동재생, 다시 재생1/7→7/7, 입력0→1→0, 캔버스 드래그 중 시트 위치·스크롤 불변 확인. 정적이미지0·애니메이션1, 콘솔 경고·오류0. 기존 재생속도 코드는 변경하지 않았다.
- 실제 적용4,995/5,978자(83.6%), 미적용983자. 남은 수:1급65,2급1,특급II288,특급629. 다른 급수는 모두 적용됐다.

다음 杝(특급7획)은 완성 원본3개 의존 레코드와 엔진 재현을 확보했다. 전체 시각 검토·런타임 승인은 아직 하지 않았다.

비공개 사전 그래픽은 RAM에서만 사용했다. 비교/UI 탭·서버와 격리 워크트리는 정리했고 공개 원본 RAM조회 서버51967만 다음 후보를 위해 유지했다.
