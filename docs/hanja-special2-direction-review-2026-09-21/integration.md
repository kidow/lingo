## 적용

- `dictionary-reviewed-special2-direction-variants.json`은 검토된 원본 경로를 `proposals.json` 순서로만 재배열한다. 좌표 추가·삭제·수정이나 획 분할·합병은 없다.
- `hanja-stroke-variants.ts`의 명시적 허용 목록에 세 글자의 배정 획수·재생 획수·후보 해시·경로 해시를 고정했다. 전체 획수 예외는 기존 18자에서 **21자**로 늘었다.
- 기존 `HanjaStudyGlyph`, `HanjaStudyStrokeCount`, `StrokePlayback`, `WritingPractice` 연결을 사용한다. 정적 표시와 애니메이션이 같은 경로를 공유하고 **사전 자형 · 재생 N획 (배정 N획)**으로 차이를 알린다. UI 코드는 변경하지 않았다.
- 기존 `review.json`, `originals.json`, `proposals.json`, `source-checks.json`, `verification.json`은 적용 전 증거로 보존했다. 최신 검증은 `integration-checks.json`에 기록한다.

## 검증

한자 관련 테스트 **760개 통과**. 원본 좌표·검토된 일대일 순열·사전 출처·검토 파일 해시·정적/동적 데이터 일치,
배정 획수가 다른 입력 거절과 전체 카탈로그의 정확한 21자 예외를 확인했다.
초기 실행에서 이전 18자 기대값과 새 테스트의 nullable 획 번호 타입 오류를 발견해 수정했다.

검증용 임시 라우트는 실제 `HanjaCard`를 그대로 렌더링했다. 프로덕션 빌드의 390×844 화면에서 다음을 확인했다.

- 세 글자 모두 소개 화면과 쓰기 시트 진입 때 `1 / N`부터 자동 재생된다.
- 세 글자의 정적 SVG 경로와 소개·쓰기 애니메이션 경로가 모두 일치한다.
- 쓰기 칸에는 재생 SVG 한 개만 있고 중복 정적 자형이 없다. 모바일 가로 넘침도 없다.
- 嘯 다시 재생 버튼은 16획 완료 후 1획부터 재시작한다. 캔버스 드래그는 입력 1획을 만들면서 시트 상단 126.6015625px과 캔버스 상단 307.6015625px을 그대로 유지한다. 캔버스 `touch-action`은 `none`이다.
- 보류한 纛에는 재생 조작이 나타나지 않는다. 브라우저 오류·경고 로그는 없다.

임시 라우트, 검증 서버와 뷰포트 설정을 정리했다. 최종 빌드 결과와 명령은 `integration-checks.json`에서 확인한다.

```sh
node --test --test-reporter=tap 'lib/hanja*.test.ts'
node docs/hanja-special2-direction-review-2026-09-21/verify.mjs
pnpm build
```
