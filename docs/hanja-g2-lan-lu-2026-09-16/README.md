# 藍·蘆 2자·38획 검토

2026-09-16. **藍 18획·蘆 20획을 적용했다.** 각 글자의 초두를 공식 권장 순서로 배열하고, 전체 경로 대조에서 발견한 6개 경로를 보정했다. 원본 라이선스 경로 32개는 그대로 유지했다.

## 근거와 적용 범위

[한국어문회 필순 자료](https://www.hanja.re.kr/kccpt/exam/otherData.do)의 `f37.hwp`를 새로 받아 문서 해시를 확인했다.

- 문서 본문은 초두를 **4획으로 쓰는 필순을 권장**한다. 일반적인 답안 쓰기 허용에 대한 상담 답변을 필순 근거로 확대하지 않았다.
- `BIN000D.gif` 7행의 **草** 누적 도해는 왼쪽 가로 → 왼쪽 세로 → 오른쪽 가로 → 오른쪽 세로를 보여 준다.
- [藍 사전 재생](http://img.e-hanja.kr/hanjaSvg/aniSVG/8500/85CD.svg)의 **17단계**, [蘆 사전 재생](http://img.e-hanja.kr/hanjaSvg/aniSVG/8600/8606.svg)의 **19단계**를 모두 직접 대조했다. 사전은 하나로 이은 초두 가로를 사용하므로 각각 전체가 한 단계 적다.
- 런타임 좌표는 [고정된 Make Me a Hanzi 판본](https://github.com/skishore/makemeahanzi/tree/bddc96d41bef78427ed0e034e9f7e31d71fd1b92)의 허가된 medians와 명시적인 국소 보정으로 만든다. 사전 SVG 경로를 복사하지 않는다.

**藍 18단계·蘆 20단계를 직접 보여 주는 단일 원문은 확보하지 않았다.** 전체 사전 재생과 공식 초두 필순 지침을 결합해 검토했다. 이번 SVG가 시험 주관 기관의 인증을 받았다는 뜻은 아니다. 런타임 분류는 `ehanja-crosschecked`이며, 사전 방향 근거의 단계 수는 실제 17·19로 유지한다. 적용 대상은 두 글자로 한정했고, 다른 초두 글자는 자동 승인하지 않는다.

## 전체 필순과 방향

사전의 XML 저장 순서와 재생 순서가 달랐다. CSS 시작 시간으로 정렬해 순서를 확정했다.

| 글자 | 사전 재생 순서에 대응하는 XML 인덱스 | 적용 획수 |
|---|---|---:|
| 藍 | 15,16,17,1…14 | 18 |
| 蘆 | 17,18,19,1…16 | 20 |

MM 후보의 처음 네 획은 세로·가로·세로·가로여서 **2,1,4,3** 순서로 재배열했다. 런타임 1~4획은 사전의 1단계 왼쪽 부분·2단계·1단계 오른쪽 부분·3단계에 대응한다. 나머지 런타임 n획은 사전 n−1단계와 직접 비교했다.

| 글자 | 적용 획 | 보정 내용 |
|---|---:|---|
| 藍 | 7 | 臣 오른쪽의 말린 끝을 아래로 내려 닫는 가로에 연결 |
| 藍 | 13 | 사전 자형에 맞춰 내려찍는 점을 왼쪽→오른쪽 가로로 보정 |
| 藍 | 15 | 皿 오른쪽 끝의 왼쪽 말림을 제거하고 아래 가로까지 연결 |
| 蘆 | 3 | 오른쪽 초두 가로를 세로 왼쪽까지 연장해 십자 접점 확보 |
| 蘆 | 13 | 田 안쪽 가로를 양쪽 테두리에 연결 |
| 蘆 | 17 | 皿 오른쪽 끝의 왼쪽 말림을 제거하고 아래 가로까지 연결 |

초두 8획을 포함한 **38개 결과 경로를 모두 재검토**했다. 획 시작·끝·방향과 누적 자형을 확인했으며, 별도 원문 근거 없이 획수만 맞추기 위한 분할이나 삽입은 하지 않았다.

## 적용 파일과 검증

- 배포 데이터: `public/hanja-strokes/dictionary-reviewed-g2-lan-lu.json`

테스트는 17·19획 조회 차단, 4획 초두 순서, 분리된 두 십자의 간격, 藍 가로·점 차이, 테두리 접점, 증거 변조와 미검토 글자의 끼워 넣기를 확인한다.

한자 테스트 **51개 파일·298개**, HWP 파서 테스트 **7개**, **프로덕션 빌드**를 통과했다.

```sh
node docs/hanja-g2-lan-lu-2026-09-16/verify.mjs
node --test lib/hanja-stroke-dictionary-g2-lan-lu.test.ts
python3 -B docs/hanja-g2-lan-lu-2026-09-16/serve.py
```

검토 서버의 `/official`은 공식 지침·草 도해, `/?i=0&corrected=1&start=13&end=16`은 藍 보정 구간이다. `i=1`은 蘆다. 원본 HWP·SVG·도해·HTML·스크린샷은 파일로 저장하지 않고 메모리에서만 처리한다. URL·해시·라이선스 경로와 관찰 기록만 남긴다.
