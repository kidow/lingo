## 후보 교체 0

플래그가 걸린 열 글자를 같은 획수를 가진 모든 말뭉치와 다시 재 봤지만,
**60°를 넘는 획의 수를 바꾸는 대체 후보가 하나도 없었다.**

褊과 嘏은 최대 각도를 몇 도 깎는 후보가 있었다(143° 대 145°, 88°/sum 319 대 322).
"획수가 바뀔 때만 손댄다"는 규칙 그대로 두 자리 다 그냥 뒀다.
지금까지 열두 회차에서 후보 교체는 늘 한 자 이상 나왔다.

| 보정 | 글자 | 내용 |

| 丷 / 爫 | 苹·徯 | 두 표시를 바깥으로 벌어지게 반전 (苹 6·7, 徯 5·7) |
| 广·亠의 첫 점 | 瀌·翯 | 세로로 곧게 (瀌 4, 翯 7) |
| **羽 안쪽 넷** | 翯 | 점 둘(2·5)은 반전, 올려 긋는 획 둘(3·6)은 역방향으로 |

이번 회차에 羽를 가진 글자가 둘인데 **栩는 갈리지 않았다** — 사전과 Ja가 안쪽 넷을 같게 그린다.
같은 부수라도 글자마다 따로 재는 이유다.

苹은 사전 그림이 `translate(12, -830)`로 가로 오프셋을 가진다.

부수 유사성으로 승인하지 않았다. 쉰 글자의 사전 전체 필순을 순서대로 보고,
색으로 나눈 25% 진행 구간에서 방향·펜 떼기·획 경계·완성 자형을 대조했다.
[direction-probe.mjs](direction-probe.mjs)의 60° 초과 표시는 교환·보정으로 해소했고,
남은 둘은 자형 차이라 보류했다.
공개한 순서·경로로 다시 재면 60°를 넘는 획이 없다.
45~60° 구간은 여섯 획(旆 1, 麃 1, 襃 1, 鑣 9, 頏 1, 覈 12)이고, 이전 회차와 같은 기준으로 그대로 뒀다.
