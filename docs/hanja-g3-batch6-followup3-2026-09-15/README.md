- **穫**: 隹 내부 가로획 왼쪽의 빈틈은 교재에도 있어 유지했다.
- **擴**: 아래 중앙 세로획이 네모 위의 가로획과 연결되는 것이 원본과 같아 유지했다.

- **嫌**: 중앙 세로획 두 개는 첫 가로획 위의 짧은 획에서 시작한다. 초기 검토에서 빠진 차이까지 보정했다.
- **縣**: 왼쪽 小의 갈고리와 바닥 연결은 원본과 같아 유지했다.
