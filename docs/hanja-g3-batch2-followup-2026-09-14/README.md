## 근거와 검토 방법

[비상교육 고등학교 한문 교재](https://text.vivasam.com/detail/186)의 기존 배치에 고정한 12개 영상을 사용했다. 파일 전체 SHA-256·크기를 재확인하고, 2fps 누적 프레임 및 시작/끝 표시가 있는 후보 경로를 모든 획에 걸쳐 대조했다. 飜 17획은 21.2~23.4초를 5fps·확대 화면으로 확인했다. 상단에서 하단 왼쪽으로 내려가는 획이므로 역방향으로 바꾸지 않고, 과도하게 넓던 경로만 가파르게 보정했다.

독립 보강 자료는 네이버 한자사전의 **㈜오픈마인드인포테인먼트/e-hanja** 제공 [屯](https://hanja.dict.naver.com/#/entry/ccko/5ad8c79d4319404faeda0b992bf87197)·[鈍](https://hanja.dict.naver.com/#/entry/ccko/c6617f6490394f36a687aca63d463277)·[邦](https://hanja.dict.naver.com/#/entry/ccko/d73622c47a854811a49071ecc5d7af22)이다. 각 표제어에서 실제 사용하는 SVG 주소를 확인했으며, 전체 해시·크기·애니메이션 시각을 `sources.json`에 기록했다. 네이버와 e-hanja는 같은 자료로 계산한다.

SVG의 XML 경로 배열 순서를 재생 순서로 취급하지 않는다. 鈍은 XML의 屯 경로가 먼저 나오지만 재생 시각을 정렬하면 **金 8획 다음 屯 4획**이다. 사전의 XML 경로 1·3은 실제 9·11획에 해당한다. 9획 방향은 교재와 일치하고 11획 방향만 충돌한다. 屯도 1획은 두 자료가 오른쪽→왼쪽으로 일치하며, 3획만 충돌한다. 특정 자료의 방향을 임의로 정답으로 선정하지 않았다.

邦은 별도의 5획(가로→왼쪽 아래)과 6획(곡선→왼쪽 갈고리)을 0/25/50/75/100% 마스크 진행 상태로 확인했다. 교재에서 이어져 보이던 부분에 독립적인 펜 들기 경계가 있음을 확인했다.

## 경로와 출처의 구분

- 경로는 고정 커밋의 [Make Me a Hanzi](https://github.com/skishore/makemeahanzi/tree/bddc96d41bef78427ed0e034e9f7e31d71fd1b92)와 [animCJK](https://github.com/parsimonhi/animCJK/tree/ec5e17cca76c87587790bcbce5ea0b4d4fb753d6)의 허용된 데이터에서 가져왔다. 저장된 대체 경로 12자도 같은 코퍼스와 완전히 일치하는지 검증한다.
- 보정은 7개 명시적 레시피로 기록했다. 騰·廉·伴·叛의 점은 기존 경로의 가로 좌표만 반사했고, 冒은 4획 양 끝을 줄였다. 騰 11/12, 飜 10/11은 명시적으로 순서를 교환했다. 飜 17획은 방향을 유지하며 경로를 보정했다.
- 零의 11~13획은 교재의 가로·꺾어 갈고리·세로 구성을 확인한 뒤 별도로 작성한 좌표다. 원본 경로 번호는 `null`로 기록해 코퍼스 원본으로 오인하지 않도록 했다.
- 교재 영상·프레임과 사전 SVG 경로는 메모리에서만 읽고 표시했다. 제품이나 저장소에 복사하지 않았다.
- 이번 승인은 **교재를 시각 대조한 프로젝트 내부 검토 결과**다. 시험 주관 기관의 공식 인증이나 전문가 감수를 뜻하지 않는다.

- `node docs/hanja-g3-batch2-followup-2026-09-14/verify.mjs --sources`: 12자 검토 완전성, 10자/7레시피 재현, 보류 2자 미등록, 기존 배열 전체 보존, 16개 원본 해시·크기 확인 통과.

- `node scripts/hanja-stroke-textbook-build.ts --check`: 교재 승인 1,067자와 배포 번들 완전 일치.
- `node --test --test-reporter=spec 'lib/hanja*.test.ts'`: 231개 통과.
- `pnpm run build`: TypeScript와 Next.js 프로덕션 빌드 통과.

`prepare.mjs`는 파일을 쓰지 않고 승인 레코드·레시피·배포 경로를 재현한다. `serve.py`는 로컬 주소에서만 자료를 비교하며 재생 시각순으로 사전 경로를 정렬한다. 실제 적용 경로는 `candidate-paths.json`, 보정은 `proposals.json` 및 `corrections.json`, 수동 관찰은 `observations.json`에 있다.
