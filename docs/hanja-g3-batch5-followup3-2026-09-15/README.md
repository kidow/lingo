## 근거와 범위

- [비상교육 고등 한문 교재](https://text.vivasam.com/detail/186)의 [기초 한자 필순 뷰어](https://viewer.vivasam.com/qrviewer/viewer.html?qrcode=106502_171p_25_ST&teacher=false)를 각 글자 전체의 대조 근거로 사용했다.
- 글자·행·파일명·영상 URL·전체 SHA-256은 [원래 queue.json](../hanja-g3-batch5-2026-09-15/queue.json)에 고정되어 있다. 이번 11개 영상의 전체 바이트 수와 해시를 다시 확인했다.
- 11자 모두 고정 MM 원본의 해시·좌표와 기존 Arphic 라이선스·고지를 유지한다.
- 기본 2fps 전체 프레임을 대조했다. 聰의 12.4–16.4초 구간은 5fps로, 替 8–16.5초와 臭 9–12.5초는 확대해 연결을 확인했다.
- 기록 시각은 표본에서 획 완성을 확인한 시점이며 정확한 펜 이탈 시각이 아니다.
- 동영상과 프레임은 RAM에서만 처리했다. 저장소·공개 경로에 복제한 출판사 영상/이미지는 0개다.
- **출판사 영상과의 시각 대조이며 시험 주관 기관의 개별 경로 인증이나 별도 전문가 감수가 아니다.** 부수 유사성이나 같은 획수만으로 승인하지 않았다.
