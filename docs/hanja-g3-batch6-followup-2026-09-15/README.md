## 근거와 재현

- [비상교육 고등 한문](https://text.vivasam.com/detail/186)의 [교재 뷰어](https://viewer.vivasam.com/qrviewer/viewer.html?qrcode=106502_171p_25_ST&teacher=false) 원본을 기준으로 했다.
- 고정한 XLSX 행·정확한 글자·MP4 URL/해시/바이트 수는 [원본 queue](../hanja-g3-batch6-2026-09-15/queue.json), 이번 재확인은 [source-checks.json](source-checks.json)에 있다.
- 10개 전체 MP4와 해당 후보 원본을 메모리로 받아 해시를 확인했다. 0.5초 간격의 누적 프레임을 끝까지 보고 모든 후보 시작점·끝점·방향·획 경계 및 선폭 5의 최종 자형을 비교했다.
- 승인한 경로는 [proposals.json](proposals.json)과 [corrections.json](corrections.json), 시각 관찰은 [observations.json](observations.json), 배포 항목은 [candidate-paths.json](candidate-paths.json)에 있다.
- 후보는 9자 Make Me a Hanzi, 墮 1자 일본어 후보 원본이다. 원본 출처와 Arphic 라이선스를 유지하며, 각 수정 획은 원본 획 번호와 연결되어 있다.
- 출판사 자료와의 Codex 시각 대조이며, 한국어문회·전문가 인증을 의미하지 않는다. 시간은 샘플링된 완료 상한으로 정확한 붓 떼기 시각이 아니다.
- 출판사 영상·캡처는 저장하지 않았다. [serve.py](serve.py)는 고정 출처를 RAM에서 표시하는 검토 도구다.
