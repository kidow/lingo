# 奔·慈 2자·21획 검토 및 적용

2026-09-13. 奔8획·慈13획을 대조하고 애니메이션에 적용했다.
전체 적용은 **1,480→1,482/5,978자**, 3급II는 **490→492/500자(98.4%)**다.
전체 미적용은4,496자, 3급II 미적용은8자다.

e-hanja는 국내 사전 제공자의 자료다. 한국어문회 인증이나 시험기관의 최종
필순 판정으로 표시하지 않는다. 기존9획·14획 교재의 획을 합친 결과가 아니라,
정확한8획·13획 자료를 별도로 대조한 결과다.

[앞선12자 사전 대조](../hanja-g3ii-dictionary-12-2026-09-13/README.md)의
9획 관찰에 이번12획을 보완해21획 전부를 확인했다. 慈4·7·11획은 중간·끝
구간5장도 추가 관찰했다. 이번 회차 움직이는 화면 관찰은총17장이며, 기존9획을
새 관찰로 중복 계산하지 않았다. 사전 원본2개의 제목·바이트 수·SHA-256과
21개 재생 구간도 다시 확인했다.

## 경로와 보정

사용 가능한 기하 데이터는 [Make Me a Hanzi 고정 원본](https://github.com/skishore/makemeahanzi/tree/bddc96d41bef78427ed0e034e9f7e31d71fd1b92)이다.
전체 파일의 해시를 검증한 뒤 두 글자의 중심선을 추출하고 기존 함수로 정규화했다.

慈의 원본4·7획은 꺾인 뒤 오른쪽 위로 향했지만 사전은 오른쪽 아래로 향한다.
원본11획의 갈고리는 왼쪽 위로 올라가고 사전은 오른쪽 위로 올라간다.
이미 검증된 玄·幼·心 등의 경로에서도 이번 방향에 맞는 것을 찾지 못했다.
따라서 **세 획은 관찰한 역할·꺾임·끝 방향에 맞춘 단순 중심선으로 직접 작성**했다.
사전의 원본 SVG path·윤곽·스크립트·이미지는 복사하거나 배포하지 않았다.

원본 후보21단계와 보정 후 慈13단계를 눈으로 대조했다. 좌우 幺와 心의 점을
구분하고, 가로의 교차·간격과 갈고리 끝을 확인했다. 획 역할·방향·누적 구조에
추가 충돌을 발견하지 못했다. 사전 글꼴의 픽셀 단위 복제나 필기 정답 판정의
검증은 아니다. 이 보정으로 다른 幺·心 포함 글자가 자동 승인되지는 않는다.

보정한3획의 원본 인덱스는 `null`로 남겼다. 전체21획에서 순서 변경·분할·병합은
없으며, 나머지18획은 정규화한 원본과 동일하다. 기존 訣·紋·森·楓의 공개 항목은
변경되지 않았다. [출처·라이선스 안내](../../public/hanja-strokes/dictionary-reviewed.README.md)도 갱신했다.

`node docs/hanja-g3ii-bun-ja-2026-09-13/verify.mjs --online`도 통과했다.
`pnpm exec next build`의 컴파일·TypeScript·정적 페이지 생성이 통과했다.
공유 콘텐츠를 생성하는 prebuild 전체는 실행하지 않았으며, prebuild가 호출하는
사전 번들 검사는 별도로 실행했다. 새 근거5개 파일의 해시와 경로 재구성을 검사해
근거 변경이나 보정 되돌리기가 조용히 승인되지 않도록 했다.
