보정 과정에서 실제 재생 두께 5로 겹침도 확인했다. 窟의 지붕과 오른쪽 꺾임
사이 간격, 雇의 첫째·둘째 획 간격, 膠의 月·羽 사이 간격을 추가 조정했다.
회귀 테스트는 이 간격과 迦·雇의 의도된 접합을 수치로 확인한다.

## 근거와 재현

사전 SVG의 제목·바이트 수·SHA-256을 이번 작업에서 다시 확인했다.
clip-path 참조와 CSS 지연 시간으로 획을 연결하고, 75개 누적 상태 및 각 획의
25% 단위 마스크 진행을 비교했다. 수정한 부분뿐 아니라 전 획의 순서·방향·경계·
최종 자형을 재검토했다. 마스크 진행률은 시간 비율을 뜻하지 않는다.

검토 출처는 e-hanja 국내 사전이며 시험 주관 기관 인증과 구별한다.
배포 경로는 Make Me a Hanzi 및 AnimCJK의 라이선스 원본과 명시된 로컬 보정에서
재구성한다. 사전의 원본 경로·마스크·스크립트·스크린샷은 저장하거나 배포하지 않았다.

- [originals.json](originals.json): 원본 중간선과 코퍼스·사전 출처
- [source-checks.json](source-checks.json): 이번에 재확인한 75획의 시간·참조 메타데이터
- [observations.json](observations.json): 전 획의 방향과 보정 후 시각 대조 기록
- [corrections.json](corrections.json), [proposals.json](proposals.json): 보정 경로·순서와 원본 계보
- [review.json](review.json), [candidate-paths.json](candidate-paths.json): 승인된 경로와 고정 검토 해시
- [prepare.mjs](prepare.mjs), [verify.mjs](verify.mjs): 읽기 전용 재현·검증 도구

기존 44자 검토에서는 여전히 보류로 남겨 두고, 이번 별도 완료 기록이 있어야
6자가 재생된다. 출처 변경, 원래 보류 경로로의 복원, 누락된 검토 또는 잘못된
코퍼스 출처는 빌드 검증에서 거부한다.
