## 글자별 보정

- **莞:** 풀머리를 가로·세로·가로·세로로 분리했다. 5획은 지붕에 닿는 수직 점으로, 6획은 아래로 내려와 왼쪽으로 굽도록 보정했다. 7획은 두 획에 연결되는 가로와 오른쪽 끝에서 왼쪽 아래로 꺾이는 방향을 확인했다. 元의 가로 둘을 분리하고, 아래 가로에서 왼쪽 삐침과 오른쪽 갈고리가 시작되도록 했다. 마지막 획은 아래로 내려온 뒤 수평 바닥을 지나 오른쪽에서 위로 오른다.
- **芸:** 풀머리 4획과 云의 두 가로를 보정했다. 7획은 긴 가로에서 시작해 왼쪽 아래로 내려간 뒤 아래 모서리를 지나 오른쪽 위로 뻗는다. 8획의 오른쪽 아래 점은 MM 원본을 유지했으며, 7획 끝과 닿고 긴 가로와 떨어지는 관계를 확인했다.
- **蔚:** 풀머리 4획 뒤 尸의 가로꺾기·가로·왼쪽 삐침 순서를 유지했다. 示의 위 가로는 尸와 떨어지고 아래 가로는 왼쪽 삐침에 닿도록 보정했다. 示·寸의 갈고리는 왼쪽으로 끝나도록 고쳤다. 示 오른쪽 점이 갈고리와 붙지 않도록 조금 오른쪽으로 옮겼고, 寸 가로도 尸 오른쪽 변과 분리했다. 11획 왼쪽 점과 15획 寸의 점은 MM 원본을 유지했다.

모든 보정의 원본 획 번호·원본 경로·이유를 `corrections.json`에 기록했다. 원본 유지 획은 芸 8획(MM 7획), 蔚 11획(MM 10획)·15획(MM 14획)이다.
