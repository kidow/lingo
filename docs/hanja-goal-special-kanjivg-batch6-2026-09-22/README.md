# 特급 魴 적용 / 隴 보류 — 2자·34획

## 판단과 근거

- **魴 15획 적용**: 국내 사전은 魚 내부의 가로획을 세로획보다 먼저 쓴다. 공개 후보의 5·6획을 바꾼 `[1,2,3,4,6,5,7,8,9,10,11,12,13,14,15]` 순서로 전체 방향·꺾임·갈고리·누적 상태를 확인했다.
- 기본 굵기 5에서는 灬의 마지막 점이 인접한 획에 닿는다. 고정 KanjiVG 원본의 `stroke-width:3`을 좌표와 함께 100/109로 축소한 **300/109**로 적용했다. 15개 누적 상태와 완성형을 다시 검토해 점들의 분리를 확인했다. 제어점·시작점·끝점은 바꾸지 않았다.
- **隴 19획 보류**: 순서와 방향은 대체로 맞지만, 阜 2획의 하단이 세로 3획에 닿지 않아 국내 사전의 연결과 다르다. 굵기 5에서는 立 8획이 阜에 닿기도 한다. Kaisho의 2·3획도 바이트 단위로 같고, 대체판의 4획은 국내 세로점과 방향이 다르다. 임의 연결선을 추가하지 않았다.

기본 후보 34획 전체, 정규화 후 34개 누적 상태·두 완성형, 隴 대체판 2·3·4·8획을 비교했다. 魴은 승인 굵기에서 15개 누적 상태·완성형을 별도로 확인했다. 사전 원본은 RAM에서만 대조했다.
