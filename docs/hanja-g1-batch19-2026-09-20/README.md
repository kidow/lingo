# 1급 跆~披 50자 검토 — 50자·599획 반영

2026-09-20 · **50자 반영, 보류 없음**

[1급 18차 炒~笞](../hanja-g1-batch18-2026-09-20/README.md)의 `next-batch.json`에 고정한 후보 50자를
같은 방식으로 대조했다. 첫 대조에서 42자가 일치했고, 8자는 보정 후 전체 획을 다시 확인했다.
허가된 중간선 596획을 유지하고 3획을 국소 보정했으며, 6자의 획 순서를 바꿨다.
MM 원본 44자, Ja 원본 6자에서 출발했다.

## 보정

| 보정 대상 | 변경 |
| --- | --- |
| 跛·婆·披 | 皮의 긴 왼쪽 삐침을 위쪽 꺾임보다 먼저 (跛 8·9, 婆 4·5, 披 4·5획 교환) |
| 套 | 長의 긴 왼쪽 세로를 위 가로보다 먼저 (4·5획 교환) |
| 騙 | 馬의 긴 왼쪽 세로를 위 가로보다 먼저 (1·2획 교환), 扁 안 戶의 첫 획(11획)을 오른쪽 위에서 왼쪽 아래로 반전 |
| 慟 | 重의 아래 가로를 긴 가운데 세로보다 먼저 (10·11획 교환) |
| 堆 | 隹의 오른쪽 위 짧은 획(6획)을 왼쪽 아래로 반전 |
| 稟 | 亠의 첫 점(1획)을 세로로 |

같은 회차의 疱·庖·袍·泡·咆처럼 包의 순서가 이미 사전과 맞는 글자와,
撐의 尚처럼 丷이 양쪽 모두 바깥으로 떨어지는 글자는 손대지 않았다.

부수 유사성으로 승인하지 않았다. 각 글자의 사전 전체 필순을 순서대로 보고,
색으로 나눈 25% 진행 구간에서 방향·펜 떼기·획 경계·완성 자형을 대조했다.
보정 8자는 변경 획뿐 아니라 전체 획을 재대조했다.

[direction-probe.mjs](direction-probe.mjs)가 60°를 넘는 획 15개(8자)를 표시했고,
8자 모두 보정으로 이어졌다. 표시만 되고 그대로 둔 획은 없다.
사전과 허가 원본의 획 끝점을 글자마다 맞대응시켜 순서가 어긋난 자리를 따로 확인했는데,
나온 것은 皮 셋과 套·騙·慟뿐이었고 疱의 巳 두 획은 좌표 차이가 0.3 이내라 같은 순서로 확인됐다.
45~60° 구간의 방향 차이는 8개였다. 사전이 세로로 긋고 허가 원본이 기울여 쓰는 짧은 점 일곱(褪 1, 辦 1·10, 疱 1, 庖 1, 褒 1, 袍 1)과
사전이 납작하게 긋는 豹의 勺 점(10획) 하나로, 이전 회차와 같은 기준으로 임계 아래는 허가된 중간선을 그대로 뒀다.
이번 회차 원문에는 가로 이동 변환이 없었다.
