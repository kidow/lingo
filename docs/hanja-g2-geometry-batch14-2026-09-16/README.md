## 전체 획 검토

원본과 보정 후보를 각각 사전 41단계의 25/50/75/100% 마스크 공개 상태와 브라우저에서 대조했다. 동일 시간 간격의 재생 테스트는 아니다. 모든 획 쌍 **264쌍**의 접촉·간격을 사전 윤곽으로 RAM에서 확인했다(곡선당 30개 표본의 근사 거리). 최종 경로에도 5단위 선폭에서 같은 관계가 유지되는지 검증했다.

- **塏:** 土의 두 가로 중 마지막 획은 오른쪽 위로 올리고 세로에 닿도록 했다. 山은 가운데 세로 → 왼쪽 세로·가로 꺾기 → 오른쪽 세로 순서로 대조했다. 豆의 상자 아래 왼쪽 점은 상자 및 바닥에서 떨어지고, 오른쪽 삐침은 바닥 가로에 닿는다. 왼쪽 점과 상자 사이의 불필요한 접촉은 간격을 보정해 제거했다.
- **璟:** 王의 두 가로·긴 세로·오른쪽 위로 오르는 획을 개별 확인했다. 日의 내부 및 아래 가로를 양변에 연결했다. 가운데 점은 사전처럼 아래로 내려오며 日과 떨어지고 긴 가로에 닿는다. 아래 상자에서 세로 갈고리가 내려와 왼쪽 위로 끝난다. 마지막 두 획은 상자·갈고리와 분리된다.
- **琯:** 王 네 획을 개별 대조했다. 宀의 가운데 점은 세로로 쓰며 지붕에 닿고, 왼쪽 획도 지붕에 연결된다. 긴 내부 왼쪽 세로를 먼저 쓰고, 위 상자의 지붕·바닥과 아래 상자의 지붕·바닥을 각각 연결했다. 위아래 오른쪽 세로는 별개이며 서로 떨어진다.

사전 SVG/XML·스크린샷·HTML은 저장하지 않았다. 출처 메타데이터·해시·자체 관찰·공개 라이선스 경로·보정 레시피만 저장했다.
