# Batch725 · 燄 16획 보류

브라우저 패널95에서 전체형 2종과 국내 16획의 순서·방향을 대조했다. 두 전체형 모두 둘째 획이 비스듬히 내려간 뒤 왼쪽 갈고리를 추가한다. 국내 둘째 획에는 이 갈고리가 없어 자형·경로를 승인하지 않았다. 나머지 15획의 정적 방향은 대조했지만 진행 재생·미세 프레임·재생 검증은 하지 않았다.
