## 兎 후보

[KanjiVG Hyougai 원본](https://github.com/KanjiVG/kanjivg/blob/422b5538595676da918c288a4230cb5e22a1ee7e/kanji/0514e-Hyougai.svg)을 사용한다. 라이선스는 CC BY-SA 3.0이며, 출처와 라이선스 정보는 `candidate.json`에 함께 보존했다. 일본 자료 자체를 한국 필순 근거로 삼지 않고, 국내 e-hanja의 8획과 각각 시각 대조했다.

국내 사전 순서에 대응하는 원본 인덱스는 **1, 2, 3, 5, 4, 6, 7, 8**이다. 첫 가로 삐침의 오른쪽→왼쪽 방향, 세로와 꺾임, 중앙 세로/밑가로의 순서 차이, 아래 삐침, 위로 올리는 갈고리, 마지막 오른쪽 아래 점을 모두 확인했다. 중앙 세로와 아래 삐침을 별도 획으로 유지한다. Jinmei는 전체 자형만 비교했으며 개별 8획 승인 대상으로 삼지 않았다.

원본 곡선은 수정하지 않았다. `candidate.json`은 원본 109 좌표계의 허용된 SVG 경로와 적용할 순열을 담는다. **100/109 정규화, 순서 보정 후 누적 자형, 런타임 등록과 자동재생 UI 검증은 다음 작업**이다. 배정표의 7획과 사전 재생의 8획을 구분하는 기존 변형 처리 방식을 적용해야 한다.
