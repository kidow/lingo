## 검토 범위

- 일반 검색 UI에서 정확한 유니코드 글자를 선택했다. URL 추측이나 유료 페이지 우회는 하지 않았다.
- 상세 페이지의 획수, SVG 제목, 타이밍 행 개수는 11자 모두 현재 카탈로그와 일치한다. 4급II 5자·68획, 4급 6자·63획이다.
- 모든 SVG의 전체 윤곽을 브라우저로 확인했다. 이는 모든 획의 시작·끝·방향을 관찰했다는 뜻이 아니다. 연속 번호와 재생 간격 검증도 필순의 정확성을 자동 증명하지 않는다.
- 예전 교과서 보류 기록은 당시 관찰로 유지한다. 새 출처가 생겼다는 이유로 예전의 衞·豐·姊·奬·鐘·册 영상을 다른 글자로 재분류하지 않는다.
- 런타임 경로·승인 목록·획수·UI는 바꾸지 않았다. 사전 원본의 윤곽·중심선·스크립트·CSS·스크린샷도 저장하지 않았다.

## 검증과 현재 적용 수

[verify.mjs](verify.mjs)는 이전 근거 4개 해시, 11자 카탈로그·출처 일치와 131개 재생 정보의 연속성을 확인한다. `--online`은 기록된 원본 URL만 다시 받아 바이트·해시·제목·재생 정보를 대조한다. 이미지 내용의 정확성을 판정하는 코드는 아니다.

```sh
node docs/hanja-g4-held-11-2026-09-14/verify.mjs --online
node --test lib/hanja*.test.ts
```

실행 결과는 [verification.json](verification.json)에 기록한다. 이번 작업 전 적용 수는 전체 **1,490 / 5,978자**, 3급II까지 누적 **1,489 / 1,500자**다. 누적 미적용 11자가 이번 대상 전부이며, 출처 검토만으로 적용 수를 올리지 않는다.
