## 확보·대조

- 사전 상세 페이지에서 실제 애니메이션 iframe을 확인하고, 자형·표시 획수·SVG 획수·재생 순서·clip 연결을 검증했다.
- 고정된 animCJK Ko/Ja 및 Make Me a Hanzi 전체 파일을 다시 조회하고 SHA-256을 확인했다. NFKC 호환자를 포함해도 27·15·13획과 일치하는 공개 후보가 없었다.
- 세 글자 모두 MM 경로를 보정 기반으로 사용했다. Ja에는 蔡 14획·葡 12획 대안이 있고 鑽은 없다. Ko에는 세 글자 모두 없다.
- 원본과 최종 후보를 각각 55단계, 25/50/75/100% 마스크 공개 상태로 브라우저에서 대조했다. 동일 시간 간격으로 애니메이션을 재생한 테스트는 아니다.
- 사전 윤곽의 접촉·분리 **101쌍**을 RAM에서 수치 보강했다(곡선당 30개 표본의 근사 거리). 최종 경로에도 5단위 선폭에서 같은 관계가 유지되는지 테스트했다.
- 鑽 보정 중 金·先 사이와 두 先의 세로·다리 사이에서 불필요한 접촉을 발견했다. 간격을 다시 보정하고 해당 6쌍을 회귀 검증에 추가했다.
- 사전 SVG/XML·스크린샷·HTML은 저장하지 않았다. 출처 메타데이터·해시·자체 관찰·공개 라이선스 경로·보정 레시피만 저장했다.

## 글자별 보정

- **鑽:** 金의 가로·긴 세로·점·오른쪽 위로 오르는 받침을 대조했다. 왼쪽 先의 14획은 내려온 뒤 오른쪽 위로 꺾인다. 오른쪽 先는 공개 원본 19획에 합쳐진 세로와 굽은 다리를 분리했다. 최종 17획 세로 → 18획 아래 가로 → 19획 왼쪽 다리 → 20획 오른쪽 굽은 다리 순서를 적용했다. 貝는 두 변에 닿는 내부 가로 3개를 확인하고, 마지막 두 획은 바닥 가로와 분리했다.
- **蔡:** 풀머리를 가로·세로·가로·세로로 분리했다. 왼쪽의 두 점은 긴 굽은 획에는 닿되 첫 삐침과는 떨어지도록 했다. 오른쪽 가로꺾기와 긴 오른쪽 삐침이 만나는 관계를 확인했다. 示의 두 가로 뒤 수직 갈고리가 내려와 왼쪽으로 끝나고, 양옆 획은 갈고리에서 분리된다.
- **葡:** 풀머리 4획 뒤 왼쪽 삐침과 긴 바깥 꺾기를 대조했다. 안쪽 가로와 양쪽 세로, 내부 가로 둘이 연결되는 관계를 보정했다. 중앙 긴 세로는 12획으로 쓰며 바깥 지붕과는 떨어지고 안쪽 가로들을 관통한다. 13획 점은 바깥 지붕·중앙 세로와 떨어지되 긴 안쪽 가로에는 닿도록 했다.

모든 보정의 원본 획 번호·원본 경로·이유를 `corrections.json`에 기록했다. 부수의 기존 승인 여부를 근거로 자동 승인하지 않았다.
