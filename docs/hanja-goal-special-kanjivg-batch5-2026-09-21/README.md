# 闍 적용 / 闥·餤 보류 — 3자·55획 검토

특급 후보 세 글자의 원본 55획·완성형을 국내 e-hanja 자료와 눈으로 대조했다. **闍 1자·17획을 런타임에 적용**하고, **闥·餤 2자·38획은 보류**했다. 한국어문회 공식 확인으로 표시하지 않는다.

闍는 원본 전체 17획과 정규화 후 17개 누적 상태를 확인했다. 앱 기본 굵기 5에서는 내부 12획이 門의 8획과 닿고 13획의 점도 인접 획과 붙는다. [동일 원본](https://raw.githubusercontent.com/KanjiVG/kanjivg/422b5538595676da918c288a4230cb5e22a1ee7e/kanji/095cd.svg)이 명시한 굵기 3을 균등 정규화한 **300/109**로 17개 누적 상태·완성형을 다시 확인하면 간격이 보존된다. 이 굵기를 고정하며 경로 점·순서·방향·획 분할/병합은 바꾸지 않았다. 이전 배치에서 추가한 글자별 굵기 기능을 사용하며 플레이어 코드를 다시 수정하지 않았다.

Kaisho와 기본판의 경로를 바이트 비교했다. 闥은 3·7획만, 餤는 6획만 달라 문제 획은 동일하다. 闍의 대체판은 3·7·16획만 다르며 기본판이 충분해 선택하지 않았다. 대체판 전체를 눈으로 검토했다고 주장하지 않는다. 변경 경로 목록과 판단은 findings.json에 있다.

闥·餤의 보류 해제에는 국내 꺾임·방향이 맞는 재사용 가능한 전체 경로 또는 독립적으로 입증된 수정 근거가 필요하다. 근거 없이 점을 이동하거나 반사하지 않았다.

## 검증

- 한자 테스트 **798개 통과**, 타입 검사 통과.
- 경로·해시·원순서·라이선스·굵기 재현, 부적합 굵기 거부, 보류 글자 제외 및 대체판 문제 경로 동일성 검사.
- 분리 체크아웃 프로덕션 빌드 통과. 임시 HanjaCard 화면의 제품 파일은 작업 트리와 바이트 단위 동일.
- Desktop Chrome: 학습 자동재생 0→17, 다시 재생 1→17, 쓰기 진입 자동재생 1→17, 쓰기 다시 재생 1→17과 실제 재생 종료 상태 확인.
- 학습·쓰기 완성 자형의 내부 간격 확인. 쓰기 SVG 1개, 굵기 300/109, 정적 오버레이 중복 없음.
- 캔버스 1획 입력, 전후 dialog·canvas 좌표 동일, touch-action:none. 앱 오류 0; 별개 번역 확장 프로그램 오류 20건은 분리했다. 실제 모바일 기기는 검증하지 않았다.
- 자체 검토 탭·서버·분리 체크아웃은 완료 후 정리한다.
