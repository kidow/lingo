# 특급II 齷~鰲 50자 검토 — 50자·698획 반영

2026-09-18 · **50자 전부 반영, 보류 없음**

[8차 謖~鄂](../hanja-special2-batch8-2026-09-18/README.md)의 `next-batch.json`에 고정한 후보 50자를
같은 방식으로 대조했다. 첫 대조에서 40자가 일치했고, 10자는 보정 후 전체 획을 다시 확인했다.
허가된 중간선 689획을 유지하고 9획을 국소 보정했으며, 7자의 획 순서를 바꿨다.
MM 원본 42자, Ja 원본 8자에서 출발했다. 이번 회차에는 보류한 글자가 없다.

## 보정

| 보정 대상 | 변경 |
| --- | --- |
| 蒻·曄 | 艹의 十 둘을 각각 가로 다음 세로 (1·2와 3·4, 5·6과 7·8획 교환) |
| 瀁 | 養의 羊 가로획을 긴 세로획보다 먼저 (7·8획 교환) |
| 馭 | 馬의 왼쪽 세로획을 윗가로획보다 먼저 (1·2획 교환) |
| 艅 | 舟의 긴 가로획을 안쪽 두 획 뒤로 (5·6획 교환) |
| 禳 | 襄의 아래 가로획을 짧은 세로 둘보다 먼저 (17획 → 15번째) |
| 鰲 | 敖의 가로획(5획)을 왼쪽에서 오른쪽으로 역방향, 짧은 획을 긴 삐침보다 먼저 (6·7획 교환) |
| 蒻 | 弱 안쪽 네 획(8·9·13·14)을 왼쪽 아래 방향으로 반전·역방향 |
| 剡·琰 | 火의 왼쪽 점(1·5획, 5획)을 왼쪽 아래 방향으로 반전 |
| 瀛 | 亠의 점(4획)을 세로점으로 보정 |

같은 회차의 穰은 허가 원본도 사전과 같은 순서를 써서 그대로 뒀다. 襄을 공유하지만
Ja 원본인 禳만 순서가 달랐다.

부수 유사성으로 승인하지 않았다. 각 글자의 사전 전체 필순을 순서대로 보고,
색으로 나눈 25% 진행 구간에서 방향·펜 떼기·획 경계·완성 자형을 대조했다.
보정 10자는 변경 획뿐 아니라 전체 획을 재대조했다.

[direction-probe.mjs](direction-probe.mjs)가 60°를 넘는 획 25개(10자)를 표시했고,
10자 모두 보정으로 이어졌다. 표시만 되고 그대로 둔 획은 없다.
弱·襄·敖처럼 덩어리로 얽힌 자리는 획 끝점 좌표를 숫자로 확인한 뒤 판정했다.
사전이 세로로 긋고 허가 원본이 기울여 쓰는 짧은 점이 45~60° 구간에 15개 더 있었다.
1~8차와 같은 기준으로 임계 아래는 허가된 중간선을 그대로 뒀다.
蒻·曄의 원문은 가로 이동 `translate(12, -y)`를 쓴다. 이동은 방향 벡터를 바꾸지 않는다.
