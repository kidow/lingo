## 보류

**瀆**: 사전은 賣의 가운데를 四(안쪽에 짧은 삐침과 작은 꺾임)로 쓰는데, 고정한 MM 후보는 罒(안쪽 세로 둘)로 쓴다.
세로획의 좌표로는 삐침이나 꺾임을 만들 수 없어 승인하지 않았다. 목록에 18획 Ja·Ko 후보가 없다.
특급II에서 보류한 犢·牘·竇와 같은 자형 차이다.

**疼**: 사전은 冬의 마지막 획을 왼쪽 아래에서 오른쪽으로 길게 올려 긋는데, 고정한 MM 후보는 오른쪽 아래로 짧은 점을 찍는다.
점의 좌표만으로는 긴 획의 길이와 방향을 만들 수 없어 승인하지 않았다(砥의 氐 가로와 같은 사유).
목록에 10획 Ja 후보가 있어 뒤에 Ja로 다시 고정하면 회복할 수 있다.
보류한 글자는 이후 회차의 후보 큐에서 뺀다.

簾의 兼 오른쪽 윗획(11획)은 사전과 MM 모두 왼쪽 아래로 긋지만 사전이 더 눕혀 그어 61°가 표시됐다.
반전이나 역방향은 관찰한 방향에서 오히려 멀어지므로 확인 후 허가된 중간선을 그대로 뒀다.

같은 회차의 掉·捏·辣처럼 순서와 방향이 모두 같은 글자와, 禱·屠·堵·遁·閭·礫(Ja 원본)은 그대로 뒀다.
言·今·令·金의 짧은 첫 획을 사전은 가로로, 허가 원본은 점으로 긋는 鸞·斂·殮·齡·囹은
시작·끝 방향 차이가 임계 아래라 이전 회차와 같이 그대로 뒀다.

부수 유사성으로 승인하지 않았다. 각 글자의 사전 전체 필순을 순서대로 보고,
색으로 나눈 25% 진행 구간에서 방향·펜 떼기·획 경계·완성 자형을 대조했다.
보정 12자는 변경 획뿐 아니라 전체 획을 재대조했다.

[direction-probe.mjs](direction-probe.mjs)가 60°를 넘는 획 27개(13자)를 표시했고,
12자는 보정, 1자(瀆)는 보류로 이어졌다. 표시만 되고 그대로 둔 획은 簾 11획 하나이며 위에 사유를 적었다.
疼은 표시 없이 자형 대조에서 보류했다.
馬·里·白·隹·𡈼처럼 덩어리로 얽힌 자리는 획 끝점 좌표를 숫자로 확인한 뒤 판정했다.
사전이 세로로 긋고 허가 원본이 기울여 쓰는 짧은 점이 45~60° 구간에 16개 더 있었다.
이전 회차와 같은 기준으로 임계 아래는 허가된 중간선을 그대로 뒀다.
逞의 원문은 가로 이동 `translate(12, -y)`를 쓴다. 이동은 방향 벡터를 바꾸지 않는다.
