## 보류를 해제한 근거

기존 비상교육 영상은 해당 지점에서 펜이 정지한 뒤 같은 접점에서 다시 진행한다. **정지 시간만으로 획 경계를 확정하지 않는 기존 판단은 유지한다.**

추가로 [郭](https://hanja.dict.naver.com/#/entry/ccko/ad40871b478e4ca5971bfec564bffe8b)·[郊](https://hanja.dict.naver.com/#/entry/ccko/38ba42eb95484436984b2f80d36c7493)·[那](https://hanja.dict.naver.com/#/entry/ccko/91778f0ee5124451a86eb8d083a29658)의 네이버 한자사전에서 **㈜오픈마인드인포테인먼트/e-hanja** 제공 표제어와 11·9·7획 표시를 확인하고, 각 항목이 실제 사용하는 SVG 주소를 확보했다. 네이버와 e-hanja를 서로 다른 두 근거로 세지 않는다.

원문 SVG에는 두 획의 **별도 윤곽, 각 윤곽을 참조하는 독립 클리핑 경로, 별도 시작·지속 시간**이 있다. DOM 순서만 믿지 않고 클리핑 참조와 재생 일정의 대응을 검증했다. 해당 6획을 각각 0·25·50·75·100% 마스크 진행 상태로 표시해 시작점·방향·끝점·접점을 대조했다. 이는 마스크의 진행률이며 실제 영상 타임스탬프가 아니다.

전체 비상교육 영상을 다시 2fps로 열람했다. **96개 영상 프레임**, 사전의 **27개 누적 상태**, 제품 후보의 **27개 누적 상태**, 경계 6획의 **30개 마스크 진행 상태**를 확인했다. 사전의 직립한 점 등 인쇄 서체 차이는 제품 좌표에 옮기지 않았다. 전체 경로·방향은 교재 영상과 대조했고, 사전은 불명확했던 경계의 보완 근거다.

`strokeEndsSeconds`는 완성 상태를 관찰한 보수적인 상한 시각이다. 정확한 펜 들기 시각을 뜻하지 않는다. 郭 9획과 세 글자의 마지막 획은 후속 완성 프레임으로 시각을 보완했다.

사전은 민간 한국어 사전이며 **한국어문회 등 시험 주관기관의 인증을 의미하지 않는다**. 검토자는 Codex root 1명이다.

## 출처와 제품 데이터

- 주요 필순 근거: [비상교육 고등 한문 교재](https://text.vivasam.com/detail/186)의 고정된 영상 0160·0186·0280. 이전 영상 해시와 일치했다.
- 보완 근거: `sources.json`의 실제 사전 SVG 주소·SHA-256·바이트 수·개별 획 ID·재생 일정.
- 제품 경로: 고정 커밋의 animCJK `graphicsJa.txt` 중심선. 기존 Arphic 라이선스를 유지한다. `originals.json`과 `candidate-paths.json`으로 재현한다.
- 사전 SVG 윤곽·마스크 경로, 교재 영상, 프레임 및 스크린샷은 저장하거나 제품으로 복제하지 않았다. 열람 서버는 루프백에서 원문을 메모리에만 보관한다.
- `prior-review.json`은 과거 보류 기록이다. 현재 승인 기록은 `review.json`이다. `baseline.json`으로 이전 모든 승인·제품 항목의 보존을 검증한다.
