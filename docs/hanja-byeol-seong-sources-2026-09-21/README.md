## 鱉

- [README 저작권 설명](https://github.com/g0v/zh-stroke-data/blob/26f12d65063cc97d2773b7777232277bfca5f563/README.md#資料來源--copyright)은 교육부에서 얻은 데이터와 그 외 CC0 파일을 구분한다. g0v.json의 CC0 표기만으로 필순 데이터를 자유 재사용할 수 있다고 판단하면 안 된다.

- Connum/hanzivg의 전체 비절단 트리에서도 같은 코드포인트 후보를 찾지 못했다. 이 결과는 조사한 저장소 범위의 부재이며 인터넷 전체에 자료가 없다는 뜻은 아니다.

## 宬

- 중국 교육부 공식 서버의 [GF 0023-2020 원문](https://www.moe.gov.cn/jyb_sjzl/ziliao/A19/202103/W020210318300204215237.pdf)을 직접 확보해 메모리에서 읽었다. PDF 173번째 페이지(0-based 172), 인쇄 167쪽, 항목 6900/U+5BAC에서 **9획**, 획종 번호 **445135534**와 9단계 누적 자형을 시각 확인했다. 파일 해시와 위치는 official-seong.json에 기록했다.
- [CNS11643 宬](https://www.cns11643.gov.tw/wordView.jsp?ID=142954)은 **10획**과 획종 문자열 **丶丶㇕一丿一㇕㇕丶丿**를 직접 제공한다. 이는 전체 SVG 경로나 시간에 따른 방향 데이터가 아니다. 관련 wordWrite.jsp는 법첩 검색이며 필순 애니메이션 다운로드로 오인하지 않는다.
- 두 기관의 기준이 다르다. 공식 9획 자료를 찾았다는 이유로 배정표 10획을 바꾸거나 획을 임의로 합치지 않는다. 중국 공식 순서의 4획 가로→5획 삐침과 기존 국내 사전 대조의 순서 차이도 구분한다.
- 공식 획종 번호의 ‘4’는 점이라는 분류이며 첫 점의 정확한 진행 방향을 단독으로 증명하지 않는다. 기존 AnimCJK Hans 후보의 첫 점과 국내 사전의 방향 차이를 해소할 재사용 가능 경로는 여전히 없다.
- 추가로 조사한 g0v/zh-stroke-data, Connum/hanzivg, hanzi-writer-data 전체 트리에는 宬의 독립 파일이 없었다. twpen/hanzipi의 페이지·이미지 존재도 확인했으나, 재사용 가능한 벡터 원본의 출처나 권한은 확인하지 못해 채택하지 않았다.

## 검증과 다음 작업

collect.mjs는 출처별 URL·HTTP 상태·크기·해시와 저장소 파일 목록을 수집하고, Hanzi Writer의 중복 medians를 비교한다.
sources.json에는 원본 그림이나 경로 좌표를 넣지 않았다. verify.mjs로 기록의 일관성, 원본 대조, 두 글자의 미적용과 현재 전체 적용 수를 검사한다.
공식 PDF 시각 검토는 방문/추출 기록과 구분해 official-seong.json에 남겼다. 원본 PDF 및 렌더링은 RAM에서만 처리하고 임시 서버·브라우저를 정리했다.
