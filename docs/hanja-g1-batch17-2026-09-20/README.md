# 1급 篡~稍 50자 검토 — 46자·654획 반영, 讒·瘠·脊·凸 보류

2026-09-20 · **46자 반영, 4자 보류**

[1급 16차 稠~纂](../hanja-g1-batch16-2026-09-20/README.md)의 `next-batch.json`에 고정한 후보 50자를
같은 방식으로 대조했다. 첫 대조에서 36자가 일치했고, 10자는 보정 후 전체 획을 다시 확인했으며, 4자는 자형 차이로 보류했다.
승인 46자에서 허가된 중간선 644획을 유지하고 10획을 국소 보정했으며, 4자의 획 순서를 바꿨다.
MM 원본 49자, Ja 원본 1자에서 출발했다.

## 보류

- **讒**: 18획 자리에서 사전은 아래 덩어리를 가로지르는 완만한 오른쪽 내림으로 긋는데
  허가된 MM 원본은 짧게 오른쪽으로 들어갔다가 아래로 쓸어내려, 毚의 완성 모양이 서로 다르다.
- **凸**: 1·2획은 같지만 펜을 떼는 자리가 다르다. 사전은 왼쪽 세로와 아래 가로를 한 획으로 잇고 오른쪽 세로로 끝내는데,
  허가된 원본은 왼쪽 세로를 따로 쓰고 위 덩어리와 오른쪽 세로를 한 획으로 이은 뒤 아래 가로로 끝낸다.
- **脊·瘠**: 사전은 脊 위쪽 네 획을 왼쪽 둘·오른쪽 둘의 가로로 쓰는데 허가된 원본은 人 둘레의 짧은 빗금 넷으로 그린다.

넷 다 순서·방향 조정으로 메울 수 없어 贖·猜·朕과 같은 기준으로 보류했다.
보류 4자는 `next-batch.json` 후보에서 뺀다.

같은 회차의 礁처럼 隹의 짧은 획이 이미 왼쪽 아래로 떨어지는 글자와,
瘡·倡·娼·猖처럼 순서가 그대로 맞는 글자는 손대지 않았다.

부수 유사성으로 승인하지 않았다. 각 글자의 사전 전체 필순을 순서대로 보고,
색으로 나눈 25% 진행 구간에서 방향·펜 떼기·획 경계·완성 자형을 대조했다.
보정 10자는 변경 획뿐 아니라 전체 획을 재대조했다.

[direction-probe.mjs](direction-probe.mjs)가 60°를 넘는 획 28개(14자)를 표시했고,
10자는 보정으로, 讒·瘠·脊·凸 4자는 보류로 이어졌다. 표시만 되고 그대로 둔 획은 없다.
脹·漲·艙·柵처럼 덩어리로 얽힌 자리는 획 끝점 좌표를 숫자로 확인한 뒤 대응을 맞췄다.
45~60° 구간의 방향 차이는 9개였다. 모두 사전이 세로로 긋고 허가 원본이 기울여 쓰는 짧은 점(擦·站·廠·瘡·寨·瘠·穿·擅·諦)으로,
이전 회차와 같은 기준으로 임계 아래는 허가된 중간선을 그대로 뒀다.
이번 회차 원문에는 가로 이동 변환이 없었다.
