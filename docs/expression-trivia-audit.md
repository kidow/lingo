# 표현·상식 콘텐츠 점검

점검일: 2026-09-07

## 수정 적용 결과 — 2026-09-07

사용자의 수정 요청에 따라 아래 점검 결과를 실제 콘텐츠에 반영했다. 이후 본문의 “현재 문제” 표는 수정 전 상태를 기록한 이력으로 읽는다.

- **상식 81문항 수정 완료**: en 15, ja 11, zh 12, fr 10, de 13, es 10, ru 10. 질문·보기·정답·해설을 함께 다듬었다. 기존 ID와 전체 1,613문항 수는 유지했다.
- **표현 18개 개념 수정**: 대표 문구 21개(프랑스어 하이픈 9개 포함), 외국어 예문 42개, 관련 한국어 번역을 수정했다. 아침 인사는 공통 뜻과 14개 예문 번역에 상황을 명시했다. 추가 표현 후보도 환불·통신 속도·참여 요청 등의 뜻이 명확한 문장으로 정리했다.
- **기존 음성 11개 재생 제외**: 발화 내용이 바뀐 음성은 `/private/tmp/lingo-expression-audio-1788733116369`에 보관했다. 새 음성은 생성하지 않았다. 변경된 표현 12개 중 1개는 원래 음성이 없었다. 예문 음성은 해당 경로에 원래 없었으며 문장 해시도 바뀐다.
- `SayButton`이 음성 목록을 확인하도록 보완했다. CDN에 예전 음성이 남아 있어도 제외된 낱말의 음성은 요청·자동 재생하지 않는다. 명시적으로 비활성화한 버튼도 재생하지 않는다.
- `pnpm romanize scene`, `pnpm audio manifest`, `pnpm split`으로 로마자·음성 목록·배포용 데이터를 갱신했다.
- 트랙 이름을 `DELF·DALF`, `한자능력검정`으로 명확히 했다. 출처 목록에 없는 단어는 시험에도 안 나온다는 주장, 미국식 발음만 사용하는 듯한 설명, 실제 발음과 문자 전사의 혼동을 주석·명세에서 바로잡았다. 외부 JLPT 태그·FLELex 연구 분류·Goethe 자료를 해당 시험의 공식 단어표와 구분했다.
- **새 시험 등급을 부여하지 않았다.** 문구가 바뀐 `my-data-is-slow/ja`의 이전 N1 값은 새 문장에 이전할 근거가 없어 제거했다. 근거 보류 11문항과 유지 가능 5문항은 상식 수정 대상에서 제외했다.

등급 전체 조회는 이번 작업에서 실행하지 않았다. 따라서 표현 파일의 등급 조회 지문이 낡았다는 경고는 남는다. 이를 숨기기 위해 지문만 새 값으로 바꾸거나 연구 분류를 공식 등급으로 다시 채우지 않았다. 최종 검증 결과는 문서 끝에 기록한다.

## 결론

현재 콘텐츠를 오류가 없는 상태로 볼 수 없다. 7개 언어 모두에서 정답 오류, 잘못된 일반화 또는 필수 조건 누락을 확인했다. 아래에는 우선 수정해야 할 상식 25문항의 상세 근거와 표현의 표기·의미 문제를 기록했다. 추가 후보 72개도 질문·정답·해설을 대조하고 수정 필요, 조건 명시, 유지 가능, 근거 확인 보류로 분류했다.

이하 내용은 최초 점검 당시의 기록이다. 최초 점검에서는 콘텐츠·정답·음성·시험 등급을 바꾸지 않았고, 이후 적용한 변경은 위 “수정 적용 결과”에 구분해 적었다. 다른 작업도 진행 중이므로 전체 작업 트리의 변경을 이 점검의 수정 결과로 간주하지 않는다.

심화 검토한 상식 97문항의 분류는 다음과 같다. **81개가 모두 정답 자체의 오류라는 뜻은 아니다.** 25개 상세 항목과 추가 수정 34개, 조건 보완 22개를 합쳐 81개에 조치가 필요하다고 판단했다.

## 우선 수정할 상식 25문항

파일은 모두 `content/trivia/<언어>.json`이다. `id`로 정확한 항목을 찾을 수 있다. 수정 방향에 있는 반례 중 출처에서 직접 인용했다고 표시하지 않은 짧은 문장은 규칙 설명용이며, 공식 시험 예문이나 공식 등급 자료라는 의미가 아니다.

### 추가 표현 검토 후보 — 확정 오류와 구분

- `my-data-is-slow`: 중국어 `我的流量很慢`, 독일어 `Meine Daten sind langsam`, 일본어 `データが おそいです`는 모바일 통신 속도라는 뜻이 명확한지 검토가 필요하다. 데이터 양과 연결 속도를 구분하는 현지 표현을 선택해야 한다.
- `have-allergy`: 중국어 `我有过敏`의 자연스러움과 알레르기 대상 생략을 검토한다.

- 스페인어 의문문의 `¿` 및 문장 끝 부호 정책을 검토한다. 대표 문구와 완전한 예문의 표기 정책을 구분해서 적용해야 한다.

## 수정 시 적용할 원칙

1. 상식은 질문·보기·정답·해설을 한 묶음으로 고친다. 잘못된 전제를 해설만 덧붙여 유지하지 않는다.
