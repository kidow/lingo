# 瘦 — 새 HK 원본 의존성

기존 원문의 실제 root `hkcs_m7626`@2를 보존했다. `u7626-hkcs`는 로컬 자료 식별자이며 제공자 별칭이 아니다. root는 재취득하지 않았다.

누락된 `hkcs_m7592-p05-s00`(疒)와 `hkcs_m53df-p02-s00`(叟)만 공개 API에서 읽고, 관측 버전@2를 명시 요청해 같은 원문을 확인했다. 원래 bare 참조 key와 반환 version의 문자열 타입을 보존했다. 두 원문은 각5행·12행이며 추가 자식 참조가 없다.

총3개 record의 혼합 관측일 closure다. 하나의 과거 시점 복원으로 주장하지 않는다. 배정14획·국내15clip을 수정하지 않으며 leaf17행을 어느 한쪽 논리획 수로 동일시하지 않는다. 기존 첫 세로획·마지막 가지의 시작 접촉 HOLD도 유지한다.

새 HK whole 캡처와 원본 화면 대조는 별도다. 개별 사전 자형 정책으로 허용하려면 국내15 방향·자형 대응과 실제 재생 검토가 추가로 필요하다. 이 자료는 source 준비이며 등록·필순·native·runtime 승인이 아니다.
