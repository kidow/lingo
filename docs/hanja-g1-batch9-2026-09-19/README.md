# 1급 腑~娑 50자 검토 — 50자·609획 반영

2026-09-19 · **50자 반영, 보류 없음**

[1급 8차 槃~訃](../hanja-g1-batch8-2026-09-19/README.md)의 `next-batch.json`에 고정한 후보 50자를
같은 방식으로 대조했다. 첫 대조에서 42자가 일치했고, 8자는 보정 후 전체 획을 다시 확인했다.
허가된 중간선 601획을 유지하고 8획을 국소 보정했으며, 3자의 획 순서를 바꿨다.
MM 원본 46자, Ja 원본 4자에서 출발했다.

## 보정

| 보정 대상 | 변경 |
| --- | --- |
| 孵 | 卵의 오른쪽 점을 긴 오른쪽 세로보다 먼저 (6·7획 교환) |
| 鄙 | 口 아래 十의 가로를 세로보다 먼저 (4·5획 교환) |
| 憑 | 馬의 왼쪽 세로획을 윗가로획보다 먼저 (3·4획 교환) |
| 焚 | 火의 왼쪽 점(9획)을 왼쪽 아래 방향으로 반전 |
| 譬 | 辛의 첫 점(7획)을 세로로 |
| 翡 | 羽 안쪽 넉 획을 모두 왼쪽 아래로: 위 점(10·13획) 반전, 아래 획(11·14획) 역방향 |
| 扉 | 戶의 첫 획(1획)을 오른쪽 위에서 왼쪽 아래로 긋는 방향으로 반전 |
| 麝 | 比의 셋째 짧은 획(10획)을 왼쪽에서 오른쪽으로 역방향 (砒·妣·秕·琵·庇의 허가 원본과 같은 방향) |

같은 회차의 糞처럼 田의 안쪽 가로가 이미 세로보다 앞선 글자와,
砒·妣·秕·琵·庇의 比, 裨·臂·痺의 辟, 殯·濱·嬪의 賓, 雰·祠·奢(Ja 원본)처럼
순서와 방향이 모두 같은 글자는 그대로 뒀다.

부수 유사성으로 승인하지 않았다. 각 글자의 사전 전체 필순을 순서대로 보고,
색으로 나눈 25% 진행 구간에서 방향·펜 떼기·획 경계·완성 자형을 대조했다.
보정 8자는 변경 획뿐 아니라 전체 획을 재대조했다.

[direction-probe.mjs](direction-probe.mjs)가 60°를 넘는 획 12개(7자)를 표시했고,
7자 모두 보정으로 이어졌다. 표시만 되고 그대로 둔 획은 없다.
孵는 표시되지 않았지만 시트에서 卵의 오른쪽 점과 긴 세로의 순서가 사전과 달라 획 끝점 좌표로 확인한 뒤 교환했다.
점과 세로의 시작·끝 방향 차이가 22°·46°에 그쳐 프로브가 잡지 못한 자리다.
麝의 比는 같은 회차 砒·妣·秕·琵·庇의 허가 원본이 모두 오른쪽으로 오르는 획이라 그쪽에 맞춰 역방향으로 뒀다.
45~60° 구간의 방향 차이는 17개였고 그중 孵의 한 획이 위 순서 교환에 들어갔다.
나머지 16개는 대부분 사전이 세로로 긋고 허가 원본이 기울여 쓰는 짧은 점이며,
孵의 爫 점 둘(58°·53°)도 임계 아래라 이전 회차와 같은 기준으로 허가된 중간선을 그대로 뒀다.
이번 회차 원문은 모두 `translate(0, -y)`만 쓰고 가로 이동이 없다.

## 근거와 재현

- [observations.json](observations.json): 50자 판정, 8자의 첫 판정·보정·재대조 기록, 8방향 코드
- [source-checks.json](source-checks.json): 50자의 원문 해시·획별 시간·XML 참조·좌표 변환
- [originals.json](originals.json): 고정한 라이선스 원본의 중간선과 정규화 경로
- [proposals.json](proposals.json), [corrections.json](corrections.json): 획별 원본 대응과 국소 보정 이유

- [verify.mjs](verify.mjs): 재현 결과·공개 데이터·적용 수·다음 후보 검증. 1급 회차의 보류 글자는 큐에서 뺀다
- [checks.json](checks.json), [progress.json](progress.json): 이번 검증과 전체 진행 현황
- [next-batch.json](next-batch.json): 다음 徙~搔 50자·642획 후보
- [acquire.mjs](acquire.mjs), [source-checks.mjs](source-checks.mjs), [serve.py](serve.py): 원본 고정·원문 확인·검토 시트

필순 근거는 e-hanja 사전이며, **한국어문회 인증으로 표시하지 않는다.**
재생 중간선은 Arphic Public License의 고정 MM·Ja 원본에서 출발했다.
사전의 경로·마스크·영상·스크린샷을 파일에 저장하거나 배포하지 않았다.
