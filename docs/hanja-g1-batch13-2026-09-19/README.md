# 1급 訛~毅 50자 검토 — 46자·556획 반영, 揄·癒·諭·愉 보류

2026-09-19 · **46자 반영, 4자 보류**

[1급 12차 軋~壅](../hanja-g1-batch12-2026-09-19/README.md)의 `next-batch.json`에 고정한 후보 50자를
같은 방식으로 대조했다. 첫 대조에서 38자가 일치했고, 8자는 보정 후 전체 획을 다시 확인했으며, 4자는 자형 차이로 보류했다.
승인 46자에서 허가된 중간선 553획을 유지하고 3획을 국소 보정했으며, 6자의 획 순서를 바꿨다.
MM 원본 41자, Ja 원본 9자에서 출발했다.

## 보류

揄·癒·諭·愉 네 자는 사전이 兪의 오른쪽을 巜(꺾임 둘)로, 왼쪽 아래 月의 안을 점 둘로 쓰는데
허가된 MM 원본은 俞로 그려 오른쪽이 刂(짧은 세로와 갈고리 세로), 안쪽이 가로 둘이다.
순서·방향 조정으로 메울 수 없는 자형 차이라 특급II 瑜와 같은 기준으로 보류했다.
揄에서 표시된 9·10획은 이 자형 차이 자체다.
같은 兪를 가진 喩는 Ja 원본이 사전과 같은 巜 자형이라 그대로 승인했다.
보류 4자는 `next-batch.json` 후보에서 뺀다.

부수 유사성으로 승인하지 않았다. 각 글자의 사전 전체 필순을 순서대로 보고,
색으로 나눈 25% 진행 구간에서 방향·펜 떼기·획 경계·완성 자형을 대조했다.
보정 8자는 변경 획뿐 아니라 전체 획을 재대조했다.

[direction-probe.mjs](direction-probe.mjs)가 60°를 넘는 획 16개(9자)를 표시했고,
8자는 보정으로, 揄 1자는 보류로 이어졌다. 표시만 되고 그대로 둔 획은 없다.
饒·聳·揖처럼 덩어리로 얽힌 자리는 획 끝점 좌표를 숫자로 확인한 뒤 대응을 맞췄다.
45~60° 구간의 방향 차이는 16개였다. 그중 7개는 보류한 癒·諭·愉 안에 있고,
1개(饒 5획)는 飠 재배열 전 어긋난 대응이라 재배열로 해소됐다.
나머지 8개는 사전이 세로로 긋고 허가 원본이 기울여 쓰는 짧은 점으로(窈·宥의 첫 점은 정확히 60°),
이전 회차와 같은 기준으로 임계 아래는 허가된 중간선을 그대로 뒀다.
이번 회차 원문에는 가로 이동 변환이 없었다.

- [observations.json](observations.json): 50자 판정, 8자의 첫 판정·보정·재대조 기록, 4자의 보류 사유, 8방향 코드

- [verify.mjs](verify.mjs): 재현 결과·공개 데이터·적용 수·다음 후보 검증. 1급 회차의 보류 글자는 큐에서 뺀다
- [checks.json](checks.json), [progress.json](progress.json): 이번 검증과 전체 진행 현황
- [next-batch.json](next-batch.json): 다음 椅~嫡 50자·591획 후보
- [acquire.mjs](acquire.mjs), [source-checks.mjs](source-checks.mjs), [serve.py](serve.py): 원본 고정·원문 확인·검토 시트

필순 근거는 e-hanja 사전이며, **한국어문회 인증으로 표시하지 않는다.**
재생 중간선은 Arphic Public License의 고정 MM·Ja 원본에서 출발했다.
사전의 경로·마스크·영상·스크린샷을 파일에 저장하거나 배포하지 않았다.
자형의 구조와 진행 방향을 비교한 것으로 폰트 외곽선의 픽셀 일치나 필기 채점이 아니다.
