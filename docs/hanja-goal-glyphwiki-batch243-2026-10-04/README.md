# 絪 12획 전체 검토 — 보류

브라우저 패널에서 국내 사전 12획 방향·누적·완성 자형을 정확한 전체 u7d6a-k 원본과 대조했다. 첫 두 꺾임의 원본 경로가 이어지지 않는다. 1획은 [27.675,56]→[12.87,45], 2획은 [26.97,110]→[14.28,113] 사이가 끊긴다. 원본 200 좌표계에서 간격은 각각 18.44418675355463, 13.039789108724111이다.

확인한 u7d6a-k·u7d6a·u7d6a-ue0100은 모두 같은 선언된 u7cf8-01을 쓴다. 임의 연결·부수 이식은 하지 않는다. 원본 엔진 8개 파일·15개 raw 그룹·16개 draw와 해시, 연결 불일치 및 미등록 상태를 `verify.mjs --engine`으로 검증했다. 진행 프레임은 승인하지 않았고 런타임을 추가하지 않았다. 국내 사전 교차검토이며 공식 시험기관 승인과 구분한다. 비공개 그래픽은 RAM에서만 대조했다.

보류 해제에는 첫 두 꺾임의 연속 궤적을 제공하는 라이선스 허용된 정확한 전체 글자가 필요하다. 확보 후 전체 12획과 108개 진행 프레임을 브라우저에서 검토한다. 기존 보류 목록은 변경하지 않고 이 기록에 사유를 남긴다.

적용 5,106/5,978자(85.4%), 미적용 872자. 특급II 949/1,150자(82.5%), 201자 미적용. 다음 후보는 菁 12획이다. 물·실 관련 끊어진 경로를 반복하는 대신 독립적인 전체 원본을 우선했다. 6개 선언 레코드의 정확한 closure를 확보했으며 국내·진행 검토는 아직 하지 않았다.
