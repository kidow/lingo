# 瓊 19획 자형·경로 검토

瓊 1자·19획을 적용했다. 한국어문회의 해당 글자 자형 설명, 대만 교육부의 **19획 전체 자료**, 국내 e-hanja의 공통 1–15획을 교차검토했다. 국내 시험 주관 기관이 19획 애니메이션 전체를 인증했다는 뜻은 아니다.

## 근거와 범위

- [한국어문회 2010 답변 7946](https://www.hanja.re.kr/klea/counsel/hanjaDetail.do?id=7946)은 마지막을 夂 3획으로 쓰는 18획과 攵 4획으로 쓰는 19획을 모두 인정한다.
- [2021 답변 10717](https://www.hanja.re.kr/klea/counsel/hanjaDetail.do?id=10717)은 瓊의 夐 마지막 구건이 攵/攴 4획이며, 일부 폰트가 이를 夂 3획으로 나타내 획수 차이가 생긴다고 설명한다. 목록의 19획을 유지한다.
- [대만 교육부 瓊](https://stroke-order.learningweb.moe.edu.tw/dictView.jsp?ID=29898&la=0)의 본문 내 XML은 19개의 Outline/Track을 포함한다. 전 획의 순서·방향·누적 자형을 화면에서 대조했다. 원문 XML 해시: `8b3af69f2301ca72701f2d0a17511f7a97f17d73e89286daacdfaa5362949d5c`. 외국의 공식 자료는 국내 시험 필순의 단독 인증 근거로 취급하지 않는다.
- [e-hanja 瓊 18획](http://img.e-hanja.kr/hanjaSvg/aniSVG/7400/74CA.svg)은 1–15획의 경계·순서·방향이 공통이다. 마지막 3획은 다른 자형이며 런타임 16–19획에 일대일 대응시키지 않았다. 런타임의 `dictionaryDirectionStrokes`도 **1–15만** 기록했다.
- 대만 페이지에 적힌 `provideStrokeInfo.do` 주소는 404였다. 실제 페이지가 포함하는 XML을 사용했고, 임의 주소 추측이나 원본 데이터 재배포는 하지 않았다.

## 경로와 직접 검토

라이선스가 확인된 Make Me a Hanzi 19획을 사용했다. 17획은 그대로 유지하고 **13·14획**만 보정했다. 두 획은 目 내부 가로획으로, 원래 중심선의 끝이 오른쪽 세로획에 닿지 않았다. 두 전체 자형 자료의 닫힘을 확인하고 기존 오른쪽 경계까지 연장했다. 시작점·진행 방향·획수·순서는 바꾸지 않았다.

처음 19획을 각각 대조하고, 보정 후 13–19획의 누적 자형을 다시 확인했다. 짧은 10획의 방향은 화면과 원본 Track의 오른쪽 아래 진행을 함께 확인했다. 마지막 16–19획은 왼삐침 → 독립 가로 → 긴 왼삐침 → 오른쪽 아래 파임이다. 다른 한자에 대한 부수 조합 자동 승인은 추가하지 않았다.

사전 SVG, 교육부 XML·이미지, 상담 HTML, 화면 캡처는 저장하지 않았다. 출처 URL·해시·메타데이터·직접 작성한 관찰 및 라이선스 후보 경로만 보존했다. 검토 서버는 원본을 메모리에서만 처리한다.

## 검증과 진행

- 한자 테스트 52개 파일 **301개 통과**, HWP 파서 **7개 통과**.
- 새 테스트의 readonly 배열 변경 오류를 고친 뒤 해당 테스트 3개와 **프로덕션 빌드 통과**.
- `node docs/hanja-g2-qiong-2026-09-16/verify.mjs`로 후보 재구성, 증빙 해시, 런타임 등록, 중복 여부와 진행 수치를 확인한다.
- 전체 **2,280/5,978자(38.1%)**, 남은 **3,698자**. 적용 획 **25,402획**.
- 2급 **462/538자(85.9%)**, 남은 **76자**. 8급~3급은 완료 상태다.
- 2급 남은 분류: 출처·획수 대조 4자·49획, 경로·획수 대조 38자·491획, 경로 확보 34자·452획.
