## 원 decimal의 정확 유리수와 pointwise 조건

원 Q를 γ(t)=P0+2At+Bt², 0≤t≤1로 씁니다. 마지막 y decimal을 49.4575로 반올림하지 않았습니다.

```text
P0 = (17.4, 80.375)
P1 = (18.99, 75.905)
P2 = (35.685, 49.457499999999996)
A  = (159/100, -447/100)
B  = (3021/200, -5494375000000001/250000000000000)
aa = A·A = 22509/1000
ab = A·B = 3056409375000000447/25000000000000000
bb = B·B = 44448220703125010988750000000001/62500000000000000000000000000
c  = cross(A,B) = 814378124999999841/25000000000000000 > 0
S(t) = aa + 2ab t + bb t²
γ′(t) = 2(A+Bt)
κ(t) = c / (2 S(t)^(3/2))
```

ab>0,bb>0이므로 S는 t≥0에서 증가합니다. 이상적인 원 곡선의 호길이를 d(t)=2∫₀ᵗ√S(u)du, ρ(t)=min(7,d(t))라 두면 d(t)≤2t√S(t)입니다. 따라서

```text
ρ(t)κ(t) ≤ d(t)κ(t) ≤ c t / S(t).
Δ15 = 4aa bb − (2ab − 15c)² > 0.
```

bb>0과 이 음의 판별식 조건으로 S(t)−15ct>0이 모든 실수 t에서 성립합니다. 따라서 t≥0에서 **ρκ<1/15**입니다. 이는 고정 global κ 상한을 작게 가정한 결과가 아니라 성장 반경과 감소 곡률을 함께 묶은 pointwise 부등식입니다.

접선은 A·(A+Bt)=aa+ab t>0이므로 같은 전방 반평면에 있습니다. 정확 항등식 aa bb−ab²=c²를 사용하면

```text
cos²(T0,Tt) = (aa+ab t)² / (aa S(t))
            = 1 − c²t²/(aa S(t))
            ≥ ab²/(aa bb) > 9/10 > (1/15)² > (ρκ)².
```

따라서 요청된 접선 제곱 부등식도 정확하게 성립합니다. ab²/(aa bb)의 근삿값은 0.9337109771154298이며, 단언은 근삿값이 아니라 10ab²−9aa bb>0의 정수 부호 계산으로 확인했습니다. T=1/2에서 |γ(T)−P0|²>49이므로 최초 arc7은 t<1/2 안에 있습니다.

다음은 S 증가성만 이용한 더 느슨한 구간별 상한 c·b/S(a)입니다. 모든 값은 원 유리수로 계산했고 표는 읽기용 근삿값입니다. 위 global pointwise 1/15가 더 강합니다.

| t 구간 | ρκ 상한의 근삿값 |
|---|---:|
| [0/1, 1/16] | 0.09045027822204449 |
| [1/16, 1/8] | 0.1003693592569901 |

## 고정 반폭7 tube에는 적용 범위 차이가 남음

현재 renderer의 butt sweep는 반폭을 ρ로 줄이지 않습니다. 경로·폭14는 그대로이며, ρ는 시작/끝 cap 반경입니다. 그러므로 위 ρκ 부등식을 고정폭 normal-strip 증명의 rκ 자리에 대입할 수 없습니다.

정확 산술에서 49c²−4aa³>0입니다. 즉 κ(0)≈0.15251824296254152>1/7이고 최초 focal 정상거리 1/κ(0)≈6.556592710326463<7입니다. 고정폭 strip의 정상좌표 F(s,u)=γ(s)+uN(s)는 |u|≤7 안에서 국소 접힘이 생길 수 있습니다.

더 직접적인 반례는 t1=1/2000,t2=1/1000의 서로 다른 두 내부 정상선입니다. J(x,y)=(-y,x), v=A+t1B, h=t2−t1, S1=v·v라 두고 다음 **정확 유리수 좌표식**으로 동일 교점을 정의합니다. 이는 원 경로를 바꾸는 새 좌표 입력이 아니라 분석용 교점 식입니다.

```text
λ = [2S1 + 3(v·B)h + bb h²] / c
Z = P0 + 2A t1 + B t1² + λ Jv
δ = 2v h + B h²
(Z−γ(t2))·(A+t2B) = (λ Jv−δ)·(A+t2B) = 0
|Z−γ(t1)|² = λ²S1 < 49
|Z−γ(t2)|² = |λ Jv−δ|² < 49
```

두 거리는 각각 약 6.637045947553933, 6.63704594524135이며 모두7보다 작습니다. 서로 다른 source 매개변수의 정상선이 실제 고정폭 안에서 교차하므로 그 strip의 단사성을 주장할 수 없습니다. 이것은 **원 outline P와의 교집합·실제 SVG paint의 실패나 분리 현상을 판정하는 반례가 아닙니다.** 원 P가 이 교차 부분을 포함하는지도 조사하지 않았습니다.

## 별도 nested-set 증명 경로와 미확보 조건

단사성을 요구하지 않는 별도 집합 보조정리는 다음과 같습니다. 여기서 s는 이상적인 단위속도 호길이이며, renderer가 이 집합과 같다고 아직 가정하지 않습니다.

```text
N_d = { γ(s)+uN(s) : 0≤s≤d, |u|≤7 }
W_d = N_d ∪ B(γ(0),min(7,d)) ∪ B(γ(d),min(7,d))
```

- 0≤d1≤d2≤7이면 |γ(d2)−γ(d1)|≤d2−d1입니다. cap 반경 증가량도 d2−d1이므로 끝 disc는 B(γ(d1),d1)⊆B(γ(d2),d2)입니다. N_d와 시작 disc도 포함관계로 증가합니다.
- d≥7이면 prefix에 대한 최근접점이 내부인 경우 원 곡선 접선에 직교한다는 사실로 W_d는 prefix의 반경7 neighborhood와 같습니다. 정상선의 단사성 없이도 prefix 포함에 따라 W_d가 증가합니다. d=7에서 두 정의가 일치합니다.
- N_d는 연속 정상 map의 상이고 중심 경로를 포함합니다. 두 disc 중심도 그 경로에 있으므로 이상적인 W_d는 연결됩니다.
- N_d 면적은 normal map의 |1−uκ(s)| 적분으로 상계됩니다. 원 Q는 시작 근처에서 유계 곡률이므로 이 상계는 O(d), 두 cap 면적은 O(d²)입니다. 따라서 d→0+에서 면적은0으로 갑니다. d=0에서 실제 코드가 ink를 비우는 조건은 별도로 유지해야 합니다.

이 보조정리는 **normal-strip 집합을 가정한 별도 증명**이며 기존 cert를 약화하거나 바꾸는 것이 아닙니다. 실제 SVG butt/miter dash paint가 고곡률 self-overlap과 UA 근사까지 포함해 이 N_d와 같은지는 확인하지 않았습니다. SVG stroke가 fill-rule로 상쇄된다는 규정을 확인한 것은 아닙니다. 따라서 이것만으로 현재 renderer 인증을 발급할 수 없습니다. 또한 W_d의 연결성은 P∩W_d의 연결성을 뜻하지 않습니다. 고정 원 P가 분리되어 있거나 접촉 시점이 다르면 교집합에는 섬/간격이 남을 수 있습니다.

권장 후속 경로는 **일반 nested-set 보조정리 + 실제 SVG paint 동등성 근거 연구**, 또는 **고정 source P에 한정한 별도 증명**뿐입니다. 원 곡선·outline·폭 축소·새 connector·임의 nib 조정·100% unmask로 회피하지 않습니다. 새 native/coverage/시간 방향 승인은 이 문서에서 하지 않습니다.

## 공식 SVG2 문서 대조 추가 — 2026-10-21

ROOT가 이미 확보한 [SVG2 TR §13.5.7](https://www.w3.org/TR/SVG2/painting.html#StrokeShape)을 공유 cache에서 읽고 [공식 Editor’s Draft의 같은 절](https://svgwg.org/svg2-draft/painting.html#StrokeShape)을 대조했습니다. 별도 검색은 하지 않았습니다. Editor 페이지를 index로 가져온 뒤 cache 검색의2000자 제한 때문에 같은 페이지의 line view로 뒤쪽 union 문장까지 확인했습니다. 공개 spec URL만 조회했고 repo/source/비밀을 외부로 보내지 않았습니다. 이는 앞선 산술 재실행이나 UA/native 실행이 아닙니다.

두 문서는 dash를 호길이별 정상선상의 점들로 정의하고 시작/끝 cap 및 통과한 segment join을 합집합으로 더합니다. butt cap은 빈 모양입니다. 따라서 정상선 단사성 대신 집합 union으로 기술하는 연구 방향은 문서상 근거가 있습니다. 다만 이것은 규범적 이상 모양에 대한 근거입니다. [Editor §13.5.7 서두](https://svgwg.org/svg2-draft/painting.html#StrokeShape)는 성능상 구현 재량을 허용하고 극히 급한 곡선에서 플랫폼별 stroke 모양 차이가 있을 수 있다고 명시합니다. spec의 집합 정의만으로 해당 UA의 paint·AA·dash/length 근사가 통과했다고 말할 수 없습니다.

정확 반폭에는 문구 불일치가 남습니다. 두 버전 모두 dash 본문은 짧게 인용하면 **“within distance stroke-width”**라고 적지만, [cap 정의](https://svgwg.org/svg2-draft/painting.html#LineCaps)는 round cap의 지름을 전체 stroke-width로 하고 [join 구성](https://svgwg.org/svg2-draft/painting.html#StrokeShape)은 좌우 offset을 stroke-width/2로 둡니다. 또한 마지막 shape union은 **“union of shape and stroke”**라고 써서 앞서 정의한 dash와 변수명이 다릅니다. 정오표나 의도 확인 없이 오타로 확정하지 않습니다. cap/join의 반폭 해석과 일관된 r7 모델은 연구 가설이며, 이 dash 문구 하나를 r7의 형식적 동등성 증명으로 인용하지 않습니다. 두 짧은 인용은 페이지당 합계25단어 이하입니다.

본 대상은 한 개의 regular Q라 내부 segment join이 없지만, 고곡률 normal-strip 자기 겹침의 실제 UA 처리와 pathLength 정규화/같은-frame 측정은 여전히 별도 확인 대상입니다. 원 P와의 교집합 연결성은 공식 문서로도 승인되지 않습니다. 후속은 **일반 nested-set + 실제 SVG paint 동등성 근거 연구 또는 source P 한정 proof**만 권장하며, 기존 cert 범위·source·renderer·runtime·native false는 바꾸지 않습니다.
