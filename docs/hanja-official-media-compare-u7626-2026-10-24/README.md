# 瘦 — 국내15획 원본 방향 검토 준비

배정14획은 원문 그대로 유지한다. 이 검토는 사전 원본15clip의 각 .1/.5/.75, 총45화면에 한정한다. 실제 HK 제공자 `hkcs_m7626`와 사전문맥 `u7626`는 서로 다른 식별자이며 alias가 아니다.

기존 Hant 비교에는 첫 세로/가로 접속과 마지막 가지의 시작 접속 관찰만 구체적으로 적혀 있다. 새 HK whole의 거시적 대응 PASS로15획 순서·방향 또는 개별 variant를 자동 승인하지 않는다. 원본15 방향 확인 뒤에만 HK17raw의 합획·순서 후보를 확정한다. 원P·guide·폭·flag·행은 수정하지 않는다.

원SVG1회 RAM에서 CSS시간표와 속성 해시만 추출했다. 이미지/경로 원문은 저장하지 않았다. 게시자 JS는 실행하지 않고 고정 원CSS만 사용한다. 서버는 ROOT만 실행한다.
