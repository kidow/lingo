# 2급 538자 필순 출처·후보 전수 목록

확인일: 2026-09-15. 대상은 2급에 새로 배정된 **538자·6,668획**이다.

공개 국내 사전에서 538자 모두의 필순 SVG에 접근했다. 이 중 **457자·5,595획**은 사전 메타데이터와 라이선스가 있는 후보 경로의 획수가 배정 획수와 일치하여, 전체 획 검토를 시작할 수 있다. 이번에는 획별 시각 검토나 애니메이션 추가를 하지 않았다.

| 다음 작업 분류 | 문자 | 배정 획수 |
| --- | ---: | ---: |
| 전체 획 순서·방향·경계·자형 검토 | 457 | 5,595 |
| 국내 사전과 배정 획수 차이 검토 | 9 | 130 |

## 출처와 경로는 따로 집계한다

- **배정 기준:** 기존 [한국어문회 배정 자료](https://www.hanja.re.kr/kccpt/exam/levelConfirm.do)의 카탈로그와 해시를 그대로 사용했다.
- **교과서:** [비상교육 고등 한문 공개 자료](https://text.vivasam.com/detail/186)의 고정된 1,800자 목록에는 이번 2급 538자가 없다. 이것은 국내 자료 전체가 없다는 의미가 아니다.
- **국내 사전:** [e-hanja 공개 상세 페이지](http://www.e-hanja.kr/e-hanja/dic/contents/jajun_content.asp?hanja=%E6%9F%AF&keyword=%E6%9F%AF)가 호출하는 AJAX 응답에서 실제 연결 SVG 주소를 추출했다. 538자 모두 HTTP 200·정확한 title·타이밍·클립 대응을 확인했고, 529자는 표시 획수·외곽선 수·애니메이션 경로 수·누적 단계 이미지 항목 수가 배정 획수와 일치했다. 누적 이미지 본문이나 모든 획의 실제 재생을 확인했다는 뜻은 아니다.
- **경로 후보:** 고정 버전 Make Me a Hanzi와 AnimCJK Ja·Ko를 다운로드해 해시와 구조를 확인했다. MM은 476자(획수 일치 412), Ja는 451자(402), Ko는 0자다. 합집합은 504자이며, 적어도 하나의 후보가 획수까지 일치하는 문자는 461자다.

경로만 보면 획수 불일치가 **43자·553획**이다. 이 중 5자는 사전 자체의 획수 차이도 있어 위 작업 표의 9자에 먼저 배정했다. 표의 38자는 이 중복을 뺀 값이다. 두 원래 분류는 [summary.json](summary.json)과 각 inventory에 보존했다.

## 다음 묶음

**柯~揆 50자·581획**을 [next-batch.json](next-batch.json)에 정리했다. 카탈로그 순서를 유지하며 사전 획수 일치와 후보 경로 획수 일치를 모두 만족하는 문자만 포함했다. 같은 획수 후보가 여럿이면 기존 기준 Ko → MM → Ja 순으로 우선 선택한다. 선택은 검토 시작점이며 적합 판정이 아니다.

첫 획부터 마지막 획까지 사전 재생 순서와 후보 경로의 방향·획 경계·최종 자형을 대조한다. SVG의 XML 나열 순서는 재생 순서와 다를 수 있으므로 공개 CSS에서 확인한 --d(지연)·--t(길이)를 기준으로 실제 재생을 확인해야 한다.

e-hanja는 국내 민간 사전이며 한국어문회 필순 인증으로 표기하지 않는다. 사전 SVG·영상·누적 이미지 경로를 앱에 복사하지 않았고, 후보 데이터의 라이선스와 출처 구분은 유지한다. title·HTTP·획수·타이밍 메타데이터 일치는 전체 획의 시각 검토를 대신하지 않는다.

## 재현과 검증

- [audit.mjs](audit.mjs): 교과서 목록과 고정된 후보 말뭉치를 다시 조회하여 JSON을 표준 출력한다.
- [dictionary-audit.mjs](dictionary-audit.mjs): 공개 페이지 → AJAX → 연결 SVG 메타데이터를 조회한다. auditDictionary({ retryInventory })는 최초 실패 행만 한 번 재시도한다.
- [plan.mjs](plan.mjs): 저장된 두 inventory에서 독립 상태 분류·작업 목록·첫 50자를 다시 산출한다.
- [verify.mjs](verify.mjs): 카탈로그 해시·538자 유일성·분류 누락/중복·획수 합계·출처/후보 핀·재시도 이력·첫 50자 선정 조건을 검증한다.

검증 명령: node docs/hanja-g2-inventory-2026-09-15/verify.mjs --runtime-baseline

조회 스크립트는 원격 자료를 메모리에서 분석해 결과만 출력한다. 검증은 저장된 inventory를 사용한다. 네트워크 재조회에서는 일시 오류나 출처 변경으로 결과가 달라질 수 있다.

현재 적용은 **1,818/5,978자(30.4%)**, 미적용 **4,160자**다. 8급~3급은 완료했고, 2급은 0/538자다. 이번 작업 추가 적용은 0자이며 런타임·카탈로그는 변경하지 않았다. [progress.json](progress.json)에 급수별 수치를 기록했다.
