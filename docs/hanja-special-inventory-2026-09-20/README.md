# 특급 1,328자 필순 출처·후보 전수 목록

확인일: 2026-09-20. 대상은 특급에 새로 배정된 **1,328자·18,270획**이다. 특급II 조사([hanja-special2-inventory-2026-09-18](../hanja-special2-inventory-2026-09-18/README.md))와 같은 절차·같은 출처·같은 분류인데, 후보 말뭉치를 셋이 아니라 **다섯**(MM·AnimCJK Ja·Ko·ZhHant·ZhHans)으로 처음부터 본다. 이번 회차에는 획별 시각 검토나 애니메이션 추가를 하지 않았다.

공개 국내 사전에서 1,328자 모두의 필순 SVG에 접근했다. 이 중 **680자·8,886획**은 사전 메타데이터와 라이선스가 있는 후보 경로의 획수가 배정 획수와 일치하여, 전체 획 검토를 시작할 수 있다.

| 다음 작업 분류 | 문자 | 배정 획수 |
| --- | ---: | ---: |
| 전체 획 순서·방향·경계·자형 검토 | **680** | 8,886 |
| 국내 사전과 배정 획수 차이 검토 | 17 | 258 |

특급II와 가장 다른 점은 **후보 미확보가 절반 가까이(41%)**라는 것이다. 특급II는 1,150자 중 217자(19%)였다.

## 왜 네이버가 아니라 e-hanja인가

네이버 한자사전의 필순 애니메이션에는 `©2020.(e-hanja)` 표시가 있다 — 네이버가 보여주는 그림의 원본이 e-hanja다. 네이버는 `robots.txt`로 ClaudeBot·Claude-SearchBot을 전부 막고 `entry` 경로는 모든 봇에 닫혀 있어 자동 조회를 하지 않는다([spec.md](../../spec.md)의 사전 규칙). 원본인 e-hanja는 2급부터 써 온 경로 그대로다. 사전 SVG는 순서·방향 대조에만 쓰고 런타임 기하로는 쓰지 않는다.

## 출처와 경로는 따로 집계한다

- **배정 기준:** 기존 [한국어문회 배정 자료](https://www.hanja.re.kr/kccpt/exam/levelConfirm.do)의 카탈로그와 해시를 그대로 사용했다.
- **교과서:** [비상교육 고등 한문 공개 자료](https://text.vivasam.com/detail/186)의 고정된 1,800자 목록에 특급은 **鄰 하나**만 있다. 영상은 HTTP 200으로 존재한다(HEAD만, 완전성 검증 아님). 교과서는 사전보다 앞선 출처이므로 鄰은 사전 대조가 아니라 교과서 영상 대조로 넘긴다. 나머지 1,327자는 영상을 요청하지 않았다.
- **국내 사전:** [e-hanja 공개 상세 페이지](http://www.e-hanja.kr/e-hanja/dic/contents/jajun_content.asp?hanja=%E6%96%9D&keyword=%E6%96%9D)가 호출하는 AJAX 응답에서 실제 연결 SVG 주소를 추출했다. 1,328자 모두 HTTP 200·정확한 title·타이밍·클립 대응을 확인했고, 1,311자는 표시 획수·외곽선 수·애니메이션 경로 수·누적 단계 이미지 항목 수가 배정 획수와 일치했다. 누적 이미지 본문이나 모든 획의 실제 재생을 확인했다는 뜻은 아니다.
- **경로 후보:** 고정 버전 Make Me a Hanzi와 AnimCJK Ja·Ko·ZhHant·ZhHans를 다운로드해 해시와 구조를 확인했다. MM은 648자(획수 일치 552), Ja는 440자(399), Hans는 507자(416), Hant는 12자(12), Ko는 1자(冂, 1)다. 적어도 하나의 후보가 획수까지 일치하는 문자는 687자다.

경로만 보면 획수 불일치가 **88자·1,137획**, 미확보가 **553자·8,131획**이다. 이 중 사전 자체의 획수 차이도 있는 글자(불일치 2자·미확보 9자)는 위 작업 표의 17자에 먼저 배정했다. 표의 86자·544자는 이 중복을 뺀 값이다. 두 원래 분류는 [summary.json](summary.json)과 각 inventory에 보존했다.

## 후보 미확보 544자 — 특급의 진짜 벽

부수로 보면 木 37·艸 23·人 23·水 22·糸 21·馬 21·心 20·金 19·口 17·言 17자다.
檟·瞯·衎·矙·槩·鏗·賡·硜·秔·臄처럼 현대 중국어·일본어 상용 범위 바깥의 벽자가 대부분이라, 폰트 기반 말뭉치 다섯이 모두 비어 있다.
특급II의 201자([hanja-special2-queue-2026-09-20](../hanja-special2-queue-2026-09-20/README.md))가 인명용 한자·국자였던 것과 결이 다르다 —
이쪽은 한국에서만 쓰는 글자가 아니라 **어디서나 드문 글자**다. 새 라이선스 원본을 찾지 않으면 특급 천장은 **784자(59%)**다.

## 후보 획수 차이 86자 — 艹가 40자

81자는 정확히 한 획 차이이고 후보 쪽이 한 획 적다. 그중 艹 부수가 40자(葭·蒹·苓·莅·藐·蘩…)로, 배정과 사전은 艹를 4획으로 세고 MM·Ja·Hans는 3획으로 그리는 특급II와 같은 자리다.
나머지 41자는 邑·阜(阝)·辵·食 등이며, 이것도 부수 획수를 세는 방식 차이다.
한 획 차이가 아닌 다섯은 嘅(배정 14 / MM 12)·蘧(21 / 19)·莒(11 / 9)·曁(16 / Ja 17)·頤(15 / MM 16)다.

## 다음 묶음

**斝~觳 50자·618획**을 [next-batch.json](next-batch.json)에 정리했다. 카탈로그 순서를 유지하며 사전 획수 일치와 후보 경로 획수 일치를 모두 만족하는 문자만 포함했다.
같은 획수 후보가 여럿이면 `matchingCandidates`에 전부 적고, 시작점은 **Ko → Ja → Hant → MM → Hans** 순이다(이번 50자는 Ja 23·MM 20·Hans 5·Hant 1·Ko 1).
1급 24차·특급II 19차에서 보류 대부분이 MM 자형 차이였고 Ja가 사전 자형과 같았기 때문에 Ja를 MM보다 앞에 뒀다.
그래도 회차에서는 고정 순서 대신 **사전과의 획별 방향 거리**로 후보를 고른다. 선택은 검토 시작점이며 적합 판정이 아니다.

검토 가능한 680자 중 획수가 맞는 후보가 MM 하나뿐인 글자가 108자, Ja 하나뿐이 89자, Hans 하나뿐이 33자다. 이 230자는 바꿔 볼 원본이 없으니 자형이 다르면 보류로 남는다.

첫 획부터 마지막 획까지 사전 재생 순서와 후보 경로의 방향·획 경계·최종 자형을 대조한다. SVG의 XML 나열 순서는 재생 순서와 다를 수 있으므로 공개 CSS에서 확인한 --d(지연)·--t(길이)를 기준으로 실제 재생을 확인해야 한다.

e-hanja는 국내 민간 사전이며 한국어문회 필순 인증으로 표기하지 않는다. 사전 SVG·영상·누적 이미지 경로를 앱에 복사하지 않았고, 후보 데이터의 라이선스와 출처 구분은 유지한다. title·HTTP·획수·타이밍 메타데이터 일치는 전체 획의 시각 검토를 대신하지 않는다.

- [verify.mjs](verify.mjs): 카탈로그 해시·1,328자 유일성·분류 누락/중복·획수 합계·출처/후보 핀 다섯·재시도 이력·첫 50자 선정 조건을 [expected.json](expected.json)의 수치와 대조한다.

검증 명령: `node docs/hanja-special-inventory-2026-09-20/verify.mjs --runtime-baseline`

조회 스크립트는 원격 자료를 메모리에서 분석해 결과만 출력한다. 검증은 저장된 inventory를 사용한다. 네트워크 재조회에서는 일시 오류나 출처 변경으로 결과가 달라질 수 있다.
