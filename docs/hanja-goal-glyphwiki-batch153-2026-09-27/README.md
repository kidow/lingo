- 고정 엔진 8파일 재현, 테스트 239파일/1,063개 및 격리 빌드·타입 검사·정적 7페이지 생성 통과.
- 모바일 소개/쓰기 자동재생·다시 재생·8/8 완료, 오버레이 비중첩, 캔버스 0→1→0 및 시트 고정 확인.
- JEV는 보조 분류이며 런타임 승인 권한 없음. 비공개 그래픽은 RAM에서만 사용.
