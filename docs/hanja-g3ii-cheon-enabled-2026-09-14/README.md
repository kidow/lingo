# 遷 15획 서비스 데이터 반영

2026-09-14: [검토를 마친 15획 후보](../hanja-g3ii-cheon-paths-2026-09-13/README.md)를 기존 `moyaland-numbered` 등록부에 추가했다. 遷을 학습하거나 쓰기 연습할 때 공통 필순 플레이어가 15개 경로를 받을 수 있다.

## 적용한 내용

- **경로**: 검토 후보의 해시 `ad14e4955ce0585f21eb3481c280d47b960c44e974ded49c33f0e9ed898d38ba`와 정확히 같다. MM 원본은 14획으로 보존하고, 원본 13획을 공유점에서 둘로 나누며 11획 끝점만 보정한다. 기존 3개 번호 도해 한자의 원본·재생 데이터는 변경하지 않았다.
- **근거**: 遷 전용 출처·방향 검토 기록을 연결했다. 국내 번호 도해와 대만 교육부의 동일 자형 방향 자료를 대조한 결과이며, 한국 시험기관의 공식 인증으로 표시하지 않는다.
- **검사**: 빌드 전 출처·레시피·검토 결과·고정 경로의 파일 해시를 확인하고, 실제 원본에서 재생 경로를 다시 만들어 비교한다. 잘못된 14획, 원본을 그대로 15획으로 표시한 자료, 원본 순번을 1~15로 바꾼 매핑, 다른 한자의 출처, 11획 방향을 되돌린 경로를 거부한다.

교육부의 외곽·Track·미디어·코드는 포함하지 않았다. 실행 기하는 기존 Make Me a Hanzi의 Arphic Public License 자료와 검토한 보정만 사용한다. [라이선스](../../public/hanja-strokes/ARPHICPL.txt)와 [원본 고지](../../public/hanja-strokes/MAKEMEAHANZI-COPYING.txt)를 유지한다.

이전 후보 검토의 `runtimeApproved: false`와 당시 1,489자 기준 검증 결과는 **그 시점의 기록**으로 보존했다. 현재 적용 여부는 이 반영 기록과 실행 등록부, 아래 테스트를 기준으로 확인한다.

## 검증 결과

- `node --test lib/hanja*.test.ts`: 29개 파일, **192개 통과**.
- `pnpm run build`: 출처 검사, Turbopack 컴파일, TypeScript 검사, 정적 페이지 생성 성공.
- 생성된 `out/`을 로컬로 제공해 390×844 브라우저에서 실제 제품을 확인했다. 한능검 → 찾기 → 遷 상세에서 **1/15 → 15/15** 재생과 다시 재생 시 **1/15** 복귀를 관찰했다. 콘솔 오류·경고는 없었다.
- 쓰기 바텀시트의 공통 자동 재생은 첫 학습 카드 **校**로 회귀 확인했다. 遷 자체의 쓰기 시트에 직접 진입한 브라우저 확인은 하지 않았으며, 遷의 15획 데이터 조회와 쓰기 컴포넌트의 공통 연결을 코드·테스트로 확인했다.
