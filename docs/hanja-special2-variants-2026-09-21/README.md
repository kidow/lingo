## 무엇을 확인했나

e-hanja 공개 상세 페이지를 문자별로 POST해 `iframe#svgAni`가 가리키는 URL을 다시 얻었다.
URL은 추측하지 않았다. 35자 모두 HTTP 200, 표제 글자·표시 획수·윤곽 수·애니메이션 수가 일치했다.
시간 지연과 지속 시간을 기준으로 순서를 정렬했으며, 시간 중첩과 클립 누락이 없었다.
**35개 SVG 해시는 9월 18일 조사와 모두 동일**했다. 스타일시트의 시간 변수 해석도 다시 확인했다.

MM와 AnimCJK Ko·Ja·Hans·Hant 다섯 원본은 고정 리비전과 SHA-256을 확인했다.
사전 획수와 같은 후보에 대해서만 획 순서대로 시작점→끝점 방향을 비교했다.
사전과 후보의 Y축 방향을 맞춘 뒤, 60도를 넘거나 방향 벡터가 0인 획을 추가 검토 대상으로 분류했다.

이 검사는 **획 내부 굴곡·갈고리 방향·경로 위치·누적 자형·한국에서 인정되는 자형을 검증하지 않는다.**
방향이 유사한 획끼리 순서가 바뀌어도 놓칠 수 있다. 그러므로 16자는 시각 검토의 우선순위일 뿐 승인 목록이 아니다.
