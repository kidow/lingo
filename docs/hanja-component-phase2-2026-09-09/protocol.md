# 부품 합성 2차 실험 — 평가 규칙

이 문서는 신규 평가 점수를 확인하기 전에 고정한 절차다. 실제 결과는 별도 보고서와 result.json에 기록한다.

- 원본: 승인 애니메이션 743자와 기존 IDS 스냅샷. 신규 한자의 외국 필순·획 좌표는 입력하지 않는다.
- 개발 집합: 1차 실험의 100자. 이미 확인한 결과이므로 독립 평가라고 부르지 않는다.
- 신규 평가: 개발 집합과 겹치지 않는 100자를 배치 코드 수정과 위치형 부품 검토보다 먼저 고정했다.
- 분할 파일: `scripts/hanja-component-phase2-split.json`.
- 분할 SHA-256: `a398a419b5a720350c03032e2d438208824f51d236170c2a1f9e92587123ae85`.
- 위치형 부품 검토는 초기 분할의 허용 원본 389자 안에서 시작한다. 이 목록은 상한이며 아래 누출 방지 보강으로 실제 평가 원본은 더 줄어든다.
- 검토한 부품의 원본 해시, 최종 승인 경로의 1부터 시작하는 인덱스, 위치, 검토 범위를 기록한다. upstream 인덱스는 출처 정보이며 정렬·중복 제거하지 않는다.
- 배치는 원본 전체에서 해당 직접 부품이 차지하는 영역 비율을 사용한다. 다른 부품 안에 중첩된 부분을 전체 글자의 직접 부품 위치로 재분류하지 않는다.
- 위치 프로필이 없으면 독립 글자의 종횡비를 유지해 셀 안에 맞춘다. 새 글자별 수동 보정값은 추가하지 않는다.
- 20자 개발 시안의 정적 비교에서 셀별 맞춤만으로 글자 전체가 납작하거나 좁아지는 문제가 보여, 조립 후 전체 경계 상자를 표시 영역에 한 번 맞춘다. 부품 간 상대 비율을 유지하고 좌표 변환 이력을 갱신하며, 이 최종 단계에서 간격을 줄이는 축소는 보류한다.
- 부품 사이에는 중심선 기준 최소 6 단위 간격을 둔다. 이는 두께 5인 선의 겹침을 줄이기 위한 제약이며 원본 자형을 보장하지 않는다.
- 개발 집합과 20자 시안을 확인한 뒤 구현 파일 해시를 고정하고 신규 평가를 실행한다. 신규 점수 확인 뒤 재조정하면 독립 평가가 끝난 사실을 기록한다.
- v1과 v2는 동일한 집합과 제외 원본을 사용한다. 생성 실패는 다른 글자로 교체하지 않는다.
- 신규 점수 확인 전, IDS에 미확인 부분 `？`가 있으면 알려진 형제 부품까지 검사에서 빠지던 v1의 한계를 발견했다. 2차 비교에서는 미확인 부분을 그대로 둔 채 알려진 이름과 하위 트리를 재귀 추적하고, 추가 제외를 v1·v2 양쪽에 동일하게 적용한다. 최초 1차 실험 결과는 덮어쓰지 않는다.
- 軍·春에서 추출한 부품은 원본 검토 기록과 20자 시안에는 사용할 수 있지만, 신규 평가의 알려진 목표 부품을 포함하므로 해당 평가에서는 제외한다. 실제 추가 제외 목록과 원본 수는 result.json에 보존한다.
- 기하 선별 기준은 v1과 같다: 획수 일치, 순서·방향 일치율 1, 평균 거리 ≤8, 최대 획별 평균 거리 ≤16.
- 위 수치는 중심선 근사 비교다. 한국 필순의 정답률, 교과서 검증 또는 전체 글자의 승인으로 해석하지 않는다.
- 20자 출력은 검토용 초안이며 런타임 승인 목록에는 추가하지 않는다.
