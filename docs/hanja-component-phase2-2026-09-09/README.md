# 한자 부품 합성 2차 실험

기존 승인 743자의 획을 재사용하는 방식을 비교했다. **독립 평가 100자에서 v2는 6자를 생성했고, 기하 선별을 통과한 글자는 江 1자였다.** 현재 결과로 대량 적용하지 않는다. 런타임에 추가한 한자는 0자이며 기존 승인 743자를 유지했다.

## 결과

각 집합의 분모는 100자다. 생성은 경로 초안을 만들었다는 뜻이며, 기하 선별 통과도 한국 필순 승인이나 정답률을 뜻하지 않는다.

| 집합 | v1 생성 | v1 기하 선별 통과 | v2 생성 | v2 기하 선별 통과 |
|---|---:|---:|---:|---:|
| 개발 100자 | 10 | 3 | 12 | 8 |
| 독립 신규 100자 | 5 | 0 | 6 | 1 — 江 |

v2의 독립 평가에서는 나머지 94자를 생성 보류했다. 개발 100자는 이미 결과를 확인하며 개선에 사용했으므로 독립 성능으로 해석하지 않는다. 별도 시범 20자는 모두 생성하여 정적 검토했지만, 모두 새 글자 전체의 필순 검토를 기다리는 초안이다. 20자는 위 선별 통과 수에 포함하지 않았다.

## 평가 범위와 제한

- v1·v2에 같은 평가 집합과 도너 제외 규칙을 적용했다. 개발용 도너는 446자, 독립 평가용 도너는 352자다.
- 초기 독립 평가 도너 389자에서 불완전 IDS의 알려진 자식까지 추적한 뒤 목표 부분을 포함한 37자를 추가 제외했다. 미확인 부분은 임의로 복원하지 않았다.
- 위치형 부품 7종을 정적으로 검토했다. 軍·春은 강화된 누출 검사로 독립 평가에서 제외하여 해당 평가에는 5종을 사용했다. 두 부품의 검토 기록은 보존하고, 전체 승인 도너를 쓰는 별도 시범에는 사용할 수 있다.
- 목표 정답 경로와 외국 자료의 목표 획 좌표·`matches`는 생성 입력으로 사용하지 않았다. 기존 승인 도너의 경로와 IDS 구조를 사용했으며, 중국 기준 IDS 자체는 한국 필순 근거가 아니다.
- 20자 개발 시안에서 부품을 셀 안에 맞춘 결과를 보고, 조립 후 전체 경계 상자를 표시 영역에 맞추는 정규화를 추가했다. 이후 구현을 고정하고 신규 100자를 평가했다. 신규 점수를 확인한 뒤에는 조정하지 않았다.
- 기하 선별은 획수 일치, 순서·방향 일치율 1, 평균 거리 ≤8, 최대 획별 평균 거리 ≤16을 사용한다. 중심선의 근사 비교이며 교과서 검증을 대신하지 않는다.
- Noto SVG는 자형 비교 참고용이다. 획 경계·필순의 근거로 사용하지 않았다.

## 재현

저장소 루트에서 실행한다. 아래 명령은 결과를 출력하거나 저장된 결과와 비교하며 런타임 데이터를 수정하지 않는다.

```sh
# 개발 100자 결과를 JSON으로 출력
rtk proxy node scripts/hanja-component-phase2.ts --development

# 고정된 독립 신규 100자 결과를 JSON으로 출력
rtk proxy node scripts/hanja-component-phase2.ts --json

# 독립 평가 결과와 저장된 result.json의 동일성 확인
rtk proxy node scripts/hanja-component-phase2.ts --check

# 최초 v1 실험 산출물과의 호환성 확인
rtk proxy node scripts/hanja-component-pilot.ts --check
```

`--check`는 다른 옵션과 함께 사용하지 않는다. 최초 v1 실험 결과는 이번 비교 결과로 덮어쓰지 않는다.
