# 위치별 한자 부품 정적 검토

2026-09-09. 기존 승인 도너의 최종 경로에서 **7종, 25획**을 배정했다. 도너 전체·선택 획 강조·선택 획만 표시한 그림을 실제로 확인했다. [검토 그림](component-review.svg), [레시피](../../scripts/hanja-component-reviewed-parts.json).

고정 split: `a398a419b5a720350c03032e2d438208824f51d236170c2a1f9e92587123ae85`. 검토에 사용한 7자는 당시 `allowedValidationDonors` 389자에 모두 포함됐다. 새 평가 100자와 제외 도너의 정답 경로는 검토하지 않았고 외국 말뭉치의 획 인덱스·`matches`·목표 정답 경로로 부품을 정하지 않았다. 인덱스는 `HANJA_STROKES`의 **최종 paths에 대한 1부터 시작하는 번호**다. 상류 원본 획 번호가 아니다.

강화된 누출 검사에서는 불완전 IDS의 알려진 자식까지 추적하여 **軍·春을 독립 평가 도너에서 추가 제외**한다. 두 레시피는 초기 허용 목록에서 수행한 정적 검토 사실로 보존하지만 독립 평가에서는 건너뛴다. 전체 승인 도너를 사용하는 별도 시범 합성에서만 사용할 수 있다. 독립 평가에 남는 위치형은 5종이다.

위 구조에서 선택 부품은 도너 전체의 최상위 좌우·상하 구분에 직접 속한다. `？`는 알려지지 않은 형제 부분으로 남겨 두며 복원하지 않았다. 구조 메타데이터는 고정 [Make Me a Hanzi dictionary](https://raw.githubusercontent.com/skishore/makemeahanzi/bddc96d41bef78427ed0e034e9f7e31d71fd1b92/dictionary.txt)를 사용하는 통합 파이프라인의 루트 구조 확인과 대조했다. 이것은 중국 기준 분해 정보이며 한국 필순 근거가 아니다.

## 근거 경계와 재현

경로를 추가·변형·재정렬하지 않았다. 그림의 파란 획은 승인 도너의 경로 문자열 그대로이며 선폭 5, 둥근 끝과 접합으로 표시했다. 純의 糹는 조회 키다. 도너의 실제 여섯 획, 특히 아래 중앙 세로획과 양쪽 획을 그대로 보존했으며 중국식 점 세 개로 교체하지 않았다.

이번 검토는 **기존 승인 경로의 정적 부품 배정**이다. 새로 원본 필순 영상을 대조한 검토가 아니며, 새 한자 전체의 필순·방향·접합·자형 또는 다른 위치로의 전이가 맞는다는 승인이 아니다. 합성 결과는 별도 평가·개별 검토가 필요하고 현재 앱에 출시하지 않는다.
