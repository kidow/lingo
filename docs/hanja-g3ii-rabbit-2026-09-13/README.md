# 兔 8획 자형 충돌 해소와 재생 적용

2026-09-13. 兔 1자·8획을 추가했다. 전체 **1,488/5,978자**, 3급II **498/500자**다. 이 급수의 미적용 문자는 **遷·弊**다.

## 보류를 해소한 근거

기존 국내 교재 p111의 상단은 刀형인데, 앞서 본 사전 `5154.svg`는 왼쪽 내려긋기가 먼저인 다른 상단이었다. 기존 후보의 첫 두 획을 바꾸기만 해서는 교재 자형과 획 방향이 맞지 않았다.

이번에는 다음 세 근거를 함께 확인했다.

1. 한국어문회 [2017년 상담](https://www.hanja.re.kr/klea/counsel/hanjaDetail.do?id=9815)은 질문에서 구분한 刀형과 色 윗부분 모양을 모두 허용한다. [2008년 답변](https://www.hanja.re.kr/klea/counsel/hanjaDetail.do?id=6041)은 두 정자 형태의 8획을, [2015년 답변](https://www.hanja.re.kr/klea/counsel/hanjaDetail.do?id=9388)은 정자 兔 8획을 기준으로 삼는다는 점을 뒷받침한다.
2. 국내 사전에서 직접 兔를 검색한 뒤 동자 링크를 따라가, 교재와 같은 刀형 상단의 [별도 8획 애니메이션](http://img.e-hanja.kr/hanjaSvg/aniSVG/2F800/2F80F.svg)을 확인했다. 1–8획을 모두 관찰하고 1·4·6·7획의 끝 구간도 대조했다. 동양북스 교재는 앞선 검토 기록과 대조했으며 이번에 PDF를 새로 렌더링했다고 주장하지 않는다.
3. [Unicode 17.0.0](https://www.unicode.org/Public/17.0.0/ucd/UnicodeData.txt)의 U+2F80F 정규 분해 대상은 U+5154다. 사전의 동자 관계와 실제 자형·8획 관찰을 함께 사용했고, 유니코드 정규화만으로 필순을 승인하지 않았다. 앱 식별자는 계속 **兔(U+5154)**다.

한국어문회의 답변은 **자형 허용 근거**이고, 국내 사전 영상은 **개별 필순·방향 대조 근거**다. 사전 애니메이션이 시험기관의 인증을 받았다는 뜻은 아니다. 兎·免이나 다른 한자에는 이 판정을 확대하지 않는다.

## 경로와 검증

- Make Me a Hanzi의 고정 원본 8획을 원격 해시와 재대조했다. 3·4·5·6·8획은 기존 정규화 경로를 그대로 보존한다.
- 1·2획은 刀형 상단으로, 7획은 아래 가로획에 확실히 닿는 갈고리로 새로 작성했다. 이 세 획의 원본 인덱스는 `null`이다.
- 선 두께 5로 8개 누적 단계와 420px 완성형을 검토했다. 갈고리 접점과 마지막 점의 독립성을 수치 검사에도 포함했다.
- 사전의 그림·윤곽·중심선·스크립트·스크린샷은 저장하거나 배포하지 않는다. 출처와 해시, 재생 상태 수치, 자체 관찰만 기록했다.
- 기존 정적 글꼴 SVG의 시각 대조는 자동 승인 검토의 보안 차단으로 수행하지 않았다. 이 파일을 다른 경로로 열지 않았고, 후보 검토 페이지에도 포함하지 않았다.

파일: `sources.json`은 출처, `form-resolution.json`은 자형 선택 근거, `observations.json`은 실제 관찰, `originals.json`·`corrections.json`·`candidate-paths.json`은 기하 재현 자료, `review.json`은 개별 승인 기록이다. `review.html`은 자체 후보 검토 화면이다.
