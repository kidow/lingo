## 검증

- 공개 번들 재현 및 네 글자의 런타임 연결을 확인했다. 한자 테스트 **780/780개**, 타입 검사, 독립 체크아웃의 프로덕션 빌드가 통과했다. 빌드에 사용한 런타임 등록부·새 모듈·공개 번들은 작업 트리와 바이트가 같다.
- 실제 HanjaCard를 사용하는 임시 제품 화면에서 네 글자의 학습 자동재생, 다시 재생, 쓰기 바텀시트 진입 자동재생 및 다시 재생이 각각 1획부터 마지막 획까지 완료되는 것을 확인했다. 최종 카운터는 饑 21/21, 鏤 19/19, 陞 10/10, 鮟 17/17이었다.
- 饑 쓰기 화면에서 정적 자형 중첩이 없음을 확인했다. 캔버스를 드래그하면 0획→1획으로 바뀌며 시트 위치·크기가 유지되고 `touch-action: none`이었다. 네 검증 탭의 콘솔 오류는 0건이다. 데스크톱 Chrome 검증이며 실제 모바일 기기 검증으로 주장하지 않는다.
- UI 코드와 재생 속도는 변경하지 않았다. 앞서 통과한 검사는 관련 파일이 동일함을 확인하여 재실행하지 않았다. 임시 검증 자원의 정리 상태와 커밋 조회 방법은 상위 goal의 `progress.json`에 기록한다.
