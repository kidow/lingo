## 국소 보정 9획 6자

| 보정 | 글자 | 내용 |
| --- | --- | --- |
| 火의 첫 점 | 焱·縈 | 왼쪽 아래로 반전 (각 1획) |
| 亠의 첫 점 | 嬴 | 세로로 (1) |
| **羽 안쪽 넷** | 羿 | 점 둘(2·5)은 반전, 올려 긋는 획 둘(3·6)은 역방향으로 |
| 隹의 짧은 획 | 雝·廱 | 오른쪽 위 획을 왼쪽 아래로 반전 (雝 13, 廱 16) |

**羽가 네 회차 연속 나왔다** — 4차 僇, 5차 翻, 7차 熠, 이번 羿.
사전은 네 획을 모두 왼쪽 아래로 떨어뜨리고 말뭉치는 한쪽에 점 하나와 올려 긋는 획 하나를 쓴다.
점은 반전, 올려 긋는 획은 역방향이 네 번 모두 같았다.
火의 첫 점도 선례대로이고, 隹·亠는 霍·雞·售·稟과 같다.

蕘은 사전 그림이 `translate(12, -830)`로 가로 오프셋을 가진다.
[4차](../hanja-special-batch4-2026-09-20/README.md) 이후 회차마다 한둘씩 나오고, 대조에는 영향이 없다.

부수 유사성으로 승인하지 않았다. 쉰 글자의 사전 전체 필순을 순서대로 보고,
색으로 나눈 25% 진행 구간에서 방향·펜 떼기·획 경계·완성 자형을 대조했다.
[direction-probe.mjs](direction-probe.mjs)의 60° 초과 표시는 후보 교체·교환·보정으로 모두 해소했다.
끝점 배정 검사는 같은 세 교환을 찾았고 각도 검사가 놓친 것은 없었다.
공개한 순서·경로로 다시 재면 60°를 넘는 획이 없다.
45~60° 구간은 여섯 획(兗 1, 縈 5·11, 贏 1, 廱 1, 垸 4)이고, 이전 회차와 같은 기준으로 그대로 뒀다.
