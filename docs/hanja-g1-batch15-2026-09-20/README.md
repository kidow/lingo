[1급 14차 椅~嫡](../hanja-g1-batch14-2026-09-19/README.md)의 `next-batch.json`에 고정한 후보 50자를
같은 방식으로 대조했다. 첫 대조에서 43자가 일치했고, 6자는 보정 후 전체 획을 다시 확인했으며, 1자는 자형 차이로 보류했다.
승인 49자에서 허가된 중간선 662획을 유지하고 4획을 국소 보정했으며, 3자의 획 순서를 바꿨다.

## 보류

睛은 사전이 靑의 아래를 円으로 써서 위에서 가로까지 짧은 세로(12획)를 내리는데
허가된 MM 원본은 月로 그려 안쪽 가로가 둘이다.
순서·방향 조정으로 메울 수 없는 자형 차이라 鯖·猜와 같은 기준으로 보류했다.
같은 靑을 가진 靖은 사전도 月로 닫아 자형이 같고 순서도 일치해 그대로 승인했다.
보류 1자는 `next-batch.json` 후보에서 뺀다.

塡·顚(Ja)은 眞의 匕를 사전과 같은 순서로 쓰고, 箭·煎·剪의 丷은 양쪽 모두 안쪽으로 떨어져 그대로 뒀다.
霑의 雨 네 점은 사전이 납작하게 긋고 허가 원본이 떨어뜨리지만 임계 아래라 그대로 뒀다.

부수 유사성으로 승인하지 않았다. 각 글자의 사전 전체 필순을 순서대로 보고,
색으로 나눈 25% 진행 구간에서 방향·펜 떼기·획 경계·완성 자형을 대조했다.
보정 6자는 변경 획뿐 아니라 전체 획을 재대조했다.

[direction-probe.mjs](direction-probe.mjs)가 60°를 넘는 획 11개(7자)를 표시했고,
6자는 보정으로, 睛 1자는 보류로 이어졌다. 표시만 되고 그대로 둔 획은 없다.
纏·廛·癲처럼 덩어리로 얽힌 자리는 획 끝점 좌표를 숫자로 확인한 뒤 대응을 맞췄다.
45~60° 구간의 방향 차이는 14개였다. 모두 사전이 세로로 긋고 허가 원본이 기울여 쓰는 짧은 점(謫·迹·顫·纏·廛·癲·氈·錠·碇·穽·蹄)과
火·糸의 짧은 획(狄·纏·繰)으로, 이전 회차와 같은 기준으로 임계 아래는 허가된 중간선을 그대로 뒀다.
이번 회차 원문에는 가로 이동 변환이 없었다.
