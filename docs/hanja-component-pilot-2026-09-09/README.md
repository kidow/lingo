## 분할과 누출 범위

- 고정 해시 정렬로 좌우 25, 상하 25, 위치별 변형 25, 둘러싸기 15, 기타 10자를 먼저 선정했다. 결과를 보고 교체하지 않았다.
- 해당 100자 및 그 글자가 알려진 IDS 하위 부품·동일 구조로 나타나는 원본도 제외했다. NFC 비교도 적용했다.
- 확인되지 않은 이체 관계나 미상 분해까지 완전히 차단하는 것은 아니다. 따라서 알려진 IDS 범위에서의 제외라고 표현한다.
- 생성기는 목표 글자의 이름·획수·IDS 구조와 학습 원본의 경로만 받는다. 목표의 승인 경로·보정 레시피, 외국 graphics·matches·스케줄을 전달하지 않는다.
- Noto KR은 생성 후 모양 검토에만 사용했다. 생성 알고리즘의 배치 기준은 학습 원본에서 얻은 비율과 고정 기본값이다.
- 신규 20자는 평가 이후 승인 743자 전체로 만든 별도 시범이다. 100자 평가의 학습 원본과 혼동하지 않는다.

## 구현과 검사

최종 승인 SVG의 M/L/Q/C 경로를 다룬다. 원본 좌표에 쓰던 normalizeMedians를 다시 적용하지 않으며, 베지어 곡선과 펜을 떼는 경계를 보존한다. 원본 획 인덱스의 반복·명시적 null은 보존하고, 길이가 잘린 배열은 거절한다.

위치별 부품은 서로 떨어진 축 방향 구간이 유일할 때만 추정하거나, 囗 앞 2획·안쪽·마감 규칙으로 추출한다. 추출 자체는 승인되지 않은 자체 판단이다. 위치별 부품을 못 찾으면 같은 글자의 승인 독립형을 재배치하고 그 사실을 기록한다.

좌우·상하 및 囗 전체 둘러싸기만 지원한다. 다른 연산자·부품 누락·획수 불일치·공간 부족은 보류한다. 선폭 5와 여유를 포함한 최소 간격 6을 사용하며 중첩 둘레도 간격 검사를 한다. 라이브러리·부품 해시를 재확인한다.

평가 라이브러리에는 499개 템플릿이 있고 이 중 위치별 템플릿은 31개다. 전체 743자 시범 라이브러리는 별도로 생성한다. 동일 최종 원본 경로에서 추출한 번호와 외국 corpus의 원본 번호를 혼용하지 않는다.

기하학 비교는 호길이 표본과 최소 비용 일대일 대응을 사용한다. 평균/최대 거리는 100단위 좌표계에서 측정하고, 순서·방향은 대응의 대리 지표다. 정답으로 인정되는 필순 변형이나 접합의 언어적 타당성을 자동 판정하지 않는다. 기준은 실행 전에 정한 평균 거리 8 이하, 최대 획 평균 거리 16 이하, 순서·방향 지표 1이다. 화면에서 비슷해 보이거나 지표를 통과해도 승인 원장에 자동 승격하지 않는다.
