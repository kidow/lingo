# 특급II 塢~蕓 50자 검토 — 50자·653획 반영

2026-09-18 · **50자 전부 반영, 보류 없음**

[9차 齷~鰲](../hanja-special2-batch9-2026-09-18/README.md)의 `next-batch.json`에 고정한 후보 50자를
같은 방식으로 대조했다. 첫 대조에서 41자가 일치했고, 9자는 보정 후 전체 획을 다시 확인했다.
허가된 중간선 644획을 유지하고 9획을 국소 보정했으며, 5자의 획 순서를 바꿨다.
MM 원본 38자, Ja 원본 12자에서 출발했다. 이번 회차에는 보류한 글자가 없다.

## 보정

| 보정 대상 | 변경 |
| --- | --- |
| 窩·嵬 | 안쪽 가로획을 안쪽 세로획보다 먼저 (8·9, 7·8획 교환) |
| 蕓 | 艹의 十 둘을 각각 가로 다음 세로 (1·2, 3·4획 교환) |
| 繇 | 䍃의 두 번째 긴 삐침을 짧은 획 둘보다 먼저 (4획 → 2번째) |
| 燿 | 隹의 안쪽 가로 셋을 긴 세로획보다 먼저 (15~17획 재배열), 羽 안쪽 네 획(6·7·9·10) 역방향, 隹의 오른쪽 위 짧은 획(13) 반전 |
| 窪 | 穴의 첫 점(1획)을 세로점으로 보정 |
| 饔·癰 | 雍의 隹 옆 짧은 획(8획, 18획)을 왼쪽 아래 방향으로 반전 |
| 縟 | 糸 아래 왼쪽 점(5획)을 왼쪽 아래 방향으로 반전 |

9차에서 敖의 가로획과 획 순서를 보정했던 것과 달리, 이번 회차의 鼇·熬·敖는
모두 Ja 원본이라 사전과 순서가 같아 그대로 뒀다. 翫의 羽도 Ja가 사전과 맞는다.

부수 유사성으로 승인하지 않았다. 각 글자의 사전 전체 필순을 순서대로 보고,
색으로 나눈 25% 진행 구간에서 방향·펜 떼기·획 경계·완성 자형을 대조했다.
보정 9자는 변경 획뿐 아니라 전체 획을 재대조했다.

[direction-probe.mjs](direction-probe.mjs)가 60°를 넘는 획 21개(9자)를 표시했고,
9자 모두 보정으로 이어졌다. 표시만 되고 그대로 둔 획은 없다.
羽·隹·䍃처럼 덩어리로 얽힌 자리는 획 끝점 좌표를 숫자로 확인한 뒤 판정했다.
사전이 세로로 긋고 허가 원본이 기울여 쓰는 짧은 점이 45~60° 구간에 20개 더 있었다.
1~9차와 같은 기준으로 임계 아래는 허가된 중간선을 그대로 뒀다.
蕓의 원문은 가로 이동 `translate(12, -y)`를 쓴다. 이동은 방향 벡터를 바꾸지 않는다.
