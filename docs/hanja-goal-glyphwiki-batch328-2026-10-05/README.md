# Batch328: 蕁16획 적용 보류

브라우저 패널236에서 국내16획 순서·방향·누적·완성 자형을 대조했습니다. 패널237의15획 아홉 진행 상태와99/100% 확대 비교에서 갈고리의 왼쪽 끝이 완료 때 갑자기 나타났습니다. 원본 u5bf8-04의 끝 윤곽이 원본 Q 중심선 끝보다20 단위 더 왼쪽으로 뻗습니다. 기존14 폭 마스크로는 해당 윤곽을 순차 노출하지 못합니다.

전체 후보8개 가운데 국내4획 艸인 u8541-k/ue0102는 동일한 하단 전체 원본을 공유합니다. 나머지는3획 u8279-03이며, 일부는 u5c0b@4가 미확보입니다. 국내4획에 맞추려고 원본 가로획을 분할하거나 다른 윗부분을 이식하지 않았습니다. 원본 좌표·다각형·폭·중심선은 변경하지 않았습니다.

공개 전체 소스9개, 고정 엔진8개 해시,18그룹/19프리미티브·16펜, 미등록 상태 및 실패 윤곽 재현 검사가 통과했습니다. 144개 전부를 승인하지 않았고 런타임·공유 등록 코드는 변경하지 않았습니다. 이 연구 배치에서는 빌드·회귀 검사를 추가 실행하지 않았습니다. 사전 그래픽·스크린샷은 RAM에만 존재했습니다.
