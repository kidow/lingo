# 특급II 1,150자 필순 출처·후보 전수 목록

확인일: 2026-09-18. 대상은 특급II에 새로 배정된 **1,150자·15,002획**이다. 2급 조사([hanja-g2-inventory-2026-09-15](../hanja-g2-inventory-2026-09-15/README.md))와 같은 절차·같은 출처·같은 분류다. 이번 회차에는 획별 시각 검토나 애니메이션 추가를 하지 않았다.

공개 국내 사전에서 1,150자 모두의 필순 SVG에 접근했다. 이 중 **811자·10,496획**은 사전 메타데이터와 라이선스가 있는 후보 경로의 획수가 배정 획수와 일치하여, 전체 획 검토를 시작할 수 있다.

| 다음 작업 분류 | 문자 | 배정 획수 |
| --- | ---: | ---: |
| 전체 획 순서·방향·경계·자형 검토 | 811 | 10,496 |
| 국내 사전과 배정 획수 차이 검토 | 35 | 492 |

## 왜 네이버가 아니라 e-hanja인가

네이버 한자사전의 필순 애니메이션에는 `©2020.(e-hanja)` 표시가 있다 — 네이버가 보여주는 그림의 원본이 e-hanja다. 네이버는 `robots.txt`로 ClaudeBot·Claude-SearchBot을 전부 막고 `entry` 경로는 모든 봇에 닫혀 있어 자동 조회를 하지 않는다([spec.md](../../spec.md)의 사전 규칙). 원본인 e-hanja는 2급까지 써 온 경로 그대로다. 사전 SVG는 순서·방향 대조에만 쓰고 런타임 기하로는 쓰지 않는다.

## 출처와 경로는 따로 집계한다

- **배정 기준:** 기존 [한국어문회 배정 자료](https://www.hanja.re.kr/kccpt/exam/levelConfirm.do)의 카탈로그와 해시를 그대로 사용했다.
- **교과서:** [비상교육 고등 한문 공개 자료](https://text.vivasam.com/detail/186)의 고정된 1,800자 목록에 특급II는 **넷**이 있다 — 凉·秘·鐘·戱. 2급은 한 자도 없었다. 넷 다 영상이 HTTP 200으로 존재한다(HEAD만, 완전성 검증 아님). 교과서는 사전보다 앞선 출처이므로 이 넷은 사전 대조가 아니라 교과서 영상 대조로 넘긴다. 나머지 1,146자는 영상을 요청하지 않았다.
- **국내 사전:** [e-hanja 공개 상세 페이지](http://www.e-hanja.kr/e-hanja/dic/contents/jajun_content.asp?hanja=%E7%97%82&keyword=%E7%97%82)가 호출하는 AJAX 응답에서 실제 연결 SVG 주소를 추출했다. 1,150자 모두 HTTP 200·정확한 title·타이밍·클립 대응을 확인했고, 1,115자는 표시 획수·외곽선 수·애니메이션 경로 수·누적 단계 이미지 항목 수가 배정 획수와 일치했다. 누적 이미지 본문이나 모든 획의 실제 재생을 확인했다는 뜻은 아니다.
- **경로 후보:** 고정 버전 Make Me a Hanzi와 AnimCJK Ja·Ko를 다운로드해 해시와 구조를 확인했다. MM은 808자(획수 일치 668), Ja는 794자(679), Ko는 0자다. 적어도 하나의 후보가 획수까지 일치하는 문자는 818자다.

경로만 보면 획수 불일치가 **106자·1,382획**이다. 이 중 19자는 사전 자체의 획수 차이도 있어 위 작업 표의 35자에 먼저 배정했다. 표의 87자는 이 중복을 뺀 값이다. 두 원래 분류는 [summary.json](summary.json)과 각 inventory에 보존했다.

## 다음 묶음

**痂~勍 50자·643획**을 [next-batch.json](next-batch.json)에 정리했다. 카탈로그 순서를 유지하며 사전 획수 일치와 후보 경로 획수 일치를 모두 만족하는 문자만 포함했다. 같은 획수 후보가 여럿이면 기존 기준 Ko → MM → Ja 순으로 우선 선택한다(이번 50자는 MM 41·Ja 9). 선택은 검토 시작점이며 적합 판정이 아니다.

첫 획부터 마지막 획까지 사전 재생 순서와 후보 경로의 방향·획 경계·최종 자형을 대조한다. SVG의 XML 나열 순서는 재생 순서와 다를 수 있으므로 공개 CSS에서 확인한 --d(지연)·--t(길이)를 기준으로 실제 재생을 확인해야 한다.

e-hanja는 국내 민간 사전이며 한국어문회 필순 인증으로 표기하지 않는다. 사전 SVG·영상·누적 이미지 경로를 앱에 복사하지 않았고, 후보 데이터의 라이선스와 출처 구분은 유지한다. title·HTTP·획수·타이밍 메타데이터 일치는 전체 획의 시각 검토를 대신하지 않는다.

## 재현과 검증

- [audit.mjs](audit.mjs): 교과서 목록과 고정된 후보 말뭉치를 다시 조회하여 JSON을 표준 출력한다. 교과서에 실린 넷만 영상 HEAD를 확인한다.
- [dictionary-audit.mjs](dictionary-audit.mjs): 공개 페이지 → AJAX → 연결 SVG 메타데이터를 조회한다. [retry.mjs](retry.mjs)가 첫 결과를 받아 실패 행만 한 번 재시도한다.
- [plan.mjs](plan.mjs): 저장된 두 inventory에서 독립 상태 분류·작업 목록·첫 50자를 다시 산출한다.
- [verify.mjs](verify.mjs): 카탈로그 해시·1,150자 유일성·분류 누락/중복·획수 합계·출처/후보 핀·재시도 이력·첫 50자 선정 조건을 [expected.json](expected.json)의 수치와 대조한다.

검증 명령: `node docs/hanja-special2-inventory-2026-09-18/verify.mjs --runtime-baseline`

조회 스크립트는 원격 자료를 메모리에서 분석해 결과만 출력한다. 검증은 저장된 inventory를 사용한다. 네트워크 재조회에서는 일시 오류나 출처 변경으로 결과가 달라질 수 있다.

현재 적용은 **2,352/5,978자(39.3%)**, 미적용 **3,626자**다. 8급~3급은 완료, 2급 534/538, 1급 1/1,145, 특급II·특급은 0이다. 이번 작업 추가 적용은 0자이며 런타임·카탈로그는 변경하지 않았다. [progress.json](progress.json)에 급수별 수치를 기록했다.
