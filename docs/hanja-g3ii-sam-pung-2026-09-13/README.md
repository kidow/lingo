# 森·楓 2자·25획 검토 및 적용

2026-09-13. 森 12획과 楓 13획을 대조하고 애니메이션에 적용했다.
전체 적용은 **1,478→1,480/5,978자**, 3급II는 **488→490/500자(98%)**다.
전체 미적용은4,498자, 3급II 미적용은10자다.

## 근거와 경로

- [森 사전 원본](http://img.e-hanja.kr/hanjaSvg/aniSVG/6800/68EE.svg),
  [楓 사전 원본](http://img.e-hanja.kr/hanjaSvg/aniSVG/6900/6953.svg):
  e-hanja의 국내 사전 자료다. 한국어문회가 인증한 필순이라는 의미는 아니다.
- [앞선 12자 사전 대조](../hanja-g3ii-dictionary-12-2026-09-13/README.md)에서
  관찰한 두 글자의25개 움직이는 획 기록을 재사용했다. 이번 회차의 새 관찰로
  중복 계산하지 않았다. 두 원본을 다시 열어 후보의 누적25단계와 대조했고,
  원본 파일 해시·제목·바이트 수·전체 재생 구간25개를 온라인으로 재검증했다.
- 서비스 경로는 고정된 [Make Me a Hanzi 원본](https://github.com/skishore/makemeahanzi/tree/bddc96d41bef78427ed0e034e9f7e31d71fd1b92)에서
  가져왔다. 전체 원본의 해시를 확인한 뒤 두 글자의 중심선만 추출했다.
  기존 정규화 함수로 좌표를 맞췄으며 순서 변경·역방향·분할·병합·부수 이식은 없다.
- 森의 위 木→왼쪽 아래 木→오른쪽 아래 木 순서, 짧은8획과 긴12획을 구분했다.
  楓은 외곽6획의 연속 갈고리, 윗삐침7획, 중앙세로11획, 내부 虫의 접점을 대조했다.
  사전 글꼴과 기울기·비율은 다르지만 획 역할·방향·누적 구조의 충돌은 발견하지 못했다.
  픽셀 단위의 글꼴 일치나 필기 정답 판정의 검증은 아니다.

사전의 윤곽·중심선·스크립트·이미지는 복사하거나 배포하지 않았다.
기하 데이터의 출처와 Arphic 라이선스는
[공개 안내](../../public/hanja-strokes/dictionary-reviewed.README.md)에 명시했다.

## 기록과 검증

| 파일 | 역할 |
| --- | --- |
| [originals.json](originals.json) | 고정 원본 중심선과 해시 |
| [candidate-paths.json](candidate-paths.json) | 검토한25개 경로와 해시 |
| [review.json](review.json) | 획별 역할·방향·누적 구조의 판단과 근거 범위 |
| [review.html](review.html) | 시작·끝 표시를 포함한25단계 대조판. 이 폴더를 로컬 HTTP로 열어 사용 |
| [verify.mjs](verify.mjs) | 출처·원본·경로·관찰 기록·실제 적용을 읽기 전용으로 검증 |
| [verification.json](verification.json) | 이번 실행 결과 |

`lib/hanja-stroke-dictionary.ts`의 정확한 글자 허용 목록과 출처 메타데이터를
확장했다. `scripts/hanja-stroke-dictionary.ts`는 새 자료6개의 해시를 고정하고,
현재 원본에서 경로를 재구성해 공개 파일과 일치하는지 검사한다.
기존 訣·紋의 경로·근거 범위는 유지했다. 앞으로 다른 글자를 추가하려면
그 글자의 근거와 경로 검토가 별도로 필요하다.

검증 결과: 전용 검사8개, 전체 한자 검사168개 통과.
`node docs/hanja-g3ii-sam-pung-2026-09-13/verify.mjs --online` 통과.
`pnpm exec next build`의 컴파일·TypeScript·정적 페이지 생성 통과.
공유 콘텐츠를 생성하는 `pnpm run build`의 prebuild 전체는 실행하지 않았으며,
prebuild가 호출하는 사전 번들 검사는 별도로 실행했다.
