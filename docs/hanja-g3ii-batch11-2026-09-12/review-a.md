# Batch 11 — A 원문 검토

고정 배정 **蘭21·弄7, 합계2자·28획**을 승인했다. 원문 표기는 **蘭(U+F91F), 弄(U+F943)** 그대로 `record.sourceGlyph`와 `sourceReference.sourceGlyph`에 보존했다. 호환 문자 정규화는 검색에만 사용했고 실제 영상의 형태와 순서를 확인했다.

| 글자 | 원문 행 | 후보 | 원문 판단 |
|---|---:|---|---|
| 蘭 | 0391 | MM21 | 풀머리 왼 세로·왼 가로·오른 가로·오른 삐침 순서. MM3·4를 바꾼다. 門8획 뒤 중앙9획에서 점과 삐침을 각각 쓴다. Ja19의 두 합침을 채택하지 않았다. |
| 弄 | 0446 | MM7 | 위 가로·가운데 가로·세로·아래 가로·긴 가로·왼 삐침·오른 세로. MM 순서가 일치하고 Ja의2·3 순서는 다르다. |

새로 받은 개별 공식 영상의 전체2fps **75표본**, 모든 완료10fps 표본, 원문700px와420px를 직접 열람했다. 완료 시각은 표본 상한이다. 弄6은9.0초, 마지막 세로는10.8초로 보수적으로 기록했다.

실제 `textbookGeometry` 출력의 **누적28개·최종420px**를 굵기5와 둥근 끝/이음으로 렌더링해 확인했다. 접점·간격44개가 모두 통과했다. 蘭의 안쪽점16과 왼 틀14, 안쪽삐침17과 위/오른 틀15 사이의 흰 틈은700px 원문 확대에 맞춰 보정했다. 최소 중심선 거리는 각각5.842740·6.148280으로 실제 굵기에서도 틈이 남는다. 풀머리 첫 세로1/門꺾임6은 원문 접촉을 유지했다.

Ko·Ja·MM 전체 자료를 RAM으로 새로 받아 pinned SHA를 검증했다. 채택한 MM 원본 좌표와 해시를 정확히 보존했고, 모든 출력 획에 원본 번호를 연결했다. 원문 영상 SHA·전체 시각·recipe/경로 해시는 [review-a.json](review-a.json), 수치 근거는 [geometry-audit-a.json](geometry-audit-a.json), 누적 경로는 [review-a.svg](review-a.svg)에 기록했다.
