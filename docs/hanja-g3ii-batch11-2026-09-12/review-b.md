# Batch11 B — 蓮·嶺

고정 2자·기준 32획을 검토했다. 嶺 17획은 승인 제안, 蓮 기준 15획은 경계 불명확으로 보류한다.

- 개별 원문 전체를 RAM에서 새로 받아 2fps 81프레임을 모두 열람했다. 嶺 완료 17개와 蓮 연속 구간 14개의 10fps 표본, 蓮 경계 29개 표본도 실제 확인했다.
- 원문 蓮·嶺 표기를 record.sourceGlyph에 보존했다. 호환 글자 정규화는 검색에만 사용했다.
- 고정 Ko·Ja·MM corpus 전체를 새로 받아 SHA-256·용량을 검증했다. Ja/MM 완성 후보를 대조하고, 嶺 Ja17·蓮 MM14 원본 좌표 31획을 정확히 보존했다.
- 嶺 원문은 왼쪽 아래를 꺾어내린 hook 뒤 긴 세로로 쓴다. Ja7·8을 이 모습으로 명시 보정했다. 실제 생성기에서 17개 모든 누적 경로와 420px 완성형을 굵기 5·둥근 끝과 이음으로 렌더하여 열람했다.
- 두 원문 완성형을 420px, 嶺을 추가 700px로 열람했다. 嶺의 선택 접점·간격 26개는 수치 검사도 통과했다. 4·6획의 실제 잉크 간격은 0.43177, 3·9획은 1.78884, 7획 hook 끝·8획 세로는 1.12980 단위다.

蓮은 상부 11획과 점 다음 辶 꺾임이 15.2–15.4초, 16.2–16.4초 같은 점에서 정지했다가 이어진다. 독립 lift를 확인할 수 없어 이 정지를 분할 근거로 삼지 않았다. 14개 연속 구간 표본은 기준 15획을 증명하지 않는다. 승인 recipe와 15번째 출력 경로를 만들지 않았으며 고정 선택에 그대로 보류했다.

완료 시각은 실제 열람한 표본의 상한이며 정확한 pen-up 시각이 아니다. 상세 근거와 좌표는 [review-b.json](review-b.json), 원본·생성기 검사는 [b-source-audit.json](b-source-audit.json), 嶺 모든 누적 경로는 [review-b.svg](review-b.svg)에 있다. 공유 데이터와 Git은 수정하지 않았다.
