# 3급II Batch 11 검토 — 諾·蘭·蓮·戀·嶺·弄·率·吏

고정 요청 **8자·116획**을 검토해 **7자·101획을 적용**하고 **蓮 1자·15획을 보류**했다. 대체 한자는 추가하지 않았다.

| 諾 | 諾 | 16 | 적용 |
| 蘭 | 蘭 | 21 | 적용 |

蓮의 영상에서는 풀머리 4 + 車 7 + 辶 3의 **14개 연속 구간**만 확인됐다. 辶의 같은 지점 정지 후 재개만으로 별도 획 경계를 확정할 수 없어, 카탈로그 15획에 맞춘 임의 분할은 적용하지 않았다. 원본 14획 후보와 상세 관찰은 [B 검토](review-b.json), 독립 재검토는 [A 교차 검토](peer-a.json)에 남겼다.

모든 한자는 비상교육의 해당 글자 전체 영상과 완료 표본을 대조했다. 원문 호환 문자 표기·영상 행·파일명·SHA·바이트 수를 보존했으며 정규화는 후보 탐색에만 사용했다. 승인된 7자는 원본 좌표를 그대로 보관하고 명시적 보정과 원본 획 대응을 통해 생성했다. 실제 생성기의 101개 누적 상태와 최종 렌더링을 검토했고, 서로 다른 검토자가 고정 8자 모두를 교차 검토했다. 이 기록은 출판사 원문과의 대조이며 한국어문회의 인증을 뜻하지 않는다.

적용 후 **1,470/5,978자(24.6%)**, 미적용 **4,508자**다. 출판사 대조 데이터는 **967자**, 3급II는 **480/500자(96%)**가 적용됐다. 이전 출판사 데이터 960자, 이전 회차 문서 41개, 기존 등록부와 보정은 보존됐고 이번 7자만 추가됐다.

[검증 기록](verification.json): 한자 테스트 **134/134**, 타입 검사, 고정 원본을 새로 읽은 번들 재생성 일치, 프로덕션 빌드가 모두 통과했다. 다른 세션의 콘텐츠·코드 변경은 커밋 대상에서 제외한다.
