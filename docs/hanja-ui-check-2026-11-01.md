## 발견·수정

320×640에서 기존 고정 폭 캔버스 때문에 하단 정답 버튼이 y≈648~696으로 밀렸다. 쓰기 영역이 남은 flex 공간을 차지하고 그 안에서 정사각형 크기가 가로·세로·340px 중 작은 값으로 정해지도록 수정했다. `touch-action:none`과 `data-vaul-no-drag`는 유지했다.

수정한 프로덕션 빌드로 새로고침해 다시 확인했다.

- 320×640: 캔버스 약 202.22×202.22, 하단 버튼 bottom≈620로 화면 안에 표시.
- 354×767: 캔버스 약 310.41×310.41, 하단 버튼 bottom≈747.27로 화면 안에 표시.
- 수정 후 실제 입력·취소와 재생·표시 전환 정상. 재생 중 별도 한자 배경이 겹치지 않음.
- `pnpm run build`: 컴파일·타입 검사·정적 페이지 7개 생성 통과, 약 80초.

이번 수정은 쓰기 화면의 크기 배치에 한정된다. 직전 전체 테스트 5,220개 통과 기록과는 별도로, 이번 변경은 빌드 및 실제 브라우저 조작·좌표 측정으로 검증했다. 모바일 viewport 점검이며 실물 휴대폰 점검을 뜻하지 않는다.
