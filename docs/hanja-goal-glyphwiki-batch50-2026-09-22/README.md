# 萌 12획 원본 윤곽 적용

국내 사전의 전체 12획과 108개 중간 상태, 누적·완성 자형을 대조했다.
한국어문회 공식 확인으로 승격하지 않는 사전 교차검토다.

- 원본 `u840c-k@13` 및 의존 리비전 5건, KAGE 고정 엔진 8파일의 해시·출력을 재확인했다.
- 초두 순서를 국내 기준으로 교환하고, 원본에서 정확히 만나는 日·月 모서리를 한 획으로 재생한다.
- 月의 긴 왼쪽 곡선은 원본을 보존한다. 국내 사전보다 좌측으로 더 뻗지만 방향·꺾임·연결 구조가 같은 글꼴 비율 차이다. 접속이 달라지는 후보까지 허용한다는 의미는 아니다.
- 갈고리는 원본 곡선과 별도 왼쪽 윤곽을 순차적으로 드러낸다. 점·제어점·부수 경로를 새로 만들지 않았다.
