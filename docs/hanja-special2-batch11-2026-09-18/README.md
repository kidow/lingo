## 보류

**瑜**: 사전은 兪의 마지막 두 획을 巜(왼쪽 아래·오른쪽 아래로 꺾는 획 둘)로 쓰는데, 고정한 MM 후보는
刂(짧은 세로와 갈고리 세로)로 쓴다. 1~11획은 일치하지만 부수 자형 차이는 국소 보정으로 만들 수 없어
승인하지 않았다. g2 6차의 兪처럼 Ja 원본은 巜 형태를 쓰므로, 뒤에 Ja로 다시 고정하면 회복할 수 있다.
같은 회차의 逾는 Ja 원본이라 巜 형태가 사전과 같아 그대로 반영했다.
보류한 글자는 이후 회차의 후보 큐에서 뺀다.

부수 유사성으로 승인하지 않았다. 각 글자의 사전 전체 필순을 순서대로 보고,
색으로 나눈 25% 진행 구간에서 방향·펜 떼기·획 경계·완성 자형을 대조했다.
보정 12자는 변경 획뿐 아니라 전체 획을 재대조했다.

[direction-probe.mjs](direction-probe.mjs)가 60°를 넘는 획 28개(12자)를 표시했고,
12자 모두 보정으로 이어졌다. 표시만 되고 그대로 둔 획은 없다.
飴·贓·臧·牆처럼 덩어리로 얽힌 자리는 획 끝점 좌표를 숫자로 확인한 뒤 판정했다.
사전이 세로로 긋고 허가 원본이 기울여 쓰는 짧은 점이 45~60° 구간에 10개 더 있었다.
1~10차와 같은 기준으로 임계 아래는 허가된 중간선을 그대로 뒀다.
葦·瑋의 원문은 가로 이동 `translate(12, -y)`를 쓴다. 이동은 방향 벡터를 바꾸지 않는다.
