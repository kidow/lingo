# 1급 炒~笞 50자 검토 — 50자·672획 반영

2026-09-20 · **50자 반영, 보류 없음**

[1급 17차 篡~稍](../hanja-g1-batch17-2026-09-20/README.md)의 `next-batch.json`에 고정한 후보 50자를
같은 방식으로 대조했다. 첫 대조에서 32자가 일치했고, 18자는 보정 후 전체 획을 다시 확인했다.
허가된 중간선 655획을 유지하고 17획을 국소 보정했으며, 11자의 획 순서를 바꿨다.
MM 원본 42자, Ja 원본 8자에서 출발했다.

贅의 6획은 표시됐지만 양쪽 모두 같은 자리에 寸의 갈고리를 쓰고, 사전이 모서리에서 멈추는 데 비해
허가 원본이 왼쪽으로 되쓸어 나갈 뿐이어서 완성 자형이 같다. 허가된 갈고리를 그대로 뒀다.

부수 유사성으로 승인하지 않았다. 각 글자의 사전 전체 필순을 순서대로 보고,
색으로 나눈 25% 진행 구간에서 방향·펜 떼기·획 경계·완성 자형을 대조했다.
보정 18자는 변경 획뿐 아니라 전체 획을 재대조했다.

[direction-probe.mjs](direction-probe.mjs)가 60°를 넘는 획 47개(19자)를 표시했고,
18자는 보정으로 이어졌다. 표시만 되고 그대로 둔 것은 贅의 한 획뿐이다.
叢·撮·娶·錘·唾·黜처럼 덩어리로 얽힌 자리는 획 끝점 좌표를 숫자로 확인한 뒤 대응을 맞췄다.
45~60° 구간의 방향 차이는 14개였다. 모두 사전이 세로로 긋고 허가 원본이 기울여 쓰는 짧은 점(寵·贅·悴·幟·痔·癡·陀·舵·綻·宕)과
魚·糸·馬의 짧은 획(鰍·駝·綻)으로, 이전 회차와 같은 기준으로 임계 아래는 허가된 중간선을 그대로 뒀다.
蕩의 원문은 가로 이동 `translate(12, -y)`를 쓴다. 이동은 방향 벡터를 바꾸지 않는다.
