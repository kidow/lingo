# 특급II 牘~褸 50자 검토 — 48자·745획 반영, 牘·竇 보류

2026-09-18 · **48자 반영, 2자 보류**

[3차 竅~犢](../hanja-special2-batch3-2026-09-18/README.md)의 `next-batch.json`에 고정한 후보 50자를
같은 방식으로 대조했다. 첫 대조에서 38자가 일치했고, 10자는 보정 후 전체 획을 다시 확인했으며,
牘·竇 두 자는 자형이 달라 보류했다. 허가된 중간선 733획을 유지하고 12획을 국소 보정했으며,
5자의 획 순서를 바꿨다. MM 원본 43자, Ja 원본 7자에서 출발했다.

## 보류 — 牘·竇

3차의 犢과 같은 이유다. 사전은 賣의 가운데를 **四**로 쓰고(안쪽이 儿이라 한 획은 왼쪽으로 길게
삐치고 다음 획은 내려가다 오른쪽으로 꺾인다), 허가된 MM 원본은 **罒**로 안쪽이 짧은 세로 두 개다.
획 순서를 바꾸거나 한 획을 국소 보정해서 맞출 수 있는 차이가 아니라 구성 요소의 자형 차이다.
牘은 片·士·貝가, 竇는 穴·士·貝가 일치한다. 竇의 첫 획은 穴의 세로점으로 따로 보정할 수 있었지만,
같은 글자 안에 자형 차이가 있어 보정하지 않고 보류했다.
보류한 글자는 다음 회차 후보에서 뺀다. 지금까지 **犢·牘·竇** 세 자가 큐 밖에 있다.

良의 첫 점은 글자마다 달랐다. 螂은 세로로 내려긋고 琅·粮은 왼쪽 아래로 삐친다.
관찰한 대로 글자별로 다르게 보정했다.

부수 유사성으로 승인하지 않았다. 각 글자의 사전 전체 필순을 순서대로 보고,
색으로 나눈 25% 진행 구간에서 방향·펜 떼기·획 경계·완성 자형을 대조했다.
보정 10자는 변경 획뿐 아니라 전체 획을 재대조했다.

[direction-probe.mjs](direction-probe.mjs)가 60°를 넘는 획 29개(13자)를 표시했고,
10자는 보정, 2자는 보류로 이어졌다. 蠣의 원문은 가로 이동 `translate(12, -830)`을 쓴다.
이동은 방향 벡터를 바꾸지 않는다.
