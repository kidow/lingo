공식 근거는 한국어문회 [「필순 정정 및 500자 필순」](https://www.hanja.re.kr/kccpt/exam/otherData.do?search_option=subject&search_text=%ED%95%84%EC%88%9C)의 2010-03-22 판본이다. 다운로드 파일 `f37.hwp`의 SHA-256은 `4e191bbee54edd6db595f16fc83a15b9929eba0e3e01095da1e828c70e10760c`다. 표 외부의 완전한 개별 도해도 활용하며, 존재하지 않는 행 번호를 붙이지 않는다.

## 순서와 경로

- 性: 공식 1획 왼쪽 점, 2획 오른쪽 점, 3획 세로획을 따른다. Ko 원본의 1부터 시작하는 인덱스 `[1,3,2,4,5,6,7,8]`로 재배열했다. 4–8획은 그대로 유지한다.
- 回: 바깥 왼쪽 → 바깥 위·오른쪽 → 안쪽 왼쪽 → 안쪽 위·오른쪽 → 안쪽 아래 → 바깥 아래.
- 瓦: 위 가로 → 왼쪽 내려긋기 → 아래 짧은 획 → 오른쪽 굽은 획 → 안쪽 점. 4획인 다른 후보는 채택하지 않았다.
- 臼: 왼쪽 위 삐침 → 왼쪽 세로 → 왼쪽 안 가로 → 오른쪽 위·세로 → 오른쪽 안 가로 → 아래 가로.

반영한 중심선의 모든 누적 단계를 공식 도해와 다시 대조했다. 원본 점과 획 경계를 유지하고 Y축 반전, 80단위 균일 배율, 100단위 정사각형 중앙 정렬, 소수 첫째 자리 반올림만 적용했다. 性은 위 순서 교환을 추가했다. 정적 Noto 윤곽과 획별 중심선은 서로 다른 표현이며 픽셀 단위의 동일 자형을 보장하지 않는다. 이는 구현 과정의 도해 대조이지 한국어문회의 앱 인증이나 손글씨 자동 채점이 아니다.

## 재현 가능한 출처

AnimCJK 커밋은 `ec5e17cca76c87587790bcbce5ea0b4d4fb753d6`으로 고정한다.

- [graphicsKo.txt](https://github.com/parsimonhi/animCJK/blob/ec5e17cca76c87587790bcbce5ea0b4d4fb753d6/graphicsKo.txt): SHA-256 `7e703f34df54080281252a5c87a7106b85034b81fdbf93d37c07009a1448202e`.
- [graphicsJa.txt](https://github.com/parsimonhi/animCJK/blob/ec5e17cca76c87587790bcbce5ea0b4d4fb753d6/graphicsJa.txt): SHA-256 `2bcd1c6d186e5376c5f9202b4eae2eaeff13c2566675a55f1c9dd548a2ef31c8`.
- 배포 파일: `public/hanja-strokes/corrections-reviewed.json`, `supplement-reviewed.json`. APL과 저작권은 같은 디렉터리의 `ARPHICPL.txt`, `COPYING.txt`에 보존한다. 공식 도해 이미지는 배포하지 않는다.

`node scripts/hanja-stroke-audit.ts`는 두 원본을 내려받아 해시와 변환 후 경로를 검증한다. 性은 글자·원본·도해 위치·8획·보정 순서가 모두 일치해야 통과한다. 다른 글자의 임의 재배열은 거부한다. 전체 도해는 글자별 허용 이미지와 대조한다.

감사 결과: 자체 중심선 18자 + Ko 468자 + Ja 3자 = 489자. `candidateStatus`는 종전과 같이 Ko 목록만 집계한다(누락 5,456, 미승인 39, 획수 불일치 15, 등록 468). Ja 후보 7,007자 전체를 승인하지 않으며 별도 `reviewedGeometry.japanese`는 3이다.

`scripts/hanja-stroke-review.py --port 5865` 실행 후 `/reviewed`에서 원본 공식 이미지와 실제 배포 경로의 누적 단계를 비교할 수 있다(Pillow·xlrd 필요). 읽기 전용 도구이며 후보를 승인하거나 파일을 저장하지 않는다. 앞선 `hanja-stroke-remaining-review/` 보고서의 수량은 추가 적용 전 조사 시점의 기록으로 유지한다.
