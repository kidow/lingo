## 출처와 재현

- Ko·Ja·Make Me a Hanzi·ZhHans·ZhHant 고정 버전을 새로 조회했으나 세 글자의 완성 경로는 없었다. 출처·해시·부품 경로는 [originals.json](./originals.json).
- e-hanja 상세 페이지 POST와 실제 애니메이션 iframe을 새로 조회했다. 세 글자의 목록·상세·애니메이션 획수가 일치했다. [source-checks.json](./source-checks.json).
- [compose.ts](./compose.ts)는 부품 지문과 배치 영역을 검사한다. 전체 부품 묶음 및 글자별 묶음의 해시도 검사한다.
- 최초 관찰 → 보정 → 재검토: [initial-observations.json](./initial-observations.json), [proposals.json](./proposals.json), [observations.json](./observations.json).
- `node docs/hanja-g2-geometry-batch25-2026-09-17/verify.mjs`로 기록·경로·앱 데이터의 동일성, 누적 집계와 다음 조사 목록을 검증한다.
