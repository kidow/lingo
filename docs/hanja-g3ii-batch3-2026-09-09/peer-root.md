# 본 검토자의 독립 교차 검토

`莫 幕 晩 梅` 4자·47획의 원본 영상 전체 2fps, 각 획 완료 표본 10fps, 완성형 확대 및 최종 경로 선폭 5를 직접 대조했다. 영상 해시/바이트와 경로 해시를 [기록](peer-root.json)에 보존했다.

- **莫**: 원문 艹는 가로→세로→가로→세로이며 日 안가로의 오른 벽 접속과 大 시작 접속을 확인했다.
- **幕**: 원문 艹는 세로→가로→가로→세로이다. 日 아래·大와 巾 사이의 접합 및 분리를 확인했다.
- **晩**: 9.5–11.5초 영상에서 중앙세로와 왼삐침이 한 획으로 이어진다. 11획 굽은갈고리 시작은 위 가로와 분리되며 null 계보가 정직하다.
- **梅**: 12.4–14.8초 영상에서 내부 두 점이 독립된 획이다. 가운데 가로는 마지막이며 두 점의 위아래 간격이 폭 5에서 유지된다.

4자 모두 추가 수정 없이 통과했다. 원문과 중앙선을 대조한 결과이며 한국어문회 인증을 뜻하지 않는다. [검토한 경로](peer-root.svg).
