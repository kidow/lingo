48자에는 원문에 근거한 보정 레시피를 적용했다. 隆의 가로, 晩·免의 이어 쓰는 획, 梅의 두 점, 綿의 중앙세로 등 6개 새 경로는 원본 획 번호를 꾸미지 않고 `null` 계보로 명시했다.
