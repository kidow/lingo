蒙16.0–17.2초와 貿0.0–1.0초를 연속 표본으로 추가 대조해 무착색 포인터 이동과 실제 잉크 방향을 구별했다. 慕·蒙·夢·茂의 가로 분할은 각각의 개별 원문에서 확인했으며 동일한 원본 획 번호를 두 출력에 보존했다. 墨은 Ja14획의 내부 가로를 임의 대체하지 않고 원문과 동일하게 두 점을 가진 고정 MM15획을 선택했다.

독립 B 검토자는 같은 11자 전체143획 원문을 다시 보고 최종 선폭5 경로를 대조했다. 慕·夢·貿·銘·貌의 좁은 간격과 墨의 6·7획 순서 차이를 찾아 수정했다. 墨의 5.1–7.6초 표본에서는 짧은 가로가 먼저 채워지고 중앙 세로가 나중에 채워짐을 확인했으며, MM 원본 번호7·6을 교환하여 보정 계보에 보존했다. 교차검토 후 모든 변경 경로를 실제 선폭5로 다시 확인했다. [독립 교차검토 기록](peer-b.json).

각 영상 SHA·바이트·길이, 원본 중앙선 SHA, 보정 및 결과 SHA를 기록했다. 관찰 시각은 완료를 확인한 표본 시각이며 정확한 펜 떼기 시각을 뜻하지 않는다. 모든 보정은 로컬 중앙선이고 출판사가 제공한 SVG 또는 시험기관 인증을 뜻하지 않는다.
