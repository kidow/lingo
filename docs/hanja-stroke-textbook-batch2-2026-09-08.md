# 교과서 필순 2차 검토

2026-09-08. 1차에서 보류한 4자와 다음 4급II 후보 20자를 비상교육의 개별 필순 영상에 대조했다. 검토자는 Codex이며 인간 전문가 감수나 한국어문회 개별 승인으로 표시하지 않는다.

## 검토 결과

- 신규 후보 20자 중 15자 일치: **宮 起 怒 努 單 端 斷 檀 擔 督 銅 斗 豆 得 燈**.
- 기존 보류 4자는 원본 영상에 맞춘 국소 벡터 보정 후 일치: **潔 經 警 係**.
- 신규 후보 5자는 원본 데이터와 영상에 차이가 있어 보류: **禁 暖 黨 帶 隊**.

| 보류 문자 | 실제 영상과 후보의 차이 |
| --- | --- |
| 禁 | 영상의 11획은 아래로 끝나는 세로획이며 후보에는 왼쪽으로 되돌아가는 갈고리가 있다. |
| 暖 | 영상의 6획은 왼쪽 삐침, 8획은 오른쪽 점이다. 후보의 진행 방향과 형태가 다르다. |
| 黨 | 영상은 14획 가로, 15획 세로 순서이고 후보는 두 획이 반대다. |
| 帶 | 영상은 왼쪽 긴 삐침을 2획으로 쓰며 후보는 5획으로 미룬다. |
| 隊 | 영상의 오른쪽 상단 두 획은 바깥으로 펼쳐지는 八 형태이며 후보의 丷 형태와 방향이 다르다. |

## 보정 근거와 한계

潔의 13획과 係의 7획은 원본의 갈고리를 없애고 세로 끝점을 정렬했다. 經은 糸 아래 중앙 세로획과 왼쪽 점을 영상의 모양·방향에 맞추고 중앙→왼쪽→오른쪽 순서로 배치했다. 警은 기존 1획인 가로를 두 획으로 나누고, 영상에 관찰되는 왼쪽 세로→왼쪽 가로→오른쪽 가로→오른쪽 세로 순서로 배열해 19획 원본을 20획으로 보정했다.

보정 좌표는 기존 AnimCJK의 그림체를 보존한 로컬 벡터 편집이다. 필순과 획의 방향·경계·자형은 개별 영상에 대조했으며, 좌표 자체를 출판사가 제공하거나 인증한 SVG라고 표시하지 않는다. 부수 규칙으로 다른 글자의 필순을 추정하지 않는다.

이제 Ko와 Ja 중 글자별로 명시한 고정 원본에서만 경로를 가져온다. Ja 데이터의 존재나 획수 일치만으로 재생을 허용하지 않는다. 원본과 일치한 15자의 획 좌표는 변경하지 않았다. 영상과 다르게 확인된 5자는 공개 재생 데이터에 포함하지 않는다.

## 승인 데이터 연결

- 검토 대장: `scripts/hanja-stroke-textbook-review.json`. 영상 URL·SHA-256·크기, 검토자, 날짜, 전체 획 관찰 시각, 순서·방향·경계·자형 검사와 출력 경로 해시를 보관한다.
- 보정 recipe: `scripts/hanja-stroke-textbook-corrections.json`. 글자, 고정 원본 SHA, 원본 median SHA, 원본 영상 SHA, 각 출력 획의 원본 번호와 수정 좌표를 보관한다.
- `correctionSha256`은 승인 시점의 recipe 전체를 고정한다. 출력 좌표를 유지한 채 원본 획 번호만 바꾸는 변경도 재검토 없이 통과할 수 없다.
- 생성기와 전체 audit는 고정 Ko/Ja 원본에서 경로를 다시 만들고 검토 대장의 출력 해시와 비교한다. 재생에 포함되는 데이터는 `public/hanja-strokes/textbook-reviewed.json`이다.
- 프레임 도구는 기본적으로 대장에 기록된 출처와 보정 recipe를 재현한다. `--geometry-source ko|ja`는 보정 전 원본 후보를 비교하기 위한 옵션이다. 프레임 생성만으로 승인 상태가 바뀌지 않는다.

획별 시각은 관찰한 완료 표본 시점이며 정확한 펜 떼기 시각이 아니다. 영상 전체의 변화와 후보의 시작점·끝점·경계를 직접 비교한 뒤 기록한다. 출판사 영상과 검토용 프레임은 앱에 재배포하지 않는다.

## 적용 및 검증

19자를 추가해 전체 재생 대상은 **538자**(한국어문회 503 + 교과서 35)가 됐다. 교과서 검토 대장 40자 중 일치 35자·보류 5자이며, 남은 교과서 후보는 **1,249자**(보류 5 포함)다. 전체 카탈로그 5,978자 중 미적용은 **5,440자**다.

- 전체 단위 테스트 **174개 통과, 실패0**, TypeScript 및 프로덕션 빌드 통과.
- 원본 manifest·Ko/Ja 해시, 승인35자 재생 경로, 공개 bundle 일치 검사 통과.
- 이번 영상24개의 실제 다운로드 SHA-256·크기 재검사 통과.
- 승인 원장 기반 보정4자 프레임 재생성 통과. JavaScript/Python의 recipe 해시도 일치한다.
- 별도 코드 검토에서 지적된 원본 획 대응 변조 가능성은 recipe 해시 고정과 회귀 테스트로 해결했다.
