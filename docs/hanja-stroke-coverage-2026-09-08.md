## 4급II 미적용 9자와 이전 집계 정정

**兩·連·液·硏·藝·衛·砲·豊·鄕**.

이전의 “4급II 4자”는 교과서 목록과 정확한 문자 키로 직접 일치하는 미적용 후보 **藝·豊·硏·鄕**만 센 수치다. 이 범위 밖의 **兩·連·液·衛·砲 5자**를 더하면 앱 전체 4급II 미적용은 **9자**다. 교과서 후보의 잔여 수를 전체 급수의 잔여 수로 표현했던 오류를 정정한다.

전체 적용743자·미적용5,235자 집계에는 누락이 없었다. 범위가 잘못 표기된 [현재 검토 현황](hanja-stroke-review-textbook.md)과 [7차 기록](hanja-stroke-textbook-batch7-2026-09-08.md)을 함께 수정했다.

고정 교과서 manifest(SHA-256: `32853d2396dc4fe38362b9e51a828144d7e48889f60e28d850cae9fa2335620c`)를 독립 재확인한 결과, 추가 5자의 범위 제외 이유는 다음과 같다.

- 兩·連: 원문은 兩(U+F978, 행0401)·連(U+F99A, 행0416)이다. NFC 정규화 후에만 앱 문자와 일치한다.
- 衛: 원문은 衞(U+885E, 행1138)이며 NFC로도 앱 문자와 합쳐지지 않는다.
- 液·砲: 이 manifest에 정확한 문자 키가 없다. 다른 출처까지 없다는 의미는 아니다.

## 검증

- 카탈로그 5,978자 전부 고유 문자 키이며 실행 등록부 743자도 중복 없음.
- 실행 등록부의 카탈로그 외 문자 0자.
- 등록된 모든 애니메이션의 경로 개수와 해당 문자의 획수 불일치 0자.
- 급수별 등록·적용·미적용 합계는 전체 집계와 일치.
- 독립 검토에서도 4급II 250자 중 동일한 9자만 `hanjaStrokeData`가 null을 반환하며, 추가 획수 불일치가 없음을 확인했다.
- 실행 코드와 재생 데이터는 변경하지 않았다.
