# 한능검 전 급수 데이터

확인일: 2026-09-06. 한국어문회 전국한자능력검정시험의 15급수에 배정된 고유 한자 5,978자를 제공한다. 한자별 소개·한자 선택·훈음 4지선다·검색·자유 쓰기가 현재 범위다.

## 공식 자료

[한국어문회 급수별 배정한자](https://www.hanja.re.kr/kccpt/exam/levelConfirm.do)의 `배정한자 전체 대표훈음 부수 음표 명기본(xls).xls`에서 글자, 훈음, 급수, 부수, 총획수를 가져왔다. `배정한자` 시트의 데이터 행은 5,978개다. 원문 크기는 971,264바이트이며 SHA-256은 `97b8db715ebe1dd6e00e8e58d338a9ba70e7420bf5ec84da38f987d60eb64b17`이다.

같은 페이지의 급수별 `배정한자*.hwp` 15개로 각 급수의 누적 문자 집합을 별도로 대조했다. 원문 해시, 문서명, 확인일은 각 JSON의 `source`와 `grade`에, XLS 행과 원래 훈음은 각 항목의 `sourceRow`와 `sourceHunEum`에 보존한다.

## 변환과 학습

- 호환 한자를 NFC로 정규화해 ID를 만든다. 원래 표기가 다르면 `sourceGlyph`와 검색용 `glyphAliases`에 보존한다. 원문 5,978개는 정규화 후에도 서로 다른 글자다.
- XLS의 `煕`와 급수별 HWP의 `熙`는 HWP 표기 `熙`로 통일하고 `煕`로도 검색되게 한다. 이 예외를 제외한 문자 집합은 같은 정규화 방식으로 일치한다.
- `|`로 구분된 복수 훈음을 보존한다. 괄호 안 한자 설명과 장음 표기는 화면용 훈·음에서 분리하되 원문은 남긴다. 원문의 `빛날요:`는 띄어쓰기를 보정해 읽는다. 장단음 문제를 출제하는 것은 현재 범위가 아니다.
- 오답 후보는 같은 급수에서 우선 선택한다. 정답의 복수 훈음·슬래시로 병기된 뜻과 겹치는 후보를 제외하고 필요하면 전체 풀에서 보충한다.
- 기존 10자의 ID와 두 학습 기술 키를 유지한다. 숙련도 분모는 고유 한자 5,978개이고 쓰기·검색은 숙련도를 올리지 않는다.
- 원문에 한자어 예시는 없으므로 기존 10자의 예시만 유지한다. 예시가 없는 카드에는 빈 예시 영역을 만들지 않는다.
- 기본 글자는 Noto Serif CJK KR 2.003에서 추출한 로컬 SVG로 표시한다. 한자 5,978자와 추가 부수 45자의 파일·출처·해시는 `public/hanja/`에 보존한다. 공식 필순 도해로 검증한 18자만 재생을 시작하면 기존 획별 SVG 중심선으로 전환한다. 표시용 폰트 윤곽이나 총획만으로 필순을 추정하지 않으며 손글씨 자동 판정은 제공하지 않는다. [SVG 표시 기록](hanja-svg-feasibility.md), [필순 검증 목록](hanja-stroke-sources.md#현재-적용한-18자).

## 파일과 재검증

`content/hanja/characters/`의 15개 JSON에는 각 급수 신규 한자만 들어 있다. `lib/hanja-corpus.ts`는 이를 낮은 급수부터 합쳐 기존 한능검 셸에 공급한다.

읽기 전용 `scripts/hanja-source.py`는 공식 사이트에서 XLS와 HWP를 다시 받아 검증한다. Python 3와 `xlrd==2.0.2`가 필요하다. 별도 가상환경에 설치하고 저장소 루트에서 실행한다.

```sh
python3 scripts/hanja-source.py --verify-root .
npm run typecheck
npm test
```

검증기는 원문 해시, 예시를 제외한 모든 런타임 필드, 급수별 수량, ID 유일성, HWP 누적 문자 집합의 정확한 일치를 확인한다. 공식 문서가 갱신되면 해시 검사에서 중단하므로 변경분 검토 후 데이터와 판본 정보를 함께 갱신한다. 파일을 자동 덮어쓰지는 않는다.

2026-09-06 검증 결과: 공식 자료 전체 대조 통과, 타입 검사 통과, 테스트 139개 통과. 테스트는 전 5,978자의 양방향 11,956문항에 대해 보기 4개·중복 없음·정답 포함을 확인하고, 복수 훈음 충돌 제외·원래 진도 키·전 급수 검색·14자 필순 허용 목록과 재생 시간을 검사한다.

공식 사이트의 공개 다운로드 사실과 별개로, 원문 HWP·XLS 파일은 저장소에 배포하지 않는다. 원문 이미지·필순 도해의 변환 및 재배포는 자료 이용 조건과 개별 필순 대조를 확인할 후속 범위다.
