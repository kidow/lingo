아래 두 예시는 승인된 원본의 획 경로를 가져와 배치한 결과입니다. 재생하면 각 부품의 획이 차례로 그려집니다. 오른쪽의 현재 SVG와 비교하면, 경로 재사용 이후에도 크기와 접합을 다듬어야 한다는 점을 볼 수 있습니다.

03 / 국내 근거와 중요한 예외

재사용 단위는 부수보다 ‘위치별 부품’이 정확합니다

부수는 자전에서 글자를 분류·검색하는 대표 부분입니다. 애니메이션을 만들려면 대표 부수 이외의 부분까지 분해해야 합니다. 미래엔 교사용 지도서 31쪽와 Unicode의 구성요소 설명이 이 구분을 뒷받침합니다.

위치에 따라 다른 모양

水 → 氵
手 → 扌
心 → 忄 / ⺗

같은 의미의 부수라도 모양과 획 구성이 달라질 수 있습니다. 독립형을 단순히 가늘게 줄여서는 충분하지 않습니다. 미래엔 지도서는 이 변형을 실제 글자와 함께 제시합니다.

나중에 그리는 획

미래엔 지도서 33쪽은 途의 받침, 犬의 오른쪽 위 점, 中의 관통획을 나중에 쓰는 예를 제시합니다. 단순한 왼쪽→오른쪽 재생 외에 마감·지연 규칙이 필요합니다.

유일한 순서가 아닐 수 있습니다

한국어문회는 兒·舊·寫의 臼에 복수 순서를 허용했고, 田의 교차획에도 일반적인 순서와 허용 범위를 구별했습니다. 당시 개별 상담 근거이며 현행 시험 전체의 채점 규정으로 확대하지 않습니다.

해외 자료의 구성요소 모델은 참고할 수 있습니다. KanjiVG의 variant·position·part는 위치별 변형과 떨어진 획 묶음을 표현합니다. 그 데이터 형식의 유용성과 일본 필순을 한국에 적용할 수 있는지는 별개입니다.

04 / 권장 설계

부품을 조립하는 코드와 검토 원장을 만듭니다

현재 플레이어가 이미 순서 있는 SVG 경로를 재생하므로 새 애니메이션 라이브러리는 필요 없습니다. 만드는 과정의 재현성과 출처를 보강하는 작업입니다.

  1. 위치별 부품 원장

    모양·위치·변형, 승인 원본 글자, 원본 획 번호 목록, 출처·해시를 기록합니다. 부품의 획이 연속한다고 가정하지 않습니다.

  2. 분해와 배치 레시피

    IDS로 구조 후보를 찾고 한국 자형을 확인합니다. Noto KR SVG는 배치·여백 기준으로 쓰며 필순의 증거로 쓰지 않습니다.

  3. 글자 전체의 획 일정

    ‘어느 부품의 몇 번째 획’을 그릴지 명시합니다. 안쪽을 쓴 뒤 닫는 획과 나중에 쓰는 부분을 처리합니다.

  4. 재현 가능한 경로 합성

    이동·확대/축소부터 시작하고, 접합과 끝점 보정은 명시적 레시피로 남깁니다. 같은 입력은 같은 결과를 만듭니다.

  5. 전체 글자 검토

    획수·끊는 위치·방향·전체 순서·자형·접합을 확인합니다. 공식 목표 영상이 없으면 부품 근거와 적용 규칙, 자체 판단을 구분해 기록합니다.

  6. 별도의 자체 검토 등급

    ‘합성 초안’과 ‘자체 검토 합성’을 기존 개별 공식·교과서 대조 자료와 구분합니다. 부품 승인만으로 공식 검증 상태로 올리지 않습니다.

개별 공식 영상의 부재가 모든 제작을 막을 필요는 없습니다. 확인된 부품과 적용 가능한 국내 규칙을 기반으로 새 글자를 만들고 전체 검토를 거쳐 운영하는 정책을 제안합니다. 새 글자의 공식 필순이 확인됐다는 표시는 실제 개별 근거가 있을 때만 붙입니다.

유한 좌표, 경계, 획 누락·중복, 획수, 참조 해시 같은 검사는 자동화할 수 있습니다. 다만 이 조건을 모두 통과해도 언어적으로 맞다는 증명은 아닙니다. LLM은 분해와 예외 후보를 찾는 데 쓰고, 경로 조립은 일반 코드가 맡는 구성이 적합합니다.

폰트 생성 연구가 알려 주는 것

LF-Font는 부품의 국소 스타일을 재사용하면서 전체 구조도 필요하다고 봅니다. 소수 참조 예시는 대규모 사전학습을 전제로 하며 한국 필순의 검증 결과가 아닙니다.

모양 보정은 두 번째 단계

획 등록·변형 연구는 기존 획을 목표 모양에 맞추는 데 도움을 줍니다. 참조 획이 필요하고 교차·구조 차이에서 실패합니다. 처음부터 큰 학습 모델을 만드는 것보다 규칙 기반 합성을 먼저 평가하는 편이 적합합니다.

새 외부 데이터를 도입한다면 dictionary의 LGPL 3+와 graphics의 Arphic Public License를 따로 확인해야 합니다. 플레이어 코드의 라이선스가 데이터까지 대신하지는 않습니다.
