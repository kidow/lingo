## 대조와 보정

세 글자 모두 후보 초두는 3획이고 국내 사전의 초두는 4획이었다. 각 **전체 글자**의 실제 단계에서 왼쪽 가로→왼쪽 세로→오른쪽 가로→오른쪽 세로 순서를 확인했다. 부수의 이름이나 총획수만 보고 자동 분할하지 않았다.

- 초두 가로 3개를 좌우 6개 경로로 보정하고, 재생 선폭 5에서도 중앙 간격이 남도록 했다.
- 葛 7·8획과 菓 7·8획의 양끝을 좌우 세로획에 연결했다. 기존 후보의 짧거나 떠 있는 가로획을 그대로 승인하지 않았다.
- 儆 10·11획은 口의 오른쪽 세로와 아래 가로를 맞췄다. 14·15획은 앞선 가로의 오른쪽·왼쪽 접점에서 시작하도록 보정했다.
- 보정·작성된 최종 경로는 **14개**, 유지한 최종 경로는 **26개**다. 전 40획의 누적 상태·주요 진행 방향을 대조하고, 변경된 획과 최종 자형을 다시 확인했다.
- 儆 3·5·11획은 짧아서 화면 색상만으로 판단하지 않고 원본 애니메이션 경로의 시작·끝 진행도 확인했다. 모두 왼쪽→오른쪽이다.
- 결과는 단순화된 손글씨 중심선이다. 후보의 기울기·붓 진입 모양을 일부 유지하며 정적 명조 SVG의 외곽선을 그대로 재현하는 자료는 아니다.

## 출처와 보관 범위

[e-hanja 葛](http://img.e-hanja.kr/hanjaSvg/aniSVG/8400/845B.svg), [儆](http://img.e-hanja.kr/hanjaSvg/aniSVG/5100/5106.svg), [菓](http://img.e-hanja.kr/hanjaSvg/aniSVG/8300/83D3.svg)의 실제 상세 페이지 iframe 주소를 재확인했다. 사전 표시 획수·실행 단계·카탈로그가 각각 13·15·12획으로 일치한다. 사전 SVG 파일 안의 XML 순서가 아니라 실행 지연 시간 순으로 대조했다.

Ko·Ja·MM의 고정 버전을 NFKC 호환문자까지 검색했지만 일치하는 획수의 대체 후보는 없었다. 후보 경로는 기존 Arphic Public License 출처와 고정 해시를 유지한다. 사전은 국내 민간 자료이며 시험 주관 기관의 공식 인증으로 표시하지 않는다. 런타임 출처도 `ehanja-crosschecked`다.

사전 SVG·HTML·이미지·화면 캡처는 저장하지 않았다. 원본은 RAM에서만 처리했고, URL·해시·실행 메타데이터·직접 작성한 관찰과 허용된 후보·보정 경로만 남겼다.

## 검증과 파일

한자 테스트 **53개 파일·306개**와 TypeScript 검사를 통과했다. 새 회귀 테스트는 37개 원본 획에서 40개 승인 획을 재현하는지, 초두 간격과 쓰는 순서, 가로획 연결, 儆 마지막 획의 시작점·방향, 출처·검토 기록 변조 거부를 확인한다. 기존 전체 등록부 테스트에도 이번 묶음을 추가했다.

- `originals.json`·`acquire.mjs`: 고정 버전 후보와 읽기 전용 출처 재확인.
- `source-checks.json`·`initial-observations.json`·`observations.json`: 전 획 근거와 전후 관찰.
- `proposals.json`·`corrections.json`·`candidate-paths.json`·`review.json`: 명시적 획 대응과 보정 이력.
- `prepare.mjs`·`verify.mjs`·`checks.json`: 승인 경로 재생성·공개 데이터 일치·진행 현황 검증.
- `progress.json`·`next-batch.json`: 현재 런타임 집계와 다음 검토 목록.
- `serve.py`: 출처를 디스크에 저장하지 않는 임시 로컬 검토 화면.

`node docs/hanja-g2-geometry-batch1-2026-09-16/verify.mjs`로 자료·경로·등록·집계를 재검증한다.
