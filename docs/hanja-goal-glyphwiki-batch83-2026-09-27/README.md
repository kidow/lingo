# 阱 7획 적용

국내 사전 전체7획의 방향·누적·완성 자형을 고정 공개 백업의 완성 원본 `u9631`과 대조했다. 원래8그룹 중 첫 가로·곡선을 하나의 꺾임 획으로 재생하며, 내부 끝점이 정확히 연결됨을 검증했다. 2획의 굽음·왼쪽 갈고리와 6획의 내려긋는 곡선도 원본 그대로 유지한다.

- 원본3레코드와 고정 엔진8파일을 확인했다. 새 점·연결선·자르기·부수 교체 없이 네 이차곡선과 모든 외곽선 정점을 보존했다.
- 7획 × 9단계, 총63개 점진 재생 장면을 직접 검토했다.
- 한자 테스트199파일·943개 통과. 격리 빌드·타입 검사·정적7페이지 생성 통과. 검사한17파일과 공개 출력3파일이 현재 작업과 일치한다.
- 430×932 모바일에서 소개/쓰기 진입 자동재생, 다시 재생,7/7완료를 확인했다. 캔버스 입력0→1→0, 드래그 전후 시트 위치와 스크롤 동일, 정적 이미지 중첩0, 브라우저 경고/오류0.

전체4,999/5,978자(83.6%) 적용, 미적용979자. 남은 수: 1급65·2급1·특급II288·특급625. 다른 급수는 모두 적용됐다.

다음 후보 侊(특급II8획)의 전체 원본3레코드·엔진 재현과 국내 자료 메타데이터를 확보했다. 전체 시각 검토는 아직 하지 않았다. 사전 그래픽은 RAM에서만 사용했고 이번 검토 탭과 서버는 종료했다. 검증용 관리 작업 공간은 다음 배치에서 재사용한다.
