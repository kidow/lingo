# 부수 213자 說文解字 원문·번역 검수표

`pnpm hanja-radicals`가 만든다. 손으로 고치지 않는다 — 번역은 [radical-translations.json](../../content/hanja/radical-translations.json)을, 원문·명칭은 스크립트를 고친다.

- 원문: 위키문헌 [說文解字](https://zh.wikisource.org/wiki/說文解字) 大徐本. 판본 ID와 본문 SHA-256은 [radicals.json](../../content/hanja/radicals.json)에 있다.
- 번역: lingo. 상투구 «凡X之屬皆从X»와 반절·讀若 구절은 옮기지 않았다. 說文의 풀이가 갑골문 연구와 어긋나는 글자도 그대로 옮겼다.
- 훈음: 배정자는 한국어문회 배정표. `(사전)`은 배정자가 아니라 표준국어대사전의 부수 명칭이다.
- 說文에 없는 부수: 亠·爿. 康熙 자형과 다른 것은 說文 자형으로 찾았다(尢→尣, 彐→彑, 冫→仌, 巛→川, 歹→歺, 靑→青, 无→旡, 廾→𠬞, 阜→𨸏).
