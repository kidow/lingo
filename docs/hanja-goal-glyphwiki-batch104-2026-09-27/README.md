국내 e-hanja 7획의 방향·누적 상태·완성 자형을 RAM 비교 화면에서 확인했다. 2획은 가로에서 오른쪽 내리획으로 이어지지만, 공개 원본의 가로 끝(83.625,30)과 곡선 시작(79.005,30)이 일치하지 않는다. 임의 연결·잘라내기·좌표 변경 없이 재생할 수 있는 연속 경로가 확보되지 않아 적용하지 않았다.
