아래 원본 번호는 고정한 MM 또는 Ja 후보의 번호다. 출력 번호는 보정 후 실제 재생 순서다.

**원본 83획에서 3획 제외, 5획을 각각 둘로 분할하고, 2획을 별도 작성해 출력 87획**으로 만들었다.
좌표를 보정한 원본 획은 29개다. 遲·遞는 총획수만 같았으며 실제 점·꺾임 구성이 달랐다.
爵의 새 가로 두 획은 원본 경로를 분할한 것으로 표시하지 않고 `sourceStroke: null`과 명시적 좌표로 기록했다.
보정 전후 원본 대응, 제외한 획, 분리한 획과 작성한 획을 [proposals.json](proposals.json)에 보존했다.

보정된 모든 누적 경로, 시작·끝 표시, 확대 최종 자형을 실제 경로 굵기 5에서 확인했다.
遞의 5·6획은 완료 시각을 재확인하는 확대 대조에서 순서 차이를 확인해 수정하고 전체 경로를 다시 대조했다.

## 근거와 범위

- [비상교육 고등 한문 교재](https://text.vivasam.com/detail/186)의 [기초 한자 필순 뷰어](https://viewer.vivasam.com/qrviewer/viewer.html?qrcode=106502_171p_25_ST&teacher=false)를 글자 전체의 대조 근거로 사용했다.
- 정확한 문자·행·영상 파일명·URL·전체 SHA-256은 [원래 queue.json](../hanja-g3-batch5-2026-09-15/queue.json)에 고정되어 있다. 이번 6개 영상 전체를 다시 받아 바이트 수·해시를 검증했다.
- 爵·遵·逮·逐은 고정 MM, 遲·遞는 고정 Ja 원본 경로다. 원본 해시와 기존 Arphic 라이선스·고지를 유지한다.
- 기본 2fps 전체 프레임 외에 爵 위쪽과 아래 왼쪽, 각 책받침의 분리 구간, 逐 오른쪽 삐침을 5fps로 확대했다. 遞 4.8–8.2초도 확대해 순서를 확인했다. 구간과 획별 완료 관측 시각은 [observations.json](observations.json)에 기록했다.
- 기록 시각은 표본에서 완성을 확인한 시점이며 정밀한 펜 이탈 시각이 아니다.
- 영상·프레임은 RAM에서만 처리했다. 저장소·공개 경로에 복제한 출판사 영상/이미지는 0개다.
- **출판사 영상과의 시각 대조이며 시험 주관 기관의 개별 경로 인증이나 별도 전문가 감수가 아니다.** 동일한 부수나 획수만으로 승인하지 않았다.
