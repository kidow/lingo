# 僾 15획 적용

국내 사전과 원본 전체 자형·15획 방향을 대조하고, 135개 단계 화면과 곡선 마스크 14개의 99.99→100% 확대를 브라우저 패널에서 검토했다. 원본 연속 획을 유지한 15획·16마스크를 등록했다. 10획의 위쪽 끝갈고리는 고정 엔진의 terminal5 공식과 원본 폴리곤만 사용해 같은 획 안에서 노출한다.

출처 재조회·해시·원본 윤곽 일치 검증, 격리 전체 테스트 2,229개와 프로덕션 빌드, 모바일 자동재생·다시 재생·쓰기 재진입·입력·지우기·시트 고정 검증을 통과했다. 실제 학습 기록을 쓰지 않는 RAM 모의 환경이며 원본 무변경을 확인했다. 사전 교차검토이며 시험 주관 기관의 공식 승인을 뜻하지 않는다. 비공개 사전 그래픽은 저장하지 않았다.
