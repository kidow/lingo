# 艽 6획 적용

국내 사전의 전체 6획과 고정된 2016년 GlyphWiki 백업의 전체 艽 원본을 대조했다. 시험기관 공식 승인이 아닌 사전 교차검토다. 현재 API 원본과 혼합하지 않았으며, 개별 리비전 번호가 없는 백업에는 저장소 커밋과 전체 덤프 SHA256을 사용했다.

- 원본 의존 자료 5개와 엔진 파일 8개를 재현했다. 국내 풀 부수의 3·4획 순서로 맞추고, 정확히 연결된 가로선·꺾임·갈고리를 제6획으로 재생한다.
- 전체 방향·시작/끝·교차점·누적·완성 자형과 54개 중간 상태를 검토했다. 제5획 수직선과 곡선은 연속되고, 마지막 갈고리는 원본 다각형 그대로 위로 드러난다. 새 경로·연결선·좌표 수정은 없다.
- 191개 파일의 919개 테스트, 타입 검사와 프로덕션 빌드(정적 7페이지)를 통과했다. 격리 빌드의 17개 파일과 공개 산출물 3개가 일치한다.
- 430×932 모바일에서 소개/쓰기 자동재생·다시 재생·6/6 완료, 캔버스 입력 0→1→0, 시트 위치·스크롤 유지, 정적 이미지 0·애니메이션 SVG 1, 콘솔 경고/오류 0을 확인했다. 기존 1.5배 속도를 바꾸지 않았다.
- 실제 4,991/5,978자 적용(83.5%), 987자 미적용. 남은 급수별 수: 1급 65·2급 1·특급II 288·특급 633.
- 다음 伻 7획은 k 루트가 아닌 백업의 완전한 u4f3b 전체 원본을 확보하고 엔진까지 재현했다. 국내 전체 획 검토 전이므로 아직 적용하지 않았다.

출처·재사용 조건은 NOTICE.md, 검증은 validation.json, 다음 후보는 next.json에 기록했다. 비공개 사전 그래픽은 RAM에서만 대조했다. 임시 서버·탭·격리 작업 트리를 정리했으며 푸시·배포하지 않았다.
