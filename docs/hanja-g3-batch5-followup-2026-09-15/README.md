총 **20개 원본 획의 좌표를 보정**했고, **2자에서 순서를 변경**했다. 획의 분리·병합은 없으며 120획 모두 원본 획과 일대일로 대응한다. 보정 후 모든 누적 경로, 시작·끝 표시, 확대 최종 자형을 다시 확인했다. 추가 간격 조정 뒤에는 바뀐 경로를 다시 대조했다.

## 근거와 승인 범위

- [비상교육 고등 한문 교재](https://text.vivasam.com/detail/186)의 [기초 한자 필순 뷰어](https://viewer.vivasam.com/qrviewer/viewer.html?qrcode=106502_171p_25_ST&teacher=false)를 각 글자 전체의 기준으로 대조했다.
- 정확한 글자·행·파일명·영상 SHA-256은 [이전 queue.json](../hanja-g3-batch5-2026-09-15/queue.json)에 고정되어 있다. 이번 10개 원문 영상의 전체 바이트 수와 해시를 다시 확인했다.
- 고정된 MM 후보의 원본 해시·좌표·Arphic 라이선스 연결을 유지한다. 출판사 영상과 프레임은 RAM에서만 대조했고 저장소나 공개 경로에 복제하지 않았다.
- 기본 2fps 전체 프레임에서 획 순서·방향·경계를 관찰했다. 기록된 시점은 표본에서 획 완성을 확인한 시각이며 정확한 펜 이탈 시각이 아니다.
- 결과는 **출판사 영상에 대한 시각 대조**다. 한국어문회의 개별 경로 인증이나 별도 전문가 감수를 뜻하지 않는다.
