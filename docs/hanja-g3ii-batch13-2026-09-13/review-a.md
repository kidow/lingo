# 阿 8획 검토 A

**阿 1자·8획의 저자 검토를 통과했다.** 독립 교차검토와 새 정적 교재 출처 파이프라인의 재현 검증 뒤 적용을 권고한다. 이 파일을 쓰는 동안 런타임은 변경하지 않았다.

국내 근거는 [동양북스 공식 교재](https://dongyangbooks.com/book/book_view.asp?goods_code=979&menu_1=hanja&menu_2=han_hanja)가 공개한 [쓰기노트 ZIP](https://dongyangbooks.com/book/download.asp?no=352&bsno=6414)의 PDF·인쇄 **35쪽**이다. 165쪽 PDF를 RAM에서 다시 읽고, 阿 머리글자와 처음부터 끝까지 8개 누적단계를 확대 확인했다. 원본 PDF SHA는 `c25485d2b26f9ea9c34c897ba41d953823ecdd07f65c81e05fef39b666782a48`이다.

국내 도해는 획 내부의 진행 방향을 직접 보여주지 않는다. 방향은 [대만 교육부 exact 阿 공식 플레이어](https://stroke-order.learningweb.moe.edu.tw/dictFrame.jsp?ID=38463)의 느린 재생을 시작부터 끝까지 48개 연속 화면으로 실제 열람하고, 같은 페이지의 8개 순서 있는 XML Track과 대조했다. 국내의 매 단계 추가획과 MOE의 위치·모양·꺾임·경계가 일치한다. **해외 공식 방향과 국내 정적 교재를 교차확인한 결과이며, 한국 원본 영상 또는 한국어문회 승인이라고 주장하지 않는다.**

| 획 | 순서·방향 | 경계 |
|---:|---|---|
| 1 | 阝 위 가로꺾임: 왼쪽→오른쪽 위→왼쪽 아래 | 2획과 별도 |
| 2 | 안쪽굽음: 오른쪽 아래로 굽은 뒤 왼쪽 위로 마침 | 끝과 긴세로 사이 흰틈 |
| 3 | 阝 긴세로: 위→아래 | 1획 시작과 접촉 |
| 4 | 可 윗가로: 왼쪽→오른쪽 | 왼부수와 분리 |
| 5 | 口 왼세로: 위→아래 | 6·7획과 접촉 |
| 6 | 口 위/오른꺾임: 왼쪽→오른쪽→아래 | 한 획 |
| 7 | 口 아랫가로: 왼쪽→오른쪽 | 口를 닫음 |
| 8 | 可 긴세로갈고리: 위→아래→왼쪽 위 | 4획과 접촉, 口와 분리 |

각 방향은 MOE 동적 진행에서 직접 보았다. 국내 도해만 보고 시작·끝을 추정한 결론으로 대체하지 않았다. 완성 상태를 확인한 관찰 표본은 6/12/18/24/28/34/38/46번이다. 관찰시각은 브라우저 재생 기준이며 원본 영상 타임스탬프가 아니다. XML은 JSON 문자열을 그대로 해제한 UTF-8 **15,092바이트**, SHA `2925da50831c78aeeab321ab14f3d13d5a5f1b8be236b05c72f848ac546ab77e`이다.

후보 원본 3종을 고정 커밋에서 다시 조회했다. Ko에는 exact 阿가 없고, MM7은 阝 첫 두 획을 합쳐 국내 경계와 달라 제외했다. **Ja8을 1:1 연결**했다. 원본 중선 SHA는 `8d01e666fc12e8e14bb86eec2a88ca057d76b53357d7ae8c4e195496e863d3be`이며 모든 원본 좌표를 보존했다.

실제 `normalizeMedians` 결과를 먼저 보고 두 곳만 보정했다. 3획의 불필요한 상단 사선 돌출을 제거하고, 2획의 굽음과 끝을 정리해 국내 도해의 흰틈을 유지했다. 2/3획의 폭5 잉크 간격은 0.1977에서 2.5992로 늘었다. MOE의 경로 좌표를 출력SVG로 재사용하지 않았다.

최종 8개 누적 상태와 **420px 완성형**, 실제 **폭5·둥근 끝·둥근 연결**을 열람했다. 28개 관계(접촉6/간격22)가 모두 통과했고 최소 흰틈은 2.3494다. [geometry-a.json](geometry-a.json)에 원본 Ja8, 보정 이유·점좌표, 최종8경로, 1부터 시작하는 대응표와 28개 수치가 있다. [review-a.svg](review-a.svg)는 그 실제 경로를 보여준다.
