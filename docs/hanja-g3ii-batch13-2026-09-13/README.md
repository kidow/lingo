## 출처와 재현

- [동양북스 도서 안내](https://dongyangbooks.com/book/book_view.asp?goods_code=979&menu_1=hanja&menu_2=han_hanja)의 [쓰기노트](https://dongyangbooks.com/book/download.asp?no=352&bsno=6414)를 직접 확인했다. PDF는 165쪽, SHA-256 `c25485d2b26f9ea9c34c897ba41d953823ecdd07f65c81e05fef39b666782a48`이다.
- 국내 정적 교재는 각 획의 순서·형태·경계를 보여준다. 획 내부 방향은 [대만 교육부 阿 애니메이션](https://stroke-order.learningweb.moe.edu.tw/dictFrame.jsp?ID=38463)을 실제 재생해 교차 확인했다. 한국어문회 인증이나 한국 원본 영상으로 표시하지 않는다.
- 출력은 기존 Arphic 라이선스의 고정 Ja 원본과 명시적 국소 보정에 기반한다. 교육부 원본 좌표·그림·XML 및 교재 PDF를 저장하거나 재배포하지 않았다.
- 문서 출처는 `dongyang-hanja3-note`로 별도 등록했다. PDF·방향 자료·원본 medians·보정 레시피·최종 경로 해시를 검증하며, 미완료 기록과 변조된 경로를 거부한다.
- 阿의 8개 누적 출력과 420px 완성형을 실제 확인했고, 접촉 6쌍·간격 22쌍의 독립 계산이 모두 일치했다.
