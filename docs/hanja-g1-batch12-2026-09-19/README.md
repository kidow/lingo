# 1급 軋~壅 50자 검토 — 50자·701획 반영

2026-09-19 · **50자 반영, 보류 없음**

[1급 11차 贖~斡](../hanja-g1-batch11-2026-09-19/README.md)의 `next-batch.json`에 고정한 후보 50자를
같은 방식으로 대조했다. 첫 대조에서 38자가 일치했고, 12자는 보정 후 전체 획을 다시 확인했다.
허가된 중간선 691획을 유지하고 10획을 국소 보정했으며, 5자의 획 순서를 바꿨다.
MM 원본 41자, Ja 원본 9자에서 출발했다.

## 보정

| 보정 대상 | 변경 |
| --- | --- |
| 蘊 | 艹의 十 둘을 각각 가로 다음 세로 (1·2, 3·4획 교환) |
| 諺 | 彦의 긴 삐침을 파임보다 먼저 (10·11획 교환) |
| 穢 | 歲의 긴 왼쪽 삐침을 戌의 가로보다 먼저 (10·11획 교환) |
| 儼 | 嚴 안쪽의 가로 둘과 올림 가로를 오른쪽 세로보다 먼저 (15~18획 재배열) |
| 艶 | 曲의 안쪽 가로를 안쪽 세로 둘보다 먼저 (3~5획 재배열) |
| 縊 | 益의 丷 두 점을 바깥쪽으로 반전 (7·8획) |
| 鶯 | 火 둘의 왼쪽 점(1·5획)을 왼쪽 아래로 반전. 1획은 정확히 60°였지만 표시된 5획과 같은 반전이라 함께 보정 |
| 壅 | 亠의 첫 점(1획)을 세로로, 隹의 오른쪽 위 짧은 획(8획)을 왼쪽 아래로 반전 |
| 釀·瘍·臆 | 亠·疒·立의 첫 점(8 / 1 / 5획)을 세로로 |
| 瘀 | 於의 마지막 점(13획)을 반전·역방향으로 왼쪽 아래에서 오른쪽 위로 오르게 |

같은 회차의 隘처럼 益의 丷이 이미 바깥쪽인 글자(Ja 원본)와, 揶·爺처럼 耳의 가로가 이미 오른쪽 세로보다 앞선 글자,
闇·庵·裔처럼 첫 점 차이가 정확히 60°에 그친 글자는 그대로 뒀다.

부수 유사성으로 승인하지 않았다. 각 글자의 사전 전체 필순을 순서대로 보고,
색으로 나눈 25% 진행 구간에서 방향·펜 떼기·획 경계·완성 자형을 대조했다.
보정 12자는 변경 획뿐 아니라 전체 획을 재대조했다.

[direction-probe.mjs](direction-probe.mjs)가 60°를 넘는 획 21개(12자)를 표시했고,
12자 모두 보정으로 이어졌다. 표시만 되고 그대로 둔 획은 없다.
儼·艶·諺·穢처럼 덩어리로 얽힌 자리는 획 끝점 좌표를 숫자로 확인한 뒤 대응을 맞췄다.
瘀의 마지막 점은 사전이 오른쪽 위로 올리고 허가 원본이 오른쪽 아래로 내려, 반전과 역방향을 함께 써서 원본 획의 범위 안에서 방향만 맞췄다.
45~60° 구간의 방향 차이는 15개였고 그중 鶯의 한 점만 짝과 같은 반전으로 보정했다.
나머지 열넷은 사전이 세로로 긋고 허가 원본이 기울여 쓰는 짧은 점으로(闇·庵·裔는 정확히 60°),
이전 회차와 같은 기준으로 임계 아래는 허가된 중간선을 그대로 뒀다.
蘊의 원문은 가로 이동 `translate(12, -y)`를 쓴다. 이동은 방향 벡터를 바꾸지 않는다.

## 근거와 재현

- [observations.json](observations.json): 50자 판정, 12자의 첫 판정·보정·재대조 기록, 8방향 코드
- [source-checks.json](source-checks.json): 50자의 원문 해시·획별 시간·XML 참조·좌표 변환
- [originals.json](originals.json): 고정한 라이선스 원본의 중간선과 정규화 경로
- [proposals.json](proposals.json), [corrections.json](corrections.json): 획별 원본 대응과 국소 보정 이유
- [candidate-paths.json](candidate-paths.json), [review.json](review.json): 승인 경로와 증거 해시
- [prepare.mjs](prepare.mjs): 읽기 전용 승인 데이터 재현 (50자 승인을 검사)
- [verify.mjs](verify.mjs): 재현 결과·공개 데이터·적용 수·다음 후보 검증. 1급 회차의 보류 글자는 큐에서 뺀다
- [checks.json](checks.json), [progress.json](progress.json): 이번 검증과 전체 진행 현황
- [next-batch.json](next-batch.json): 다음 訛~毅 50자·614획 후보
- [acquire.mjs](acquire.mjs), [source-checks.mjs](source-checks.mjs), [serve.py](serve.py): 원본 고정·원문 확인·검토 시트

필순 근거는 e-hanja 사전이며, **한국어문회 인증으로 표시하지 않는다.**
재생 중간선은 Arphic Public License의 고정 MM·Ja 원본에서 출발했다.
사전의 경로·마스크·영상·스크린샷을 파일에 저장하거나 배포하지 않았다.
자형의 구조와 진행 방향을 비교한 것으로 폰트 외곽선의 픽셀 일치나 필기 채점이 아니다.

```bash

```
