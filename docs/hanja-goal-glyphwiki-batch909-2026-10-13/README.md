# 憯 15획 보류

브라우저 패널에서 국내 자형과 전체 원본5종 및 국내5획을 대조했다. 국내 위쪽 짧은 세로획은 맨 위 가로에서 아래 가로까지 곧게 내린 뒤 가로로 이어지는데 G는 짧은 기울어진 세로·왼쪽 꺾임으로 다르다. 다른 원본도 짧은 획의 꺾임 또는 위로 돌출된 자형이 달라 호환 원본이 없다. G의 연속 경계4곳을 묶으면 숫자15가 되지만 자형·경계 승인 근거가 아니므로 새 컴파일러를 만들지 않았다. 기존VS0 후보는 비연속 日폐합[14,18]도 포함한다. 진행·확대·재생은 미검토다.

브라우저 패널에서 전체 원본 5종과 국내 방향 5획을 대조했다. 완료하지 않은 진행 프레임·확대 경계·재생은 승인하지 않았다. 고정 원본·엔진·국내 메타데이터 검증은 통과했으며, 기존 런타임에 이 후보가 포함되지 않음을 확인했다.

적용 5459/5,978자, 미적용 519자. 빌드·전체 테스트·모바일 검증을 실행하지 않았다. 다음 후보 瑲 14획.
