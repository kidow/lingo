# 한국 필순 근거 재조사

조사일: 2026-09-08. 조사 범위: 한국어문회 공식 상담·출제기준, 한국한문교육학회 연구, 국내 교과서 발행사의 공개 자료. 앱의 필순 데이터는 변경하지 않았다.

## 결론

근거 없이 순서를 생성하는 것은 기술적으로 가능하지만, 한국어문회 기준의 올바른 필순이라고 보장할 근거는 찾지 못했다. **글자를 그릴 수 있다는 사실, 한국에서 쓰는 순서라는 판단, 시험기관이 인정하는 순서라는 판단은 별개다.** 일반 규칙을 적용해도 순서가 하나로 정해지지 않는다는 국내 연구와 실제 복수 순서를 허용하는 한국어문회 답변이 있다.

새로운 국내 공개 경로로 동아출판의 한자 기초 필순 영상과 공개 스마트 교과서를 찾았다. 씨마스는 필순 ZIP의 존재를 공식 소개에서 확인했지만 파일을 확보하지 못했다. 기존 비상교육 1,800자 자료와 합쳐 추가 승인 수를 계산하지 않는다. 이번 조사에서 새로 전체 획순을 시각 검증하여 승인한 글자는 0자다.

김영호, 「교육용한자의 필순과 획수의 諸問題檢討」, 같은 학술지 41, 2013.12, 293–321의 [학회 제공 초록](https://kiss.kstudy.com/Detail/Ar?key=3200507)도 읽었다. 한 획인지 두 획인지 애매한 글자가 있어 필순과 총획수가 함께 문제가 된다는 연구다. 이 역시 학술적 논의이며 시험기관의 인정 순서 표는 아니다. PDF 본문은 유료 미열람이다.

## 신규 국내 발행사 경로

### 동아출판: 실제 공개 영상 경로 확보

- [2022 개정 고등학교 한문 공식 소개](https://promotion.douclass.com/pc/school/details/high/cc/cc)는 필순을 포함한 전자 저작물을 제공한다고 명시한다. 대표 저자는 김우정이며 페이지에 정확한 게시일은 표시되지 않는다.
- 공식 페이지의 QR 전체 보기 링크는 [고등학교 한문 QR 모음](https://t25.kr/yalv)이다. 공개 QR 모음에서 [한자 바르게 쓰기](https://t25.kr/sby2)로 연결된다.
- 최종 [필순 영상 목록](https://qr.t25.kr/HI22CHC00TOT01101)에는 **州·小·囚·中·犬·巡** 6개 항목이 실명으로 표시된다. 각각 일반 필순 원칙을 설명하는 영상이다. 1,800자 전체 목록이라고 해석하지 않는다.
- 기존 비상교육 원본 목록을 `scripts/hanja-stroke-textbook-source.py --json`으로 다시 읽어 SHA-256 `32853d2396dc4fe38362b9e51a828144d7e48889f60e28d850cae9fa2335620c`를 검증했다. 동아의 6자는 모두 비상 1,800자에 이미 있다. 비상 행 번호는 州 `1380`, 小 `0828`, 囚 `0875`, 中 `1391`, 犬 `0075`, 巡 `0894`이다. 따라서 동아 자료는 **새로운 교차 검증 출처**이며, 기존 국내 검토 후보 문자 수를 늘리는 자료는 아니다. 특히 囚·巡도 새 문자 2자로 합산하지 않는다.
- 새 비교 자료 후보: [囚 재생 페이지](https://qr.t25.kr/HI22CHC00TOT01101/4334), [巡 재생 페이지](https://qr.t25.kr/HI22CHC00TOT01101/4340). 해당 HTML이 명시적으로 연결한 MP4에 HEAD 요청을 보내 각각 HTTP 200과 크기 937,935바이트 / 1,137,066바이트를 확인했다. 영상을 내려받거나 재생하지 않았으므로 처음부터 끝까지의 필순·획 경계·방향은 아직 검증하지 않았다.
- [공개 스마트 교과서](https://smart-book.douclass.com/22/HI/CH/CHI/Documents_240807/app/resource/include/main/index.html)도 공식 소개의 링크로 접근 가능하다. 공개 `indexdata.js`에는 교과서와 단원별 콘텐츠 경로가 있다. 첫 단원 콘텐츠 뷰어 HTTP 200을 확인했지만 글자별 전체 필순 목록은 확보하지 못했다.
- 근거 확보 수준: 발행사 연결 → 글자 실명 목록 → 해당 재생 HTML과 실제 미디어 존재까지 확인. 추가 글자의 전체 필순 승인이나 앱 내 영상 재배포 허락을 얻은 것은 아니다.

### 씨마스: ZIP 존재 확인, 파일 미확보

- [2022 개정 언어생활과 한자 공식 소개](https://viewer.cmass.kr/html/textbook/view_h_35.shtml), 대표 저자 김성중. 페이지에 충청북도교육청 표기가 있고 교과서·교사용 지도서·교사용 교과서의 공개 미리보기 링크가 있다.
- 공식 교수 지원 자료 표에 **필순 / ZIP**이 명시된다. 따라서 새 한국 발행사 자료 경로의 존재는 확인됐다.
- [실제 티칭샘 자료실](https://teachingsaem.cmass.kr/textbook-material/detail/552)까지 직접 열람했다. 사이트의 다운로드 기능에는 로그인 및 교사인증 안내가 있다. 공개 초기 HTML에는 필순 ZIP의 직접 URL 또는 글자 수가 나타나지 않았다.
- 인증을 우회하거나 교사 계정을 사용하지 않았다. ZIP 내용과 범위는 미확인이고 현재 카탈로그와의 교집합 수를 계산할 수 없다. 소개 표만 보고 실제 글자별 데이터 확보로 보고하지 않는다.

### EBS 및 상위 급수 교재: 존부와 전체 필순 수록을 구분

[EBS가 소개하는 고급 1·2급 교재](https://www.ebs.co.kr/pass/book/hanja/404540)는 메인에듀, 김봉환, 2021-03-02로 표시되며 목차에 필순 기본 원칙이 있다. 검색 결과에서는 책 설명을 확인했으나 `ebs.co.kr` 직접 접근은 robots 제한으로 원문 전체를 가져오지 못했다. 상위급 배정한자와 필순 원칙이 있다는 사실은 3,500자 전부의 획별 도해가 있다는 뜻이 아니다. 이번에 이 경로의 필순 본문은 확보하지 못했다.

한국어문회 상위급 지정지침서 판매 경로와 기존 500자 HWP는 이전 조사에서 확보했다. 이번 조사에서는 기존 경로를 신규 확보로 중복 집계하지 않았다. 상위급 교재의 전수 도해 수록 여부는 실제 본문 확인이 필요하다.

## 시험 범위와 추천 적용 기준

[한국어문회 현재 출제기준](https://www.hanja.re.kr/kccpt/exam/questInfo.do)을 다시 확인했다. 표의 필순 문항은 8급부터 5급까지 있고 4급II 이상에는 `-`로 표시된다. 단, 기관은 출제기준표가 기본지침이며 출제자에 따라 달라질 수 있다고 안내한다. 상위급 전체 필순은 유용한 쓰기 학습 기능이지만 현 표의 필순 출제대상과 같다고 설명하지 않는다.

1. 기존 503자와 한국어문회 확정 도해 기반 검증을 유지한다.
2. 비상교육 기존 1,800자 자료와 동아의 새 공개 사례를 국내 교과서 근거로 교차 검토한다. 순서·방향·획 경계를 처음부터 끝까지 확인하고 판본·영상 페이지·검토일을 기록한다.
3. 씨마스처럼 존재만 확인한 자료는 별도 확보 대기 상태로 남긴다. 현재 미확보를 자료 없음으로 해석하지 않는다.
4. 외국 표준이나 부수 합성으로 만든 것은 검토 후보로만 보관한다. 한국 기준 확인 없이 기존 승인 데이터에 편입하지 않는다.
5. 두 가지 허용 필순이 확인되면 근거별 허용 순서를 표현한다. 화면에서 하나를 재생하더라도 다른 정당한 순서를 무조건 오답 처리하지 않는다.

## 확인 한계

이 조사는 한국 정부가 5,978자 전부의 유일한 필순을 정한 표준이 존재하지 않는다는 증명이 아니다. 조사한 공개 경로에서 그러한 전수 자료를 확보하지 못했다는 뜻이다. 교과서 승인, 발행사의 공식 보조자료, 시험기관의 개별 필순 확인을 같은 근거 수준으로 합치지 않는다.
