# 遷 15획 필순 자료 확보·검토

모야랜드의 **15단계 누적 필순 도해와 1~15번 전체 윤곽 도해를 확보**하고, 15단계의 순서·분할을 대조했다. 기존의 ‘개별 15획 자료 미확보’ 상태에서 진전했다. **15획 전체의 움직임·후보 경로 검증과 런타임 승인은 아직 아니다.**

## 확보한 자료

- [모야랜드 遷 항목](https://www.moyaland.com/_new/hanja/item_01.php?it_id=1428026156): 3급Ⅱ·15획 표기와 ‘쓰기 클릭’으로 열리는 두 도해를 직접 열람했다. [누적 필순](https://www.moyaland.com/_new/data/cheditor4/1509/9b04c80cd71f79f8ac552a3e02a90b53_9rrvxtC9HHqYDYchw1XMag7D4ZWvj9vT.jpg)은 795×112, [번호 윤곽](https://www.moyaland.com/_new/data/item/1428026156_l2)은 635×597이다. **민간 교육 사이트의 자료이며 한국어문회 공식 인증 자료라고 표시하지 않는다.**
- [이전 비상교육 영상 검토](../hanja-g3ii-batch9-2026-09-12/review-a.json)의 원문을 같은 SHA-256으로 다시 확보했다. 이번에는 12.1·13.0·15.1초의 안쪽 부분과 17.7·18.1·18.5·18.9·21.9초의 책받침·완성 모습을 직접 대조했다. 영상 전체를 모든 시간 간격에서 새로 검수했다고 주장하지 않는다.
- [WORDROW](https://hanja.wordrow.kr/한자/遷/)는 획수 15를 표시하지만 영상 출처를 ‘일본어용 AnimCJK’로 명시한다. 독립된 국내 필순 근거로 채택하지 않았다.
- [씨마스 소개](https://viewer.cmass.kr/html/textbook/view_h_35.shtml)에는 필순 ZIP 안내가 있지만 [자료실](https://teachingsaem.cmass.kr/textbook-material/detail/552)에서 遷의 수록 여부·전체 순서를 확보하지 못했다. 자료가 없다고 단정하지 않는다.
- e-hanja는 [앞선 검토](../hanja-g3ii-dictionary-12-2026-09-13/review.json)의 유료 페이지 제한을 유지한다. 이번에는 추측한 상세·SVG 주소로 접근하지 않았다.

## 차이가 확인된 부분

| 자료 | 상부·가운데 | 안쪽 굽음 | 책받침 | 해석 |
|---|---:|---:|---:|---|
| 모야랜드 번호·누적 도해 | 9획 | 10~11번, 2획 | 12~15번, 4획 | 15단계가 명시됨 |
| 비상교육 기존 영상 | 이전 검토 9구간 | 12.1·13.0·15.1초에 따로 끝나는 3구간 | 점·위 꺾임·아래 굽음·파임 | 기존 16구간 보류 사유가 남음 |

모야랜드의 10번은 안쪽 위 굽음을 한 획으로 표시한다. 영상은 위 꺾임 다음에 별도 가로를 채우므로 두 자료의 안쪽 모양과 분할이 다르다. 책받침의 위·아래 굽음도 모야랜드에서 13·14번으로 분리된다. 영상을 15획에 맞추기 위해 어느 두 구간을 임의로 합치지 않는다.

누적 도해와 번호 위치는 **순서·분할을 보여 주지만, 모든 구간의 시간에 따른 진행 방향까지 보여 주지는 않는다.** 특히 10~11획의 꺾임·시작·끝은 같은 자형의 움직이는 자료 또는 명시적 방향 도해로 보강할 대상이다. 앱의 정적 SVG는 두 점 책받침인 반면 두 교육 자료는 한 점과 위아래 굽음이다. 글꼴 모양만으로 손글씨 획 경계를 정하지 않는다.

## 결과와 다음 작업

- 신규 확보: 한 글자의 **15단계 도해 + 15개 번호 윤곽**. 같은 제공자의 두 자료이므로 독립 출처 두 개로 세지 않는다.
- 신규 애니메이션: **0자**. 현재 적용 **1,489/5,978자**, 미적용 **4,489자**. 3급II는 **499/500자**, 遷만 남는다.
- 다음은 **15획 후보 전체 자형·경계 대조와 안쪽 10~11획 방향 보강**이다. 후보를 검토한 후에 런타임 승인 여부를 결정한다.

## 파일·검증

`sources.json`에 실제 주소·바이트 수·SHA-256을, `review.json`에 15획별 관찰과 영상 8시점을 남겼다. 원문 그림·영상 바이트와 스크린샷은 저장·커밋하지 않았다. `serve.mjs`는 출처 해시를 검증한 뒤 메모리에만 보관하며 루프백의 고정 경로만 제공한다. `review.html`에는 원문 영상 시점을 선택하는 대조 화면이 있다.

```sh
rtk proxy node docs/hanja-g3ii-cheon-2026-09-13/serve.mjs
rtk proxy node docs/hanja-g3ii-cheon-2026-09-13/verify.mjs
rtk proxy node --test 'lib/hanja*.test.ts'
```

자료 서버의 최초 버전은 영상 범위 요청을 처리하지 못해 시점 선택이 0초로 되돌아왔다. HTTP 206 범위 응답을 추가한 후, 실제 정지 시각과 화면을 확인한 관찰만 기록했다. 직접 이미지 탭이 0×0으로 렌더링된 상태도 관찰 증거로 세지 않았다.

문서 검사 통과: 15개 순서·번호, 6개 기존 파일 해시, 승인 없음, 실제 런타임 수량. 한자 회귀 테스트 **186개 통과**. 카탈로그·앱 코드·기존 증거 파일은 수정하지 않았다.
