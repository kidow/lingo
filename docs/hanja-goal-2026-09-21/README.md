# 연속 한자 goal 진행 기록

이 폴더는 다른 작업의 기존 보고서를 수정하지 않고 연속 goal의 상태를 기록한다. 실제 다음 행동과 미커밋 소유 경로는 `progress.json`을 먼저 확인한다.

## 2026-09-21 — 다음 후보 조사

현재 작업 트리의 미적용 1,052자에 대해 KanjiVG 고정 리비전 전체 트리를 대조했다. **212자·363파일**이 존재하며, 원본을 직접 읽어 센 결과 **65자·119파일**이 배정표 획수와 일치한다. HTTP 실패는 0건이다. 이는 후보 발견이며 필순·방향·국내 자형 승인이 아니다. 8개 우선 파일은 `next-candidates.json`에 원본 해시와 함께 기록했다.

재현: `node docs/hanja-goal-2026-09-21/inventory.mjs --limit=8`. 출력 개수 제한을 빼면 획수가 일치하는 후보 전체를 출력한다. 사전 획수가 배정표와 다른 글자를 이 방식으로 배제하거나 최종 보류 판정하지 않는다.

## 적용 완료 — 兎 8획

정규화·순열 보정·누적 자형 대조 후 런타임에 연결했다. 배정표 7획은 그대로다. 한자 검사 766개, 경로 재현 검사, 별도 체크아웃의 제품 빌드·타입 검사가 통과했다. 제품 검색의 사전 자형 표시와 학습 카드 자동재생 시작·8획 완료도 확인했다.

브라우저 연결 복구 후 쓰기 시트 자동재생 1/8→8/8, 다시 재생 1/8→8/8, 정적 오버레이 비중첩을 확인했다. 캔버스에서 아래로 드래그하면 1획이 입력되고 시트 위치는 그대로 유지됐다. 제품 콘솔 오류는 0건이었다. 상세 기록은 `../hanja-mang-yu-rabbit-2026-09-21/integration.md`에 있다.

兎 적용 직후 런타임은 4,926/5,978자, 미적용 1,052자였다. 특급II는 845/1,150자다. 커밋은 `97d6f2d0`이다.

## 적용 완료 — 饉·睹·燐 3자·50획

**饉·睹·瀆·燐 4자·68획**의 국내 사전 순서·방향·경로·완성 자형을 RAM에서 대조했다. 饉은 원본 4–7획과 17–19획의 순서를 보정하고, 정규화한 20개 누적 상태를 다시 대조했다. 睹·燐은 각각 14·16획의 순서를 유지한다. 모든 곡선은 고정 리비전의 KanjiVG 원본이며 100/109 정규화 외에 새 점·획 분할·병합·방향 반전을 하지 않았다. CC-BY-SA-3.0 출처와 수정 내역은 공개 번들에도 포함한다. 국내 사전 교차검토이며 시험 주관기관의 공식 인증이 아니다.

瀆 18획은 보류한다. 새 후보는 四 안쪽 두 획의 자형을 해결했지만, 10획 끝의 위쪽 갈고리가 국내 사전과 일치하지 않는다. 갈고리를 임의 생성하지 않는다. 해제 조건은 해당 전체 획의 재사용 가능한 경로 또는 갈고리 없는 자형을 허용하는 독립 국내 근거다.

`g1-next-review.json`은 조사 시작 시점의 출처 핀, `g1-reviewed-candidates.json`은 재사용 가능한 원본 경로, `g1-findings.json`은 전체 획 검토·보류 판단이다. `node docs/hanja-goal-2026-09-21/build-g1.mjs`는 공개 번들을 재현한다. 사전 SVG·HTML·화면 이미지는 저장하지 않았다.

검증: 전체 한자 테스트 768개 중 기존 집계 테스트 1곳에서 새 등록 3자를 누락한 것을 보완했고, 해당 검사와 신규 검사 9개를 다시 실행해 모두 통과했다. 공유 작업 트리의 타입 검사와 독립 체크아웃 제품 빌드가 통과했다. 제품 코드·번들은 체크아웃과 바이트가 같다. 임시 HanjaCard 화면에서 饉 학습 자동재생 1/20→20/20, 쓰기 진입 자동재생·완료, 다시 재생 시작을 확인했고 정적 오버레이 중첩과 콘솔 오류는 없었다. 캔버스 드래그 시 시트 유지 동작은 같은 회차의 兎 검증으로 확인했으며 관련 UI 코드는 변경하지 않았다.

현재 실제 적용은 **4,929/5,978자(82.5%)**, 미적용 **1,049자**다. 1급은 **1,055/1,145자(92.1%)**, 90자 남았다. 다음은 남은 KanjiVG 후보를 국내 사전 획수와 대조해 선별한다. 다음 목록의 鼈·瞥은 배정표와 사전 획수가 각각 25/24, 17/16으로 달라, 목록의 획수 일치만으로 승인하지 않는다.
