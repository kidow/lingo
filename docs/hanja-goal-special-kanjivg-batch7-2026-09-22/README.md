- 두 보류 글자의 Kaisho 계열은 문제의 외곽·내부 경로가 기본판과 동일하다. 다른 10획은 국내와 방향이 반대이며 11획은 위로 꺾는 끝부분이 없다. 단순 교체로 해결되지 않는다.
