諸의 별도 12획은 원문 관찰 구간이 있는 null 계보로 유지됐으며, 蒸·之·菜의 분할은 원본 획을 재사용하는 계보로 보존됐다. 원본 획 누락은 없고, 이전 보류 문자인 奔·慈는 공개 경로와 런타임에 포함되지 않았다.

모든 입력 SHA를 검사 전후 비교해 변경이 없음을 확인했다. 이 감사는 별도 프로세스의 읽기와 실제 생성기·검증 함수 호출만 실행했다. 빌드·타입 검사·공유 데이터 편집·Git 작업은 실행하지 않았다.

전체 입력 고정값, 50자별 대조 결과, 급수별 적용률, 4개 peer 고정값, 이전 35개 문서 SHA는 [audit-integration.json](audit-integration.json)에 기록했다.
