# 韔 17획 보류

브라우저 패널에서 국내 자형과 전체 원본4종을 대조했다. 기본·VS0·VS1는 자형이 호환되나 VS2는 왼쪽 아래 꺾임이 국내 곧은 세로획과 다르다. 원본 경로의 연속 경계만 사용하면 기본·VS0·VS1는19획,VS2도18획으로 국내17획을 넘는다. 기존17 후보는 비연속[4,7]·[12,17] 폐합이 포함된다. 실제 원본을 임의로 연결하거나 획수를 맞추지 않으며 방향·진행·확대·재생은 미검토다.

브라우저 패널에서 전체 원본 4종과 전체 자형을 대조했다. 국내 방향은 미검토다. 완료하지 않은 진행 프레임·확대 경계·재생은 승인하지 않았다. 고정 원본·엔진·국내 메타데이터 검증은 통과했으며, 기존 런타임에 이 후보가 포함되지 않음을 확인했다.

적용 5459/5,978자, 미적용 519자. 빌드·전체 테스트·모바일 검증을 실행하지 않았다. 다음 후보 瘥 15획.
