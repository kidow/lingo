# 伻 7획 적용

국내 사전의 전체7획·방향·누적 자형을 2016년 공개 GlyphWiki 백업의 완성 글자 `u4f3b`와 대조했다. 한국어문회 공식 필순 승인으로 표시하지 않는다.

- 가운데 두 획은 국내 순서대로 재배열했다. 원래 세 이차곡선과 모든 외곽점은 보존했고 새 경로나 연결선을 만들지 않았다.
- 원본 백업 SHA256, 정확한3개 의존 레코드, 고정 엔진8파일 재현을 확인했다. 개별 글자 리비전이 없는 백업에 임의 버전을 붙이지 않았다.
- 전체7획과63개 중간 장면 검토, 한자 테스트192파일922개 통과. 새 테스트의 타입 좁히기 수정 후 해당3개 테스트와 프로덕션 빌드·타입 검사·정적7페이지를 다시 통과했다.
- 모바일430×932에서 학습·쓰기 자동재생, 다시 재생,7/7완료, 입력0→1→0을 확인했다. 캔버스 드래그 중 시트 위치·스크롤 불변, 정적이미지0·애니메이션1, 콘솔 경고·오류0. 1.5배 속도 코드는 변경하지 않았다.
- 실제 적용4,992/5,978자(83.5%), 미적용986자. 급수별 현황은 goal 진행 기록에 있다.

다음은 迅(1급7획). 완성 원본과 엔진 재현을 확보했으며 전체 시각 검토는 아직 하지 않았다. 내부 갈고리·세로 접속과 辶의 획 경계를 먼저 대조한다.

비공개 사전 그래픽은 RAM에서만 사용했다. 이 배치 UI/검토 서버와 격리 워크트리는 정리했고, 공개 백업 RAM조회 서버51967은 다음 후보를 위해 유지했다.
