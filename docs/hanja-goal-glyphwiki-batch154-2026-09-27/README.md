# 兕 사전 7획 변형 적용 — batch154

특급 兕(외뿔소 시)는 배정표 8획을 유지하고 국내 사전에서 검토한 7획을 재생한다. 한국 자형 u5155-k@1이 가리키는 전체 u5155-j@1과 선언된 u51f9-j@2를 사용했다. 시험기관 공식 승인을 뜻하지 않는다.

- 국내 7획 방향·누적 자형, 63개 진행 프레임 검토. 사전 clip c1–c7과 복합 꺾임에 따라 원본을 묶었다. 배정표 수에 맞추기 위한 임의 분할 없음.
- 원본 이차곡선 2개와 모든 다각형 보존. 원본 연결점 일치, 새 점·연결선·부품 교체 없음.
- 고정 엔진 8파일 재현, 테스트 240파일/1,066개 통과. 기존 변형 허용목록 검사에 28번째 兕를 추가 후 전체 재검증했다.
- 격리 빌드·타입 검사·정적 7페이지 생성 통과. 빌드 후 변경은 변형 허용목록 테스트 하나뿐이며 별도 스냅샷과 파일 일치 검사로 확인했다.
- 모바일 소개/쓰기 자동재생·다시 재생·7/7 완료, 배정/재생 수 구분, 오버레이 비중첩, 캔버스 0→1→0 및 시트 고정 확인.
- JEV는 보조 분류이며 런타임 승인 권한 없음. 비공개 그래픽은 RAM에서만 사용.
- 적용 5,040/5,978자(84.3%), 미적용 938자. 다음 후보 坵 8획의 현행 전체 원본 확보 완료, 전체 검토 대기.
