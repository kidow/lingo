# 특급 11차 蜩~倩 — 50자·716획 반영

2026-09-20 · **50자·716획 전부 반영, 보류 없음** · 특급 497 → 547/1,328자

특급이 **40%**를 넘었고, 전체는 **79.8%**다. 711획은 허가된 중간선 그대로다.

## 자형이 획수를 이긴다 — 倩

倩은 후보를 바꿀 뻔했다. 시작 후보 Ja가 60°를 넘는 획 **둘**, Hans는 **하나**.
획수만 보면 교체가 맞는데, 좌표를 열어 보니 **Hans와 MM은 青**을 쓰고
**사전과 Ja는 靑** — 아래 상자를 세로 하나로 닫는 형태다.

[10차](../hanja-special-batch10-2026-09-20/README.md)에서 靚을 보류한 것과 같은 자리다.
보류할 만큼 다른 자형이라면 **그 자형을 골라 쓸 수도 없다.**
그래서 시작 후보를 지키고 두 획은 교환으로 풀었다.
후보 규칙과 자형 규칙이 반대로 당긴 **첫 사례**라 [selection.json](selection.json)에 적어 뒀다.

## 국소 보정 5획 4자

| 보정 | 글자 | 내용 |
| --- | --- | --- |
| 穴의 첫 점 | 竈·窗 | 세로로 곧게 (각 1획, 64°·62°) |
| 隹의 짧은 획 | 隼 | 오른쪽 위 획을 왼쪽 아래로 반전 (3) |
| **丷** | 鬻 | 두 표시를 바깥으로 벌어지게 반전 (19·20) |

穴의 첫 점이 같은 회차에서 두 번 나왔다 — 竈과 窗, 64°와 62°.

螽과 譖은 사전 그림이 `translate(12, -830)`로 가로 오프셋을 가진다.

부수 유사성으로 승인하지 않았다. 쉰 글자의 사전 전체 필순을 순서대로 보고,
색으로 나눈 25% 진행 구간에서 방향·펜 떼기·획 경계·완성 자형을 대조했다.
[direction-probe.mjs](direction-probe.mjs)의 60° 초과 표시는 후보 교체·교환·보정으로 **모두** 해소했다.
공개한 순서·경로로 다시 재면 60°를 넘는 획이 없다.
45~60° 구간은 여섯 획(幬 9, 躕 8, 崒 4, 蹌 10, 瘵 1, 蹢 8)이고, 이전 회차와 같은 기준으로 그대로 뒀다.
