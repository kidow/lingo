# 3급II 교과서 후보 첫 50자

기존 한자 작업을 `7ffca28c17e0ef3497c9322283a7f0e7de5e0e29`로 커밋한 뒤 시작했다. 시작 시 승인 991자, 3급II는 1/500자다.

고정 공개 교과서 목록과 정확 표기가 일치하는 미적용 480자에서 카탈로그 순서의 첫 50자를 선택했다. 어려운 글자나 보류 글자를 다른 대상으로 교체하지 않는다. [선정 명세](inventory.json)에 글자·급수·획수·원문 행·영상 파일명과 선택 해시를 보존했다.

진행 상태: 고정 50자·577획의 검토 및 공개 번들 반영 완료. 원형 일치 13자, 보정 36자, 전체 직접 작성 1자(槪)이며 이번 묶음의 보류는 없다.

검토는 개별 원본 영상의 순서·방향·펜 경계·자형을 확인하고, 좌표 후보와 다른 부분을 보정하는 절차다. 외국어 획 데이터의 존재나 획수 일치는 한국 필순의 근거로 간주하지 않는다. 영상 바이트·출처 해시, 각 획의 완료 확인 시점, 원래 획 번호와 직접 작성 부분, 최종 경로 해시를 기록한다.

공개 번들 생성 검증, 한자 테스트 134개, 타입 검사와 프로덕션 빌드를 통과했다. 기존 교과서 488자 객체는 변경 없이 유지됐고 이번 50자만 추가됐다. 원본 영상은 메모리에서만 처리했다. 선택 당시 상태를 보존한 inventory.json은 변경하지 않았으며 최종 상태는 [결과 원장](result.json)을 따른다.

출처 구성은 한국어문회 503자와 비상교육 교과서 영상 대조 538자다. 교과서 영상 대조를 한국어문회 개별 인증으로 표시하지 않는다. 각 중앙선은 원본 대조 및 로컬 보정 결과이며 출판사가 배포한 SVG를 뜻하지 않는다.

검토 자료: [A 15자](review-a.md), [B 15자](review-b.md), [C 13자](review-c.md), [본 검토 5자](review-root.md), [추가 본 검토 2자](review-root-extra.md). 寬·館은 C에서 본 검토로 옮겼으며 전체 선택은 그대로다. 다른 검토자가 본 검토 7자의 원본을 다시 확인했고, 寬·館·巧의 접합과 간격을 추가 보정했다.
