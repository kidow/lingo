# 3급II 첫 묶음 B — 비상교육 영상 대조

- 대상: **距乾劍隔兼謙頃徑硬耕契桂啓溪械**, 15자 175획.
- 결과: **15자 matched 제안**, 15개 개별 보정 레시피. 공유 원장과 런타임은 이 파일에서 변경하지 않았다.
- 원본 후보: 고정 AnimCJK Ja. 원본의 획수는 모두 영상의 예상 획수와 같지만 순서·방향·자형·접합이 모두 같지는 않았다. 외국 후보의 필순을 정답 근거로 삼지 않았다.
- 모든 개별 MP4를 메모리에서 내려받아 URL·실제 바이트 수·SHA-256을 보존했다. 전체 0.5초 진행표, 매획 종료 부근의 0.1초 표본, 600px 원본 완성형과 보정 후보의 모든 획을 직접 열람했다. 선폭 5에서 접합과 흰 간격을 확인했다.
- `strokeEndsSeconds`는 해당 획의 완료가 관찰된 보수적 표본 시각이다. 최초 완료 프레임이나 실제 펜의 중단 시각을 0.1초 정확도로 측정했다는 뜻은 아니다. 일부 다음 획이 시작된 표본도 앞 획의 완료 확인에는 사용했다. 초기 0.5초 표본에서 완료 전인 桂 8획, 啓 3·7획, 械 6·9획은 상세 영상을 보고 기록을 늦췄다.
- 이 판정은 **Codex 시각 대조**다. 비상교육의 개별 교과서 영상과 맞는다는 뜻이며, 한국어문회 개별 승인·유일한 정답·인간 전문가 확인을 뜻하지 않는다. 서예 외곽선의 픽셀 일치 평가도 아니다.
