## 24획 검토 결과

- **祐 10획:** 후보 1–5는 示 형태다. 후보 6·7은 **가로→왼쪽 내리긋기**이며 대만의 짧은 자형 순서와 같다. 국내 사전은 반대인 **왼쪽 내리긋기→가로**다. 6·7 교환은 보정 검토안으로만 기록하고 적용하지 않았다. 8–10의 口 경로도 확인했다.
- **禎 14획:** 示 5획과 貞 9획의 전체 경로를 확인했다. **10·11획 내부 가로획 끝이 오른쪽 세로획에 닿지 않는 문제**가 있다. 보정은 아직 적용하지 않았다.
- 두 글자의 앱 SVG와 후보는 示를 쓰는 구조가 맞지만, 독립적인 **목표 자형 전체 필순·방향 근거**는 확보하지 못했다. 정적 자형, 후보의 자체 순서, 부품 재사용만으로 승인하지 않는다.
