## 근거와 범위

[비상교육 고등 한문 자료](https://text.vivasam.com/detail/186)의 정확한 행 0377·0378과 전체 영상을 사용했다. 영상, XLSX, 원본 후보 경로 파일의 SHA-256을 다시 확인했다. 전체 순서·획 경계·방향·누적 경로·최종 자형을 대조했고, 문제가 된 구간은 10fps로 분리했다. 시각은 표본에서 관찰한 완료 시점이며 정확한 펜 이탈 시각이 아니다.

[Naver 屯](https://hanja.dict.naver.com/#/entry/ccko/5ad8c79d4319404faeda0b992bf87197)과 [Naver 鈍](https://hanja.dict.naver.com/#/entry/ccko/c6617f6490394f36a687aca63d463277)의 e-hanja SVG는 보충 대조에 사용했다. 鈍의 XML 1·3번은 시간순으로 9·11획이다. 두 서비스는 독립된 두 출처로 세지 않는다.

추가 확보한 [모야랜드 屯](https://www.moyaland.com/_new/hanja/item_01.php?it_id=1405666738)·[鈍](https://www.moyaland.com/_new/hanja/item_01.php?it_id=1424063471)의 정적 자료 4개는 번호와 누적 순서를 보여준다. 번호 위치만으로 방향을 확정하지 않았고, 애니메이션 원저작자의 독립성도 확인되지 않아 승인 근거로 쓰지 않았다. Daum 금성 사전 屯 항목은 뜻·획수 자료로 확인했으나 방향을 판정할 영상은 확보하지 못했다.

제품에는 기존 Arphic 라이선스의 Make Me a Hanzi 중심 경로를 사용했다. 원본 경로 대응 1–4 / 1–12를 보존하고 가로획 두 개의 점 배열만 역순으로 바꾸었다. 출판사 영상·사전 SVG·모야랜드 이미지는 RAM에서 열람했으며 저장하거나 제품에 복사하지 않았다. 이번 결과는 출판사 자료에 대한 시각 검토이며 시험 주관 기관의 인증은 아니다.
