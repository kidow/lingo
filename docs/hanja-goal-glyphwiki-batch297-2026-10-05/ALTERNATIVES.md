# 慤 전체 대체 자형 대조

네이티브 브라우저133–136에서 각 전체 후보의 국내15획 방향·누적·완성 자형을 대조했다. g만135개 진행 표본과 실제 앱 검증을 거쳐 적용했다. 다른 후보의 일부 부품을 가져오지 않았다.

결과와 수치는 alternative-review.json, 원본과8개 고정 엔진 재현은 primary/g/t/v 접두사의 JSON에 있다. primary는 원래 선택한u6164-k다. 전체 g의7→8 중심선 차이0.935/200은 수정하지 않았다. 두 원본 윤곽의 내부점70,85.2가 겹치는 것을 명시적으로 검증하고, 다른 접점은 정확한 연속성을 검사한다. 일반적인 접점 허용 오차나 새 연결선은 도입하지 않았다.
