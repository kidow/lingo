# 禴 22획 적용

국내 사전과 원본 4종 전체 자형·22획 방향을 대조했다. 3종이 일치하고 礻 형태인 VS2는 제외했다. 198개 단계 화면과 곡선·꺾임 7개의 99.99→100% 확대를 브라우저 패널에서 검토했다. 원본 연속 획을 유지한 22획·23마스크를 등록하고 하단 가로획을 두 세로획보다 먼저 재생한다. 19획 왼쪽 끝갈고리는 고정 엔진의 terminal14 공식과 원본 폴리곤으로 같은 획 안에서 노출한다.

출처 재조회·해시·원본 윤곽 일치 검증, 격리 전체 테스트 2,232개와 프로덕션 빌드, 모바일 자동재생·다시 재생·쓰기 재진입·입력·지우기·시트 고정 검증을 통과했다. 실제 학습 기록을 쓰지 않는 RAM 모의 환경이며 원본 무변경을 확인했다. 사전 교차검토이며 시험 주관 기관의 공식 승인을 뜻하지 않는다. 비공개 사전 그래픽은 저장하지 않았다.

전체 5,978자 중 5,355자 적용(89.6%), 623자 미적용. 남은 급수: 1급64·2급1·특급II91·특급467. 보류144자. 다음 후보는 餲18획 끝갈고리 재검토, 이후 颺18획.
