# 1급 椅~嫡 50자 검토 — 50자·591획 반영

2026-09-19 · **50자 반영, 보류 없음**

[1급 13차 訛~毅](../hanja-g1-batch13-2026-09-19/README.md)의 `next-batch.json`에 고정한 후보 50자를
같은 방식으로 대조했다. 첫 대조에서 34자가 일치했고, 16자는 보정 후 전체 획을 다시 확인했다.
허가된 중간선 578획을 유지하고 13획을 국소 보정했으며, 10자의 획 순서를 바꿨다.
MM 원본 41자, Ja 원본 9자에서 출발했다.

## 보정

같은 회차의 檣처럼 嗇의 순서가 이미 사전과 같은 글자(Ja 원본)와,
灼의 勺 점처럼 사전이 납작하게 긋고 허가 원본이 기울여 쓰는 50°의 차이는 그대로 뒀다.

부수 유사성으로 승인하지 않았다. 각 글자의 사전 전체 필순을 순서대로 보고,
색으로 나눈 25% 진행 구간에서 방향·펜 떼기·획 경계·완성 자형을 대조했다.
보정 16자는 변경 획뿐 아니라 전체 획을 재대조했다.

[direction-probe.mjs](direction-probe.mjs)가 60°를 넘는 획 30개(13자)를 표시했고,
13자 모두 보정으로 이어졌다. 표시만 되고 그대로 둔 획은 없다.
爾·嚼·薔·齋·觝처럼 세로 획끼리 방향이 같아 프로브에 걸리지 않거나 덩어리로 얽힌 자리는
획 끝점 좌표를 숫자로 확인한 뒤 대응을 맞췄다. 爾의 冂 재배열은 프로브 표시 없이 시트와 좌표로만 잡았다.
45~60° 구간의 방향 차이는 16개였다. 그중 7개(嚼 14, 薔 6·10, 漿 1·2, 醬 1·2)는 재배열 전에 어긋난 대응이라
재배열로 해소됐고, 나머지 9개는 사전이 세로로 긋고 허가 원본이 기울여 쓰는 짧은 점(誼·痍·疵·滓·嫡)과
糸·小·勺의 짧은 획(綽·雀·灼)으로, 이전 회차와 같은 기준으로 임계 아래는 허가된 중간선을 그대로 뒀다.
薔의 원문은 가로 이동 `translate(12, -y)`를 쓴다. 이동은 방향 벡터를 바꾸지 않는다.

## 근거와 재현

- [observations.json](observations.json): 50자 판정, 16자의 첫 판정·보정·재대조 기록, 8방향 코드
- [source-checks.json](source-checks.json): 50자의 원문 해시·획별 시간·XML 참조·좌표 변환
- [originals.json](originals.json): 고정한 라이선스 원본의 중간선과 정규화 경로
- [proposals.json](proposals.json), [corrections.json](corrections.json): 획별 원본 대응과 국소 보정 이유
- [candidate-paths.json](candidate-paths.json), [review.json](review.json): 승인 경로와 증거 해시
- [prepare.mjs](prepare.mjs): 읽기 전용 승인 데이터 재현 (50자 승인을 검사)
- [verify.mjs](verify.mjs): 재현 결과·공개 데이터·적용 수·다음 후보 검증. 1급 회차의 보류 글자는 큐에서 뺀다
- [checks.json](checks.json), [progress.json](progress.json): 이번 검증과 전체 진행 현황
- [next-batch.json](next-batch.json): 다음 謫~糟 50자·679획 후보
- [acquire.mjs](acquire.mjs), [source-checks.mjs](source-checks.mjs), [serve.py](serve.py): 원본 고정·원문 확인·검토 시트

필순 근거는 e-hanja 사전이며, **한국어문회 인증으로 표시하지 않는다.**
재생 중간선은 Arphic Public License의 고정 MM·Ja 원본에서 출발했다.
사전의 경로·마스크·영상·스크린샷을 파일에 저장하거나 배포하지 않았다.
자형의 구조와 진행 방향을 비교한 것으로 폰트 외곽선의 픽셀 일치나 필기 채점이 아니다.
