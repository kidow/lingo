## 검토 결과

- **髢 13획 적용**: 기본판 09ae2의 원순서를 유지했다. 첫 세로획 뒤 가로획 2–5, 꺾임 6, 점 7, 彡의 오른쪽→왼쪽 8–10획, 也의 꺾임·세로·위쪽 갈고리까지 전체 대조했다. 100/109 정규화 후 기본 굵기 5에서 13개 누적 상태와 완성형의 분리·연결을 확인했다. HzFst는 같은 경로의 1·2획만 바꾸므로 채택하지 않았다.
- **鏘 19획 보류**: 순서와 주요 방향은 맞지만 기본 굵기에서는 金의 점과 옆 가로획, 오른쪽 내부 점과 외곽 획이 붙는다. 원본 굵기로 줄여도 오른쪽 아래 점이 두 외곽 획을 잇고 金의 점은 세로획과 떨어진다. 국내 자형의 연결·간격을 동시에 충족하지 못한다.
- **爨 배정 29획 / 사전 30획 보류**: 국내 8획은 同 안쪽 口의 독립 세로획이다. 두 공개 후보에는 이 경로가 없고 작은 가로획이 외곽 세로획에 붙는다. 국내 9–30획과 후보 8–29획을 순차 대조했으며 국내 27획 火 왼쪽 점은 왼쪽으로 내려가지만 후보 26획은 오른쪽으로 내려가는 추가 차이를 확인했다. MdFst는 기존 1–9획만 재배열하므로 해결하지 못한다. 배정표 획수를 바꾸거나 경로를 임의 분할하지 않았다.

기본 후보 **61획**과 국내 **62단계**를 직접 대조했다. 髢의 정규화 누적 **13개**와 완성형을 승인했다. 鏘은 두 굵기의 완성형만 비교했으며 정규화 누적 승인으로 세지 않는다. 爨의 30칸 대응표에는 누락 위치를 `null`로 표시했다. 이는 진단용 대응표이며 런타임 순열이 아니다. 대체판은 경로 문자열의 동일성과 순서 차이를 확인했으며 전체 시각 검토로 세지 않는다.
