## 검토 근거와 범위

[비상교육 고등 한문](https://text.vivasam.com/detail/186)의 [교재 QR 뷰어](https://viewer.vivasam.com/qrviewer/viewer.html?qrcode=106502_171p_25_ST&teacher=false), 해시를 고정한 1,800자 XLSX 목록, 각 행의 전체 필순 영상을 대조했다. **출판사 교재 대조이며 한국어문회 인증으로 표시하지 않는다.**

- 정확한 원문 글자와 영상 행을 연결했다. 부수 규칙이나 다른 지역 데이터의 획수만으로 승인하지 않았다.
- 50개 영상 전체를 2fps로 열람하고 556개 후보 누적 경로의 시작점·끝점·연결·흰틈을 확인했다. 卿·顧·郭·郊·那는 10fps 구간을 추가 열람했다.
- `strokeEndsSeconds`는 표본에서 확인한 보수적인 완료 상한이다. 정확한 펜 이탈 시각이 아니며, 같은 위치의 멈춤만으로 획을 나누지 않는다.
- MM 44자·AnimCJK Ja 6자의 고정된 원본 중심선을 사용했다. 출처 영상과 디코딩한 이미지·프레임은 RAM에서만 처리했다. 원본 미디어를 저장하거나 제품에 복사하지 않았다.
- 검토자는 Codex root 1명이다. 자동 검증은 출처·경로·기록의 일관성을 확인하며, 별도의 사람 검수를 뜻하지 않는다.

## 재현과 검증

- `review.json`: 50자 판정, 정확한 영상 URL·SHA-256·바이트 수, 완료 관찰 시점.
- `observations.json`: 후보와 원문의 차이, 상세 열람 구간, 보정 후 판정.
- `originals.json`: 라이선스가 있는 후보 원본 중심선과 원본 해시.
- `candidate-paths.json`: 열람한 최종 후보 경로. **보류 11자도 포함하므로 제품 승인 목록으로 사용하지 않는다.**
- `corrections.json`, `orders.json`: 순서 보정 6자의 재현 자료.
- `baseline.json`: 작업 전 등록부·보정표·제품 번들의 기존 기록 해시.
- `verify.mjs`, `verification.json`: 적용 39자·보류 11자, 원본 대응, 경로 해시, 기존 기록 보존 및 검증 결과.
- `serve.py`: 로컬 RAM 검토 서버. 영상과 후보 원본 해시가 달라지면 중단한다. 기본 화면은 원래 후보, `corrected=1`은 순서 보정본이다.

```sh
node docs/hanja-g3-batch1-2026-09-14/verify.mjs
node --test --test-reporter=spec 'lib/hanja*.test.ts'
node scripts/hanja-stroke-textbook-build.ts --check
pnpm run build
python3 -B docs/hanja-g3-batch1-2026-09-14/serve.py
```
