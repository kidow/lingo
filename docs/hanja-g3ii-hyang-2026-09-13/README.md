# 響 1자·22획 검토

2026-09-13. 響의 22획 전체를 사전 재생과 대조하고 보정한 애니메이션을 추가했다.

## 기존 보류와 해결

기존 국내 교재 영상에서는 오른쪽 阝의 11·12획 경계에서 멈췄다가 같은
위치에서 다시 움직였다. 정지 장면만으로 두 획임을 단정하지 않고 보류했다.
[e-hanja 원본](http://img.e-hanja.kr/hanjaSvg/aniSVG/9700/97FF.svg)은
11획 완료 뒤 12획이 별도 구간으로 재생되고 13획 세로가 뒤따른다.
이번에 전체 22획과 1·2·11·12획의 끝 구간을 직접 관찰해 대조했다.

이는 국내 사전 업체의 개별 자형·필순과 비교한 결과다.
시험 주관기관의 공식 인증이나 교재·사전 간 모든 자형의 일치를 뜻하지 않는다.

## 경로 보정

- 첫 획: 기존 후보의 오른쪽 위로 끝나는 모양을 사전에서 관찰한 오른쪽 아래 방향으로 보정했다.
- 가운데 9획: 위 상자와 떨어지고 아래 굽은 획에 이어지도록 간격을 보정했다.
- 音 9획: 위쪽 鄉, 가로획 사이의 점·삐침, 아래 日이 실제 선 두께 5에서 구분되도록 작성했다.
- 11·12획: 시작·끝이 맞닿지만 두 개의 개별 경로로 유지했다.

AnimCJK의 고정된 20획 원본과 이전 22획 보정 후보를 보존했다.
이전 후보에서 이어온 경로는 10획이며, 직접 작성한 중심선은 12획이다.
12획에는 이전에 이미 작성했던 윗점 4획이 포함된다. 이번 교체는 11획이다.
모든 점을 같은 비율로 변환했으며 획의 순서·방향은 변환 과정에서 바뀌지 않는다.

숫자 출처 인덱스는 원본 계보이며 원본 좌표가 그대로라는 뜻은 아니다.
직접 작성한 12획은 null로 구분했다. 원본 Ja7을 바탕으로 분리한
5·10획도 글자 전체를 대조한 뒤 승인했다.
