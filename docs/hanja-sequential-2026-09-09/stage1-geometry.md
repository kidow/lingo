## 중요한 구별

硏의 오른쪽은 幵 6획이다. 研의 开 4획으로 대체하지 않았다. 왼쪽 石은 이미 승인된 破의 최종 경로 1–5를 다시 사용했다. 幵 6–11은 이번에 원본을 보고 작성한 중심선이다. 7획과 10획은 별개의 가로획이며 8획의 아래 왼쪽 곡선도 한 획으로 유지했다.

鄕은 乡 3 + 白 5 + 匕 2 + 오른쪽 邑 3이다. 鄉의 자형이나 良으로 바꾸지 않았다. 원본 9획의 짧은 삐침은 오른쪽 위에서 왼쪽 아래로 진행한다. 10획 중간 약 12.5초의 정지는 획 종료가 아니므로 세로굽은갈고리를 나누지 않았다. 오른쪽 邑은 위 접힌 11획과 이어지는 굽은 12획, 마지막 긴 세로 13획을 구분했다.

## 기하학 출처와 검증 범위

두 대상의 정확한 Ko/Ja/MM 원본 경로는 없었다. 추가로 KanjiVG와 animCJK의 전체 GitHub tree에서 표준 코드포인트 파일명을 확인했으나 대상 파일이 없었다. 이는 확인한 저장소의 표준 파일 경로 범위에 대한 결과이며 공개 자료 전체가 없다는 주장으로 확대하지 않는다.

- [KanjiVG tree](https://api.github.com/repos/KanjiVG/kanjivg/git/trees/master?recursive=1), 확인한 tree `55b5ba92a7cad78a62ef04db4be6f9562d949b7f`
- [animCJK tree](https://api.github.com/repos/parsimonhi/animCJK/git/trees/master?recursive=1), 확인한 tree `ec5e17cca76c87587790bcbce5ea0b4d4fb753d6`

따라서 대상의 `sourceStrokeIndices`는 전부 `null`이다. 외부 코퍼스에서 대상 글자를 얻은 것처럼 표시하지 않는다. 재사용한 부품은 `borrowedParts`에 donor 글자·최종 경로 번호·donor 전체 경로 해시·실제 upstream 번호·검증 출처·변환 행렬을 따로 보존했다. 都의 최종 10–12획은 보정 때문에 upstream 9–11획에 대응한다. 둘을 혼동하지 않는다.

원본의 획 순서·주요 방향·획 분리·구성 자형·접합을 대조했다. 승인 donor의 폰트 차이를 유지한 중심선이며 교과서 붓글씨 외곽선과 픽셀 단위로 일치한다는 뜻이 아니다. 빌린 기하학에는 기존 Arphic Public License 고지를 유지해야 한다.

## 폭 5 접합 확인

최종 SVG는 round cap / round join, 선폭 5다.

- 硏의 石 상단과 幵 첫 획이 초기 폭에서 맞닿아 石 배치 폭을 30에서 28로 줄였다. 최종 중심선 끝 사이 거리 `sqrt(40)`에서 선폭 5를 뺀 틈은 약 1.325다.
- 幵 좌우 중간 가로획은 별도 경로이며 끝점 간 거리 `sqrt(37)`에서 선폭을 뺀 약 1.083의 틈을 남겼다.
- 鄕의 乡·白·匕·邑 사이를 원본과 비교했으며 白과 匕가 합쳐지지 않는다. 부품 안쪽의 접합은 닫힌 입구·갈고리 등 원본의 획 관계를 유지한다.
- 수정된 모든 누적 획을 동일한 선폭으로 다시 렌더링해 비교했다.

## 검증 결과

Node 검증 스크립트가 성공했다(exit 0). 24개 경로의 해시·유한 좌표·단일 pen path, 재사용 15획의 donor 해시·최종/원본 번호·정확한 affine 재현, 자체 작성 9획과 재사용 획의 빠짐없는 분할, 전부 null인 대상 코퍼스 매핑, 전 획 검토 기록과 단조 증가하는 영상 완료 시간을 확인했다. SVG XML 파싱도 성공했다. 이 검증은 출처 대조를 대체하지 않으며 앞서 수행한 시각 검토의 데이터 연결이 깨지지 않았음을 확인한다.
