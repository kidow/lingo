# 한자 후속 작업 — 순차 진행 기록

사용자 승인 범위: ① 4급II 미적용 9자 검토, ② 4급 250자 교과서 근거 검토, ③ 부품 합성 20자 보정·전체 검토, ④ 위치별 부품 확장과 새 독립 평가. 단계별 결과를 기록한 후 다음 단계로 진행한다.

## 시작 상태

- 카탈로그 5,978자, 정적 SVG 누락 0자.
- 승인 애니메이션 743자: 한국어문회 도해 503자, 교과서 영상 대조 240자.
- 8~5급 500자 완료. 4급II 241/250자. 전체 미적용 5,235자.
- 이전 부품 실험 20자는 검토용 초안이며 런타임 미적용.
- 독립 100자 실험은 생성 6자, 기하 기준 통과 1자(江). 한국 필순의 정답 판정이 아니다.

## 1단계 검토 기록

- [兩·連](stage1-compatibility.md): 원문 호환 표기를 보존하고 원본 영상과 전체 획을 대조했다. 連의 획 분할·접합·마지막 세로획 간격을 보정했다.
- [液·衛·砲](stage1-missing-sources.md): 확인한 공개 자료로는 대상 글자의 전체 필순 근거를 확보하지 못했다. 衞 영상은 衛의 대체 근거로 사용하지 않는다.
- [藝·豊](stage1-exceptions.md): 새로 찾은 중학교 영상도 기존 고등학교 영상과 동일했다. 기존 접합 불명확·자형 불일치 보류를 유지한다.
- 영상 점검 유틸리티는 원본을 메모리에서만 처리한다. MP4 이동·offset·표본 범위 회귀 테스트 25개에서 발견한 경계 문제를 수정한 뒤 모두 통과했다.

- [硏·鄕](stage1-geometry.md): 원본 전체 대조를 거친 24획 중 재사용 15획과 직접 작성 9획을 구분했다. [획별 시안](stage1-geometry-recipe.svg)과 donor 출처·변환·경로 해시를 보존했다.
- [기존 실험 재현](stage1-replay.md): 당시 743자 입력으로 결과 전체가 동일하게 재현된다. 새 replay CLI는 현재 런타임 수를 별도로 보고한다.

1단계 공개 번들 검사: `publishedBundleMatches=true`. 총 승인 747자(한국어문회 503 + 교과서 244), 4급II 245/250자(98%). 전체 미적용 5,231자. 기존 교과서 240자의 데이터 객체는 변경하지 않았다.

검증: 관련 TypeScript 테스트 34/34, 영상 메모리 처리 테스트 25/25, 전체 typecheck, 공개 번들 재현 및 동결 실험 전체 결과 일치. ESLint 설정·의존성은 없어 별도 ESLint 검사는 수행하지 않았다.

## 2단계 검토 기록

[4급 250자 검토 결과](stage2-summary.md): 244자 적용, 筋·姉·獎·鍾·冊·灰 6자 보류. 총 승인 991자, 미적용 4,987자. 획별 영상 대조와 경로 보정을 기록했으며, 기하 원본이 없는 鑛·鬪는 전체 경로를 직접 작성하여 영상과 대조했다.

검증: 전체 한자 회귀 테스트 122/122, typecheck, 교과서 공개 번들 재생성 일치. 이전 승인 743자의 객체와 상대 순서를 보존했다.

## 3단계 검토 기록

[20자 시안 교정](stage3-summary.md)과 [재생 가능한 전후 비교](stage3-result.html)를 작성했다. 위치·자형·접합 차이를 글자별로 기록하고, 19자는 현재 승인된 전체 경로를 정확히 사용했다. 砲는 전체 근거가 없어 보류한다. 독립 합성 평가나 신규 런타임 승인으로 집계하지 않는다.

검증: 관련 회귀 테스트 6/6, typecheck, 원본·출처 해시 및 JSON·HTML 재생성 일치.

## 4단계 검토 기록

[위치형 확장과 새 독립 평가](stage4-summary.md): 기존 743자 입력과 동일한 v2 엔진, 공통 donor 585자를 사용했다. 새 위치형 7개를 추가하고, 이전 두 평가와 겹치지 않는 100자를 구현 동결 후 평가했다. 생성 25→28자, 기하 선별 14→16자이며 새 통과는 性·授다. 기하 선별은 신규 애니메이션 승인으로 계산하지 않는다.

## 최종 상태와 다음 작업

이번 네 단계로 248자를 새로 적용해 991/5,978자(16.6%)가 됐다. 미적용은 4,987자다. 4급II 245/250자(98%), 4급 244/250자(97.6%)이며 낮은 급수의 보류 11자는 별도 근거가 필요하다.

검증: 전체 한자 테스트 134/134, typecheck, 프로덕션 빌드, 공개 번들 일치, 기존 실험 및 새 실험·시안 결과 재현 통과. 기존 743개 승인 객체는 그대로이며 중복·획수 불일치·누락 import·ignore된 필수 의존성은 0건이다. 다른 세션의 콘텐츠·음성 파일은 이 작업에서 수정하지 않았다. 커밋·푸시·배포는 수행하지 않았다.
