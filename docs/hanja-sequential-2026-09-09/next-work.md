고정 교과서 목록에 남은 정확 표기 후보는 801자다. 3급II 480자, 3급 314자, 특급II 4자, 특급 1자, 4급II 2자다. 호환 표기 정규화로만 연결되는 諾·蘭·濫·戀·蓮·嶺·弄·率·吏 9자는 별도로 검토한다. 목록에 있다는 사실은 전체 영상·실제 자형·횟수·접합을 검증했다는 뜻이 아니다.

3급II 480자 중 첫 50자를 대상으로 전체 원본 영상과 획별 경로를 대조하는 것을 권장한다. 이번에 만든 보정·직접 작성·출처 해시·재현 검사 도구를 그대로 사용할 수 있다. 기본 원칙은 실제 대상 글자의 전체 근거를 먼저 확인하고, 불일치하는 획만 보정한 뒤 공개 번들을 재생성하는 것이다.

위 후보 수는 `node scripts/hanja-stroke-textbook-build.ts --check`의 현재 고정 manifest 집계에 따른다. 원본 manifest SHA-256은 `32853d2396dc4fe38362b9e51a828144d7e48889f60e28d850cae9fa2335620c`다.

## 함께 남는 과제

1. **저급수 보류 11자:** 4급II 液·衛·砲·藝·豊, 4급 筋·姉·獎·鍾·冊·灰. 같은 글자의 다른 공개 교재·도해를 찾아야 한다. 자형이 다른 衞·奬·姊·鐘·册을 대상의 근거로 바꾸지 않는다.
2. **冂과 ⿵ 구조 지원:** 검토한 冂 2획과 출처는 보존했지만, 현재 고정 엔진의 구조 규칙에 없어서 비활성이다. 내부 영역의 위치·획 순서·접합을 명시한 새 엔진 버전과 테스트가 필요하다.
3. **위치 외의 실제 자형 조건:** 같은 위치에서도 독립형과 부분형의 크기·점·갈고리·접합이 달라진다. 社의 5획 示형과 4획 礻형처럼 IDS 조회키만으로 합치면 안 되는 경우를 구분해야 한다.
4. **다음 독립 평가:** 이번 새 100자 결과를 본 뒤 개선한다면 같은 세트를 다시 독립 평가로 부르지 않는다. 이전 모든 평가 대상과 초안을 제외한 새 세트를 고정하고, 생성 경로를 정답과 분리한다.

부품 합성으로 만든 경로는 전체 대상 검증을 통과하기 전까지 검토용 초안이다. 기하 선별 통과 수를 그대로 신규 애니메이션 승인 수로 사용하지 않는다.
