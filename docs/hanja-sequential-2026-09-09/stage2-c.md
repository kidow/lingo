# 2단계 C 검토

최종 담당 **42자 전부 대조 완료**: C1–40과 閉·疲. 원형 일치 8자, 보정 후 일치 34자이며 이 구간의 보류는 없다. 기존 C81 배정은 JSON에 보존했고, 재배정한 39자의 최종 상태는 부모 및 보조 검토 문서가 우선한다. 공개 번들과 실행 데이터는 이 작업에서 변경하지 않았다.

- 원형 일치: 轉 占 丁 條 存 朱 招 疲
- 보정 후 일치: 錢 折 點 靜 整 帝 潮 組 從 座 酒 周 證 持 智 陣 差 泉 閉 誌 織 珍 盡 讚 採 聽 廳 推 縮 就 趣 寢 針 層

## 확인 방법

비상교육 공개 교과서 필순 원본 영상을 메모리로 가져와 SHA-256·바이트 수·기간을 기록했다. 0.5초 간격의 전체 진행과 각 후보의 모든 획, 실제 선폭 5에서 접합·분리·교차를 직접 대조했다. 필요한 지점은 0.1초 또는 0.2초 간격으로 확대했다. 수정한 경로는 다시 전체 진행과 매 획 완료 표본에 대조했다. 영상·프레임 파일은 저장하지 않았다.

고정 AnimCJK Ja 코퍼스(SHA 2bcd1c6d186e5376c5f9202b4eae2eaeff13c2566675a55f1c9dd548a2ef31c8)를 사용했다. 層은 Ja14획으로 원본15획을 대응할 수 없어 별도 고정 Make Me a Hanzi15획(SHA a28c478b5178e98f67f510b2d52fde08a69dc664654ef43498253b9b764d46ee)과 전체 영상을 대조하고 보정했다. 외국 코퍼스 자체를 한국 필순의 승인 근거로 쓰지 않았다.

## 보정과 재확인

- 糹가 있는 織·縮은 중앙 세로와 왼쪽 점 순서·방향을 영상에 맞췄다. 王이 있는 珍·聽·廳, 差·盡·推는 원본의 획 순서를 반영했다.
- 日·車·貝·耳·罒의 내부 획은 원본에서 닫히는 벽까지 연결했다. 서로 떨어진 부품은 실제 선폭에서 분리했다.
- 採5획과 위 삐침, 針3획과 위 삐침은 상세 원본에서 실제 접합을 확인해 초기 분리 가설을 폐기했다. 원본 접합을 유지한 최종본을 다시 확인했다.
- 聽14획의 15.5초와 廳17획의 19.7초는 꺾임 진행 중이었다. 완료가 확인되는 15.9초·20.1초로 정정했다. 완료 표본은 정확한 펜 떼기 시각을 추정한 값이 아니다.

## 파일과 통합 범위

[stage2-c.json](./stage2-c.json)의 `scope.thisAgentFinalGlyphs`에 있는 42개 `records`만 이 문서의 최종 결과이다. `correctionProposals`는 34개 보정 계약, `geometryInputs`는 42개 원본 medians·원본 SHA와 최종 paths·SHA를 담는다. 후보 원본과 수정 경로의 출처를 구분한다.

[stage2-c.svg](./stage2-c.svg)는 최종 정규화 경로의 검토표다. 원본 영상 이미지를 복제한 것이 아니며 각 셀에서 공개 원본 영상 URL을 확인할 수 있다. 영상 열람 가능성과 앱용 영상 복제 권한은 별개다.

실제 `textbookGeometry`와 canonical recipe SHA 함수로 42개 출력 경로·획수·원본 median SHA, 34개 recipe 핀, 영상 URL·SHA·바이트 수·완료 표본 수와 범위를 검증했다. 이 결과는 지정 원본 영상과 경로의 비교 기록이며, 검정 주관 기관이 앱 결과물을 인증했다는 의미는 아니다.
