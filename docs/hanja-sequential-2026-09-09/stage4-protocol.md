## 고정 조건

- 승인 입력은 기존 실험의 743자 아카이브다. 현재 제품의 승인 수 991자와 구분한다. 신규 248자를 함께 넣어 생기는 입력 증가 효과와 위치형 추가 효과를 섞지 않는다.
- 기존 개발 100자·독립 평가 100자·초안 20자를 제외한 새 100자를 먼저 선택했다.
- 선택 seed: `hanja-component-phase3-independent-v1`. 글자별 SHA 순서와 구조별 할당을 사용한다. 좌우 25, 상하 25, 위치 변형 25, 둘러싸기 15, 기타 10자다. 생성에 실패해도 대상을 교체하지 않는다.
- [분할 명세](../../scripts/hanja-component-phase3-split.json)의 hash: `82c340ef241cc0a7fd7df8de048e59e989ec92e83b11676d77516f15dc3704d7`.
- 분해 정보에서 확인 가능한 대상 부분·동일 하위 구조를 가진 donor도 제외한다. 양쪽 비교에 동일한 허용 donor 585자를 사용한다. 불완전한 IDS 정보의 한계는 유지된다.

## 비교 방법

기존 v2 합성·배치 엔진을 바꾸지 않고, 기존 7개 레시피와 위치형을 추가한 레시피를 비교한다. 기존 레시피라도 이번 대상에 해당하는 donor는 양쪽에서 똑같이 제외한다. 부품 경로·순번·출처 해시와 선택된 donor를 보존한다.

亻 왼쪽, 阝 왼쪽·오른쪽 등은 승인된 donor에서 실제 획을 확인한다. 冂의 둘러싸기 위치도 검토하되, 현재 엔진은 ⿵를 지원하지 않고 ⿴만 허용하므로 비활성 후보로 남긴다. IDS를 임의로 바꾸어 검사를 통과시키지 않는다.

모든 예측을 만든 뒤에만 대상의 승인 경로를 읽어 비교한다. 거리·방향·순번 대응은 기하 선별 기준이며 한국 필순 인증이나 자동 공개 승인이 아니다. 기준은 기존 실험과 동일하다: 평균 순번 거리 8 이하, 최대 획 거리 16 이하, 획수 일치, 순번·방향 대응 지표 1.

새 100자의 결과를 확인한 뒤 이 버전의 레시피나 엔진을 조정하지 않는다. 추가 개선은 별도 버전과 새 평가로 진행한다. 기존 743자 실험의 입력·결과·고정 구현 8개 파일은 그대로 보존한다.
