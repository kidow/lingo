# 4급 예외 표기 9자 검토

검토 9자 중 更·亂·祕 3자를 적용하고 筋·姉·獎·鍾·冊·灰 6자를 보류했다. [글자별 기록과 원본 기하](stage2-root.json), [추가 영상 확인](stage2-root-extra-sources.json)에 영상 해시와 비교 범위를 보존했다.

| 글자 | 결과 | 근거와 보정 |
|---|---|---|
| 更 | 적용 | 원문 更과 NFC가 동일하다. 7획 전체 대조 후 안쪽 가로 양끝을 벽에 연결했다. |
| 亂 | 적용 | 원문 亂과 NFC가 동일하다. 13획 전체 대조 후 안쪽 12획 끝과 바깥 틀 갈고리를 분리했다. |
| 祕 | 적용 | 목록은 秘이나 실제 0705 영상은 示 5획과 必 5획인 祕다. 별도 검토자가 영상 해시와 10획을 재확인했다. 5획 끝을 줄여 必의 왼쪽 점과 분리했다. |
| 姉 | 보류 | 1213 영상은 姊의 𠂔를 그린다. 姉의 市로 대체하지 않는다. |
| 獎 | 보류 | 1240 영상의 아래는 점 없는 大다. 犬이 있는 獎의 근거로 쓰지 않는다. |
| 鍾 | 보류 | 1363 영상은 오른쪽이 童인 鐘이다. |
| 冊 | 보류 | 1465 영상은 별도 지붕 두 개와 중앙 가로가 있는 册이다. |
| 筋·灰 | 보류 | 현재 확보한 비상 목록과 추가 공개 자료에서는 대상 전체 필순 근거를 확보하지 못했다. |

祕의 예외는 원문 표기·행·영상 SHA256·바이트 수에 묶어 검증한다. 일반 이체자 변환 허용이 아니다. 보정은 출판사가 제공한 벡터가 아니라 원본 영상과 대조한 로컬 중앙선이다. 출판사 영상 대조와 한국어문회 인증은 구분한다.

완료 표본 시각은 실제 관찰한 프레임의 시각이며 정확한 펜 떼기 시각의 추정값이 아니다. 모든 획의 순서·방향·경계·최종 연결 관계를 비교했으며 화면 선폭 5에서 분리 간격을 확인했다.

교과서 번들은 기존 244자 객체를 그대로 유지하고 3자를 추가했다. 다른 241자의 4급 검토는 계속 진행 중이다.
