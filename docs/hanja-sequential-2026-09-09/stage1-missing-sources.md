# 1단계: 液·衛·砲 추가 출처 점검

검토일: 2026-09-09. 세 글자는 이번 점검에서 재생 승인하지 않았다. 아래는 확인한 공개 자료의 범위이며, 공식 자료가 어디에도 없다는 뜻은 아니다.

| 글자 | 확인 결과 | 남은 조건 |
|---|---|---|
| 液 | 비상교육 고등학교 교육용 기초한자 1,800자 원문 목록에 없음 | 해당 글자의 전체 필순을 보여 주는 한국 교과서·시험기관 자료 확보 |
| 衛 | 목록의 1138번은 衞. 실제 영상도 衞를 그림 | 衛 자체의 전체 필순 자료 확보 및 15획 후보의 전체 대조 |
| 砲 | 같은 원문 목록에 없음 | 해당 글자의 전체 필순 자료 확보. 부품 합성은 별도 실험으로만 진행 |

## 원문 목록과 衞 영상

- 출처: [비상교육 고등학교 한문](https://text.vivasam.com/detail/186), `lib/hanja-stroke-textbook.ts`의 고정된 manifest URL.
- 목록 SHA-256: `32853d2396dc4fe38362b9e51a828144d7e48889f60e28d850cae9fa2335620c`.
- 목록에서 `液`, `衛`, `砲`의 완전 일치는 없으며, `衞`가 1138번에 있다.
- 1138 원본 영상: manifest URL 기준 `../media/video/1138.mp4`, 839,137 bytes, 24.448초.
- 원본 영상 SHA-256: `59a1406b909dfe4f513443f44999456dd1a56a007b1fbd850fb92bf75bcc5873`.
- 원본을 메모리에서 해석해 0–23초의 매초 표본을 확인했다. 가운데 아래가 衞의 형태로 그려지며 마지막 완성 자형도 衞다. 이는 해당 영상의 자형 불일치를 확인한 것이며 衛의 획별 승인 검토가 아니다.
- `NFC(衛) !== NFC(衞)`이므로 兩/兩, 連/連과 같은 호환 표기 연결을 적용할 수 없다. 다른 글자의 영상으로 바꾸지 않았다.

## 추가로 확인한 공개 경로

1. [한국어문회 자료실의 필순 검색](https://www.hanja.re.kr/kccpt/exam/otherData.do?search_option=subject&search_text=%ED%95%84%EC%88%9C): 기존 「필순 정정 및 500자 필순」 자료만 확인됐다. 이 결과만으로 위 세 글자의 전체 순서를 새로 승인하지 않았다.
2. [한국어문회 학습 자료 안내](https://www.hanja.re.kr/kccpt/exam/studyInfo.do)와 연결된 [4급II 교재 판매 안내](https://skymiru.co.kr/product01/detail.html?product_no=44): 필순 관련 목차는 있으나 필요한 글자의 원문 페이지를 공개 미리보기로 확보하지 못했다. 목차·책의 존재를 글자별 필순 증거로 취급하지 않았다.
3. [모야랜드 衛 학습 자료](https://moyaland.com/_new/hanja/item_01.php?it_id=1403584922): 한국어 설명과 15획 자료를 찾았다. 시험 주관 기관 또는 해당 교과서 출판사의 근거와 동등하다고 판단하지 않았다. 추후 교차 검토 후보로만 남긴다.

실행 중 원본 영상·웹 본문을 앱 배포 자산에 복사하지 않았다. 라이선스가 있는 벡터 후보나 로컬 부품 합성이 있더라도 그 사실만으로 한국어 필순 검토를 통과한 것으로 표시하지 않는다.
