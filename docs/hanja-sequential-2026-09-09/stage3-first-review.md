## 시각 검토와 수치의 범위

5개의 초안/승인/중첩 SVG 비교표와 1개의 색상 분리 접합표를 sharp로 메모리 렌더링했습니다. SVG 문자열의 해시는 JSON의 `method.renderings`에 기록했습니다. 원본 SVG 비교 파일이나 래스터 파일을 새로 저장하지 않았습니다.

부품 bbox는 동일 번호 획 묶음의 실제 경로 범위입니다. 접합 수치는 획당 128개 등거리 표본의 최소 중앙선 거리이며 근사치입니다. 폭 5에서 반지름 합 5를 기준으로 비교할 후보를 고르고, 鳴 6–7, 粉 3–6/5–6, 妹 1–7은 색상 분리 렌더로 추가 확인했습니다. 숫자만으로 한국 필순을 인증하지 않습니다.

`referenceCorrection.paths`는 이미 승인된 전체 경로와 정확히 동일합니다. 참조 경로·원문 근거의 해시가 바뀌면 재검증해야 합니다. 부분 affine 보정이나 새로운 부품 합성은 이번 제안에 포함하지 않습니다. 고정 v2 초안과 실험 결과, 공유 런타임 데이터는 수정하지 않았습니다.

검증은 대상 10개 누락/중복, 砲의 승인 경로 부재, 9개 승인 경로·영상 레코드 존재, 초안/참조 해시, 참조 교체 경로의 실제 `HANJA_STROKES`와의 일치를 확인합니다.
