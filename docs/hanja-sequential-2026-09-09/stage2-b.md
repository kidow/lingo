# 2단계 B: 개별 교과서 영상 80자 검토

- 검토일: 2026-09-09. 검토자: Codex visual comparison.
- 결과: **75자 일치**, **5자 보류**. 일치 중 고정 원본 그대로 13자, 개별 영상에 근거한 보정 62자.
- 부모 담당으로 분리한 **普·否·粉·負**는 이 문서에서 최초 보류를 유지하며, 최종 결과는 `stage2-b-root-corrections.json`에서 통합한다.
- **屬**은 공식 자료가 없어서 보류한 것이 아니다. Ja와 MM의 전체 21획을 원본 영상과 비교했으나 실제 선폭 5에서 상부 점·罒 및 아래 虫·바깥 갈고리의 분리 관계가 보존되지 않아 보류했다. 대안 MM 기하와 관찰도 JSON에 남겼다.

## 근거와 검토 범위

각 글자의 실제 비상교육 원본 영상 전체를 0.5초 표본으로 확인했다. 순서·방향·펜 경계가 불명확한 곳은 0.1초 표본으로 다시 확인했다. `strokeEndsSeconds`는 각 획의 완료가 실제로 관찰된 표본 시각이며 정확한 펜 떼기 시각을 추정한 값이 아니다. 교과서의 일반적인 권장 필순을 AI가 시각 대조한 기록이며, 한국어문회 개별 승인 또는 인간 전문가 확인을 의미하지 않는다.

모든 후보는 획별 시작·끝 표시와 전체 누적 모양을 확인했고, 보정 후에는 전체 경로와 실제 선폭 5의 접합·분리를 다시 확인했다. SVG는 최종 검토 후보를 빠르게 보는 색인이다. 동영상 원본을 저장하거나 SVG만으로 필순을 승인하지 않았다.

## 주요 보정

- 碑: Ja14획 대신 원본의13획과 대응하는 고정 MM13획을 선택하고 石·卑 간격과 내부 가로 접합을 보정했다.
- 鉛: Ja의 八 모양 대신 원본의 几 모양과 대응하는 MM을 선택했다.
- 絲·緣·績: 원본 중앙세로→왼점→오른점 순서를 복원하고 해당 점·세로를 영상에 맞게 보정했다.
- 與: 왼쪽부터 쓰는 순서를 복원하고 중앙 Ja2획을 두 펜 획으로 분할했다.
- 延: Ja4·5를 원본의 연속 L 한 획으로 결합했다. 레시피의 sourceStroke4는 수정 벡터 기준이고, 실제 기여 원본은4·5임을 notes에 기록했다.
- 迎·遇·遊·遺·適: 각 개별 영상에서 확인한 辶 펜 경계를 분할했다.
- 隱: MM의 阝 경계를 분할하고 爫 방향·접합, 彐 관통 가로와 心 점 간격을 개별 보정했다.

## 무결성 검증

80자 고유성, 매획 완료 표본 수·오름차순·영상 길이 범위, 원본 영상 SHA와 bytes, 모든 경로 SHA를 확인했다. 실제 `textbookGeometry` 및 `normalizeMedians` 구현으로62개 레시피의 원본 중앙선 SHA, canonical recipe SHA, sourceStrokeIndices, 최종 경로와 기대 획수를 재현했으며 **오류0건**이었다. JSON은 원본 중앙선과 경로, 영상 핀, 레시피까지 포함한다. 공유 원장·공개 데이터·런타임은 수정하지 않았다.
