# 4급 250자 교과서 필순 검토

4급 250자 중 **244자(97.6%)**를 개별 원본 영상과 대조하여 적용했다. 6자는 현재 확보한 자료로 대상 글자 전체를 확인하지 못해 보류했다. 1단계의 4급II 4자를 합하면 이번 순차 작업의 적용 증가분은 248자다.

전체 애니메이션은 **991/5,978자**, 미적용은 **4,987자**다. 한국어문회 도해 기반 503자와 교과서 영상 대조 488자를 구분한다. 교과서 대조는 한국어문회의 개별 인증이나 자동 합성 정답률을 뜻하지 않는다.

| 처리 | 글자 수 | 기준 |
|---|---:|---|

| 개별 보정 | 187 | 순서·방향·펜 경계·접합 또는 일부 경로를 보정한 뒤 전체 재대조 |
| 전체 직접 작성 | 2 | 鑛 23획·鬪 20획, 모든 획을 원본 영상에 맞춰 작성 |

보정 187자에는 紅·脫 등의 일부 획 직접 작성도 포함된다. 새 획과 재사용 획의 원본 번호를 구분했으며, 작성·병합된 획은 명시적 null 이력을 가진다. 7자는 검토한 표시 좌표를 그대로 보존하는 viewBox100 방식을 사용하여 재정규화 오차를 막았다.
