# 3단계 — 기존 합성 초안 20자 교정

상태: 완료. 원본 20자 보존, 참조 교정 19자, 砲 보류. JSON·HTML 재현 검사, 관련 테스트 6개와 타입 검사 통과.

## 범위와 결과

- 대상 20자: 砲·略·鳴·粉·松·誌·討·評·妹·妙·妨·標·燃·奇·否·崇·異·姿·智·泉.
- 19자는 2단계까지 확보한 대상 글자의 전체 필순 근거와 승인 경로로 교정한다. 부품을 다시 추측해 맞추지 않고, 이미 검토한 전체 경로를 정확히 사용한다.
- 砲는 확인한 공개 자료에서 대상 글자의 전체 근거를 확보하지 못했다. 초안은 보존하되 승인·공개하지 않는다.
- 추가 런타임 승인은 0자다. 위 19자는 이미 현재 991자에 포함된다. 교정 결과를 과거 실험의 예측 성공으로 소급 집계하지 않는다.

## 드러난 한계

초안과 승인 경로는 19자 모두 획수가 같지만, 전체 배치가 다르다. 略·鳴은 왼쪽 부분이 지나치게 크고, 標·燃은 오른쪽 부분의 크기와 간격이 달라진다. 崇·智는 위아래 비율과 정렬 문제가 두드러진다. 따라서 부품의 획수와 순서를 재사용하는 것만으로 전체 글자의 쓰기 본보기를 완성할 수 없다.

경로 거리·방향 지표는 문제 위치를 찾는 보조 수단이다. 승인 경로를 그대로 복사한 결과의 거리 0은 독립 평가 성과가 아니다. 출처 대조 기록과 원본 초안의 placements·schedule·해시를 별도로 보존한다.
