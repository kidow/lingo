# B 보조 보정 4자

普·否·負·粉의 B 원본 비교 기록을 보존하고, 부모 검토자가 전체 원본 진행표와 보정 경로를 다시 대조했다. [변경 전후 시안](stage2-b-root-corrections.svg), [원본·레시피·최종 경로·승인 기록](stage2-b-root-corrections.json).

| 글자 | 최종 보정 |
|---|---|
| 普 | 日 안쪽 11획의 오른쪽 끝을 세로에 연결 |
| 否 | 不의 세로 3획 끝을 줄여 口와 분리 |
| 負 | 貝의 가로 5·6획 끝을 오른쪽 세로에 연결, 아래 8획 시작을 줄여 바닥과 분리 |
| 粉 | 刀의 9획 머리 시작만 줄여 위쪽 7획과 분리 |

순서·방향·획 경계는 유지했다. 실제 선폭 5의 전체 후보와 확대 원본 완료 프레임을 대조했으며, B 검토자도 보정 설명이 원본 관찰과 일치함을 확인했다. 원본 candidate 기록은 비교 이력으로 남기고 별도 최종 records만 승인 등록부에 반영했다. 기존 교과서 247자 객체는 변경하지 않고 4자를 추가했다.
