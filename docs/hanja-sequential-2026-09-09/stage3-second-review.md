# 동결 v2 시안 두 번째 10자 참조 대조

검토 대상은 **妨 標 燃 奇 否 崇 異 姿 智 泉**이다. 10자 모두 현재 승인된 전체 경로가 있으며, 동결 시안은 10자 모두 위치·자형 또는 접합 보정이 필요하다. 획수와 획 대응 순서는 10자 모두 같았고, 실제 역방향 획이나 별도 획 병합·분할 문제는 발견하지 않았다.

이번 검토는 승인된 목표 경로를 확인한 뒤 진행한 **참조 기반 검토**다. 새 승인·런타임 추가는 0자이며 현재 991자를 유지한다. 승인 경로 복사 후 거리 0이 되는 것은 합성기 성능 향상이 아니다. 동결 독립 평가 결과를 바꾸지 않는다.

| 한자 | 실제로 확인한 차이 | 참조 기반 보정 시 지킬 관계 |
|---|---|---|
| 妨 | 女는 세로로 과장되고 方은 작고 아래로 내려간다. | 方 높이를 확보하되 女1 끝–方7 끝의 분리 유지 |
| 標 | 오른쪽 票가 폭·높이 모두 지나치게 작다. | 木1–票6, 票7–示11 간격 유지. 시안13은 이미 갈고리 없는 세로 |
| 燃 | 독립 火4가 길게 남고 然이 좁아져 火4–중앙6 접합이 빠진다. | 왼쪽 火 위치형과 실제 중앙6 접합, 내부7·8 양끝 연결 |
| 奇 | 윗 大가 넓고3획이 긴 삐침으로 남아2획과 붙는다. | 작은 윗 大·분리된 오른점3, 아래 口 폐합과4–8 접합 |
| 否 | 아래 口가 너무 넓고 납작하며 낮게 놓인다. | 下口를 좁혀 올리되 不3–口6 분리는 유지 |
| 崇 | 山이 크고 직각형이며 宗이 아래로 눌린다. 宀4 점이6 지붕과 붙는다. | 좁은 윗 山·짧은 宀 점 및 두 간격. 5획을 뒤집지 않음 |
| 異 | 田가 크고 共이 눌려 아래10 점이9 가로에 붙는다. | 작은 田·넓고 높은 共, 9–10 분리. 田3 가로→4 세로는 이미 맞음 |
| 姿 | 次가 넓게 눌리고 아래 女가 내려가5–7 접합이 빠진다. | 전체 부품을 일괄 분리하지 않고 실제5–7 접합 복원 |
| 智 | 日이 너무 넓고 왼쪽에 놓이며11 내부 가로가 오른벽10에 닿지 않는다. | 日의 위치·비율, 10–11 접합과 矢5–日10 분리 |
| 泉 | 白이 넓고 낮으며4–3 내부 접합과 白5–水6 접합이 빠진다. | 두 접합 복원, 水8의 진입 굴곡과8–9 접합 유지 |

100×100 좌표계의 실제 선폭5 전체형과 매 획 중첩 그림을 메모리에서 렌더링해 직접 확인했다. 기준은 현재 승인 경로와 해당 경로 해시에 연결된 원장의 개별 원본 영상 관찰이다. 이번 단계에서 같은 영상을 다시 내려받거나 신규 영상 검토를 수행하지 않았다.

**崇의 방향 지표 예외:** 비교 함수의 directionAgreement는 10/11이지만 예외는5획(宀 왼점)이다. 순방향 평균 거리15.511994, 역순15.450985로 위치 오차 때문에 역순이 약0.06101단위 작다. 실제 두 경로는 모두 위에서 아래·왼쪽으로 진행한다. 이를 역필순으로 분류하지 않았다.

부품 bounds와 256개 경로 표본의 중심선 거리는 시각 확인 보조 자료이며 한국 필순 정답률이나 원본 영상의 정확한 잉크 접촉 측정값이 아니다. 자세한 획별 근거·원본 URL/영상 SHA·바이트 수·완료 표본·승인 경로/레코드 SHA는 [JSON](stage3-second-review.json)에 저장했다. 결과 파일 자체의 SHA와 동결 split·recipe SHA도 함께 고정했다.

검증: 10자 유일성·누락 없음, 동결 시안 해시 일치, 현재 승인 객체와 경로 해시 일치, 각 원장 레코드와 sourceVideo 핀 일치, 완료 표본 수와 획수 일치를 확인했다. 오류는 0건이며 런타임 991자와 원장 파일 해시도 그대로다. 프로덕션 파일은 수정하지 않았다.
