# 4급 추가 9자 보정

稱·歎·彈·脫·探·擇·討·痛·投의 원본 전체 영상을 다시 대조했다. 討는 원본 중앙선 그대로, 나머지 8자는 획별 순서·방향·접합을 보정한 뒤 최종 후보를 다시 확인하여 적용했다.

- 원본·보정 후보: `stage2-c-middle-original.svg`, `stage2-c-middle-first.svg`, `stage2-c-middle-second.svg`, `stage2-c-middle-third.svg`.
- 영상 SHA, 매획 완료 표본, 보정 레시피와 최종 경로 SHA: `stage2-c-middle-root.json`.
- 稱7과 禾2, 痛7과 甬9는 확대 영상에서 실제로 이어져 있었다. 초기 분리 가설은 폐기하고 원래 접합을 유지했다.
- 脫의 八 두 획은 MM 데이터의 방향이 원본과 달라 별도 작성했다. 재사용 인덱스 null로 구분했고, 月 내부 가로와 儿 왼획의 간격도 대조했다.
- 鬪는 이 9자와 별도로 `stage2-tou-authored`에서 검토한다. 출판사 영상 대조는 한국어문회의 개별 인증이나 자동 합성의 정답률을 뜻하지 않는다.

9자 모두 기록된 완료 표본을 10fps로 다시 열어 누적 획을 확인했다. 稱12는 15.7초에 아직 시작 전이어서 전체 진행표에서 완료를 확인한 16.5초로 정정했다. 擇14의 18.5초에는 다음 획이 진행 중이지만 14획 자체는 이미 완료되어 기존 표본을 유지했다. 표본 시각은 해당 획의 완료 확인용이며 정확한 펜 떼기 시각이 아니다.
