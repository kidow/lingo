## 근거와 검토

- [蓮](http://img.e-hanja.kr/hanjaSvg/aniSVG/8400/84EE.svg) · [追](http://img.e-hanja.kr/hanjaSvg/aniSVG/8F00/8FFD.svg) · [透](http://img.e-hanja.kr/hanjaSvg/aniSVG/9000/900F.svg) · [還](http://img.e-hanja.kr/hanjaSvg/aniSVG/9000/9084.svg)

- 이전에 관찰한 책받침 16획에 내부 37획을 추가로 관찰했다. 還11·16·17과 蓮15·追10·透11의 끝 구간도 재확인했다.
- 별도 재생 회차에서 53획의 현재 진행값과 이전 획 완료 순서를 새로 기록했다. 이 수치와 화면 관찰은 동일 순간의 기록이 아니다.
- [review.html](review.html)의 누적 53칸을 검토했다. 연결점을 보정한 蓮8과 還10·11·13은 수정 뒤 다시 확인했다.

33획은 고정된 Make Me a Hanzi 원본 경로를 유지했다. 이 중 6개 위치만
재배열했다. 책받침 16획 및 내부 4획은 별도 작성·수정한 경로로,
`sourceStrokeIndices: null`로 구분했다. 다른 글자에 승인을 전이하지 않는다.
사전의 SVG 경로·마스크·중심선·스크린샷은 저장하거나 배포하지 않는다.
런타임 도형은 학습용 중심선이며 글꼴 외곽선 일치나 필기 채점을 보장하지 않는다.

- 원본 사전 4개: 바이트 길이·SHA-256·글자·획별 타이밍 일치.
- 경로 재현: 원본 MM → 지정 순서·보정 → 동결 후보 → 런타임 데이터 일치.

- `pnpm exec next build` 통과: Next.js 16.3.3, TypeScript, 정적 페이지 7개.
