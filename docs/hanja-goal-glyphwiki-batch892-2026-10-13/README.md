고정 원본4종에 u76ee-j가 누락되어 geometry·trace는 null이다. 완전G는19raw에서 연속[11,12]만 합쳐 최소18펜이다. 완전VS2도 연속 최소18펜이며 기존global17은 비연속[10,15]폐합을 포함한 값이다. 국내16획에 맞추기 위해 경로를 만들거나 비연속폐합을 합치지 않는다. 이 후보는 브라우저 whole·방향·프레임·확대·재생 검토를 하지 않았으며 컴파일러도 없다.
