## pending → matched 조건

명시된 글자마다 전체 영상을 대조한 뒤 검토 대장에 날짜, 모든 획이 끝나는 시점(`strokeEndsSeconds`), 영상 길이(`durationSeconds`), 순서·방향·분할·자형 대조 결과(`checks`), 관찰 메모와 승인할 경로 해시(`pathsSha256`)를 기록한다.

검증기는 원문 위치, 해시, 검토 상태, 총획, 시점의 개수·순서·범위, 모든 대조 결과를 확인한다. 경로는 고정 Ko 중심선을 정규화한 결과와 그대로 일치해야 한다. 이 1차 등록부에서는 재정렬·분할·새 획 삽입을 허용하지 않는다. 차이가 발견되면 pending을 유지하고 원인을 기록한 뒤 별도 보정 검토를 진행한다.

이 검증기는 관찰 기록의 일관성을 검사하는 도구이며, 영상의 필순을 자동으로 판정하거나 사람의 대조를 대신하지 않는다. 한국어문회 승인과 교과서 대조의 근거 수준도 같다고 표시하지 않는다.

비상교육 영상·도형은 앱 자산으로 복제하지 않았다. 향후 앱 경로는 별도 이용 조건이 확인된 AnimCJK 형상을 사용하며 해당 Arphic Public License와 원저작자 고지를 유지한다. [발행사 이용 안내](https://www.vivasam.com/support/notice/detail?noticeId=1570&page=3).

## Mac 잠금 없이 실행하는 검사와 생성

`python3 scripts/hanja-stroke-textbook-source.py`는 공개 XLSX를 읽고 해시·1,800개 행·문자·ID·파일명을 검사한다. `--json`은 원문 그대로의 한자·행·영상 파일명만 출력한다. `--manifest-file <path>`를 지정하면 기존 로컬 XLSX에 같은 해시 검사를 적용한다. 영상을 요청하거나 파일을 쓰지 않는다.

`node scripts/hanja-stroke-textbook-build.ts --check`는 Python 파서 결과와 고정 Ko·Ja 원문, 카탈로그, 검토 대장 및 공개 승인 데이터의 일관성을 검사한다. 불일치하면 종료 코드1을 반환한다. 변경된 원문을 자동 수용하지 않는다.

- 옵션 없이 실행: 신규 후보의 급수·원본·총획 일치 여부 요약.
- `--json`: 전체 후보와 검토20자의 원문 위치·변환 경로 해시까지 출력.
- `--bundle`: 전체 획 대조가 완료된 `matched` 기록만 경로로 변환한 JSON을 출력. 검토 상태를 바꾸거나 파일에 적용하지 않는다.
- 위 명령에도 `--manifest-file <path>`를 전달할 수 있다. Ko·Ja 원문은 고정 주소에서 읽고 해시를 확인한다.

생성기는 원본 Ko의 중심선 변환만 재현한다. 원문 행·문자·영상명 또는 검토 날짜·모든 획 관찰 기록·승인 경로 해시가 다르면 생성하지 않는다. pending 항목은 조건이 일부 채워져 있어도 출력 대상이 아니다.
