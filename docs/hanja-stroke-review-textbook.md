## pending → matched 조건

명시된 글자마다 전체 영상을 대조한 뒤 검토 대장에 날짜, 모든 획의 완성이 확인된 표본 시점(`strokeEndsSeconds`), 영상 길이(`durationSeconds`), 순서·방향·분할·자형 대조 결과(`checks`), 관찰 메모와 승인할 경로 해시(`pathsSha256`)를 기록한다. 시점은 표본에서 완성을 확인한 상한이며 정확한 펜 정지 시각이 아니다. 첫 묶음은 0.5초 전체 진행과 필요 구간의 0.1초 선택 프레임을 사용했다.

`reviewer`, `reviewMethod: video-frame-sequence`, `sourceVideo`의 정확한 행번호 영상 URL·SHA-256·바이트 수도 필수다. 원본 해시는 실제 디코딩한 영상 바이트를 기준으로 기록했다. 검증기는 기록의 형식과 원문 위치를 검사하며 영상을 자동 해석하지 않는다.

검증기는 원문 위치, 해시, 검토 상태, 총획, 시점의 개수·순서·범위, 모든 대조 결과를 확인한다. 경로는 글자별로 지정한 고정 Ko/Ja/Make Me a Hanzi 중심선을 정규화한 결과 또는 개별 영상에 대조한 명시적 보정 recipe와 일치해야 한다. 보정은 `geometryCorrection`과 `correctionSha256`으로 고정하며 원본 median·영상 SHA, 수정 좌표 및 원본 획 대응까지 검사한다. 원본에 없거나 여러 원본 획을 합쳐 별도로 작성한 경로는 `sourceStroke: null`과 명시적 좌표로 기록한다. 이를 기존 원본의 특정 한 획으로 표시하지 않으며, 좌표가 빠진 null 대응은 거부한다. 미검토는 pending, 차이가 확인되면 conflict로 기록한다. 보정 좌표는 로컬 벡터 편집이며 출판사가 제공한 공식 SVG 좌표로 표시하지 않는다.

이 검증기는 관찰 기록의 일관성을 검사하는 도구이며, 영상의 필순을 자동으로 판정하거나 사람의 대조를 대신하지 않는다. 한국어문회 승인과 교과서 대조의 근거 수준도 같다고 표시하지 않는다.

비상교육 영상·도형은 앱 자산으로 복제하지 않았다. 앱 경로는 별도 이용 조건이 확인된 AnimCJK·Make Me a Hanzi 형상과 명시한 로컬 보정을 사용하며 해당 Arphic Public License와 원저작자 고지를 유지한다. Make Me a Hanzi 경로에는 `MAKEMEAHANZI-COPYING.txt`를 함께 보존한다. [발행사 이용 안내](https://www.vivasam.com/support/notice/detail?noticeId=1570&page=3).

- Python 파서: 인메모리 XLSX·로컬 입력·해시 불일치·행/열 누락·중복·외부 관계·경로 등 15개 확인을 별도로 실행했다. 이 수는 npm 테스트 수에 포함하지 않는다.
- `git diff --check`: 통과.
- 별도 읽기 전용 코드 검토: 클라이언트에 Node 전용 코드가 유입되지 않고 타입 참조로 인한 런타임 순환이 없음을 확인했다.

실제 영상 대조는 Mac 잠금 해제 없이 임시 프레임 시트를 통해 수행했다. `scripts/hanja-stroke-textbook-frames.py`는 PNG만 임시 폴더에 만들고 관찰 정보를 stdout으로 출력한다. 영상은 디코딩 후 자동 삭제하며 앱에 포함하지 않는다. `--times`로 상세 표본을 재검토할 수 있고, 이미 검토한 영상의 URL·해시·크기가 달라지면 중단한다.

## Mac 잠금 없이 실행하는 검사와 생성

`python3 scripts/hanja-stroke-textbook-source.py`는 공개 XLSX를 읽고 해시·1,800개 행·문자·ID·파일명을 검사한다. `--json`은 원문 그대로의 한자·행·영상 파일명만 출력한다. `--manifest-file <path>`를 지정하면 기존 로컬 XLSX에 같은 해시 검사를 적용한다. 영상을 요청하거나 파일을 쓰지 않는다.

`node scripts/hanja-stroke-textbook-build.ts --check`는 Python 파서 결과와 고정 Ko·Ja·Make Me a Hanzi 원문, 카탈로그, 검토 대장 및 공개 승인 데이터의 일관성을 검사한다. 불일치하면 종료 코드1을 반환한다. 변경된 원문을 자동 수용하지 않는다.

- 옵션 없이 실행: 신규 후보의 급수·원본·총획 일치 여부 요약.
- `--json`: 전체 후보와 검토 대장 전체의 원문 위치·원본 후보 경로 해시까지 출력.
- `--bundle`: 전체 획 대조가 완료된 `matched` 기록만 경로로 변환한 JSON을 출력. 검토 상태를 바꾸거나 파일에 적용하지 않는다.
- 위 명령에도 `--manifest-file <path>`를 전달할 수 있다. 세 기하 원문은 각각 고정 주소에서 읽고 해시를 확인한다.

생성기는 글자별로 지정한 고정 원본의 중심선과 검토된 개별 보정만 재현한다. 원문 행·문자·영상명 또는 검토 날짜·모든 획 관찰 기록·승인 경로 해시가 다르면 생성하지 않는다. pending 또는 conflict 항목은 조건이 일부 채워져 있어도 출력 대상이 아니다.
