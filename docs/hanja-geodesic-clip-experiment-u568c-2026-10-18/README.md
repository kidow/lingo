## Algorithm and refusal

D is exactly the union of original raw14 rise polygons; the seed is the intersection with completed raw13 V. Original vertices are normalized by the existing factor1/2 only. The raster records cell-centre membership in D. A seed cell must have all four corners inside the one convex V polygon, avoiding a new external seed stamp in exact geometry. Grid adjacency uses the original union boundary intersection parameters and checks every open segment interval, not only neighbouring centres. Diagonal corner cutting is prohibited. Before rasterization, each original simple polygon is a node in an exact intersection/contact/containment graph. BigInt rational arithmetic interprets the input canonical decimal coordinates and grid centres. Every original vector component must have an exact sampled-cell witness and a whole-cell V seed witness; an unsampled independent island is rejected. A tiny polygon contained in a larger polygon belongs to the same represented component, not a false extra island. Different vector component labels cannot be connected by raster adjacency. All sampled components must also be seeded/reached; otherwise rendering is rejected with diagnostics. No bridge, arbitrary fill or100% unmask fallback exists.

Distance is an8-neighbour raster shortest path, not an exact continuous geodesic. p=0 gives an empty experimental mask. Every p>0 including1 uses the same distance threshold p*maxDistance; the original rise outline remains a vector path. The PNG clip is derived in local RAM. The existing renderer is read directly from its pinned source and keeps its original round cap and100% unmask behaviour for comparison. No original source compiler or engine is invoked.

## Important limits

- Default200 and optional400 grids still expose sampled-cell reachability, not complete vector coverage. Whole independent components absent from the raster are now rejected using the original vector graph. A thin branch attached to a represented component can still be missed; touches may be conservatively rejected, and cell footprints may cover more than their centre.
- Original component topology and sample/seed witnesses use BigInt rational predicates. Supported inputs are simple straight polygons with finite, non-exponent canonical decimal numbers of at most12 fractional digits and magnitude<=1e6; at most64 domain polygons/4096 vertices. Self-intersections, zero area, zero-length or self-overlapping edges are rejected without repair. Adjacency interval checks still use IEEE754 arithmetic. Near-degenerate raster topology can still fail numerically; refusal is safer than filling.
- Seed containment is restricted to one convex polygon; convexity is checked with BigInt rational predicates after exact simple-polygon validation, not Number area/sign arithmetic. AA/compositing at the original V boundary can still darken pixels even when the exact cell footprint is contained.
- Discrete distance thresholds can change whole pixels between frames and between99.99% and100%. This is not a proof of visual continuity or complete terminal coverage.
- A front from V overlap does not necessarily follow the authored Q start or Korean writing direction. Original Q start lies outside V; this experiment cannot approve that direction conflict.
- Build time, cell/component reachability, coverage and mask encoding/paint time are visible. PNG encoding every frame can be expensive; this is not a production performance design.
