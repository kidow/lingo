# 萸: 국내 사전 13획 직접 검토 준비

배정 카탈로그는 **12획 그대로**입니다. 이 페이지의 13은 국내 민간 사전의 원본 애니메이션 클립 수이며 한국어문회 공식 필순 승인이 아닙니다. 디렉터리와 공용 도구의 legacy 'official' 명칭은 출처의 공식성을 뜻하지 않습니다.

공용 helper·renderer·등록·allowlist는 수정하지 않았습니다. 원 SVG는 기존 6998bytes/SHA에 맞춰 RAM에서 한 번 읽어 시간·속성 해시만 추출했고 좌표·이미지는 저장하지 않았습니다. CSS와 실행하지 않는 publisher script 핀은 기존 설정을 재사용했습니다. 새 엔진·compiler·geometry 생성은 없습니다.

별도 metadata.candidate.strokes=13은 **검토 페이지의 관찰 대상 타임라인 수**입니다. 원 catalogCandidate와 원 metadata 파일/SHA를 별도 보존하며 배정12/사전13 충돌의 해제를 주장하지 않습니다.

검토: 1~13 각 원 CSS .1/.5/.75 (39장), 필요시 원 재생. 전체 순서·방향·누적 자형을 모두 직접 확인해야 합니다. 특히 오른쪽 상자 위 H→V가 실제 한 획인지, 두 밑가로가 분리되는지, 가운데 긴 곡선과 마지막 파임의 순서를 확인합니다. 기존 K/VS2 whole 최종형 비교는 참고이며 새 시간 검토로 상속하지 않습니다.

source raw10 H끝(163,71.39)=raw9 V시작(163,71.39), 원 filled영역 교집합의 양의 면적12는 **독립 코드 사실**입니다. 순서10→9/한획화는 아직 제안일 뿐이며 이 설정은 원본 소스 결합·순서 변경·자동 국내 대응을 하지 않습니다.

실행은 ROOT가 config SHA를 확인한 뒤 공용 scripts/hanja-official-media-compare.py --config 이폴더/config.json --config-sha SHA --port 59412 로 시작합니다. 한 서버만 유지하고 검토 종료 시 PID와 wrapper를 종료합니다. 이번 준비에서는 서버를 시작하지 않습니다.
