# 2급 漣~紡 50자·674획 검토 완료

2026-09-15~16 · **50자 전부 반영, 보류 0자**

첫 대조에서 20자가 일치했고, 30자는 보정 후 전체 획을 다시 확인했다.
라이선스 원본의 중간선 611획을 유지하고 63획을 국소 보정했으며,
10자의 획 순서를 수정했다. 같은 부수라는 이유로 승인을 전파하지 않았다.

모든 글자의 필순을 사전의 지연 시간 순서로 대조했다.
각 획의 진행을 25% 구간별 색으로 확인하고, 방향·펜 떼기·획 경계·완성 자형을 비교했다.
보정 30자는 변경된 획뿐 아니라 글자 전체를 재대조했다.
痲·魔·灣·蠻·紡은 이웃 획이 붙는 문제를 추가 조정했고,
재생 선 두께에서 분리 상태가 유지되는지 회귀 검사에도 포함했다.
