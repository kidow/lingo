## 근거와 방법

[비상교육 고등학교 한문 교재](https://text.vivasam.com/detail/186)의 [필순 뷰어](https://viewer.vivasam.com/qrviewer/viewer.html?qrcode=106502_171p_25_ST&teacher=false)에서 사용하는 고정 명세와 정확한 표제자·행 번호를 연결했다. 50개 영상의 전체 SHA-256·바이트 수를 확인하고, 2fps 누적 프레임을 영상 끝까지 확인했다. 후보 경로는 각 획의 시작·끝 및 누적 상태를 전부 비교했다. 관찰 시각은 샘플에서 확인한 완료 시점이며 정확한 펜 들기 시각은 아니다.

경로 원본은 고정 커밋의 [Make Me a Hanzi](https://github.com/skishore/makemeahanzi/tree/bddc96d41bef78427ed0e034e9f7e31d71fd1b92) 및 [animCJK](https://github.com/parsimonhi/animCJK/tree/ec5e17cca76c87587790bcbce5ea0b4d4fb753d6) 허용 데이터다. 似·敍·騷는 Ja, 나머지 47자는 MM 후보를 대조했다. 외국어 코퍼스나 획수 일치만으로 필순을 승인하지 않았다. 코퍼스 전체 해시와 각 영상·보정·출력 경로 해시를 묶어 기록했다.

교재 영상과 프레임은 메모리에서만 표시했으며 저장소나 제품에 복사하지 않았다. 원본 중 저장한 것은 허용된 코퍼스의 후보 중앙선 좌표다. 이번 승인은 **교재와 시각 대조한 프로젝트 내부 검토 결과**이며 시험 주관 기관의 공식 인증이나 전문가 감수를 뜻하지 않는다.

## 파일과 검증

- `queue.json`: 50자와 영상·코퍼스 출처 고정값. `originals.json`: 허용된 원본 중앙선.
- `observations.json`: 50자 수동 관찰·완료 시각·보류 근거. `orders.json`: 화면 비교용 순열.
- `review.json`, `corrections.json`, `candidate-paths.json`: 승인 40자·보정 4개·배포 경로.
- `prepare.mjs`: 파일을 쓰지 않고 승인 데이터를 재현. `serve.py`: 로컬 비교 화면. 후보 획수가 다르면 양쪽 수치를 표시하며, 화면 표시는 승인을 뜻하지 않음.
- `baseline.json`: 기존 세 등록 배열의 길이와 해시. `verification.json`: 이번 검증 결과.

검증 결과:

- `node scripts/hanja-stroke-textbook-build.ts --check`: 고정 원본으로 재생성한 교재 승인 1,107자와 배포 번들 완전 일치.
