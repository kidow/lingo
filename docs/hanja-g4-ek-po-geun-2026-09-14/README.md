사전 자체 재생 메시지로 시작한 CSS 애니메이션을 각 획 시간의 20%·80%·100%에서
정지해 비교했다. 원본 CSS는 75%에서 경로를 완성하므로 80%는 완성 경로의 색상
전환 중인 상태다. 단순한 완성 글자 비교만으로 방향을 승인하지 않았다.
획 두께 5에서 연결이 필요한 구간을 거리 계산으로도 확인했다.

`node docs/hanja-g4-ek-po-geun-2026-09-14/serve.mjs`로 비교 화면을 열 수 있다.
서버는 127.0.0.1에만 바인딩하며, 원본 SVG 세 개와 연결된 CSS·JS 두 개를
해시 확인 후 메모리에서만 제공한다. URL은 실행 결과에 표시된다.
재검증은 `node docs/hanja-g4-ek-po-geun-2026-09-14/verify.mjs --online`으로 실행한다.
