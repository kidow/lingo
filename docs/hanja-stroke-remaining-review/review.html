급수별 데이터와 출처 해시

남은 한자 획 애니메이션 심층 검토

Lingo · 2026-09-07 · 검토 대상: 현재 재생되지 않는 5,493자

결론과 권장 순서

먼저 기존 보류 15자의 경로를 공식 원문에 맞게 보정하고, 새로 전체 도해를 찾은 回·瓦·臼 3자를 등록하는 순서를 권장한다. 18자의 추가 작업을 마치면 현재 485자에서 503자로 늘릴 수 있다. 이번 검토에서는 앱의 승인 목록이나 재생 데이터를 변경하지 않았다.

남은 5,493자 전체를 6종의 획 데이터와 정확한 Unicode로 대조했다. 4,720자에는 후보가 있고 773자에는 조사한 자료 내 후보가 없다. 후보 수는 한국어문회 기준으로 검증된 수가 아니다. 상위 급수 전체의 공식 필순 자료는 확보하지 못했으며, 5,493자 각각의 공식 필순을 모두 검증했다는 의미도 아니다.

1. 보류한 15자의 수정 근거

한국어문회의 필순 정정 및 500자 필순을 같은 SHA-256으로 다시 내려받아, 15자의 전체 누적 도해와 기존 한국어 후보를 재검토했다. 총획만으로 차이를 추정하지 않았다.

각 글자의 원문 위치는 기존 5급까지 대조 기록에 있다. 공통 차이가 발견되어도 다른 글자를 자동 승인하지 않는다.

2. 새로 확보한 전체 도해 3자

공식 HWP에서 500자 표를 제외한 이미지들을 모두 조사했다. 이미지 내용 해시로 중복을 제거한 31개 보충 그림에 예제, 부수 설명, 기존 글자와 별도 누적 도해가 있었다. 이 중 아래 3자는 기존 500자 집합 밖에 있으면서 현재 카탈로그에 존재한다.

위 도해와 후보는 실제 화면에서 첫 획부터 마지막 획까지 나란히 비교했다. 일본어 후보라는 이유로 승인한 것이 아니라 한국 공식 원문에 직접 대조했다. 원문은 래스터 누적 도해이므로 모든 중간 좌표를 자동 인증하거나 자형이 픽셀 단위로 같다는 의미는 아니다.

후보 출처는 고정된 AnimCJK graphicsJa.txt다. 실제 등록 때는 500자 표의 행 번호 대신 “보충 이미지 전체”를 나타내는 근거 형식과 BMP 지원이 필요하다. 현재 재생 수에는 포함하지 않았다.

4. 획 데이터 전수 대조

분모는 기존 재생 485자를 뺀 5,493자다. Unicode 정규화나 이체자 치환을 하지 않았다. 각 행의 후보 수는 중복되므로 더하지 않는다. 6종 합집합은 AnimCJK 4종, Make Me a Hanzi, KanjiVG이며 제한적인 대만 교육부 자료는 제외했다.

AnimCJK는 같은 Unicode라도 언어에 따라 자형·필순이 다를 수 있음을 명시한다. 최신 커밋도 기존 고정본과 같아 한국어 데이터 자체가 늘어난 것은 아니다.

한국어 후보 중 아직 재생하지 않는 37자는 보류 15자와 상위 22자다. 상위 후보는 4급Ⅱ의 假·街·減·監·講·康·個·檢·潔·缺·境·經·警·慶·係·故·官·求·句·究, 1급 几, 특급 冂이다. 警은 앱 20획과 후보 19획이 다르다. 이 22자의 전 획 공식 근거를 이번 조사에서 새로 확보한 것은 아니다.

Hanzi Writer Data는 Make Me a Hanzi 파생 자료다. 둘의 일치를 두 개의 독립적인 필순 검증으로 세지 않는다. KanjiVG 집합은 변형 접미사가 없는 기본 SVG만 셌다.

  • AnimCJK 한자 그래픽과 Make Me a Hanzi/Hanzi Writer 그래픽은 Arphic Public License 대상이다. 원저작자·라이선스·변경 내역과 수정된 소스를 보존해야 한다. 플레이어 코드의 라이선스와 데이터의 라이선스를 혼동하지 않는다.
  • KanjiVG는 CC BY-SA 3.0이다. 도입할 경우 출처·변경 사항·동일조건 배포를 데이터 단위로 관리해야 한다.
  • 대만 교육부 저작권 안내는 애니메이션·전체 필순 그림에 CC BY-NC-ND 3.0 TW를 적용하고 비상업·변경 금지 및 iframe의 비상업 제한을 명시한다. 6,063자 목록 중 남은 4,097자와 겹치지만 자유로운 변환·앱 배포용 후보로 합산하지 않았다. 다른 이용은 별도 허락 경로를 안내한다.
  • 한국 공식 도해는 기준 확인에 사용했으며 보고서나 앱에 이미지를 복제하지 않았다. 공개 열람을 이미지나 경로 재배포 허락으로 해석하지 않는다.

5. 구현에 앞서 필요한 변경

  1. 性, 成, 者·都, 초두머리 11자를 각기 다른 수정 유형으로 기록한다. 수정 경로를 만든 후 공식 도해와 다시 비교한다.
  2. 기존 감사는 원본 중심선의 정규화 결과와 정확히 같은지를 확인한다. 수정 경로에는 원본 해시, 수정 전후 획 대응, 새 경로 해시, 검토일을 별도로 기록하도록 확장해야 한다. 단순히 감사 검사를 느슨하게 해서는 안 된다.
  3. 回·瓦·臼는 보충 이미지 전체를 근거로 등록할 수 있게 출처 형식을 확장한다. 외국어 후보의 출처와 한국 기준 검토 근거를 함께 보존한다.
  4. 器·戶·骨·衰 등의 부분 근거는 해당 획 검토에만 사용한다. 전체 공식 근거가 확보될 때까지 재생 승인과 분리한다.
  5. 虜·擄처럼 공식 자료가 충돌하는 항목은 판본·자형을 확정한 뒤 학습 총획과 재생 경로를 함께 맞춘다.

가장 작은 다음 구현 묶음은 性 보정과 回·瓦·臼 등록이다. 이후 나머지 14자 보정을 진행하면 근거가 확보된 18자를 모두 처리할 수 있다. 상위 수천 자는 원문 확보와 글자별 검수를 병행해야 하므로 일괄 활성화는 권장하지 않는다.

6. 조사 범위, 재현성, 남은 공백

공식 500자 원문·보충 이미지, 기존 조사 밖의 “획순” 상담 답변, 제작자 저장소와 라이선스, 대만 교육부 자료를 조사했다. 원문 해시·후보 버전을 고정하고 카탈로그 전수를 집합 비교했다. 결과 행렬과 해시는 동봉한 coverage.json에 기록한다.

시각 검토 범위는 기존 보류 15자, 중복 제거한 보충 그림 31개, 신규 3자의 전 누적 단계다. 상위 5,478자의 모든 개별 필순을 전수 판독한 것은 아니다. 공식 전체 도해가 없는 글자를 부분 답변·부수 조합·외국 기준 일치만으로 승인하지 않았다.

조사는 공개 상위급수 자료가 부분 설명과 교재 참조로 수렴한 시점에서 마쳤다. 유료 교재를 구매하거나 권리자에게 문의하지 않았다. 추가 검색만으로 전체 원문과 이용 조건을 확보했다고 결론 내릴 근거는 부족하다.

보고서 검증

급수별 합계와 후보 유무의 분할, 데이터 파일 파싱, 로컬 링크 존재를 확인했다. 공식 도해와 후보의 시각 대조는 앞서 명시한 범위에서 수행했다. 보고서 HTML 자체는 브라우저의 로컬 파일 접근 정책으로 렌더링 점검을 진행하지 못했으며, 구조 검사만 완료했다.
