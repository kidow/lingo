국소 보정은 6획뿐이고 **625획은 허가된 중간선 그대로**다. 보정 6획은 모두 선례를 따랐다 —
隹의 짧은 획은 [1급 12차](../hanja-g1-batch12-2026-09-19/README.md)의 壅과 [특급 1차](../hanja-special-batch1-2026-09-20/README.md)의 雞,
穴·亠의 첫 점은 [1급 19차](../hanja-g1-batch19-2026-09-20/README.md)의 稟,
卷·益의 丷는 1급 12차의 縊와 특급 1차의 蠲과 같다.

부수 유사성으로 승인하지 않았다. 쉰 글자의 사전 전체 필순을 순서대로 보고,
색으로 나눈 25% 진행 구간에서 방향·펜 떼기·획 경계·완성 자형을 대조했다.
[direction-probe.mjs](direction-probe.mjs)의 60° 초과 표시는 후보 교체·교환·보정으로 모두 해소했고,
각도 검사가 놓친 緄·綣·丱의 순서 차이는 끝점 배정 검사가 잡았다.
공개한 순서·경로로 다시 재면 60°를 넘는 획이 없다.
45~60° 구간은 여섯 획(裹 1, 疚 1, 佼 3, 姣 4, 虢 2, 綰 7)이고, 이전 회차와 같은 기준으로 그대로 뒀다.
