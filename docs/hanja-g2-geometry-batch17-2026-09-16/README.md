부품의 필순이나 승인 상태를 다른 글자의 근거로 간주하지 않았다. 각 글자의 **전체 사전 필순 32단계**를 후보와 대조하고, 보정한 32단계를 다시 확인했다. 접점·분리 관계 **196쌍**은 원본 윤곽을 메모리에서 분석한 결과와 재생 선폭 5의 후보를 교차검증했다.

분류는 `ehanja-crosschecked`이다. 국내 민간 사전과 대조했으며 시험 주관 기관의 공식 인증을 의미하지 않는다. 사전 SVG/XML·스크린샷은 저장하지 않았다. 자체 작성한 보정 중심선과 Arphic Public License 공개 부품, 출처 URL·해시·순서·방향·접점 관찰 기록만 보관한다.

## 출처와 재현

- 공개 자료: Ko·Ja·Make Me a Hanzi·ZhHans·ZhHant 고정 버전을 다시 조회. 출처와 해시는 [originals.json](./originals.json).
- 사전: e-hanja 실제 상세 페이지의 iframe을 새로 조회. 제목·획수·타이밍·클립 수와 전체 방향 확인 결과는 [source-checks.json](./source-checks.json).
- 후보 생성: [compose.ts](./compose.ts)가 공개 부품의 지문을 검사하고 명시한 배치 영역으로 변환한다. 전체 부품 묶음과 개별 글자 묶음도 각각 해시로 검사한다.
- 최초 관찰 → 보정안 → 재검토: [initial-observations.json](./initial-observations.json), [proposals.json](./proposals.json), [observations.json](./observations.json).
- `node docs/hanja-g2-geometry-batch17-2026-09-16/verify.mjs`는 기록·경로·배포 데이터의 동일성, 전체 적용 집계와 다음 후보를 검증한다.
