# TOCFL만 문맥 카드가 44.3%다 — 예문이 간체라서다

확인일: 2026-09-08. 대상은 `lib/entries.ts`·`lib/quiz.ts`와 `content/*.json`,
그리고 로컬 `.cache/cedict.txt`(CC-CEDICT, CC BY-SA 4.0)다.

## 무엇을 봤나

카드 다섯 종 가운데 문맥 카드는 예문에서 정답을 뚫는다(§5). 뚫으려면 정답
문자열이 예문 안에 **그대로** 있어야 한다(`clozeAt`). TOCFL은 정답이
번체(`traditional`)인데 예문은 간체다. 그래서 세어 봤다.

```
트랙별 · 출제 가능한 낱말 중 문맥 카드가 만들어지는 것

  TOEIC    703/ 703  100.0%
  JLPT    6134/6134  100.0%
  HSK     6134/6134  100.0%
  TORFL   6134/6134  100.0%
  DELE    6134/6134  100.0%
  TOCFL   1932 중 856   44.3%   ← 여기만 다르다
```

## 원인이 하나로 딱 갈린다

```
문맥 카드가 되는 856개 — 전부 번체가 간체와 같은 낱말이다
안 되는 1,076개    — 전부 번체가 간체와 다른 낱말이다
```

예외가 없다. `开→開` `买→買` `读→讀` `写→寫` `关→關`처럼 **번체가 다른
낱말은 예외 없이 문맥 카드를 잃는다.** 대만 학습자가 가장 연습해야 할
낱말이 그대로 빠지는 셈이다.

## 어떻게 어긋나나

`lib/engine.ts:261`이 문맥 칸에서 `canCloze`를 확인하고, 안 되면 재인
카드로 되돌린다.

```ts
if (rung >= RUNG_CLOZE && canCloze(entry)) { … }
…
return buildChoice(entry, words, attempt)
```

**깨지지는 않는다.** 그 낱말은 사다리의 문맥 칸에 올라가도 재인 카드를 계속
받는다. 조용히 빠지므로 눈으로는 안 보인다 — 이 문서가 그래서 있다.

## 고치려면 예문에 번체가 있어야 한다

정답만 번체로 두고 문장을 간체로 남기면 대만 학습자에게 섞인 글자를 보여
주게 된다. 문맥 카드만의 문제가 아니라 **표시 자체가 그렇다.**

`scripts/tocfl.ts`는 문장 변환을 **일부러 피한다.** `scene`을 건너뛰며 그
이유를 적어 뒀다 — "글자마다 후보를 곱하면 문장 길이만큼 부풀어 진짜 갈리는
자리를 파묻는다(了 하나가 문장마다 了/瞭 미확정을 찍어낸다)". 그 판단은
**글자 단위**에 대해 맞다.

```
TOCFL 낱말의 zh 예문 3,864문장 · 쓰인 한자 1,894자
  번체 후보 하나 1,522 · 후보 여럿 372
  가장 잦은 것: 了(972번) 是(301) 个(279) 里(256) 着(153)
```

**낱말 단위로 보면 달라진다.** CC-CEDICT로 최장일치 분절해 조각마다 번체를
찾으면 이렇다.

```
조각 18,895개 · 후보가 여럿인 조각 2,593개 (13.7%)
문장 3,864개 중 조각이 다 갈리는 것 1,840개 (47.6%)
```

그런데 **갈리는 13.7%가 짧은 목록에 몰려 있다.**

| 조각 | 후보 | 횟수 |
| --- | --- | ---: |
| `了` | 了 · 瞭 | 913 |
| `是` | 是 · 昰 | 281 |
| `里` | 裏 · 裡 · 里 | 167 |
| `着` | 着 · 著 | 120 |
| `个` | 個 · 箇 | 57 |

대부분 한쪽이 현대 대만 표준이고 나머지는 옛 이체자다(`昰`·`秊`·`芲`·`㝡`).
`了`는 `瞭解`·`瞭望`을 빼면 `了`이고, `个`는 늘 `個`다. **조각 예순 남짓에
기본값을 정하면 문장의 95% 이상이 자동으로 갈린다.** 진짜 사람이 봐야 하는
것은 `scripts/tocfl.ts` 머리말이 이미 적어 둔 그 짧은 목록이다 —
`里/裡` · `只/隻` · `后/後` · `发/發·髮` · `干/乾·幹`.

## 그래서 무엇을 할 것인가

이 문서는 **재지 않아도 되게** 하려고 쓴다. 고치는 것은 별개의 결정이다.

| 안 | 무엇을 하나 | 비용 | 남는 문제 |
| --- | --- | --- | --- |
| 그대로 둔다 | 없음 | 0 | TOCFL 문맥 카드 44.3%가 고정된다 |
| 예문에 번체를 붙인다 | `zh.examples[].traditional`을 만들고 `pnpm tocfl` 식으로 채운다. 갈리는 조각은 MANUAL 표 | 스크립트 하나 + 손 판정 예순 남짓 | 검사·스키마·`lib/lang.ts`가 함께 움직여야 한다 |
| 문장을 간체로 두고 정답만 번체 | 코드 몇 줄 | 작다 | 간체 문장에 번체 보기가 섞인다 — 표시가 틀린다 |

**둘째를 권한다.** 문맥 카드는 부수 효과이고, 진짜 이유는 대만 시험 트랙의
예문이 대만 글자로 보여야 한다는 것이다. 규모도 잰 대로 감당할 만하다.
