조사일: 2026-09-13 (KST). 기준 커밋: `4a31a7d5ffa88c5727d7fc83ed5fde26f93dfcfb`.

**涼·戲 2자·28획의 국내 출판사 전체 영상 후보를 확보했다.** 목록의 글자와 실제 영상 자형이 달라 정확한 글자 검색에서 빠져 있던 경우다. **나머지 9자·104획은 조사한 국내 경로에서 전체 필순을 아직 확보하지 못했다.** 대만 교육부에서는 정확한 11자·132획의 전체 누적 도해와 획별 순서 데이터를 확인했다. 해외 기준을 한국 필순 승인으로 바꾸지는 않았다.

이번 작업은 출처 조사다. 새 애니메이션 승인·배포 데이터 변경은 **0건**이며, 적용 현황은 **1,470 / 5,978자**, 출판사 근거 적용 **967자**, 3급Ⅱ **480 / 500자**로 유지한다.

## 해외 공식 자료의 확보 범위

[대만 교육부 자료실](https://stroke-order.learningweb.moe.edu.tw/resource.jsp?ID=1)의 전체 도해 PNG와 현행 `dictFrame.jsp`의 인라인 XML을 확인했다. 11자 모두 정확한 글자 및 카탈로그 획수와 일치하고, 132개 획에 Outline과 Track이 있다. 담당 검토자가 **모든 누적 PNG 단계**를 실제 열람했으며, 일부는 원문 브라우저의 최종 자형도 확인했다. 전체 애니메이션 프레임을 획별로 재검토했다는 의미는 아니다.

공통 배포물은 다음과 같다.

## 국내 미확보 9자의 다음 확보 경로

우선순위는 **한국어문회가 안내한 판매처의 연구회 편찬 3급Ⅱ 교재 본문 확보**다. [어문회 참고 교재 안내](https://www.hanja.re.kr/kccpt/exam/studyInfo.do)와 연결된 [상품43 상세](https://skymiru.co.kr/product/%ED%95%9C%EC%9E%90%EB%8A%A5%EB%A0%A5%EA%B2%80%EC%A0%95%EC%8B%9C%ED%97%98-3%EA%B8%89/43/)에서 남기탁·한국어문교육연구회, 2023년 8월, 624쪽, 제목 3급Ⅱ 및 목차의 필순 항목을 확인했다. 訣·紋·森·阿·笛·蹟·稚·兔·楓의 실제 필순 페이지는 아직 확보하지 못했다.

추가 경로도 확보 완료로 집계하지 않았다.

- [씨마스 교과서 자료실](https://teachingsaem.cmass.kr/textbook-material/detail/552)의 필순 ZIP은 교사 인증 경로가 필요하다. 해당 9자 수록 여부는 미확인이다.
- [비상 중학교 한문 자료실](https://v.vivasam.com/educourse/index.do?textbookCd=106210)의 “단원별 새로 배울 한자 필순”(205747 / CN030)은 로그인·교사 인증 검사로 연결된다. 인증을 우회하지 않았고 본문을 확보하지 못했다.
- [사사연 『실용한자 3500』 출판사 소개·서지](https://www.yes24.com/product/goods/18760757)는 글자별 필순 수록을 설명한다. 실제 9자 페이지 확보 전에는 전체 필순 근거로 인정하지 않는다.
- [어문회 토끼 토 상담](https://www.hanja.re.kr/klea/counsel/hanjaDetail.do?id=9388)은 **兔 8획 / 兎 7획** 구분을 뒷받침한다. 兔 전체 필순 도해는 아니다.

접근 경로와 제한은 [국내 자료 접근 기록](domestic-access-audit.json), [A 조사](research-a.md), [B 조사](research-b.md), [C 조사](research-c.md)에 분리해 기록했다.
