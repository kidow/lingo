# 阿·笛·蹟·稚 대체 출처 조사 — B

2026-09-13. 고정 4자·50획 조사이며 재생 승인 **0자**다. 한국 시험기관·공공교육·교과서출판사의 exact 전획 자료는 이번 공개 접근 범위에서 확보하지 못했다. 대만 교육부의 exact 전획 도해 4개는 실제 모두 열람했다. 해외 자료의 획수와 자형이 맞는 사실은 한국 필순 승인을 뜻하지 않는다.

| 글자 | 카탈로그 | 대만 원본 XML / 도해 | 한국 exact 전획 |
|---|---:|---|---|
| 阿 | 8 | 8획, 阝+可, 전체 누적 도해 열람 | 미확보 |
| 笛 | 11 | 11획, 竹+由, 전체 누적 도해 열람 | 미확보 |
| 蹟 | 18 | **18획**, 足+責, 전체 누적 도해 및 공식 플레이어 최종 자형 열람 | 미확보 |
| 稚 | 13 | 13획, 禾+隹, 전체 누적 도해 열람 | 미확보 |

[阿](https://stroke-order.learningweb.moe.edu.tw/dictFrame.jsp?ID=38463), [笛](https://stroke-order.learningweb.moe.edu.tw/dictFrame.jsp?ID=31515), [蹟](https://stroke-order.learningweb.moe.edu.tw/dictFrame.jsp?ID=36447), [稚](https://stroke-order.learningweb.moe.edu.tw/dictFrame.jsp?ID=31258)는 대만 교육부 《國字標準字體筆順學習網》의 개별 공식 화면이다. 모두 현재 HTTP 200이며 inline XML의 exact Unicode와 모든 Stroke의 Outline·Track을 확인했다. 사이트 표제의 판본은 2025이고 개별 제작일은 표시되지 않았다.

蹟(U+8E5F)은 跡(U+8DE1)과 다르다. 직접 본 원문은 足+責이며 18획이다. 좁은 원본 PNG에서는 17·18번째 누적 도해가 옆열 상단으로 이어진다. 기존 한국 manifest의 跡 row1280은 대체 근거로 사용하지 않았다. 해당 비상 영상의 검토는 root 담당이므로 B의 직접 시청으로 계수하지 않는다.

한국 자료의 현재 상태는 다음과 같다.

- [한국어문회 학습정보](https://www.hanja.re.kr/kccpt/exam/studyInfo.do)에서 푸른하늘미루 연결을 확인했다. [상품43](https://skymiru.co.kr/product/%ED%95%9C%EC%9E%90%EB%8A%A5%EB%A0%A5%EA%B2%80%EC%A0%95%EC%8B%9C%ED%97%98-3%EA%B8%89/43/)의 실제 상품은 **《한자능력검정시험 3급Ⅱ》, 남기탁·한국어문교육연구회, 2023년 8월, 624쪽**이다. 현재 HTTP 200이며 목차에 필순이 있지만, 담당4자의 실제 본문 도해는 보지 못했다. 목차나 판매 설명은 전획 증거가 아니다.
- [씨마스 공식 교과서 소개](https://viewer.cmass.kr/html/textbook/view_h_35.shtml)는 2022 개정 《언어생활과 한자》의 **필순 ZIP**을 안내한다. [자료실](https://teachingsaem.cmass.kr/textbook-material/detail/552)의 현재 HTML은 로그인·교사인증 접근 제한을 명시한다. 인증 파일에 진입하지 않았고 ZIP의 담당4자 포함 여부는 미확인이다.
- [씨마스 공개 교과서](https://viewer.cmass.kr/html/ebook/25exh/high/liberalarts/H22_ChineseCharacter/H22_ChineseCharacter_text/H22_ChineseCharacter_text.html)의 검색 데이터 212항목에서 阿와 稚는 어휘 예시로만 나타나고 笛·蹟은 검색되지 않았다. [공개 지도서](https://viewer.cmass.kr/html/ebook/25exh/high/liberalarts/H22_ChineseCharacter/H22_ChineseCharacter_TG/H22_ChineseCharacter_TG.html) 검색 데이터에는 4자 hit가 없었다. 이는 모든 페이지 이미지의 부재 증명이 아니며, 어휘 예시는 전획 자료로 세지 않았다.
- [미래엔 옛 공개 지도서 PDF](https://textbook-miraen.cdn.x-cdn.com/textbook/newbook/mid/chinese/%EC%A4%91%29%ED%95%9C%EB%AC%B8_%EA%B5%90%EC%82%AC%EC%9A%A9%EC%A7%80%EB%8F%84%EC%84%9C.pdf)는 검색에 남아 있으나 현재 표준 TLS 요청이 인증서 호스트명 불일치로 실패했다. 검증을 끄지 않았고 내용은 미열람이다.

시험기관 도메인 3곳, 공공교육·출판사 도메인과 exact字/훈음/필순 조합을 검색했다. 새 공개 한국 exact 전획 자료를 찾지 못했다는 범위 한정 결론이다. 검색 결과 없음, robots 제한, 뜻풀이 또는 비슷한 글자 결과를 전 세계 자료 부재나 원문 확보로 해석하지 않았다. 선행 [한국 근거 조사](../hanja-stroke-deep-research-2026-09-08/korean-evidence.md)와 추가 출처 목록을 읽고 현재 접근 상태를 구분했다.

대만 [공식 교학 자료](https://stroke-order.learningweb.moe.edu.tw/resource.jsp?ID=1)에서 연결한 원본 묶음을 RAM으로 확인했다. 저장소에 원본 매체는 추가하지 않았다.

CSV에서 **訣·涼·紋·森·阿·笛·蹟·稚·兔·楓·戲 11자 모두 exact glyph/decimal Unicode 행**을 확인했다. B가 직접 시각 열람한 전획 PNG는 담당4자다. 나머지7자의 전체 영상·도해를 B가 보았다고 주장하지 않는다. ZIP은 디렉터리를 포함해6,064항목이며 HTTP Last-Modified는 2026-04-14이다. 이 날짜는 개별 도해 발행일이 아니다. 파일명은 Big5 복원으로 exact 매칭했다. 각 XML·PNG 해시와 접근 상태는 [research-b.json](research-b.json)에 있다.

[공식 저작권 설명](https://stroke-order.learningweb.moe.edu.tw/page.jsp?ID=52)은 애니메이션과 전체 필순 도해에 CC BY-NC-ND 3.0 TW를 표시한다. 여기서는 한국 표준성이나 앱 내 복제·변형 허가가 확보됐다고 판단하지 않는다.

다음 검토는 **2023년 8월 3급Ⅱ 지침서의 exact 본문 면 + 판권 + 정오표 확보**가 우선이다. 담당4자 외 국내 미확보 글자에도 같은 교재를 후보로 조사할 수 있으나 개별 도해 존재는 확인해야 한다. 정당한 교사 인증 접근권으로 씨마스 ZIP의 포함 목록과 exact 원문을 확인하는 방법도 남아 있다. 한국 원문을 확보한 뒤에만 전체 경계·순서·방향·자형을 판정하고, 후보 경로의 실제 width5 누적 렌더·접점·독립 peer 검토로 이어간다. 자료 미확보 글자는 계속 미승인으로 유지한다.
