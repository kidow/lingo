## 한국어문회 兔: 자형·획수 근거만 확보

발행기관은 대만 교육부다. 각 페이지를 HTTP 200으로 새로 확인하고, 실제 전체 누적 도해를 브라우저에서 끝까지 열람했다. 페이지 제목의 2025는 사이트 버전이며 개별 자료 게시일은 확인되지 않았다.

## 범위와 검증

국내 시험기관, 공공교육 및 교과서 출판사 중심의 검색어 16개와 한국어문회 상담을 조사했다. 검색 결과의 뜻풀이, 일반적인 필순 설명, 자 목록, 검색 요약은 정확한 글자의 전체 순서 확보로 세지 않았다. EBS 검색은 robots 제한으로 접근하지 못했다. 동아·씨마스의 앞선 접근 범위와 대만 6,063자 묶음 정보는 [2026-09-08 조사](../hanja-stroke-deep-research-2026-09-08/korean-evidence.md)를 참고했으며, 이번에 해당 국내 제한 자료나 대만 전체 묶음을 다시 확보했다고 주장하지 않는다.

고정 대상 3자·38획, 대만의 전획 레코드 38개, 전체 도해 3개 열람, 비상교육 전체 영상 개요 및 확대 최종 자형 1개 열람을 확인했다. 국내 영상 후보는 戲 1자이며, 兔·楓의 국내 전체 필순은 미확보 상태다. 재생 승인 0건, 공유 런타임 파일 변경 0건이다.
