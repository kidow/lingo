# 특급II KanjiVG 배치 4 — 餉 15획

2026-09-21, 국내 사전 e-hanja와 KanjiVG `09909`의 전체 15획을 대조했다. **국내 사전 교차검토이며 시험 주관기관의 공식 인증이 아니다.**

食의 국내 4–7획은 원본 5,6,7,4에 대응한다. 가로꺾음·안쪽 가로 두 획 뒤에 긴 세로를 긋는 순서다. 나머지는 원순서를 유지한다. 向의 10획 삐침, 11획 세로, 12획 가로꺾음갈고리, 내부 口 13–15획의 방향과 구성을 모두 확인했다.

100/109 정규화 후 **15개 누적 상태와 완성 자형**을 다시 검토했다. 새 점 생성, 방향 반전, 경로 평탄화, 획 분할·병합은 없다. Kaisho 대체판은 출처 메타데이터만 확보했으며 시각 검토 완료로 세지 않는다.

## 산출물과 권리

- `candidates.json`: 두 원본 후보 경로와 출처 URL·리비전·SHA-256·바이트·라이선스, 국내 사전 출처 핀.
- `findings.json`: 전체 획 관찰과 순열의 근거.
- `normalized.json`: 대조 완료된 정규화 경로.
- `node docs/hanja-goal-special2-kanjivg-batch4-2026-09-21/build.mjs`: 공개 번들 재현.
- KanjiVG © Ulrich Apel and contributors, CC-BY-SA-3.0. 공개 번들에 출처와 변경 내역을 포함한다.
- 국내 사전 그래픽은 RAM에서만 대조했고 SVG·HTML·스크린샷을 파일로 저장하지 않았다.

## 검증과 진행

- 공개 번들 재현, **한자 테스트 784/784개**, 타입 검사, 독립 체크아웃 제품 빌드가 통과했다. 제품 파일 세 개는 작업 트리와 바이트가 같다.
- 실제 HanjaCard 학습 화면과 쓰기 바텀시트에서 자동재생·다시 재생이 각각 1/15→15/15로 완료됐다. 콘솔 오류는 0건이다.
- 재생 중 정적 자형 중첩이 없었다. 캔버스 드래그 시 0획→1획으로 기록됐고 시트의 위치·크기가 유지됐다. `touch-action: none`도 확인했다. 데스크톱 Chrome 검증이며 실제 모바일 기기 검증으로 주장하지 않는다.
- 재생 UI와 속도는 변경하지 않았다. 검증 자원 정리 상태와 커밋 조회 방법은 상위 goal의 `progress.json`에 기록한다.

이번 검증 후 **4,947/5,978자 적용(82.8%)**, **1,031자 미적용**이다. 특급II는 **857/1,150자(74.5%)**, 293자 남았다. 새 보류는 없다. 직전 커밋은 `002cd3a7`이며, 이번 커밋은 `git log -1 --format=%H -- public/hanja-strokes/dictionary-reviewed-special2-kanjivg-batch4.json`으로 조회한다.

전체 미적용 목록과 고정 KanjiVG 트리의 324개 파일을 재대조했다. 배정표 획수가 맞는 후보는 44자·81파일이며, 기존 goal의 보류 목록을 제외하면 33자·61파일이다. 1급 嫂·諛·斃는 기존 사전 획수와 차이가 있어 별도 변형 검토가 필요하다. 다음은 **특급 鵙 18획**이다. `next-inventory.json`에 집계·첫 여섯 출처 핀과 제한사항을 기록했다. 이 수량은 승인된 적용 가능 수가 아니다.
