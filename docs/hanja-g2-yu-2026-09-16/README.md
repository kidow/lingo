# 庾 11획·12획 자형과 전체 경로 검토

2026-09-16. **11획 후보 전체를 대조했으나 적용은 보류했다.** 이번 회차 신규 적용은 0자다.

## 확인한 차이

- 목록과 정적 SVG는 11획 자형이다. Make Me a Hanzi 후보도 11획이다.
- 대만 교육부의 庾 본문에는 11개의 Outline/Track이 있다. 11개 누적 상태와 후보 경로·방향을 모두 대조했다.
- 국내 e-hanja 사전은 12획이다. 안쪽 아래 가로를 **7획(왼쪽)·10획(오른쪽)**으로 나누며, 대만 교육부와 후보는 이를 **9획 한 획**으로 쓴다. 단순히 같은 번호끼리 대응시키지 않았다.
- 위 점도 다르다. 국내 사전·정적 SVG는 짧은 세로점, 후보·대만 자료는 오른쪽 아래 점이다.
- MOE의 짧은 6·8획은 화면 색상만으로 방향을 판독하기 어려워 Track의 시작·끝 진행도 확인했다. 두 획 모두 왼쪽에서 오른쪽이다.
- 국내 사전과 방향까지 대응한 후보는 2–8·10–11획, 총 9획이다. 1·9획을 국내 자료로 검증했다고 기록하지 않았다.

## 근거의 범위

- [한국어문회 답변 8581](https://www.hanja.re.kr/klea/counsel/hanjaDetail.do?id=8581): 질문에 庾가 있으나 답변은 자형별 획수 차이와 臼 6획을 설명한다. **庾 전체 11획·12획의 필순을 직접 공인하는 답변이 아니다.**
- [대만 교육부 庾](https://stroke-order.learningweb.moe.edu.tw/dictView.jsp?ID=24254&la=0): 11획 전체 순서·방향의 독립된 근거다. 국내 시험 필순 인증으로 확대하지 않는다.
- [e-hanja 庾](http://img.e-hanja.kr/hanjaSvg/aniSVG/5E00/5EBE.svg): 국내 민간 사전의 12획 자형. 실행 지연 순으로 정렬한 XML 경로 번호는 10·11·12·1–9다.
- 후보는 기존 고정 버전 Make Me a Hanzi의 허용된 median 자료만 보관했다. Ko·Ja·MM의 NFKC 호환문자까지 검색했으며 이 버전들에서는 MM의 庾 11획만 발견했다.
- 국내 사전·대만 자료의 원본 SVG/XML/HTML/이미지는 RAM에서만 처리했다. 저장한 것은 URL·해시·메타데이터·직접 작성한 관찰과 허용된 후보 경로다.

11획 庾 전체에 대한 국내 필순 자료 또는 해당 자형에 대한 시험 기관 설명이 필요하다. 아래 가로의 경계·순서와 위 점의 방향을 확인한 뒤 전체 경로를 재대조한다. 획수만 맞추는 병합, 카탈로그 변경, 런타임 등록은 하지 않았다.
