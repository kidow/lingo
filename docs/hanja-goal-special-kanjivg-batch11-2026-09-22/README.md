# 特급 餔·鐶·敝 경로 검토 — 2026-09-22

餔 **16획**을 국내 사전과 전체 대조해 적용했다. 鐶 **21획**과 敝 **후보 12/사전 11획**은 보류했다. 시험 주관기관 인증이 아닌 국내 사전 교차검토다.

- 기본 후보 **49획**, 국내 **48단계**의 순서·방향·꺾임·갈고리·경로를 검토했다.
- 餔는 食 순열 `1,2,3,5,6,7,4,8,9,10,11,12,13,14,15,16`과 100/109 좌표 정규화를 적용했다. 경로 점은 바꾸지 않았다.
- 餔의 굵기 5에서는 甫의 점이 가로획에 붙고, 원본 굵기에서는 食 지붕이 떨어졌다. **4.6**에서 접합과 분리를 대조하고 정규화된 **누적 16상태와 완성 자형**을 확인했다. 공개 경로 간 거리 계산은 굵기 후보 선정의 보조 자료이며 시각 검토를 대체하지 않았다.
- 餔 Kaisho의 다른 세 경로(6·13·14)도 대조했다. 내부 가로획이 오른쪽 경계까지 닿지 않아 기본판을 사용했다.
- 鐶은 金의 오른쪽 점이 중앙 세로획에 닿지 않고 마지막 삐침의 시작 접합도 다르다. 敝는 국내의 연속 중앙획이 후보에서 두 획으로 분리된다. 임의 연결·병합하지 않았다.
