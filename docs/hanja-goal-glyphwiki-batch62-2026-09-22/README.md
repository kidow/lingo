# 坰 8획 적용

특급II **坰(들 경) 8획**의 개별 순서·방향·누적/완성 자형과 **72개 순차 재생 단계**를 국내 e-hanja 사전과 대조해 적용했다. GlyphWiki `u5770-k@7` 전체 자형과 6개 고정 레코드의 경로를 사용한다.

- 土는 가로→세로→올림 곡선. 冂의 가로/세로가 같은 점에서 이어지고, 원본 아래 곡선 뒤 왼쪽 갈고리를 재생한다.
- 안쪽 口의 가로/세로도 원본 공통점에서 이어진다. 경로 연결선이나 새 좌표를 만들지 않았다.
- 원본 다각형을 200→100으로 정규화하고 감김 방향을 맞춰 독립 채움의 합집합을 유지한다. 첫 꼭짓점과 모든 좌표는 보존한다.
- [검토](progressive-review.json), [연결 근거](findings.json), [라이선스](NOTICE.md), [검증](validation.json).
- 공개 소스6개·엔진8파일의 해시 및 원본 재생 일치. 한자 **895테스트·183파일**, TypeScript·프로덕션 빌드·정적7페이지 통과.
- 430×932 실제 소개/쓰기 자동재생·다시 재생·8/8 완료, 정적 SVG 비중첩, 필기0→1→0과 시트 위치 유지 확인.
