# 1급 轎~矜 50자 검토 — 50자·623획 반영

2026-09-18 · **50자 반영, 보류 없음**

[1급 2차 鯨~驕](../hanja-g1-batch2-2026-09-18/README.md)의 `next-batch.json`에 고정한 후보 50자를
같은 방식으로 대조했다. 첫 대조에서 40자가 일치했고, 10자는 보정 후 전체 획을 다시 확인했다.
허가된 중간선 612획을 유지하고 11획을 국소 보정했으며, 2자의 획 순서를 바꿨다.
MM 원본 43자, Ja 원본 6자, Ko 원본 1자(几)에서 출발했다. Ko 원본을 1급 회차에 쓴 것은 처음이다.

## 보정

| 보정 대상 | 변경 |
| --- | --- |
| 矩 | 巨의 윗가로획을 왼쪽 세로획보다 먼저 (6·7획 교환) |
| 駒 | 馬의 왼쪽 세로획을 윗가로획보다 먼저 (1·2획 교환) |
| 眷·捲·倦 | 龹의 위 점 둘을 바깥쪽으로 (왼쪽 점은 왼쪽 아래, 오른쪽 점은 오른쪽 아래; 1·2, 4·5, 3·4획 반전) |
| 灸 | 火의 왼쪽 점(4획)을 왼쪽 아래 방향으로 반전 |
| 衢 | 隹의 오른쪽 위 짧은 획(16획)을 왼쪽 아래 방향으로 반전 |
| 廏·窺·擒 | 广·穴·亠의 첫 점(1, 1, 6획)을 세로로 |

같은 회차의 硅·戟처럼 土·十의 가로가 이미 세로보다 앞선 글자와,
逵·隙·汲(Ja 원본), 几(Ko 원본)처럼 순서와 방향이 모두 같은 글자는 그대로 뒀다.
言·今의 짧은 첫 획을 사전은 가로로, 허가 원본은 점으로 긋는 詭·謳·衾·矜은
시작·끝 방향 차이가 임계 아래라 이전 회차와 같이 그대로 뒀다.

부수 유사성으로 승인하지 않았다. 각 글자의 사전 전체 필순을 순서대로 보고,
색으로 나눈 25% 진행 구간에서 방향·펜 떼기·획 경계·완성 자형을 대조했다.
보정 10자는 변경 획뿐 아니라 전체 획을 재대조했다.

[direction-probe.mjs](direction-probe.mjs)가 60°를 넘는 획 15개(10자)를 표시했고,
10자 모두 보정으로 이어졌다. 표시만 되고 그대로 둔 획은 없다.
巨·馬·龹·衤처럼 덩어리로 얽힌 자리는 획 끝점 좌표를 숫자로 확인한 뒤 판정했다.
사전이 세로로 긋고 허가 원본이 기울여 쓰는 짧은 점이 45~60° 구간에 17개 더 있었다.
이전 회차와 같은 기준으로 임계 아래는 허가된 중간선을 그대로 뒀다.
이번 회차에는 가로 이동 `translate(12, -y)`를 쓰는 원문이 없다.

## 근거와 재현

- [observations.json](observations.json): 50자 판정, 10자의 첫 판정·보정·재대조 기록, 8방향 코드

- [verify.mjs](verify.mjs): 재현 결과·공개 데이터·적용 수·다음 후보 검증. 1급 회차의 보류 글자는 큐에서 뺀다
- [checks.json](checks.json), [progress.json](progress.json): 이번 검증과 전체 진행 현황
- [next-batch.json](next-batch.json): 다음 亘~賭 50자·667획 후보
- [acquire.mjs](acquire.mjs), [source-checks.mjs](source-checks.mjs), [serve.py](serve.py): 원본 고정·원문 확인·검토 시트

재생 중간선은 Arphic Public License의 고정 MM·Ja·Ko 원본에서 출발했다.
사전의 경로·마스크·영상·스크린샷을 파일에 저장하거나 배포하지 않았다.
