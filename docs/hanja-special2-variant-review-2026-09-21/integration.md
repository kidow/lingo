# 특급II 사전 자형 15자·190획 적용

2026-09-21. [review.json](review.json)에서 경로 대조를 마친 **夔·犁·蓼·鵡·筬·亐·臾·贇·卄·渚·猪·簒·砦·穉·啣**을 학습 화면과 쓰기 연습에 연결했다.
e-hanja는 국내 민간 사전이며, 이번 대조는 한국어문회의 개별 자형 공식 인증이 아니다.

## 적용 방식

- 배정 한자의 원래 획수와 Noto 원본 SVG는 유지한다. 학습·쓰기 화면에서는 `사전 자형 · 재생 N획 (배정 N획)`으로 구분한다.
- 기존 `HanjaStudyGlyph`와 `StrokePlayback`이 동일한 검토 경로를 사용한다. 夔·臾·渚·猪의 Noto/사전 구조 차이가 학습 중 섞이지 않는다.
- 글자·배정 획수·재생 획수·후보 해시·경로 해시를 허용 목록에 고정했다. 검토하지 않은 획수 차이는 허용하지 않는다.
- 夔는 검토한 Hans 21획 전체를 사용하고, 나머지 14자는 Ja 후보 전체를 사용한다. 원본 경계·순서·모든 점을 보존하며, 분할·합치기·경로 추정은 하지 않았다.
- 애니메이션 자동재생, 다시 재생, 쓰기 바텀시트, 캔버스 드래그 방지 등 기존 동작을 그대로 사용한다.

공개 데이터와 라이선스는 [dictionary-reviewed-special2-variants.README.md](../../public/hanja-strokes/dictionary-reviewed-special2-variants.README.md)를 본다.
사전 원본 SVG·마스크·영상·스크린샷은 저장하거나 배포하지 않았다.

## 검증

- 한자 관련 테스트 **756개 통과**. 15자의 경로를 보관한 라이선스 원본에서 재현하고, 정적 학습 자형과 애니메이션이 같은 데이터를 참조함을 확인했다.
- 임시 라우트를 제거한 최종 **`pnpm build` 통과**(타입 검사 포함). 첫 빌드 호출은 검사 도중 도구의 55초 제한에 걸렸고, 충분한 제한을 둔 재시도와 최종 빌드는 통과했다.
- 원격 Ja/Hans 원본의 바이트·해시, 정규화 경로, 시각 검토 범위와 사전 근거 메타데이터를 재검증했다.
- 프로덕션 빌드의 실제 컴포넌트를 390×844 화면에서 확인했다. 15자 전체의 자동재생·획수 문구·정적/동적 경로 일치·가로 넘침 없음, 夔·臾·渚·猪의 쓰기 자동재생·오버레이 없음, 夔의 다시 재생·캔버스 입력·시트 위치 유지, 篠의 재생 조작 미노출을 확인했다.
- 검증 전용 임시 라우트는 제거했다. 테스트 서버와 모바일 뷰포트 설정도 정리했다. 개발 모드에서 클라이언트 초기화가 완료되지 않아 프로덕션 빌드로 화면을 검증했다.
- 이전 `review.json`과 `checks.json`은 적용 전 증거로 그대로 보존한다. `verify.mjs`는 15자 적용과 篠 보류를 함께 검사하며 최신 결과는 `integration-checks.json`에 기록한다.

재현 명령:

```sh
node --test lib/hanja-stroke-variants.test.ts lib/hanja-stroke-special2-variants.test.ts
node docs/hanja-special2-variant-review-2026-09-21/verify.mjs
pnpm build
```
