# 諗 15획 적용

국내 사전과 전체 자형 2종·15획 방향을 대조하고, 135개 단계 화면과 7개 곡선의 99.99→100% 확대를 브라우저 패널에서 검토했다.

원본의 연속 꺾임 두 쌍을 각각 한 획으로 유지했다. 6획은 기존 가로·세로 폴리곤을 순차 노출해 완료 순간 윤곽이 튀는 현상을 보정했다. 13획의 갈고리는 고정 엔진의 원본 폴리곤 공식으로 검증한 위쪽 노출이며 새 경로를 만들지 않았다. 15획·17마스크를 런타임에 등록했다.

출처 재조회·해시·원본 윤곽 일치 검증, 격리 전체 테스트 2,223개와 프로덕션 빌드, 모바일 자동재생·재생·쓰기 재진입·입력·지우기·시트 고정 검증을 통과했다. 기존 학습 기록은 쓰지 않는 RAM 모의 기록으로 검증했으며 원본 무변경을 확인했다. 사전 교차검토이며 시험 주관 기관의 공식 승인을 뜻하지 않는다. 비공개 사전 그래픽은 저장하지 않았다.

전체 5,978자 중 5,352자 적용(89.5%), 626자 미적용. 남은 급수: 1급64·2급1·특급II91·특급470. 다음 후보는 迓8획, 이후 頞15획.
