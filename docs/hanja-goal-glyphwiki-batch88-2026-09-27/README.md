# 昑 8획 적용

국내 사전의 전체 8획 방향·누적·완성 자형을 완성 원본 `u6611`과 대조했다. 7획은 점이 아니라 가로획이다. 기본 명조에서는 5획 끝이 日에 닿지만, 원본 엔진의 내장 소형 명조 `new Kage(1)`에서는 떨어져 국내 자형과 일치한다. 모든 획을 이 설정으로 다시 검토했다.

- 완성 원본 4레코드, 고정 엔진 8파일과 4가지 내장 설정 재현 검증 통과.
- 빈 제어 항목5를 제외한 실제 외곽선을 전부 유지했다. 2·8획의 원본 꺾임이 정확히 이어지며, 두 이차곡선과 마지막 직선 사선도 원래 좌표 그대로다. 임의 좌표·굵기 수정이나 새 연결선은 없다.
- 8획 × 9단계, 72개 중간 프레임 직접 검토.
- 한자 테스트 202파일·952개 통과. 새 테스트의 타입 참조 오류를 수정하고 해당 3개 테스트 및 최종 빌드·타입 검사·정적 7페이지 생성 통과. 검사한 20파일과 공개 출력 3파일 일치.
- 430×932 소개·쓰기 자동재생, 다시 재생,8/8완료, 입력0→1→0, 시트 위치·스크롤 유지, 정적 이미지 중첩0, 경고·오류0 확인.

전체 **5,002/5,978자(83.7%) 적용**, 미적용 **976자**. 남은 수: 1급65·2급1·특급II285·특급625. 다른 급수는100%.

다음은 沕(특급II·7획). 완성 원본3레코드·엔진 재현·국내 자료 메타데이터를 확보했고 전체 시각 대조는 아직 하지 않았다. 사전 그래픽은 RAM에서만 사용했다. 이번 검토/모바일 탭과 서버52006–52008은 종료했고 뷰포트를 복원했다. 국내 사전 교차검토이며 시험기관의 공식 승인이 아니다.
