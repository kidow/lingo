# 珽 11획·공개 경로 10획 차이 검토

확인일: 2026-09-16.

## 결과

珽의 **11획 전체를 검토·보정하고 등록했다.** 공개 후보의 9획에 합쳐져 있던
廴 부분이 사전에서는 9획과 10획으로 나뉜다는 것을 확인했다.
공개 후보의 마지막 10획은 사전의 11획에 대응한다.

분류는 `ehanja-crosschecked`다. 국내 민간 사전과의 필순·방향 교차검토이며
시험 주관 기관의 인증을 뜻하지 않는다. 같은 부품을 가진 다른 한자를 자동 승인하지 않는다.

## 근거와 획 분할

- [animCJK graphicsZhHans.txt](https://github.com/parsimonhi/animCJK/blob/ec5e17cca76c87587790bcbce5ea0b4d4fb753d6/graphicsZhHans.txt)의 고정 버전에서
  珽 10획을 확인했다. SHA-256은
  `5a5c157fddd0fd9bfaf5580b25c20a1ba2b0cabc0b7142e09f6149cbd5547798`이다.
  [Arphic Public License 안내](https://github.com/parsimonhi/animCJK/blob/ec5e17cca76c87587790bcbce5ea0b4d4fb753d6/README.md#licences)와 기존 저장소 고지를 유지한다.
- Ko·Ja·MM·ZhHans·ZhHant 다섯 자료를 갱신했다. 珽의 완전한 후보는 ZhHans의 10획뿐이었다.
- [e-hanja 珽 필순](http://img.e-hanja.kr/hanjaSvg/aniSVG/7300/73FD.svg)은
  상세 페이지에서 실제 iframe을 다시 확인했다. 제목 珽, 표시 11획,
  외곽선 11개, 애니메이션 마스크 11개가 일치했다.
  원문 SHA-256은 `a5062745f1b3871166cac4495e8730d94973c3132ef5d421597f398da9d0bf64`다.
- XML 나열 순서는 실제 필순과 다르다. 지연 시간순으로 정렬하면
  XML 인덱스 **8·9·10·11·1·2·3·4·5·6·7**이다.

| 사전 단계 | 공개 후보 대응 | 확인한 동작 |
| --- | --- | --- |
| 9획 | 후보 9획의 앞부분 | 오른쪽으로 쓴 뒤 왼쪽 아래로 꺾는다. |
| 10획 | 후보 9획의 뒷부분 | 앞 획의 끝에서 다시 오른쪽으로 쓰고 왼쪽 아래로 내려간다. |
| 11획 | 후보 10획 | 앞 획에 닿는 마지막 오른쪽 아래 획을 쓴다. |

사전 9획은 7,487ms에 시작해 813ms 동안 그려지고,
10획은 8,500ms에 새로 시작한다. 10획의 1,073ms가 지난 뒤
11획은 9,773ms에 시작한다. **획별로 독립된 마스크와 재시작이 존재한다.**

공개 후보 9획은 네 번째 점(0부터 세면 인덱스 3)을 공통 경계로 나누면
두 부분에 해당한다. 분할한 공개 원본을 다시 이어 붙이면 모든 원본 점이 복원된다.
이 대응을 `split-review.json`에 기록하고 컴파일러와 테스트에서 확인한다.
최종 경로는 이 공개 원본에서 보정했으며, 사전 외곽선·마스크 경로를 복사하지 않았다.

## 전체 검토와 보정

브라우저에서 원본의 모든 11단계와 보정 후 11단계를 비교했다.
25·50·75·100% 마스크 구간으로 시작점·방향·종점을 확인했다.

- 王의 가로·세로·올림획을 연결하고 불필요한 진입 꺾임을 없앴다.
- 안쪽 위 삐침을 사전처럼 완만한 왼쪽 아래 방향으로 보정했다.
- 안쪽 세로획과 위 삐침·두 가로획의 접점을 맞췄다.
- 廴의 첫 꺾임과 다음 꺾임을 별도로 재생하고 마지막 오른쪽 획과의 접점을 보존했다.

모든 획 쌍 **55개**의 연결·분리를 원문과 대조했다.
외곽선 곡선당 30개 표본을 사용하는 RAM 근사 거리·교차 검사가 시각 검토를 보조한다.
원문의 연결 8쌍과 나머지 간격이 재생 선폭 5에서도 유지된다.

사전 SVG/XML·이미지·HTML은 저장하지 않았다.
출처 URL·해시·시간·관찰 기록과 공개 라이선스 경로만 저장했다.

## 구현과 검증

- 별도 런타임 JSON과 등록 모듈에 珽 11획을 추가했다.
- 원본 10획, 최종 11획, 원본 9획의 중복 대응을 구분한다.
- 증빙·원본·분할 경계·보정 경로·출처 해시가 달라지면 등록 검증에 실패한다.
- 이전 배치 테스트의 전역 미적용 목록에서 珽을 빼고,
  이전 배치에는 여전히 포함되지 않는다는 검사를 유지했다.
- 한자 테스트 **68개 파일 425개 통과**, 실패·건너뜀 0.
- `pnpm exec tsc --noEmit --incremental false`와 문법 검사 통과.
- 단계별 방향·자형을 확인했다. 실제 경과 시간에 따른 재생 속도나
  전체 앱 빌드를 새로 검사한 것은 아니다.
