# 2급 旁~蟾 50자·594획 검토

2026-09-16. 50자 전체를 검토해 모두 적용했다. 32자의 경로 63획을 보정하고 6자의 순서를 바꿨으며, 531획은 라이선스가 확인된 후보 경로를 유지했다. 보류는 없다.

각 글자의 e-hanja 필순을 첫 획부터 마지막 획까지 관찰하고, 순서·방향·획의 경계·완성 자형을 대조했다. 보정한 32자는 모든 누적 단계를 다시 확인했다. 등록 상태는 **`ehanja-crosschecked`**이며, 한국어문회 등 시험 주관 기관의 공식 인증을 뜻하지 않는다. 사전 원화·스크린샷은 저장하거나 배포하지 않는다.

## 출처와 보정

- Make Me a Hanzi 48자와 AnimCJK `graphicsJa.txt`의 汎·毘 2자를 사용했다. 고정 커밋, 원본 해시와 라이선스는 `originals.json` 및 [배포 자료 안내](../../public/hanja-strokes/README.md)에 기록했다.
- 보정 32자: 旁·龐·賠·俳·柏·僻·卞·甫·輔·潽·馥·敷·膚·傅·鵬·匪·泌·毖·毘·馮·唆·泗·酸·箱·庠·碩·錫·奭·繕·瑄·纖·蟾.
- 순서 변경 6자: 泌·毖·毘·馮·繕·纖.
- 繕·纖의 분리된 점·사선, 非 계열의 세로획 끝, 둘러싼 획의 연결, 蟾의 내부 간격 등을 개별 보정했다. 繕 6·15획은 재생 굵기에서도 붙지 않도록 간격을 조정하고 전체 18단계를 재검토했다.
- 부수나 획수 일치만으로 승인하지 않았다. 원본과 보정 경로, 관찰 기록, 사전 자료의 해시를 연결하고 하나라도 달라지면 검증이 실패하도록 했다.

## 기록

| 파일 | 내용 |
|---|---|
| `initial-observations.json` | 보정 전 50자·594획 관찰 및 불일치 |
| `originals.json`, `source-checks.json` | 라이선스 후보 원본과 사전 출처·순서 메타데이터 |
| `proposals.json`, `corrections.json` | 획별 재현 규칙과 보정 이유 |
| `observations.json`, `review.json` | 최종 대조 결과 및 출처 연결 |
| `candidate-paths.json` | 재현 가능한 최종 경로 |
| `prepare.mjs`, `verify.mjs` | 읽기 전용 재현·집계 검증 |
| `checks.json`, `progress.json`, `next-batch.json` | 검증 결과·누적 진행률·다음 후보 |

`acquire.mjs`와 `serve.py`는 사전 자료를 메모리에서 대조하는 도구다. 사전 경로를 배포 경로로 복사하지 않는다.
