## 확인 방법과 근거

[비상교육 고등 한문 교재](https://text.vivasam.com/detail/186)의 [기초 한자 영상 뷰어](https://viewer.vivasam.com/qrviewer/viewer.html?qrcode=106502_171p_25_ST&teacher=false)를 기준으로, 정확히 일치하는 글자 행과 전체 동영상 SHA-256을 고정했다. 교재 자료와의 대조이며 **시험 주관 기관의 공식 인증이나 전문가 감수를 뜻하지 않는다.**

- [scope.json](scope.json), [queue.json](queue.json): 50개 정확한 행, 영상 URL·바이트 수·전체 SHA-256, 원본 경로 출처와 라이선스.
- 매니페스트 128,318바이트·1,800행과 SHA-256 `32853d2396dc4fe38362b9e51a828144d7e48889f60e28d850cae9fa2335620c` 확인.
- 50개 전체 영상 **28,270,846바이트**를 읽고 해시를 고정했다. 시각 검토 서버에서 다시 읽은 영상도 모두 같은 해시인지 확인했다.
- 기본 2fps 전체 프레임과 각 후보의 모든 누적 획·초록 시작점·빨강 끝점을 비교했다. 懲의 山·王은 5fps 확대(3.6–7.0초, 7.2–10.6초), 醜의 아래 삐침 시작은 5fps 확대(15.2–18.6초)로 보강했다.
- 자형 충돌은 실제 경로 굵기 5로 렌더링한 결과와 교재 확대 상태를 대조했다. [observations.json](observations.json)에 글자별 판단과 보류 이유를 기록했다.
- 관측 시간은 해당 획이 완성된 것으로 확인한 표본 시각이다. 실제 펜을 뗀 순간을 정밀 측정한 값은 아니다.
- 동영상·원본 프레임은 RAM에서만 처리했다. 저장·배포한 비상교육 동영상/이미지 **0개**. [originals.json](originals.json)은 고정 커밋의 라이선스가 있는 후보 경로 49자·559획과 영상 길이만 기록한다. 玆의 후보 배열은 비어 있다.
- MM·animCJK 경로는 Arphic Public License의 기존 출처·고지 체계를 유지한다. 공개 번들에는 전체 글자 검토를 통과한 12자만 추가했다.
