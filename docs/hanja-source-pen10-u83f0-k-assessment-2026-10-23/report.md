# 菰 10획: 원 guide와 장식 구분

원 guide의 큰 방향은 국내 10획과 상충하지 않습니다. 원 raw10은 세로 아래이고, raw11은 처음부터 끝까지 오른쪽 위로 진행하는 Q입니다. 정적 화면에서 강하게 보인 수평바와 왼쪽 장식 때문에 반대 방향이나 추가 획으로 판단해서는 안 됩니다.

- raw10: `cdDrawLine(127.5,79.4,127.5,168.33499999999995,0,32)`. x가 같고 y가 증가합니다.
- raw11: `cdDrawCurve(92.4,175.685,122.1,172.01,157.2,166.13,0,7)`. Q 도함수의 x 성분은 59.4~70.2로 양수이고, y 성분은 -7.35~-11.76으로 음수입니다. SVG 좌표에서 항상 오른쪽 위입니다.
- 강한 수평바는 별도 가로획 호출이 아니라 raw11 Q의 원 몸통 P입니다. 원 몸통의 bounds는 [92.6,165.2,157.3,181.5]입니다.
- 왼쪽 두 삼각형은 원 Kage의 `a1=0` 아래→위 시작 장식입니다. 기존 시작점 보정·장식 공식과 좌표 내림을 대입하면 확보된 두 P와 정확히 같습니다. 세로 raw10의 본체·시작 장식까지 합쳐 원 P 4개의 소스 공식 등식을 신규 1회 확인했습니다. 전체 엔진이나 투영을 실행한 결과가 아닙니다.

원본은 [pinned Kage kagecd.js](https://github.com/kamichikoichi/kage-engine/blob/49232bac0348fe815f4200d4116ab7917e0db47f/kagecd.js)의 세로 분기와 Q 시작 장식 분기입니다. 파일 해시와 줄 범위, 실제 원 P는 [evidence.json](evidence.json)에 기록했습니다. 원 `u83f0-k` 전체를 유지했으며 다른 variant를 섞지 않았습니다.

시간적 연결은 여전히 보류합니다. 세로 guide 끝 (127.5,168.335)과 Q 시작 (92.4,175.685)의 원 간격은 약 35.8613입니다. 100 단위 표시 좌표로는 약 17.9306입니다. 정적 P가 최종 화면에서 호환된다는 사실이 이 간격이나 초기 노출의 연결을 해결하지는 않습니다.

특히 원 Q 시작 중심의 반경7 클립만 사용하는 초기 노출을 가정하면, 그 클립의 최대 x는 53.2이고 완료한 세로 P의 최소 x는 60.75입니다. x축상 7.55의 분리가 남습니다. 이는 해당 초기 클립 전략의 원자료 경계 조건이며, 새 플레이어를 실제 재생해 확인했다는 뜻이 아닙니다.

원 P와 guide를 보존하는 대상별 연결 prefix 증명과 브라우저 패널의 시작·전환·완료 검토가 필요합니다. 이 검증 전에는 장식 삭제, guide 간격을 메우는 새 연결선, 원 guide 이동 또는 런타임 등록을 하지 않습니다.

기존 공식36화면·정적14화면은 재생하지 않았습니다. 신규 API·미디어 조회·엔진 실행·전체 투영·공유 코드 변경·서버 실행은 모두 0입니다.
