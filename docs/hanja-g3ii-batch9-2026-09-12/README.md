## 검토 결과

- 모든 개별 영상 전체와 획별 완료 표본을 대조했다. 승인509획은 실제 선폭5 누적 경로로 확인했다. 별도 검토자가 위험 후보24자·기준315획을 독립적으로 다시 확인했다.
- 塔·荷의 원본 획을 영상에 맞춰 분할했고, 나머지 순서·방향·접점 보정도 원본 좌표와 획 대응을 보존했다.
- 교차 검토에서 漆·肺·鶴의 좁은 간격을 보정하고 전체 누적 경로를 다시 확인했다. 塔·透의 원본 후보 획수 메타데이터도 바로잡았다.
- 遷·追·透는 영상이 잠시 멈춘 뒤 같은 끝점에서 이어지는 구간을 별도 획으로 단정하기 어려워 보류했다. 弊는 중앙 세로가 하나로 이어져 영상14획과 등록 기준15획이 다르다. 보류 경로는 진단 자료에만 남기고 공개 번들·승인 등록부에는 넣지 않았다.
- 원본3종과1800행 목록의 해시를 다시 확인했다. 저장한 원본 좌표49건이 새로 받은 원본과 일치하며, 승인46개 보정의509획을 실제 생성기로 재현했다. 완료 시각은 관찰한 표본 상한이며 정확한 펜 떼기 시각이 아니다.

이 결과는 출판사 원문에 대한 대조이며 한국어문회나 사람 전문가의 개별 인증을 뜻하지 않는다.
