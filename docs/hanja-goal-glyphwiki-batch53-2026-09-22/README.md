# 萄12획 적용 — 원본 Gothic 프리셋

국내 사전의 전체12획,108개 중간 상태,누적·완성 자형을 공개 원본3건과 대조했다. 고정 KAGE 엔진의 기본 Mincho와 size1 Mincho는 초두 세로와 바깥 삐침 윤곽이 겹쳐 제외했다. 엔진에 정의된 `new Kage(1); k.kShotai = k.kGothic`은 원본 좌표를 바꾸지 않고 두 윤곽을 분리한다(원본 단위 간격1.2). 임의 선폭 보정·획 연장·부수 교체는 하지 않았다.

초두3/4의 순서와 勹·缶 순서를 국내 자료에 맞추고, 정확히 공유되는 끝점에서 바깥 꺾임과 안쪽 아래 꺾임을 묶었다. 갈고리는 원본 엔진의 두 이차곡선을 그대로 따른다. 긴 삐침과 고딕 끝 모양은 검토한 순서·방향·접속을 유지하는 서체 차이로 기록했다. **국내 사전 교차검토이며 시험 주관기관의 공식 승인이 아니다.**

원본3건·엔진8파일 재조회/해시/도형/호출 재현, 신규3개 및 전체885개 한자 테스트(179파일), TypeScript 포함 격리 빌드7페이지가 통과했다. 빌드 체크아웃과23파일·공개 배포파일3개가 일치한다. 모바일430×932에서 소개·쓰기 자동/다시 재생과12/12완료, 오버레이 비중첩, 필기0→1→0과 시트 위치 유지, 콘솔 오류·경고0건을 확인했다. 기존1.5배 재생 속도와 공통 렌더러는 변경하지 않았다.

신규 **萄1자·12획**, 실제 적용 **4,980/5,978자(83.3%)**, 미적용 **998자**. 남은 급수는1급66·2급1·특급II293·특급638이다. 다음은 전체 원본4건을 확보한 **蓑14획**이다.
