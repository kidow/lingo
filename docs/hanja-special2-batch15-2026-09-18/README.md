# 특급II 倬~泫 50자 검토 — 50자·586획 반영

2026-09-18 · **50자 반영, 보류 없음**

[14차 蹠~咤](../hanja-special2-batch14-2026-09-18/README.md)의 `next-batch.json`에 고정한 후보 50자를
같은 방식으로 대조했다. 첫 대조에서 38자가 일치했고, 12자는 보정 후 전체 획을 다시 확인했다.
허가된 중간선 569획을 유지하고 17획을 국소 보정했으며, 7자의 획 순서를 바꿨다.
MM 원본 45자, Ja 원본 5자에서 출발했다.

瀚의 习 안쪽 획 넷은 재배열한 자리에 놓이므로, 보정 경로는 대응하는 허가 원본 획의 좌표에서만 만들었고
`proposals.json`·`corrections.json`에 원본 획 번호(`derivedFromStroke`)를 남겼다.

같은 회차의 瓢(覀)·嫦(⺌)·闔(皿)처럼 가로가 이미 세로보다 앞선 글자와,
匏·彪·孩·垓처럼 순서와 방향이 모두 같은 글자는 그대로 뒀다.

부수 유사성으로 승인하지 않았다. 각 글자의 사전 전체 필순을 순서대로 보고,
색으로 나눈 25% 진행 구간에서 방향·펜 떼기·획 경계·완성 자형을 대조했다.
보정 12자는 변경 획뿐 아니라 전체 획을 재대조했다.

[direction-probe.mjs](direction-probe.mjs)가 60°를 넘는 획 36개(12자)를 표시했고,
12자 모두 보정으로 이어졌다. 표시만 되고 그대로 둔 획은 없다.
羽·瓜·舟처럼 덩어리로 얽힌 자리는 획 끝점 좌표를 숫자로 확인한 뒤 판정했다.
사전이 곧게 긋고 허가 원본이 기울여 쓰는 짧은 획이 45~60° 구간에 22개 더 있었다.
1~14차와 같은 기준으로 임계 아래는 허가된 중간선을 그대로 뒀다.
榻·覇의 원문은 가로 이동 `translate(12, -y)`를 쓴다. 이동은 방향 벡터를 바꾸지 않는다.

## 근거와 재현

- [observations.json](observations.json): 50자 판정, 12자의 첫 판정·보정·재대조 기록, 8방향 코드

- [checks.json](checks.json), [progress.json](progress.json): 이번 검증과 전체 진행 현황
- [next-batch.json](next-batch.json): 다음 孑~畦 50자·647획 후보
- [acquire.mjs](acquire.mjs), [source-checks.mjs](source-checks.mjs), [serve.py](serve.py): 원본 고정·원문 확인·검토 시트
