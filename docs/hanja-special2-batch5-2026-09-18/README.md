# 특급II 瘻~泯 50자 검토 — 50자·659획 반영

2026-09-18 · **50자 전부 반영, 보류 없음**

[4차 牘~褸](../hanja-special2-batch4-2026-09-18/README.md)의 `next-batch.json`에 고정한 후보 50자를
같은 방식으로 대조했다. 첫 대조에서 30자가 일치했고, 20자는 보정 후 전체 획을 다시 확인했다.
허가된 중간선 652획을 유지하고 7획을 국소 보정했으며, 16자의 획 순서를 바꿨다.
MM 원본 43자, Ja 원본 7자에서 출발했다. 이번 회차에는 보류한 글자가 없다.

같은 회차의 楙는 사전도 왼쪽 木부터 써서 그대로 두었고, 懋만 矛가 앞선다.
글자마다 관찰한 대로 따로 판정했다.

부수 유사성으로 승인하지 않았다. 각 글자의 사전 전체 필순을 순서대로 보고,
색으로 나눈 25% 진행 구간에서 방향·펜 떼기·획 경계·완성 자형을 대조했다.
보정 20자는 변경 획뿐 아니라 전체 획을 재대조했다.

[direction-probe.mjs](direction-probe.mjs)가 60°를 넘는 획 54개(20자)를 표시했고,
20자 모두 보정으로 이어졌다. 표시만 되고 그대로 둔 획은 없다.
繆·黴는 화면만으로 가리기 어려워 획 끝점 좌표를 숫자로 확인한 뒤 판정했다.
驀·冪·蓂·錨의 원문은 가로 이동 `translate(12, -y)`를 쓴다. 이동은 방향 벡터를 바꾸지 않는다.
