## 근거와 검토 범위

- [앞선 대체 출처 조사](../hanja-special2-alternatives-2026-09-21/README.md)의 고정된 KanjiVG 원본 3개를 사용했다.
- [KanjiVG 원본](https://github.com/KanjiVG/kanjivg/tree/422b5538595676da918c288a4230cb5e22a1ee7e/kanji), © Ulrich Apel, [CC BY-SA 3.0](https://creativecommons.org/licenses/by-sa/3.0/). 기존 candidates.json의 SVG SHA256와 Git blob SHA1, 라이선스를 연결한다.
- e-hanja 국내 민간 사전의 고정된 SVG를 메모리에서만 대조했다. 이는 한국어문회 공식 필순 인증을 뜻하지 않는다. 원본 이미지·SVG·스크린샷은 저장하지 않았다.
- 원본 65획을 확인한 다음 조정본 65획을 네 획 이하의 화면으로 다시 대조했다. 매 획의 시작·끝·진행 방향·갈고리·꺾음 및 이전 획의 누적 상태를 확인했다. 색상은 파랑→초록→주황→빨강이다.
- 纛의 6획 갈고리와 15·22획의 갈고리 없는 세로, 蘿의 12–14획 糸와 17획 왼쪽 삐침, 藺의 9획 門 갈고리와 14획 왼쪽 삐침을 확인했다.
- 필기체 후보와 사전 명조 자형의 곡률·비례는 동일하지 않다. 획의 역할·연결·방향에 대한 시각 대조이며 픽셀 단위 일치 판정이 아니다. 배정표 획수는 수정하지 않았다.

## 재현

`python3 docs/hanja-special2-kanjivg-review-2026-09-21/serve.py`로 RAM 전용 대조 서버를 실행한다.
`http://127.0.0.1:51829/?id=07e9b&pairs=1:1,2:2,3:3,4:4`에서 조정본을 볼 수 있다.
오른쪽 candidate 번호는 조정한 뒤의 순서다. 원본 번호 대응은 proposals.json에 기록했다.

`node docs/hanja-special2-kanjivg-review-2026-09-21/verify.mjs`는 원본 해시·출처 연결, 순열, 전체 관찰 범위, 런타임 미적용 상태를 검사한다.
브라우저 방문 기록만으로 시각적 정답을 증명하지는 않는다. 구체적 판정은 findings.json을 함께 확인한다.
