# 纛·蘿·藺 3자·65획 앱 적용

2026-09-21. 전체 검토를 통과한 KanjiVG 원본 곡선을 학습 카드와 쓰기 연습에 연결했다.
현재 **4,925/5,978자(82.4%) 적용**, **1,053자 미적용**이다.
특급II는 **844/1,150자(73.4%) 적용**, **306자 미적용**이다.

## 적용 내용

- 원본 M/C/c/s 명령과 곡선을 유지하면서 모든 제어점·끝점·상대 좌표에 100/109를 적용했다. 소수점 8자리로 저장하며 원본 단위로 역산한 각 좌표 오차는 1e-7 미만이다. 경로 재작성·평탄화·획 분할·합병은 없다.
- 기존 proposals.json의 순서를 유지한다. 재생 획은 纛 24획, 蘿 22획, 藺 19획이며, 배정표의 25·23·20획은 변경하지 않는다. 기존 사전 자형 안내와 정적/동적 경로 공유를 사용한다.
- 한정된 허용 목록에 세 글자의 원본·변환 경로 해시와 획수를 고정했다. 전체 획수 예외는 21자에서 24자가 됐다.
- 새 다운로드 JSON은 KanjiVG의 CC BY-SA 3.0 출처·수정 내역을 각 글자에 포함한다. 기존 Arphic 데이터와 라이선스를 구분한다. 민간 e-hanja 대조이며 한국어문회 공식 필순 인증은 아니다.
- 기존 검토 파일과 적용 전 수치는 보존한다. 최신 재현 검사는 verify-integration.mjs다.

## 검증

한자 테스트 765개 통과. 원본 명령·모든 제어 좌표·순열·해시·라이선스와 24자 예외 집합, 보류 14자 미적용을 확인했다.
build.mjs 출력과 배포 JSON의 완전 일치를 검증했다.

실제 HanjaCard를 렌더링하는 임시 페이지를 프로덕션 빌드해 390×844 모바일 화면에서 확인했다.

- 세 글자 모두 소개 화면 및 쓰기 시트 진입 시 1획부터 자동 재생된다.
- 세 글자 모두 다시 재생 버튼으로 1획부터 재시작한다. 藺은 19/19 완료 화면까지 확인했다.
- 쓰기 시트의 글자 SVG는 각각 하나이며 중복 정적 자형과 가로 넘침이 없다. 蘿·藺의 소개/쓰기 경로 문자열 일치도 DOM으로 확인했다.
- 纛 캔버스 드래그 후 입력 1획이 기록되고 시트 상단 126.6015625px, 캔버스 상단 307.6015625px가 유지됐다. touch-action은 none이다.
- 보류한 鱉에는 재생 조작이 없다. 브라우저 오류·경고 로그는 비어 있다.

임시 페이지는 제거했다. UI 컴포넌트와 재생 속도는 변경하지 않았다.
최종 빌드 및 환경 정리 결과는 integration-checks.json에 기록한다.
