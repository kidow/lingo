# 熙 14획 전체 검토·적용

2026-09-16 · 이전: [9자 획수 차이 검토](../hanja-g2-count-review-2026-09-16/README.md)

**熙 1자·14획을 적용했다.** 국내 사전의 전 14단계를 라이선스 후보와 대조하고, 4·8획의 말린 끝부분을 보정한 뒤 전 획과 완성 자형을 다시 확인했다. 순서 변경 없이 **2획 보정·12획 유지**다.

## 근거의 범위

[한국어문회 상담 9699](https://www.hanja.re.kr/klea/counsel/hanjaDetail.do?id=9699)의 煕 13획·熙 14획 구분은 이전 회차에서 확인했다. 앱은 熙 14획을 표시하고 XLS 원문의 煕 13획은 보존한다. 이번에는 목록·학습 키를 변경하지 않았다.

전체 획의 순서·방향·경계·자형은 [e-hanja의 熙 필순](http://img.e-hanja.kr/hanjaSvg/aniSVG/7100/7199.svg)과 대조했다. e-hanja는 **민간 국내 사전**이므로, 애니메이션을 시험 주관 기관이 인증한 것으로 표시하지 않는다. 앱의 검증 출처도 `ehanja-crosschecked`다.

새 사전 응답에서 제목 熙, 표시 14획, 윤곽 14개, 애니메이션 14개, 클립의 일대일 대응과 재생 시간의 비중첩을 확인했다. 순서는 XML 배열을 가정하지 않고 `--d` 지연값 순서로 정렬했다. 사전 SVG 해시는 이전 조사와 같다.

실제 경로는 고정된 [Make Me a Hanzi 원본](https://github.com/skishore/makemeahanzi/tree/bddc96d41bef78427ed0e034e9f7e31d71fd1b92)의 라이선스 중심선을 사용한다. Arphic Public License 고지는 기존 `public/hanja-strokes/`의 라이선스와 출처 기록을 따른다. 사전 원본 경로·이미지·HTML·스크린샷은 저장하거나 런타임 경로로 전용하지 않았다.

다음 권장 작업은 **晟 11획의 경계 보강·전체 경로 검토**다. [한국어문회 답변 10026](https://www.hanja.re.kr/klea/counsel/hanjaDetail.do?id=10026)은 丁 2획 기준 11획을 설명하지만 사전과 MM/Ja 후보는 10획이다. 공식 경계를 확인하고 전체 후보를 대조해야 하며, 획수에 맞추려고 임의로 분할해서 승인하지 않는다. [next-batch.json](next-batch.json)에 검토 조건을 남겼다.

## 검증·재현

한자 테스트 **49개 파일·292개**, Python 가져오기 테스트 **7개**, 프로덕션 빌드·TypeScript 검사를 통과했다. 테스트는 기존 13획으로 되돌아간 상태의 재생 거부, 라이선스 출처, 보정한 두 획의 마무리와 가로 연결, 네 점의 분리, 증거·경로 변조 거부를 포함한다.

- `node docs/hanja-g2-xi-2026-09-16/verify.mjs`: 경로·증거 해시·런타임·진행 현황 재현
- `node docs/hanja-g2-xi-2026-09-16/acquire.mjs`: 해시가 고정된 라이선스 후보를 읽어 표준 출력으로만 반환
- `python3 docs/hanja-g2-xi-2026-09-16/serve.py`: 51746 포트에 RAM 전용 검토 화면 제공. `?i=0&detail=1&start=1&end=4&corrected=1`처럼 범위 선택
- [initial-observations.json](initial-observations.json), [observations.json](observations.json): 보정 전·후 전 획 관찰
- [source-checks.json](source-checks.json), [count-basis.json](count-basis.json): 필순 메타데이터와 공식 획수 근거
- [review.json](review.json), [checks.json](checks.json), [progress.json](progress.json): 승인 기록·검증 결과·현재 수치

이전 회차 문서는 해당 시점의 스냅샷으로 유지하며, 최신 대기열은 이번 `progress.json`을 기준으로 한다.
