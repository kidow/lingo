# 1급 贖~斡 50자 검토 — 48자·589획 반영, 贖·猜 보류

2026-09-19 · **48자 반영, 2자 보류**

[1급 10차 徙~搔](../hanja-g1-batch10-2026-09-19/README.md)의 `next-batch.json`에 고정한 후보 50자를
같은 방식으로 대조했다. 첫 대조에서 38자가 일치했고, 10자는 보정 후 전체 획을 다시 확인했으며,
2자는 허가 원본의 자형이 사전과 달라 보류했다.
반영한 48자는 허가된 중간선 585획을 유지하고 4획을 국소 보정했으며, 8자의 획 순서를 바꿨다.
MM 원본 43자, Ja 원본 7자에서 출발했다.

## 보류

| 글자 | 이유 |
| --- | --- |
| 贖 | 사전은 賣의 가운데를 四(안에 儿)로 쓰는데 허가된 MM 원본은 罒(안쪽 세로 둘)이다. 瀆·犢·牘·竇와 같은 자리 |
| 猜 | 사전은 靑의 아래를 円(위에서 내려오는 세로 다음 가로)으로 쓰는데 허가된 MM 원본은 月(가로 둘)이다. 鯖과 같은 자리 |

순서·방향 보정으로는 자형 차이를 메울 수 없어 큐에서 빼고 다음 후보에서도 제외한다.

## 보정

| 보정 대상 | 변경 |
| --- | --- |
| 讎 | 왼쪽 隹를 言보다 먼저 (1~15획 재배열). 각 隹 안에서 가로 셋을 안쪽 세로보다 먼저 (7, 22획). 隹의 오른쪽 위 짧은 획(3·18획)을 왼쪽 아래로 반전 |
| 衙 | 가운데 吾를 오른쪽 亍보다 먼저 (4~13획 재배열) |
| 繡 | 肅 아랫부분을 사전 순서로 (10~19획 재배열, 簫·蕭과 동일) |
| 蝕 | 飠의 꺾임과 안쪽 가로 둘을 긴 왼쪽 세로보다 먼저 (4~7획 재배열) |
| 蒐 | 艹의 十 둘을 각각 가로 다음 세로 (1·2, 3·4획 교환) |
| 戍 | 긴 왼쪽 삐침을 가로보다 먼저 (1·2획 교환) |
| 羞 | 羊 윗부분의 둘째 가로를 세로보다 먼저 (4·5획 교환) |
| 馴 | 馬의 왼쪽 세로획을 윗가로획보다 먼저 (1·2획 교환) |
| 塾·晏 | 亠·宀의 첫 점(1 / 5획)을 세로로 |

같은 회차의 遜·羞·蝕(Ja 원본)의 나머지 부분과, 灑·穗·殯처럼 순서와 방향이 모두 같은 글자,
鞍·按·宸처럼 宀의 점이 임계 아래인 글자는 그대로 뒀다.

부수 유사성으로 승인하지 않았다. 각 글자의 사전 전체 필순을 순서대로 보고,
색으로 나눈 25% 진행 구간에서 방향·펜 떼기·획 경계·완성 자형을 대조했다.
보정 10자는 변경 획뿐 아니라 전체 획을 재대조했다.

[direction-probe.mjs](direction-probe.mjs)가 60°를 넘는 획 39개(12자)를 표시했고,
10자는 보정으로, 2자(贖·猜)는 보류로 이어졌다. 표시만 되고 그대로 둔 획은 없다.
讎·衙·繡·蝕처럼 부품 순서가 통째로 다른 자리는 획 끝점 좌표로 스물세 획의 대응을 하나씩 맞췄다.
45~60° 구간의 방향 차이는 11개였고, 그중 讎·蝕의 둘은 재배열로 대응이 바뀐 자리다.
나머지 아홉은 사전이 세로로 긋고 허가 원본이 기울여 쓰는 짧은 점으로(粹의 亠 점은 정확히 60°),
이전 회차와 같은 기준으로 임계 아래는 허가된 중간선을 그대로 뒀다.
蒐의 원문은 가로 이동 `translate(12, -y)`를 쓴다. 이동은 방향 벡터를 바꾸지 않는다.
