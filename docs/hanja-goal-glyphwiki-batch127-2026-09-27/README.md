# 怲 8획: 일곱째 곡선의 왼쪽 세로 접촉으로 보류

국내 전체 8획의 방향·누적·완성 자형을 직접 대조했다. 국내 일곱째 곡선은 왼쪽 세로와 떨어지지만, 고정 전체 원본은 붙는다. 기본/소형 명조·고딕 네 가지 모두 해당 다각형 모서리 교차 2개를 재현했다.
