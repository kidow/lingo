## 출처와 대조 방법

- [비상교육 고등 한문 교재](https://text.vivasam.com/detail/186)의 [교육용 기초 한자 필순 뷰어](https://viewer.vivasam.com/qrviewer/viewer.html?qrcode=106502_171p_25_ST&teacher=false)를 사용했다.
- 1,800행 목록의 정확한 문자·행·영상 파일명을 대조하고, 이번 50개 영상의 전체 바이트 수와 SHA-256을 고정했다. 목록 해시는 `32853d2396dc4fe38362b9e51a828144d7e48889f60e28d850cae9fa2335620c`다.
- Make Me a Hanzi와 animCJK의 고정 커밋에서 원본 medians를 확보했다. 적용한 후보 중 耶·汚는 animCJK Ja, 나머지는 Make Me a Hanzi다. 각 원본 및 라이선스는 `queue.json`과 기존 공개 데이터의 라이선스로 추적한다.
- 글자마다 전체 영상을 2fps 누적 상태로 보며 후보의 모든 획과 시작·끝 표시를 대조했다. 방향이나 연결이 불명확한 부분은 5fps 또는 확대된 최종 자형으로 확인했다. 관찰 시각은 획이 완성되어 보인 표본 시점이며 정확한 펜 이탈 시각이 아니다.
- 전체 획의 순서·방향·경계·자형이 일치한 글자만 등록했다. 동일 획수나 공통 부수만으로 승인하지 않았다.
- 이 기록은 **출판사 영상과의 시각 대조**다. 한국어문회가 해당 경로를 인증했다거나 별도의 전문가 심사를 마쳤다는 뜻이 아니다.
- 교재 영상과 프레임은 RAM에서만 열어 대조했고 저장소나 공개 번들에 복제하지 않았다. 공개되는 경로에는 기존 Arphic 라이선스 체계를 유지한다.

## 산출물과 재현

- `scope.json`, `queue.json`: 범위, 원문 행, 영상 해시, 원본 corpus 핀.
- `originals.json`: 원본 라이선스 경로 좌표.
- `observations.json`: 50자의 관찰 시각 또는 보류 사유.
- `review.json`, `candidate-paths.json`: 적용 40자의 검토 기록과 재현한 공개 경로.
- `corrections.json`: 이번 적용에는 보정 없음.
- `baseline.json`: 기존 검토 1,119개, 보정 768개, 교재 공개 경로 1,117개의 접두부 해시.
- `prepare.mjs`, `verify.mjs`: 원본 좌표로 결과를 재현하고 실제 등록·보류·기존 데이터 보존을 검증.
- `collect.py`, `serve.py`: 원문 확보 및 RAM 전용 영상 비교 도구. 서버는 `127.0.0.1:51724`.
- `verification.json`: 완료 시점 집계와 검사 결과.
