# Batch10 B — 衡慧浩豪胡虎惑魂

고정 8자·98획을 모두 개별 출판사 영상과 대조했다. 승인 제안 8자·98획, 보류 0자다. 아직 공유 승인 데이터에 반영하지 않은 작성자 검토 결과다.

- 전체 영상 2fps 표본 285개와 획별 완료 10fps 표본 98개를 실제 열람했다. 완료 시각은 표본 기준 상한이며 정확한 펜 들기 시각을 뜻하지 않는다.
- 세 고정 원본 corpus를 새로 받아 SHA256·바이트를 확인했다. Ja/MM 각 8자 전체 후보를 비교했고 Ja 원본 98획 좌표를 변경 없이 보존했다. 출력 보정점은 별도 recipe에 기록했다.
- 실제 `textbookGeometry`·`textbookCorrectionSha256` 함수로 경로와 recipe 해시를 재현했다. 5단위 굵기·둥근 끝·둥근 이음으로 누적 98획과 420px 완성형을 모두 렌더해 열람했다.
- 원문 완성형 8자는 420px, 豪·魂은 추가 700px로 확인했다. 선택한 접점·간격 120개는 모두 수치 검사도 통과했다. 이는 모든 기하 관계를 자동으로 증명한다는 뜻이 아니다.

|---|---:|---|
| 衡 | 16 | Ja9 중간 가로 → Ja8 중앙 세로로 재배열. 오른쪽 가로와 중앙 상자 사이를 분리. |
| 慧 | 15 | 중앙 가로를 원문처럼 오른쪽까지 연장. 상부 좌우 가로 사이와 아래 네 획 간격 보존. |

분할·새로 만든 null 계보 획은 없다. 원본 순서나 부수로 출판사 순서를 추정하지 않았다. 이 결과는 학습용 중심선 대조이며 시험기관·사람 전문가 인증이 아니다.

독립 검토와 220~240px 인접 10fps 표본 재열람 뒤 완료 상한 9개를 늦춰 정정했다: 衡6 8.4초, 慧9 12.5초, 魂1·9·13 1.2·11.6·19.0초, 浩4·9 5.0·12.4초, 胡4 5.5초, 惑3 3.8초. 경로·원본·recipe 해시는 바뀌지 않았다. 이전 시각과 재검토 표본은 JSON에 남겼다.
