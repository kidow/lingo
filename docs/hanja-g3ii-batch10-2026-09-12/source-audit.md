각 corpus 전체의 해시, 모든 후보 좌표 해시, 30개 원본 좌표 일치 결과, 실제 생성 경로·recipe 해시, sourceStrokeIndices, 원문 영상 해시·용량·길이·완료 표본 시각은 [source-audit.json](source-audit.json)에 기록했다. 좌표 원문은 각 최종 저자 파일에 보존했다. 승인 분할은 禍·荒이며, 승인 경로의 null source나 빠진 원본 획은 없다.

이 감사 담당자 B가 직접 전체 원문 영상을 새로 받아 육안 검토한 범위는 衡慧浩豪胡虎惑魂과 響獻懸脅의 12자다. 나머지 18자의 영상 해시와 시각 검토 증거는 고정된 저자·peer 파일에서 취합했다. 30개 영상을 감사 단계에서 모두 다시 직접 열람했다는 의미는 아니다. 전체 2fps 검토 선언은 합계 1,123프레임이며, 승인 완료 표본은 339개다. 별도의 響 진단 진행 표본 22개와 還 연속 구간 표본 16개를 승인 획수로 세지 않았다. 실제 width 5, round cap/join 누적 렌더 및 최종·확대 검토 범위는 해당 저자·peer 문서에 귀속된다.

響은 13.1–13.5초 같은 끝점에서 정지한 뒤 13.6초 재개한다. 이 정지만으로 독립 경계를 확정할 수 없어 기준 22획을 보류했다. 22개의 제안 경로는 진단용이며, null authored stroke 1개와 원본 7획 재사용을 포함한다. 還은 16개 연속 구간을 관찰했지만 21.1–21.7초 정지와 21.8초 재개만으로 별도 획을 확정할 수 없어 기준 17획을 보류했다. 17번째 경로를 만들지 않았다.
