# 3급II 교과서 후보 다섯 번째 50자

削부터 飾까지 고정 50자·638획을 적용했다. 49자는 원문에 맞춰 보정했고, 壽는 후보 경로를 그대로 사용했다. 이번 묶음의 보류는 없다. 기존 보류 奔은 자료의 획수 충돌이 해결되지 않아 계속 제외한다.

- 전체 적용: **1,240 / 5,978자** · 미적용 4,738자
- 3급II 적용: **250 / 500자 (50%)**
- 교과서 영상 근거 데이터: 737자
- 개별 원문 전획 검토: 50자·638획
- 별도 교차 검토: **23자·319획**

검토 범위는 비상교육의 개별 필순 영상 대조다. 획수나 부수의 유사성만으로 승인하지 않았다. 원본 코퍼스 전체 해시와 50자의 원본 좌표를 검증하고, 원문 전체·방향·펜 경계·완료 표본·실제 선폭 5의 접합과 간격을 대조했다. 완료 시각은 표본에서 채움이 끝났음을 확인한 상한이며 정확한 펜 이탈 시각을 뜻하지 않는다.

교차 검토에서 緖의 도입 방향, 襲·僧·昇의 접합/분리, 裳·像·塞·昇·飾의 완료 표본을 보정한 뒤 다시 확인했다. 영상·원본 좌표·보정 레시피·최종 경로의 해시와 원본 획 계보를 보존했다.

검증: 한자 테스트 **134개 통과**, 타입 검사 통과, 공개 데이터 재생성 검사 통과, 프로덕션 빌드 통과. 기존 공개 데이터 687자의 개별 해시, 이전 묶음 문서 37개, 기존 3개 원장의 내용도 보존됐다.
