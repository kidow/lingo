# 3급II batch5: root 3자 독립 교차 검토

**巡·述·昇 3자·24획을 통과**했다. 원문 전체 2fps와 24개 완료 표본 10fps, 펜 경계 12fps 상세, 원해상도 접합 및 500px 원문·선폭 5 완성형을 직접 확인했다. 영상과 프레임은 메모리에서만 처리했다.

- **巡**: 개별 원문 전체 7획을 대조했다. 巛의 세 굽은 획을 먼저 왼쪽부터 그리고, 辶의 점·위 가로/왼꺾임·아래 굽은 획·긴 파임을 그린다. 12.1667–13.1667초 12fps에서 위 굽은 획5 완료 후 커서가 이동했다가 다시 아래 획6을 그리는 펜 경계를 확인했다. 분할 경로의 원본 번호5 중복은 이 경계와 일치한다. 점과 巛·辶 사이 분리, 아래 굽은 획6과 긴 파임7 접합이 폭5에서 원문과 맞는다.
  최종 경로 SHA: `5d3e748a82356ecadbd12bec25a9f42460d3b75d1ba6dd67781cb28b18cebb77`

- **述**: 개별 원문 전체 9획을 대조했다. 朮은 가로·세로·짧은 왼삐침·아래로 내려간 뒤 오른쪽으로 굽은 획·점 순서다. 辶의 점 뒤 위 굽은 획7과 아래 굽은 획8이 나뉘며, 12.1667–13.4167초 12fps의 실제 커서 이탈과 재진입으로 경계를 확인했다. 짧은 삐침3과 세로2·긴 파임9 사이 분리, 아래 굽은 획8과 긴 파임9 접합을 폭5 완성형으로 대조했다.
  최종 경로 SHA: `ac89d2e8381024f48ba5941c49af138f57e4ad1e050181ce3c1e5c2423afd22e`

- **昇**: 개별 원문 전체 8획을 대조했다. 日4획 다음 짧은 왼삐침5→긴가로6→왼세로/삐침7→오른세로8이며 원본6/7 순서 교환이 원문과 맞다. 초기 완료 표본7의 13.2초는 끝이 미완성임을 발견해 정정을 요청했다. 실제 10fps 13.7초에는 커서가 떠난 뒤 끝까지 채워졌다. 원해상도에서 삐침5는 日과 떨어지고 아래 세로/삐침7과 연결됨을 확인했다. 초기 후보의 반대 접합을 지적한 뒤 수정된5·7획을 최종500px 폭5 완성형으로 다시 대조해 양쪽 관계가 맞음을 확인했다. 日 안가로3의 양벽 접합, 긴가로6과 아래 두 획7·8 접합도 유지된다.
  최종 경로 SHA: `941285e545ec89d2a575fb3f3566ee824f2faaaf74f80e26218ca904572b4049`

昇은 최초 후보에서 발견한 잘못된 접합 두 곳과 완료 표본을 수정한 버전을 다시 확인했다. 巡·述의 경로는 변하지 않았다. 선폭 5에서 접합/분리 관계 17개를 수치 대조했으며 시각 대조 결과와 일치한다. 모든 원영상·경로·레시피 해시와 관찰 시각은 [peer-a.json](peer-a.json)에 보존했다.

기존에 배정된 襲·僧·飾은 C 담당에게 재배정되어 이 문서의 승인 범위에 포함하지 않는다. 출판사 원문 대조이며 한국어문회 개별 인증을 뜻하지 않는다.
