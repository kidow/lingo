# 한능검 전 급수 필순 출처 조사

조사일: 2026-09-06. 추가 적용일: 2026-09-07. 대상은 앱에 적용된 한국어문회 15급수의 고유 한자 5,978자다. 필순을 자체 추론하지 않고 공식 자료에 근거해 첫 획부터 끝 획까지 재생할 수 있는지 조사했다. 공식 도해와 대조한 18자에 한해 앱 재생 기능을 적용했다.

## 결론

**5,978자 전체에 바로 적용할 수 있는 한국어문회 공식 필순 데이터는 공개 경로에서 확보하지 못했다.** 공식 교재가 존재하는 것, 필순이라는 목차가 있는 것, 모든 글자의 전체 획순 도해가 있는 것, 애니메이션용 경로 데이터가 있는 것은 서로 다른 상태다.

- 한국어문회가 공개한 500자 필순 문서는 확인했다. 공식 설명상 5급 누적 범위를 다룬다. 개별 도해 전수 판독·SVG 전사·검수를 완료한 것은 아니다.
- 상위 급수 지침서는 특급까지 존재한다. 특급·특급Ⅱ의 목차에 `漢字의 筆順`이 있지만, 그 사실만으로 배정 한자 전체의 개별 필순을 제공한다고 결론 내릴 수 없다. 현재 공개 본문으로 5,978자를 대조할 수 없다.
- 공식 상담실에는 글자별 보충 답변이 있다. 이견 있는 필순에 대한 처리까지 설명하므로 원문 판본과 함께 검토할 근거가 된다. 전체 필순 데이터베이스를 대신하지는 않는다.
- 대만 교육부의 공식 애니메이션 자료는 존재한다. 그러나 문자 목록을 전수 비교했을 때 앱의 5,978자 중 4,572자만 NFC 기준으로 일치했다. 나머지 1,406자는 연결되지 않으며, 일치하는 글자도 한국어문회와 획순이 같다고 검증된 것은 아니다.

현재 한국어문회 원문과 대조해 앱에 적용한 획 경로는 18자다. 여기서 대조는 Lingo 구현 과정의 확인이며 한국어문회의 앱 승인·인증을 의미하지 않는다. 500자는 “공식 문서가 명시하는 범위”이며 “앱에 넣을 준비가 끝난 수량”이 아니다.

모두 8급 배정 한자다. SVG 경로는 Lingo에서 직접 그린 단순한 중심선이며 공식 제공 SVG나 서체가 아니다. 공식 도해는 획의 순서·분할·방향을 대조하는 근거로 사용했다. 원본 HWP·GIF와 외국 필순 데이터는 앱에 포함하지 않는다. 원문 위치·판본·해시는 `lib/hanja-strokes.ts`에 기록한다.

소개·검색 상세·쓰기 연습에서만 재생을 제공한다. 퀴즈는 기존 글자를 유지한다. 획당 650ms, 획 사이 180ms로 재생하고 일시정지·이어 재생·처음부터 재생을 지원한다. 동작 줄이기 설정이나 애니메이션 API 미지원 환경에서는 클릭마다 한 획씩 표시한다. 화면 비활성화·탭 숨김은 재생을 멈추고, 글자 변경·닫기는 애니메이션을 해제한다. 필기 내용과 숙련도에는 영향을 주지 않는다.

허용 목록에 없거나 공식 총획과 경로 수가 다르면 재생하지 않는다. 추가 글자도 같은 수준의 원문 대조 후 목록에 넣어야 한다. 테스트는 18자의 중복·총획·좌표·출처 식별자·미검증 문자 제외·재생 시간을 확인한다. 총획 일치만으로 순서가 검증되었다고 판단하지 않으며 순서 근거는 위 도해 대조다.

2026-09-07에는 Motion을 추가하지 않고 기존 Web Animations 재생기를 유지했다. 校의 공식 도해는 木의 네 획, 위 점과 가로획, 양쪽 짧은 삐침, 아래 교차하는 두 획의 누적 순서를 대조했다. 敎·九·兄도 각 행의 전체 누적 도해를 대조해 단순 중심선을 작성했다. 기존 Noto 완성형 SVG를 획으로 자동 분할한 것이 아니며 애니메이션의 중심선 모양은 Noto 서체와 다르다.

후보 점검 도구 `node scripts/hanja-stroke-audit.ts`는 고정한 AnimCJK 한국어 자료를 해시로 검증하고, 앱 전체 글자의 후보 누락·좌표 이상·획수 불일치와 기존 검증 상태를 따로 보고한다. `--json`은 5,978자별 전체 목록을 표준 출력으로 내보낸다. 파일을 쓰거나 후보를 자동 승인하지 않는다. 현재 후보 522자 중 507자는 공식 대조가 필요한 후보이며 15자는 획수도 다르다. 5,456자는 이 후보 자료에 없다. 앱 재생 가능한 자체 경로는 18자다. 후보 원본의 경로를 앱에 복사하지 않았다.

추가 검증: 타입 검사와 전체 테스트 144개 통과. 브라우저에서 校의 1/10 재생 시작, 9/10 일시정지, 이어 재생 후 10/10 완료, 처음부터 재생 시 1/10 복귀를 확인했다.

검증 결과: 타입 검사·139개 테스트 통과. 실제 브라우저에서 山의 첫 획·일시정지·이어 재생·완료·처음부터 재생, 韓의 버튼 미노출, 水 쓰기에서 필기 보존·취소·기준 표시를 확인했다. 아직 시작하지 않은 획의 둥근 끝점이 보이던 문제도 브라우저 확인 후 수정했다. 동작 줄이기 분기는 코드 검토했으며 운영체제 설정을 바꾼 실기 검증은 하지 않았다.

## 1. 한국어문회 공개 원자료

### 필순 정정 및 500자 필순

[한국어문회 공식 기타자료 검색](https://www.hanja.re.kr/kccpt/exam/otherData.do?search_option=subject&search_text=%ED%95%84%EC%88%9C)

공식 설명은 필순 예제, 한국어문교육연구회 지침서의 정정·보충, 필순 원칙, 5급 500자 필순을 수록한다고 안내한다. 검색 결과는 1건이다. 기타자료 전체 56건도 6페이지에 걸쳐 확인했으며, 별도의 전 급수 필순 묶음은 찾지 못했다. 급수별 배정한자 파일은 문자 집합 확인용이며 획순 경로 데이터가 아니다.

기존 다운로드 확인 기록: HWP `f37.hwp`, 750,080바이트, SHA-256 `4e191bbee54edd6db595f16fc83a15b9929eba0e3e01095da1e828c70e10760c`. 다운로드 식별자 `file_seq=12751`, `target_id=115`. 기존 문서 조사에서 확인한 수정일은 2010-03-22다. 이번 조사는 공식 게시가 계속 제공됨을 재확인한 것이며 도해 500개를 전수 판독한 것은 아니다.

이용 가능한 범위는 8급·7급Ⅱ·7급·6급Ⅱ·6급·5급Ⅱ·5급의 누적 500자다. 애니메이션으로 만들려면 글자별 원문 위치, 전체 획 순서, 획별 경로, 대조 결과를 확보해야 한다.

## 3. 공식 연결 앱

한국어문회 학습교재 페이지는 와포 앱을 연결한다. 개발자의 [Google Play 설명](https://play.google.com/store/apps/details?id=com.wafour.hanzitest_am&hl=ko)에는 한국어문회 기출문제·모의고사·필순 집중 문제를 제공한다고 적혀 있다. 전체 글자의 획 애니메이션, 공개 API, 원본 경로 배포, 제3자 앱 이용허락은 확인하지 못했다. 공식 사이트의 링크만으로 이 앱 데이터를 Lingo에 재사용할 수 있다고 판단하지 않는다.

## 5. 전체 적용을 위해 남은 확인

1. 한국어문회·한국어문교육연구회에 5,978자 전부의 글자별 필순 자료 또는 디지털 원본이 존재하는지 확인한다. 일부만 있다면 정확한 문자 목록과 판본을 받는다.
2. 상위 급수 지침서의 필순이 원칙 설명인지, 낱글자 전체 도해인지, 쓰기 배정자만인지 확인한다. 구매 전에 목차가 아닌 실제 도해 수록 범위를 확인해야 한다.
3. 공식 정정·보충 답변을 포함해 기준 판본을 정하고, 앱에 제공할 획별 경로의 제작·이용 조건을 확인한다.
4. 확보된 글자만 원문 위치와 전체 획을 일대일 대조해 등록한다. 자료가 없는 나머지는 모델·일반 필순 규칙으로 생성하지 않는다.

교재 내용 확인 연락처는 공식 교재 안내에 기재된 푸른하늘미루 `02-332-1275~6`이다. 한자학습 관련 질문은 [공식 한자상담실](https://www.hanja.re.kr/klea/counsel/hanja.do)이 안내된 경로다. 제3자에게 문의를 보내거나 책을 구매하지는 않았다.

## 조사 범위와 종료 이유

한국어문회 공식 기타자료 56건, 교재 목록 30건, 필순 상담 검색 88건의 제목을 조사했다. 관련 상담 답변 7건과 상위급수 정오표 5건, 공식 연결 판매처·앱, 최신 특급 교재 공개 미리보기, 국내 공식 데이터 검색, 대만 교육부 배포 자료를 확인했다. 원문이 공개되지 않은 유료 교재 본문, 정오표 이미지 전체, 상담 답변 88건 전체의 본문까지 읽었다는 뜻은 아니다.

검색으로 드러난 공백은 상위 5,478자의 한국어문회 기준 전체 획순 근거와 디지털 이용 조건이다. 현재 공개 설명만 더 읽어서는 이 공백을 증명할 수 없어, 전 급수 데이터 확보 완료로 보고하지 않는다. 다음 단계는 권리자·편찬처의 실제 원문/목록 확인이다.
