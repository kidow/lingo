# 挻 10획 검토·적용

특급II 挻의 중국 전체 자형 u633b-g@1과 선언된 u624c-01@4·u5ef6-g02@2·u5ef4-g02@4를 사용했다. 국내 e-hanja 10획의 순서·방향·누적 상태와 90개 진행 상태를 Codex 브라우저 패널에서 대조했다. 시험기관 공식 승인이 아닌 국내 사전 교차검토다.

원본 13개 경로를 [[0],[1],[2],[12],[8],[9],[10,11],[3,4],[5,6],[7]] 순서의 10획으로 묶었다. 사전 근거로 순서를 맞췄으며 원본의 5개 이차곡선·다각형·좌표·엔진 기본값을 보존했다. 접점 41.5,171 · 123,142 · 92,30 · 100,85는 연속이다. 새 좌표·연결 경로·잘라내기·부품 교체는 없다.

한국 전체 소스 u633b-k@2(별칭 u633b@6)는 마지막 획의 중심 경로 83,105→81,113이 √68만큼 끊어져 제외했다. 대만 소스 편집기에 기존 데이터가 없는 것도 확인했으며 제출하지 않았다. 중국 전체 자형의 모든 획을 별도로 검증해 적용했다. 제외 소스와 선택 소스 모두 원본 엔진으로 재현했다.

집중 테스트 10개, 전체 한자 테스트 263파일·1135개, 원본 엔진 8파일 재현, 타입 검사와 정적 7페이지 빌드, 공개 3파일 내보내기 바이트 비교가 통과했다. 모바일 430×932에서 소개·쓰기 자동재생 및 다시 재생을 각각 1/10→10/10으로 확인했다. 오버레이 이미지 0개, 캔버스 0→1→0획, 시트 위치·스크롤 유지, 해당 화면 콘솔 오류 0개도 확인했다.

누적 5063/5978자(84.7%), 미적용 915자다. 특급II 906/1150자(78.8%). 이번 적용은 1자·10획이며 다음 후보는 栯 10획이다.
