## 근거와 범위

- 각 글자의 [e-hanja](http://www.e-hanja.kr/) 필순 자료를 처음부터 끝까지 확인했다. 정확한 글자 제목, SVG SHA-256, 지연시간에 따른 획 순서와 획수를 고정했다. 개별 URL과 해시는 [source-checks.json](source-checks.json)에 있다.
- 각 획의 25·50·75·100% 마스크 진행을 허가된 후보 경로와 나란히 비교해 순서·방향·경계·최종 자형을 검토했다. 재생 시간의 등분이 아니라 마스크 진행 구간을 보여주는 비교다.
- 한국의 민간 사전과 대조한 결과이며 한국어문회 등 시험 주관기관의 인증이 아니다. 부수나 획수만으로 미검토 한자를 승인하지 않았다.
- 후보는 Make Me a Hanzi 44자, AnimCJK 일본어 데이터 6자(甕·郁·魏·兪·踰·楡). 원본 커밋·라이선스·SHA-256은 [originals.json](originals.json)과 [배포 고지](../../public/hanja-strokes/README.md)에 남겼다.
- 사전의 SVG 윤곽·그림·스크린샷은 저장하거나 배포하지 않았다. 재생 경로는 라이선스가 확인된 중심선을 유지하거나 개별 검토 후 보정했다. 정밀한 원본 서체 복제나 손글씨 자동 채점의 검증은 포함하지 않는다.
