# 芃 7획 적용 — 고정 공개 백업

개별 API에서 확보하지 못했던 전체 원본을 [공개 백업](https://github.com/tomcumming/glyphwiki-database/tree/a7dd7f3d911936770fa742e8c37d16bee7e2173c)에서 확보했다. 2016-05-02 커밋의 최신본 전용 덤프이며 개별 글리프 리비전 번호는 제공하지 않는다. 현재 API 원본과 섞거나 버전을 추정하지 않았다. 백업의 재사용 허가와 귀속은 NOTICE.md에 기록했다. 사전 교차검토이며 시험기관 공식 승인이 아니다.

- 덤프 63,801,771바이트의 SHA256을 확인하고 전체 5개 원본 의존 관계를 복원했다. KAGE 엔진 8개 파일의 해시와 렌더링을 재현했다.
- 국내 7획 전체의 방향·순서·꺾임·갈고리·누적·완성 자형 및 63개 중간 상태를 검토했다. 풀 부수 3·4 순서만 바꾸고, 원본에서 정확히 연결되는 가로선과 꺾임을 국내 제6획으로 묶었다. 원본 위쪽 갈고리를 마지막에 재생한다. 새 경로·연결선·좌표 수정·부수 교체는 없다.
- 집중 검사 3개, 전체 190개 파일의 916개 테스트, 타입 검사와 프로덕션 빌드(정적 7페이지)를 통과했다. 격리 빌드 17개 파일·공개 산출물 3개가 일치한다.
- 430×932 실제 화면에서 소개/쓰기 진입 자동재생·다시 재생·7/7 완료, 입력 0→1→0, 캔버스·시트 좌표 및 스크롤 유지, 정적 이미지 0·애니메이션 SVG 1, 콘솔 경고/오류 0을 확인했다. 기존 속도는 바꾸지 않았다.
- 전체 4,990/5,978자 적용(83.5%), 988자 미적용. 1급 65자·2급 1자·특급II 288자·특급 634자가 남는다.
- 다음 艽 6획은 같은 백업의 완전한 원본과 엔진 재현을 확보했다. 전체 시각 검토는 아직 남았다. 芎은 정확한 u5f13@3가 백업에 없고 伻의 k 루트도 없어 보류한다.

공식 덤프 HEAD는 200이었지만 실제 GET은 403이었다. 이를 우회하지 않고 별도 공개 백업을 이용했다. 사전 그래픽과 전체 백업은 RAM에서만 처리했다. 서버·탭·격리 작업 트리를 정리했고 푸시·배포하지 않았다.
