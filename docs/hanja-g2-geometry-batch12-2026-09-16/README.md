## 확보·대조

- 사전 상세 페이지에서 실제 애니메이션 iframe을 확인하고, 자형·표시 획수·SVG 획수·재생 순서·clip 연결을 검증했다.
- 고정된 animCJK Ko/Ja 및 Make Me a Hanzi 전체 파일을 다시 조회하고 SHA-256을 확인했다. Ko/Ja에는 세 글자 모두 없으며 NFKC 호환자를 포함해도 획수가 일치하는 공개 후보는 없었다.
- 세 글자 모두 MM 경로를 보정 기반으로 사용했다.
- 원본 후보와 최종 후보를 각각 사전 27단계의 25/50/75/100% 마스크 공개 상태와 브라우저에서 대조했다. 동일 시간 간격으로 애니메이션을 재생한 테스트는 아니다.
- 사전 윤곽의 모든 획 쌍 **111쌍**을 RAM에서 수치 보강했다(곡선당 30개 표본의 근사 거리). 최종 경로에도 5단위 선폭에서 같은 접촉·분리 관계가 유지되는지 검사했다.
- 사전 SVG/XML·스크린샷·HTML은 저장하지 않았다. 출처 메타데이터·해시·자체 관찰·공개 라이선스 경로·보정 레시피만 저장했다.

## 글자별 보정

- **陜:** 왼쪽 阝의 합쳐진 공개 경로를 위 가로꺾기와 아래 굽은 갈고리로 분리했다. 3획 긴 세로 뒤 오른쪽 긴 가로를 쓰고, 두 작은 人을 먼저 쓴 다음 9획 큰 세로·왼쪽 삐침과 10획 오른쪽 삐침을 쓴다. 공개 원본의 큰 大를 먼저 쓰는 순서를 수정했다. 작은 人과 큰 大는 떨어지고, 큰 大의 두 획은 닿는 관계를 확인했다.
- **邢:** 开의 가로 두 획을 먼저 쓰고, 왼쪽 굽은 세로와 오른쪽 곧은 세로가 두 가로에 모두 닿도록 했다. 오른쪽 阝의 위 가로꺾기와 아래 굽은 갈고리를 독립된 두 획으로 나눴다. 마지막 긴 세로는 지붕에는 닿되 갈고리 끝과는 떨어진다.
- **祜:** 공개 원본의 4획 礻와 사전의 5획 示가 달라 왼쪽 전체 자형을 보정했다. 짧은 가로 → 긴 가로 → 가운데 세로 → 왼쪽으로 굽는 세로 → 오른쪽 세로 순서다. 가운데 세로만 긴 가로에 닿고 양옆 획은 분리했다. 오른쪽 古의 긴 세로가 가로를 관통하고 口 지붕에 닿으며, 마지막 바닥 가로는 양쪽 변에 닿도록 했다.

모든 보정의 원본 획 번호·원본 경로·이유를 `corrections.json`에 기록했다. 부수의 기존 승인 여부를 근거로 자동 승인하지 않았다.
