# 頟 15획 적용

국내 사전과 원본 전체 자형·15획 방향을 대조하고, 135개 단계 화면 및 곡선 6개·꺾임 2개의 99.99→100% 확대를 브라우저 패널에서 검토했다. 원본의 연속 꺾임 세 쌍을 각각 한 획으로 유지하며 15획·17마스크를 등록했다. 5·10획은 원본 가로·세로 폴리곤을 순차 노출한다.

출처 재조회·해시·원본 윤곽 일치 검증, 격리 전체 테스트 2,226개와 프로덕션 빌드, 모바일 자동재생·다시 재생·쓰기 재진입·입력·지우기·시트 고정 검증을 통과했다. 실제 학습 기록을 쓰지 않는 RAM 모의 환경이며 원본 무변경을 확인했다. 사전 교차검토이며 시험 주관 기관의 공식 승인을 뜻하지 않는다. 비공개 사전 그래픽은 저장하지 않았다.

전체 5,978자 중 5,353자 적용(89.5%), 625자 미적용. 남은 급수: 1급64·2급1·특급II91·특급469. 보류143자. 다음 후보는 餲18획, 이후 僾15획.
