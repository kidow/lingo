## 濫와 濫의 동일성

출판사 0392행 원문은 **濫(U+F922)**, 카탈로그는 **濫(U+6FEB)**이다. [Unicode 17.0.0 공식 UnicodeData](https://www.unicode.org/Public/17.0.0/ucd/UnicodeData.txt)의 F922행은 canonical decomposition을 **6FEB**로 정의한다. 실제 JavaScript NFC 정규화 결과도 濫과 일치했다.

- UnicodeData 전체: **2,198,209바이트**, SHA-256 `2e1efc1dcb59c575eedf5ccae60f95229f706ee6d031835247d843c11d96470c`.
- [identity.json](identity.json)에 정확한 코드 포인트·원본 행·정규화 결과·자료 해시를 기록했다.
- 승인 기록의 `glyph`는 濫, `sourceGlyph`와 런타임 출처 참조의 `glyph`는 원문 濫를 보존한다.
- 기존 NFC 검증기를 사용하며 이체자 허용 규칙이나 예외를 추가하지 않았다.

**정규화 동일성만으로 애니메이션을 승인하지 않았다.** 다음 전체 영상 관찰과 17개 누적 경로·최종 자형 대조를 별도로 수행했다.

1,800행 목록 원본 XLSX의 **128,318바이트**와 해시 `32853d2396dc4fe38362b9e51a828144d7e48889f60e28d850cae9fa2335620c`를 확인했다. 검증 때 목록·두 전체 영상·UnicodeData를 다시 받아 해시 일치를 확인했다.

전체 영상을 0.5초 간격으로 보고 **30개 누적 경로·시작점·끝점·방향·완성 자형**을 대조했다. 携의 마지막 두 획은 **13~18.4초의 5fps**, 濫의 臣 경계는 **3.2~10.2초의 5fps**로 보강했다. 携 18.5초, 濫 20초의 상단 접합은 840px 원본 부분 확대로 확인했다.

[observations.json](observations.json)은 실제 관찰과 완료 상한 시각이다. 시각은 샘플링한 관찰값이며 정확한 붓 떼기 시각이 아니다. [proposals.json](proposals.json)은 보정 좌표, [candidate-paths.json](candidate-paths.json)은 적용 벡터, [review.json](review.json)은 승인 기록이다.

고정 Make Me a Hanzi의 원본 기하 해시·획 대응 번호와 Arphic 라이선스를 유지했다. 이는 **출판사 자료와의 Codex 시각 대조**이며 시험 주관 기관 또는 전문가의 애니메이션 인증을 의미하지 않는다. 원본 영상·캡처·XLSX·UnicodeData 전체 파일은 저장하지 않았고 [serve.py](serve.py)는 원본을 RAM에서만 읽는다.
