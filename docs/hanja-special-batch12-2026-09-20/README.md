## 叕 — 각도 검사가 볼 수 없는 차이

叕은 又 넷이 2×2로 앉은 글자다. 사전은 **왼쪽 세로줄을 위아래로 먼저 쓰고** 오른쪽 줄로 넘어가는데,
다섯 말뭉치가 모두 **윗줄을 먼저** 쓴다.

획 넷이 전부 같은 방향으로 달리기 때문에 **각도 검사는 아무것도 잡지 못한다.**
끝점 배정 검사만 갈랐고, 이득이 292·330·286으로 이번 회차에서 가장 컸다.

**叕을 가진 세 글자가 전부 같은 자리에서 같은 방향으로 갈렸다.**

**隹의 오른쪽 위 획이 한 회차에서 세 번 나왔다.** 羽는 趯·羿·熠과 같은 처리다.

이번 회차는 [4차](../hanja-special-batch4-2026-09-20/README.md) 이후 처음으로 **가로 오프셋을 가진 그림이 하나도 없다.**

부수 유사성으로 승인하지 않았다. 쉰 글자의 사전 전체 필순을 순서대로 보고,
색으로 나눈 25% 진행 구간에서 방향·펜 떼기·획 경계·완성 자형을 대조했다.
[direction-probe.mjs](direction-probe.mjs)의 60° 초과 표시는 후보 교체·교환·보정으로 **모두** 해소했다.
공개한 순서·경로로 다시 재면 60°를 넘는 획이 없다.
45~60° 구간은 열두 획(彘 2, 甃 6, 蹜 8, 瘁 1·6, 廁 1, 褫 1, 庤 1, 佗 3, 沱 4, 它 1, 疃 6)이고, 이전 회차와 같은 기준으로 그대로 뒀다.
**甃 6은 정확히 60°다** — 지금까지 그대로 둔 획 중 임계값에 가장 가깝다.
