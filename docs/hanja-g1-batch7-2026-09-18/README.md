# 1급 挽~駁 50자 검토 — 50자·603획 반영

2026-09-18 · **50자 반영, 보류 없음**

[1급 6차 鈴~彎](../hanja-g1-batch6-2026-09-18/README.md)의 `next-batch.json`에 고정한 후보 50자를
같은 방식으로 대조했다. 첫 대조에서 41자가 일치했고, 9자는 보정 후 전체 획을 다시 확인했다.
허가된 중간선 601획을 유지하고 2획을 국소 보정했으며, 7자의 획 순서를 바꿨다.
MM 원본 47자, Ja 원본 3자에서 출발했다.

## 보정

| 보정 대상 | 변경 |
| --- | --- |
| 襪·糢·蕪 | 艹의 十 둘을 각각 가로 다음 세로 (6·7, 8·9 / 7·8, 9·10 / 1·2, 3·4획 교환) |
| 襪 | 戍의 긴 왼쪽 삐침을 가로보다 먼저 (15·16획 교환) |
| 罵·駁 | 馬의 왼쪽 세로획을 윗가로획보다 먼저 (6·7, 1·2획 교환) |
| 拇 | 母의 둘째 점을 긴 가로보다 먼저 (7·8획 교환) |
| 謐 | 必의 다섯 획을 사전 순서대로 (위 점·긴 삐침·누운 갈고리·왼쪽 점·오른쪽 점, 8~12획 재배열) |
| 耗 | 耒의 첫 가로획(1획)을 오른쪽에서 왼쪽으로 긋는 방향으로 역방향 |
| 靡 | 广의 첫 점(1획)을 세로로 |

같은 회차의 瞞처럼 艹의 가로가 이미 세로보다 앞선 글자와, 膊·搏·縛의 尃, 撲·樸의 業처럼
순서와 방향이 모두 같은 글자, 麪·歿·憮(Ja 원본)는 그대로 뒀다.
言의 짧은 첫 획을 사전은 가로로, 허가 원본은 점으로 긋는 誣·謐은
시작·끝 방향 차이가 임계 아래라 이전 회차와 같이 그대로 뒀다.

부수 유사성으로 승인하지 않았다. 각 글자의 사전 전체 필순을 순서대로 보고,
색으로 나눈 25% 진행 구간에서 방향·펜 떼기·획 경계·완성 자형을 대조했다.
보정 9자는 변경 획뿐 아니라 전체 획을 재대조했다.

[direction-probe.mjs](direction-probe.mjs)가 60°를 넘는 획 21개(9자)를 표시했고,
9자 모두 보정으로 이어졌다. 표시만 되고 그대로 둔 획은 없다.
艹·馬·母·必·耒처럼 덩어리로 얽힌 자리는 획 끝점 좌표를 숫자로 확인한 뒤 판정했고,
謐의 必은 한 획씩 확대해 다섯 획의 대응을 다시 맞췄다.
45~60° 구간의 방향 차이가 14개 있었고 대부분 사전이 세로로 긋고 허가 원본이 기울여 쓰는 짧은 점이다.
이전 회차와 같은 기준으로 임계 아래는 허가된 중간선을 그대로 뒀다.
襪·糢·蕪의 원문은 가로 이동 `translate(12, -y)`를 쓴다. 이동은 방향 벡터를 바꾸지 않는다.

## 근거와 재현

- [observations.json](observations.json): 50자 판정, 9자의 첫 판정·보정·재대조 기록, 8방향 코드
- [source-checks.json](source-checks.json): 50자의 원문 해시·획별 시간·XML 참조·좌표 변환
- [originals.json](originals.json): 고정한 라이선스 원본의 중간선과 정규화 경로
- [proposals.json](proposals.json), [corrections.json](corrections.json): 획별 원본 대응과 국소 보정 이유
- [candidate-paths.json](candidate-paths.json), [review.json](review.json): 승인 경로와 증거 해시
- [prepare.mjs](prepare.mjs): 읽기 전용 승인 데이터 재현 (50자 승인을 검사)
- [verify.mjs](verify.mjs): 재현 결과·공개 데이터·적용 수·다음 후보 검증. 1급 회차의 보류 글자는 큐에서 뺀다
- [checks.json](checks.json), [progress.json](progress.json): 이번 검증과 전체 진행 현황
- [next-batch.json](next-batch.json): 다음 槃~訃 50자·632획 후보
- [acquire.mjs](acquire.mjs), [source-checks.mjs](source-checks.mjs), [serve.py](serve.py): 원본 고정·원문 확인·검토 시트

필순 근거는 e-hanja 사전이며, **한국어문회 인증으로 표시하지 않는다.**
재생 중간선은 Arphic Public License의 고정 MM·Ja 원본에서 출발했다.
사전의 경로·마스크·영상·스크린샷을 파일에 저장하거나 배포하지 않았다.
자형의 구조와 진행 방향을 비교한 것으로 폰트 외곽선의 픽셀 일치나 필기 채점이 아니다.
