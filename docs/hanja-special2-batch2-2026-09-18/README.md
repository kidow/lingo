# 특급II 涇~赳 50자·619획 검토 완료

[1차 痂~勍](../hanja-special2-batch1-2026-09-18/README.md)의 `next-batch.json`에 고정한 후보 50자를
같은 방식으로 대조했다. 첫 대조에서 37자가 일치했고, 13자는 보정 후 전체 획을 다시 확인했다.
허가된 중간선 609획을 유지하고 10획을 국소 보정했으며, 9자의 획 순서를 바꿨다.
MM 원본 38자, Ja 원본 12자(逕·絅·堺·誥·攷·梱·洸·紘·餃·逑·柾·毬)에서 출발했다.

부수 유사성으로 승인하지 않았다. 각 글자의 사전 전체 필순을 순서대로 보고,
색으로 나눈 25% 진행 구간에서 방향·펜 떼기·획 경계·완성 자형을 대조했다.
보정 13자는 변경 획뿐 아니라 전체 획을 재대조했다.

[direction-probe.mjs](direction-probe.mjs)가 60°를 넘는 획 30개(13자)를 표시했고 모두 보정으로 이어졌다.
耿·餃·麴·堀처럼 두 획 교환으로 풀리지 않는 경우는 후보 중간선 좌표로 각 획의 위치를 확인해
어느 획이 어디로 옮겨지는지 정했다. 蕎의 원문은 가로 이동 `translate(12, -830)`을 쓰므로
검토 서버·원문 확인·방향 프로브가 가로 이동을 받아들이도록 고쳤다. 이동은 방향 벡터를 바꾸지 않는다.

## 근거와 재현

- [observations.json](observations.json): 50자 승인, 13자의 첫 판정·보정·재대조 기록, 8방향 코드

- [verify.mjs](verify.mjs): 재현 결과·공개 데이터·적용 수·다음 후보 검증
- [checks.json](checks.json), [progress.json](progress.json): 이번 검증과 전체 진행 현황
- [next-batch.json](next-batch.json): 다음 竅~犢 50자·629획 후보
- [acquire.mjs](acquire.mjs), [source-checks.mjs](source-checks.mjs), [serve.py](serve.py): 원본 고정·원문 확인·검토 시트

재생 중간선은 Arphic Public License의 고정 MM·Ja 원본에서 출발했다.
사전의 경로·마스크·영상·스크린샷을 파일에 저장하거나 배포하지 않았다.
