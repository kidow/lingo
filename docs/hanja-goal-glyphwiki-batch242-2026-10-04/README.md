# 睍 12획 검증·적용

브라우저 패널에서 국내 사전의 전체 12획 방향·누적·완성 자형과 원본의 108개 진행 프레임을 대조했다. 정확한 whole u774d-k 및 선언된 5개 레코드를 사용한다. 원본 엔진 8개 파일과 기본 설정을 고정하고 두 꺾임과 마지막 연속 곡선을 보존했다. 사전 교차검토이며 시험 주관기관의 공식 승인을 의미하지 않는다.

전체 321개 파일의 1,481개 테스트와 격리 프로덕션 빌드가 통과했다. 모바일 브라우저 패널에서 학습·쓰기 자동재생 및 재재생, 이미지 중첩 없음, 캔버스 입력·취소, 시트 고정을 확인했다. 데이터 17개 파일이 빌드 스냅샷과 동일함을 재확인했다. 비공개 그래픽은 RAM에서만 대조했다.

실제 적용 5,106/5,978자(85.4%), 미적용 872자. 특급II는 949/1,150자(82.5%), 201자가 남았다. 다음 후보 絪 12획의 정확한 전체 원본 5개 레코드를 확보했다. 국내·진행 프레임 검토는 아직 하지 않았다.
