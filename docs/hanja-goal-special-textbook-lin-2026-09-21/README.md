- 대상: 특급 **鄰**, 배정표·교과서 재생·공개 경로 모두 15획. 3급 **隣**과 다른 글자다.
- 결론: 15획 모두 순서·방향·꺾임·갈고리·누적 자형을 대조했다. 원순서를 유지하고 100/109 균일 정규화한 경로를 적용했다. 실제 재생 굵기 5의 완성 자형도 확인했다.
- 출처 범위: 국내 **출판사 교과서 대조**이며 시험기관 공식 인증으로 표시하지 않는다.

## 구현과 검증

- 교과서용 KanjiVG 번들과 어댑터를 추가했다. 기존 MM/Ja 교과서 검토 등록부의 의미를 바꾸지 않았다.
- 글자·영상·목록 행·경로 출처·순서·검토 해시·라이선스의 변경을 거부하고, 전체 번들 재현 검사로 경로 해시까지 검증한다.
- 한자 테스트 **801개 통과**, 타입 검사 통과.
- 빌드·UI 확인 뒤 파일 말미 빈 줄과 그에 따른 검토 문서 해시만 정리했다. 경로·재생 코드는 동일하며 최종 교과서 검사 10개를 다시 통과했다.
- 분리 체크아웃 프로덕션 빌드 통과. 임시 HanjaCard 페이지와 제품의 관련 8개 파일을 바이트 단위로 대조했다.
- Desktop Chrome에서 학습 자동재생 0→15, 학습 다시 재생 1→15, 쓰기 진입 자동재생 1→15, 쓰기 다시 재생 1→15를 확인했다. 마지막 획 번호뿐 아니라 재생 종료 버튼 상태까지 확인했다.
- 쓰기 SVG 1개, 실제 굵기 5, 정적 오버레이 중복 없음. 캔버스 2획 입력, touch-action:none.
- 최초 입력은 재생 버튼 조작과 네이티브 도구 전환 전후의 좌표가 달라 위치 보존 근거로 쓰지 않았다. 두 번째 입력은 드래그 직전·직후를 직접 비교해 canvas/dialog 좌표와 dialog.scrollTop 155.5가 모두 동일함을 확인했다.
- 앱 콘솔 오류 0. 번역 확장 프로그램 오류 2건은 별도로 구분했다. 실제 모바일 기기는 검증하지 않았다.

재현: `node docs/hanja-goal-special-textbook-lin-2026-09-21/build.mjs`와 `node --test lib/hanja-stroke-textbook-kanjivg.test.ts`.
