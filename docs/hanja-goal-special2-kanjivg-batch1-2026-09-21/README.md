# 특급II KanjiVG 배치 1 — 鱇·菰·廐·饋

## 근거와 판정

2026-09-21, 국내 공개 사전 e-hanja의 전체 필순과 고정 리비전 KanjiVG 후보를 대조했다. **국내 사전 교차검토이며 시험 주관기관의 공식 인증이 아니다.**

- **鱇 22획**: 기본판 `09c47` 선택. 국내 순서에 맞춰 원본 5·6획만 교환했다. Kaisho도 22획 전체를 검토했으며, 기본판의 수직에 가까운 12획 점이 국내 자료와 더 가깝다.
- **廐 14획**: 기본판 `05ed0`의 순서를 유지한다. 12획이 처음부터 한 획의 ㄴ자 경로라 이전 후보에서 필요했던 병합이 필요 없다.
- **饋 21획**: 기본판 `0994b`의 원본 4–7획을 5,6,7,4 순으로 배치했다. 食의 아래 가로획 두 개도 원본에서 독립되어 있어 이전 후보의 분할 문제를 피할 수 있다.
- **菰 12획 보류**: 국내 艹는 4획, 공개 후보는 3획이다. 瓜의 국내 10획 ㄴ자 경로는 공개 후보에서 9·10획으로 나뉜다. 총 획수 일치만으로 승인할 수 없고, 순열로 해결되지 않는다. 동일한 부수별 획 구성을 가진 재사용 가능 전체 경로가 필요하다.

네 글자의 대표 경로 69획, 鱇 대체판 22획을 직접 보았다. 廐·饋 Kaisho는 메타데이터만 확보했으며 검토 완료로 세지 않는다. 적용 세 글자는 정규화 후 **57개 누적 상태와 각각의 완성형**을 다시 확인했다. 단순 방문 기록은 시각 검토를 대신하지 않는다.

## 재현과 권리

`candidates.json`에는 재사용 가능한 KanjiVG 경로와 각 출처 URL·리비전·바이트·SHA-256을 담았다. 국내 사전 경로는 RAM에서만 읽고 SVG·HTML·스크린샷을 파일로 저장하지 않았다. `findings.json`에 획별 판단과 보류 해제 조건을, `normalized.json`에 선택된 경로와 순열을 기록했다.

`node docs/hanja-goal-special2-kanjivg-batch1-2026-09-21/build.mjs`는 공개 번들을 재현한다. 100/109 균일 배율과 검토된 순열만 적용한다. 곡선 평탄화, 방향 반전, 새 점, 획 분할·병합은 없다. KanjiVG © Ulrich Apel and contributors, CC-BY-SA-3.0 출처와 변경 내역은 런타임 번들에도 포함한다.

## 검증

- 한자 테스트 **778/778 통과**, 타입 검사 통과.
- 첫 런타임 확인에서 템플릿의 이전 JSON import가 남아 count mismatch가 발생했다. 새 번들 import로 수정한 뒤 위 검사와 실제 런타임 집계를 통과했다.
- 독립 체크아웃 `/tmp/lingo-hanja-goal-special2-kvg1-check`의 프로덕션 빌드 통과. 실제 제품 변경 세 파일을 바이트 대조했으며 임시 HanjaCard 검증 페이지만 추가했다. 공유 개발 서버는 건드리지 않았다.
- 세 글자 모두 학습 자동재생 시작·전체 완료, 쓰기 진입 자동재생 시작·전체 완료, 학습 다시 재생 초기화, 쓰기 다시 재생 시작·전체 완료를 확인했다. 鱇 22획, 廐 14획, 饋 21획이 표시됐다. 제품 콘솔 오류는 0건이었다.
- 쓰기 캔버스에서 정적 한자와 애니메이션의 중첩이 없었다. 饋의 캔버스 아래 방향 드래그는 0→1획 입력으로 처리됐고 시트 위치는 x=117, y=129.3046875, width=480, height=732.6953125로 유지됐다. `touch-action: none`을 확인했다. 실제 모바일 기기 검증은 아니며 데스크톱 브라우저 입력이다. UI와 기존 1.5배 재생 속도 코드는 수정하지 않았다.
