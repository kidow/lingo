# 澯 16획 보류

브라우저 패널에서 전체 원본5종과 국내3획 물수변을 대조했다. 국내3획은 이어 올리는 한 획인데 원본raw2곡선과 raw3올림 경로가 분리되어 있다. 모든 원본19raw에서 정확히 이어지는 경계는 [7,8]·[10,11] 두 곳뿐으로 최소17획이며 국내16획과 다르다. VS2는 오른쪽 又의 내려긋기 자형도 다르다. 경로 연결·좌표 이동·획수 보정 없이 보류하며 진행·확대·재생은 미검토다.

브라우저 패널에서 전체 원본 5종과 국내 방향 3획을 대조했다. 완료하지 않은 진행 프레임·확대 경계·재생은 승인하지 않았다. 고정 원본·엔진·국내 메타데이터 검증은 통과했으며, 기존 런타임에 이 후보가 포함되지 않음을 확인했다.

적용 5459/5,978자, 미적용 519자. 빌드·전체 테스트·모바일 검증을 실행하지 않았다. 다음 후보 纘 25획.
