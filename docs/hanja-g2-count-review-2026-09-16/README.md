# 2급 사전·목록 획수 차이 9자 검토

2026-09-16 · 이전 작업: [2급 일반 후보 완료](../hanja-g2-batch10-2026-09-16/README.md)

9자의 획수 차이를 대조했다. **熙의 표시 획수만 13→14획으로 보정**하고 나머지 8자는 목록 획수를 유지한다. 이번 작업으로 승인하거나 추가한 애니메이션은 없다.

사전 9자의 **125개 단계**를 순서대로 화면에서 살피고 최종 자형·앱 정적 SVG를 비교했다. 이것은 획수와 자형 차이 조사다. 라이선스 후보 경로와 매 획을 대조하는 승인 검토는 수행하지 않았다. 9자 목록의 총획은 130→131획이 된다.

## 熙 보정 근거와 원문 보존

- [한국어문회 상담 9699, 2016-10-08](https://www.hanja.re.kr/klea/counsel/hanjaDetail.do?id=9699)는 煕 13획과 熙 14획을 명시적으로 구별한다.
- [2007 답변 4805](https://www.hanja.re.kr/klea/counsel/hanjaDetail.do?id=4805)도 닫힌 口 형태에서 획이 늘어나는 차이를 설명한다. 반면 [2012 답변 8732](https://www.hanja.re.kr/klea/counsel/hanjaDetail.do?id=8732)는 모두 13획이라고 설명했다. 이 충돌을 기록하고, 후속 9699의 구체적인 자형 구분을 적용한다.
- [2024 답변 10933](https://www.hanja.re.kr/klea/counsel/hanjaDetail.do?id=10933)은 煕·熙 두 자형의 쓰기를 인정한다. 이 답변을 두 자형의 획수가 같다는 뜻으로 해석하지 않는다.
- [현재 배정 자료](https://www.hanja.re.kr/kccpt/exam/levelConfirm.do)를 다시 내려받아 확인했다. 전체 XLS는 기존 해시와 동일하며 이번에는 행을 재파싱하지 않았다. 2급 HWP는 2,355개 배정자를 추출했고 熙가 있으며 煕는 없다.
- XLS의 煕 13획 자체는 오류가 아니다. `sourceGlyph: 煕`, `sourceStrokes: 13`, `sourceRow: 5954`와 검색 별칭을 보존한다. 표시 글자·급수·훈음·학습 기록 키는 유지한다.

보정은 [명시적 보정 목록](../../content/hanja/stroke-count-corrections.json)과 기존 가져오기 경로에 연결된다. 원문 행·자형·획수가 바뀌면 조용히 보정하지 않고 실패하는 회귀 테스트를 추가했다.

## 나머지 8자의 해석 한계

- 瓊의 오래된 답변 일부는 19획을 오류로 설명했으나, [2010 답변](https://www.hanja.re.kr/klea/counsel/hanjaDetail.do?id=7946)과 [2021 답변](https://www.hanja.re.kr/klea/counsel/hanjaDetail.do?id=10717)은 자형별 18·19획 차이를 설명한다. 정적 폰트의 모양만 보고 목록을 바꾸지 않는다.
- [초두 상담](https://www.hanja.re.kr/klea/counsel/hanjaDetail.do?id=3656)은 **필순 문제가 아닌 경우**의 3·4획 쓰기 허용이다. 이 허용을 시험 필순의 인증으로 확대하지 않는다.
- [식변 획수 상담](https://www.hanja.re.kr/klea/counsel/hanjaDetail.do?id=10635), [晟 11획 상담](https://www.hanja.re.kr/klea/counsel/hanjaDetail.do?id=10026), [示·礻 상담](https://www.hanja.re.kr/klea/counsel/hanjaDetail.do?id=9906)으로 차이를 분류했지만, 전체 경로를 승인한 것은 아니다.
- [庾 관련 검색 결과의 답변 8581](https://www.hanja.re.kr/klea/counsel/hanjaDetail.do?id=8581)은 臼 6획만 설명한다. 庾 전체 11획 또는 12획을 직접 공인한 답변으로 사용하지 않는다.

e-hanja는 민간 국내 사전이며 시험 주관 기관이 아니다. 원본 SVG·이미지·화면 캡처·HTML은 저장하지 않았다. 출처 URL, 응답 해시와 메타데이터, 직접 작성한 관찰만 남겼다. 부수 재사용이나 획수 맞추기용 분할·병합만으로 승인하지 않는다.

## 검증·재현

한자 테스트 48개 파일 **289개**, Python 가져오기 테스트 **7개**, 프로덕션 빌드와 TypeScript 검사를 통과했다.

- `node docs/hanja-g2-count-review-2026-09-16/verify.mjs`: 현재 목록·원문 보존·승인 수·증거 해시·진행 현황·후속 후보 재현
- `python3 docs/hanja-g2-count-review-2026-09-16/serve.py`: 메모리에서만 사전 자료를 읽어 51746 포트에 단계별 획수 비교 화면 제공
- [official-evidence.json](official-evidence.json): 공식 답변 14건, 상충 답변, 배정 자료 해시, 9자 검색 범위

- [source-checks.json](source-checks.json): 새로 확인한 사전 메타데이터. `catalogStrokes`는 **검토 전** 값
- [progress.json](progress.json), [checks.json](checks.json): 현재 수치와 검증 결과

이전 회차의 자료는 해당 날짜의 스냅샷으로 유지한다. 최신 대기열은 이번 `progress.json`을 기준으로 한다.
