# 飼·祐·禎 사전 자형 적용

2026-09-21 · 검증한 **3자·35획**을 런타임에 추가했다.

| 글자 | 배정 획수(보존) | 재생 획수 | 표시 자형 |
| --- | ---: | ---: | --- |
| 飼 | 14 | 13 | 飠 |
| 祐 | 10 | 9 | 礻 |
| 禎 | 14 | 13 | 礻 |

`hanja-stroke-variants.ts`는 위 세 글자와 정확한 배정 획수 조합에만 예외를 허용한다.
다른 글자는 기존 획수 일치 검사를 계속 적용한다. 飼에 13획을 넘기는 등 카탈로그가
변경된 입력도 거절한다. 庾와 특급II 보류 35자는 이번 적용에 포함하지 않는다.

공개 JSON은 앞서 검토한 경로를 그대로 담는다. 祐의 원본 5·6획 순서만 교환하며,
필순·방향 검토 해시, 사전 SVG 해시, 원본 말뭉치 해시와 획 대응표를 함께 보존한다.
출처는 `ehanja-crosschecked`다. 공개 데이터 옆에 원본·수정 내역·라이선스 안내도 추가했다.

## 화면

- 소개·찾기 상세·쓰기 연습은 재생 데이터와 **동일한 경로**로 정적 자형을 그린다.
  정답 숨김→보기, 자동 재생 전후에도 Noto의 배정 자형으로 바뀌지 않는다.
- 세 글자에는 `礻 자형 · 재생 9획 (배정 10획)`처럼 자형과 두 획수를 표시한다.
- 퀴즈와 찾기 목록은 기존 배정 자형을 유지한다. 퀴즈 정답 뒤의 획수도 배정 값이다.
- 일반 한자의 기존 정적 SVG·재생·횟수 표시는 유지한다. 필기 횟수는 사용자가 실제 그린 횟수다.

`HanjaStudyGlyph`는 새로운 상태나 이벤트 리스너 없이 검토한 자형을 선택한다.
기존 재생기의 자동 재생·재생 속도·일시정지·동작 줄이기 분기는 변경하지 않았다.
React 검토에서 훅 규칙, 정적/장식 SVG 접근성, 안정된 경로 순서와 중복 자형 표시를 확인했다.

## 검증

- `node --test lib/hanja*.test.ts`: 전체 한자 테스트 통과.
- `pnpm exec tsc --noEmit --incremental false`: 통과.
- `pnpm build`: 프로덕션 빌드 통과. 임시 검증 경로는 빌드 전에 제거했다.
- `node docs/hanja-g2-variants-2026-09-21/verify.mjs`: 원문·후보 고정 해시 및 실제 런타임 경로 재현 통과.
- 실제 제품 컴포넌트를 사용한 임시 페이지에서 390×844 화면을 확인했다.
  세 자의 소개/쓰기 자동 재생, 飼 다시 재생·일시정지·정답 숨김/표시,
  祐 캔버스 필기 중 바텀시트 유지, 庾 재생 차단, 山 기존 3획 재생을 확인했다.
  飼 정답 다시 보기에서는 기존 정적 SVG의 `use`가 0개이고 검증 경로가 13개인 것도 확인했다.

신규 테스트는 세 자의 원본 경로·순서·검토 해시 일치, 0~29 사이 잘못된 획수 입력 차단,
전체 카탈로그에서 획수 예외가 정확히 이 세 자뿐인 것을 검사한다.
검증 결과는 [integration-checks.json](integration-checks.json)에 있다.

현재 **4,904/5,978자(82.0%)**, 남은 **1,074자**.
2급은 **537/538자(99.8%)**이며 庾 1자가 남는다.
다음은 특급II 획수 차이 35자를 개별 검토하여 같은 방식으로 적용 가능한 자형을 선별하는 작업이다.
