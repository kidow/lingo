# 薪 — 새 HK 원본 의존성

실제 제공자 root는 기존 보존 원문의 `hkcs_m85aa`@3이다. `u85aa-hkcs`는 로컬 자료 폴더명이며 제공자 별칭이 아니다. 기존 root·新·亲왼쪽 3개 원문은 재취득하지 않았다.

누락된 `hkcs_m8279-p03-s05`와 `hkcs_m65a4-p02-s00`만 공개 API로 읽고 각 관측 버전@2를 명시 요청해 동일 원문을 확인했다. 두 자식은 추가 참조가 없는 4행 원문이다. 원래 bare 자식 이름은 참조 key에 그대로 보존한다.

총5개 record의 혼합 관측일 closure다. 하나의 과거 시점 복원이나 old archive 대체로 주장하지 않는다. 배정17획·기존 국내17clip은 원자료 수치로 유지하며 leaf17행이 논리17획과 같다고 승인하지 않는다. 국내12의 분리 시작과15의 휘어짐이라는 기존 HOLD는 아직 해결되지 않았다.

새 HK full5/whole은 별도 1회 캡처 뒤 ROOT 원본 화면 대조가 필요하다. 현재 이 폴더는 source 준비이며 적용·필순·접촉·native·runtime 승인이 아니다.
