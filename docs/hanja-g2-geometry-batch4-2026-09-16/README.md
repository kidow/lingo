## 확보·대조

- 사전 상세 페이지의 실제 애니메이션 iframe을 다시 확인했다. 표시 획수, 애니메이션 수, 외곽선 수는 각각 15·9·9로 일치했다.
- 원본 파일의 XML 나열 순서와 실제 재생 순서는 다르다. 지연시간으로 정렬한 재생 순서를 사용했다. 蔑의 XML 인덱스는 12–15→1–11, 茅·范은 6–9→1–5다.
- 고정 커밋의 Ko·Ja·MM 데이터를 다시 받아 해시를 검사하고 NFKC 호환 글자까지 조사했다. Ko 후보는 없고 Ja·MM은 모두 14·8·8획이다. 이번에는 MM 후보를 사용했다.
- 33개 누적 단계와 각 획의 25·50·75·100% 진행 구간을 브라우저에서 대조했다. 보정된 26개 경로 및 최종 자형 3개를 다시 확인했다.
- 사전 SVG·외곽선·스크린샷은 디스크에 저장하지 않았다. 라이선스 원후보, 자체 보정 경로, 원본 URL·해시·검토 결과만 기록했다.

## 글자별 보정

**蔑:** 초두 통가로를 1·3획으로 분리했다. 원후보 10→9획을 사전의 10→11획에 대응시켜, 아래 바깥 삐침을 지붕 가로보다 먼저 그린다. 테두리·내부 세로의 접점, 아래 곡선과 삐침, 마지막 점의 위치를 보정했다. 마지막 점은 9획과 떨어지고 11획에 닿는다. 원본 외곽선의 최소 간격은 각각 7.429·0 좌표 단위였다. 5단위 재생 선폭 검사에서 초두 왼세로의 미세 겹침을 발견해 끝점을 추가 단축하고 재확인했다.

**茅:** 초두를 4획으로 나눴다. 5획 끝→6획 점→7획 가로의 접점을 맞추고, 8획을 곧은 세로와 왼쪽 갈고리로 보정했다. 마지막 9획은 7획에 닿고 8획과 떨어진다. 원본 외곽선의 5/6·6/7·7/9 간격은 0, 8/9 간격은 34.974 좌표 단위였다.

**范:** 초두를 4획으로 나눴다. 삼수변 올림획은 위 점 옆 높이까지 올라가면서 점·오른쪽 부분과 분리된다. 오른쪽 8획은 가로→세로→왼쪽 갈고리, 9획은 지붕 왼쪽 모서리에서 내려가 밑가로로 돌아 위로 갈고리다. 원후보의 긴 비스듬한 안쪽 갈고리와 모서리 위의 진입선을 보정했다.

보정 결과는 학습용 중심선이다. 정적 Noto 글꼴이나 사전 서체의 외곽선을 그대로 재현한 데이터는 아니다.
