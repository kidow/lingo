## 확인 방법과 한계

[e-hanja](http://www.e-hanja.kr/)의 일반 검색에서 정확한 글자를 선택했다. 검색 결과에는 간체자·이체자·동음자가 함께 있으므로, 검색어만 맞는 결과를 채택하지 않았다. 상세 화면의 획수와 그 화면에 실제 연결된 SVG 주소를 함께 기록했다.

원본 SVG를 직접 눌러 재생하고 **움직이는 화면66개**를 관찰했다. 森·楓은25획 전체, 나머지9자는 쟁점 및 인접 맥락41획을 관찰했다. 모든11자의 전체143획을 각각 시각 대조한 것으로 확대해서 해석하지 않는다. SVG의 획 번호·지연·지속 시간은11자143획 모두 확인했다. DOM에 나열된 순서는 필순과 달라 획 번호를 기준으로 정렬했다.

각 화면 직전에 읽은 dash offset과 완료 획 목록을 [observations.json](observations.json)에 남겼다. 이는 스크린샷의 정확한 촬영 시각을 뜻하지 않는다. 번호·시간 메타데이터만으로 방향을 승인하지 않고, 실제 빨간 획의 진행과 앞선 완료 획을 함께 관찰했다. 수집 초기에 `px` 단위를 숫자로 처리하지 못한 회차는0개 수집으로 끝났으며, 수정 후 확보한66개만 집계했다.

이 자료는 **국내 사전 제공자의 원자료**다. 한국어문회·교육부 인증이나 국내 모든 교재와의 일치를 뜻하지 않는다. 兔와 弊에서 확인한 충돌도 그대로 남겼다. 遷의 회원 전용 페이지나 추측한 SVG 주소로 접근하지 않았다.

사전의 외곽선·중앙선·CSS·스크립트·스크린샷은 저장·재배포하지 않았다. URL·해시·시간 메타데이터와 직접 작성한 관찰 기록만 보관한다. 향후 구현은 사용 가능한 라이선스의 기존 경로 또는 근거를 대조해 작성한 경로로 진행해야 한다.
