# 吪 7획 적용

국내 사전의 전체7획·방향·누적·완성 자형과63개 중간 장면을 공개 백업의 완성 글자 `u542a`와 대조했다. 한국어문회 공식 필순 승인으로 표시하지 않는다.

- 입구의 가로→세로를 국내2획으로 묶었다. 원본 접속점이 일치하며 모든 경로와 외곽점을 보존했다.
- 세 이차곡선과 마지막 위쪽 갈고리는 원본 그대로 재생한다. 새 연결선·자르기·좌표 보정·부수 교체가 없다.
- 백업SHA256·6개 정확한 의존 레코드·엔진8파일 재현 통과. 한자194파일928테스트, 프로덕션 빌드·타입검사·정적7페이지 통과.
- 모바일430×932 학습·쓰기 자동재생, 다시 재생1/7→7/7, 입력0→1→0, 캔버스 드래그 중 시트 위치·스크롤 불변 확인. 정적이미지0·애니메이션1, 콘솔 경고·오류0. 속도 코드는 변경하지 않았다.
- 실제 적용4,994/5,978자(83.5%), 미적용984자. 남은 수:1급65,2급1,특급II288,특급630. 나머지 급수는 모두 적용됐다.

다음은 杇(특급7획). 이전 실시간API 타임아웃을 반복하지 않고 고정 공개 백업에서 완성 원본4개 의존 레코드와 엔진 재현을 확보했다. 전체 시각 대조·런타임 승인은 아직 하지 않았다.

비공개 사전 그래픽은 RAM에서만 사용했다. 비교/UI 탭·서버와 격리 워크트리는 정리했고 공개 원본 RAM조회 서버51967만 다음 후보를 위해 유지했다.
