# 3급 신규 배정 한자 출처·후보 정리

2026-09-14. **317자·3,483획**을 조사했다. 현재 3급 신규 배정분의 애니메이션은 **0/317자**이며, 이번 작업에서 추가 적용한 글자는 없다. 전체 적용 수는 **1,501/5,978자**다. 대상은 누적 급수 전체가 아니라 `content/hanja/characters/g3.json`의 신규 배정분이다.

## 결과

| 다음 단계 | 글자 수 | 판정 기준 |
|---|---:|---|
| 전체 필순·경로 검토 | 286 | 교재 표기 정확 일치, 영상 응답 확인, 획수가 맞는 벡터 후보 존재 |
| 획수 차이 검토 | 25 | 교재 표기 일치, 조사한 벡터 후보와 카탈로그 획수 불일치 |
| 교재 자형 예외 검토 | 3 | 濫·隷·隣; 정규화 또는 다른 자형과의 대조 필요 |

| 합계 | **317** | 서로 겹치지 않는 분류 |

286자는 **검토에 들어갈 후보**다. 획수 일치는 필순·방향·획 경계·자형의 정확성을 보장하지 않는다. 부수의 공통성만으로 순서나 경로를 추정하지 않았다.

## 교재 출처

[비상교육 고등학교 한문(이동재)](https://text.vivasam.com/detail/186)의 [공개 필순 뷰어](https://viewer.vivasam.com/qrviewer/viewer.html?qrcode=106502_171p_25_ST&teacher=false) 연결 자료를 확인했다. 출판사 자료이며, 한국어문회가 해당 애니메이션을 인증했다는 뜻은 아니다.

- XLSX 1,800행을 다시 받아 기존 SHA-256 및 128,318바이트와 일치하는지 검증했다.
- 정확한 글자 일치 **314자**, NFC 변환으로만 연결되는 후보 **1자**, 정확/NFC 대응 없음 **2자**다.
- 연결된 **315개 영상** 모두 HEAD 200, 양수 Content-Length, Range 206 및 처음 32바이트의 MP4 `ftyp` 표식을 확인했다. 응답 MIME은 `application/octet-stream`이었다.
- 이 검사는 링크와 파일 형식 확인이다. 영상 전체의 무결성·재생·내용·필순·방향은 확인하지 않았으며 영상 파일도 저장하지 않았다.

| 카탈로그 | 교재 원문 | 행 | 처리 |
|---|---|---|---|
| 濫 | 濫 | 0392 | NFC 후보로만 기록. 원문 표기 유지 |
| 隷 | 隸 | 0435 | 다른 글자이므로 자동 대체 금지 |
| 隣 | 鄰 | 0480 | 다른 글자이므로 자동 대체 금지 |

대체 출처로 e-hanja 디지털 한자사전의 정확한 표제자 **隷 16획**, **隣 15획**과 연결된 [隷 필순 SVG](http://img.e-hanja.kr/hanjaSvg/aniSVG/9600/96B7.svg), [隣 필순 SVG](http://img.e-hanja.kr/hanjaSvg/aniSVG/9600/96A3.svg)를 확보했다. 본문의 자형·표시 획수와 SVG 제목·획 ID 개수까지만 확인했다. 전체 획 대조는 아직이며, 민간 사전 자료를 시험 주관 기관의 인증으로 취급하지 않는다. 본문 URL과 자산 해시는 [supplemental-sources.json](supplemental-sources.json)에 기록했다. SVG의 경로·스크립트·이미지는 복제하지 않았다.

## 벡터 후보

고정 리비전의 [Make Me a Hanzi](https://github.com/skishore/makemeahanzi/tree/bddc96d41bef78427ed0e034e9f7e31d71fd1b92), [AnimCJK](https://github.com/parsimonhi/animCJK/tree/ec5e17cca76c87587790bcbce5ea0b4d4fb753d6) 자료를 새로 받아 기존 해시와 대조했다. 각 자료의 정확한 글자만 검색했다. 획 경로와 중심선 개수, 유효 좌표 구조를 검사했지만 시각적인 경로 검토는 하지 않았다.

| 자료 | 정확한 글자 존재 | 카탈로그와 획수 일치 |
|---|---:|---:|
| Make Me a Hanzi | 304 | 263 |
| AnimCJK Japanese | 309 | 265 |
| AnimCJK Korean | 0 | 0 |

표의 수치는 자료별로 중복된다. 일본·중국 자료의 획수를 한국 필순 근거로 사용하지 않는다. 세 자료에 없다는 결과는 다른 출처에도 데이터가 없다는 뜻이 아니다. 이번 산출물에는 후보의 획수만 저장했다.

획수 차이 검토 대상 25자: **慨·遣·苟·旣·飢·茫·暮·募·苗·迷·返·祥·暑·逝·蔬·遂·餓·爵·遵·逮·逐·誕·遍·蔽·飽**. 각각의 획수 차이는 [inventory.json](inventory.json)의 `fields`와 `rows`에서 확인할 수 있다.
