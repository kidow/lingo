**珈가 이번 회차의 요령이다.** 지금까지 순서가 어긋나면 획을 교환했는데, 珈는 같은 획수를 가진 다른 말뭉치(MM)가
사전 순서 그대로였다. [1급 24차](../hanja-g1-batch24-2026-09-20/README.md)에서 정한 «사전과의 획별 거리로 후보를 고른다»를
보류가 아니라 **승인 쪽으로** 쓴 첫 사례다. 바꾼 이유와 원래 후보는 [selection.json](selection.json)에 남겼다.

국소 보정은 7획이고, 나머지 **611획은 허가된 중간선 그대로**다. 보정 7획은 모두 앞선 회차의 선례를 따랐다 —
益의 丷는 [1급 12차](../hanja-g1-batch12-2026-09-19/README.md)의 縊, 火의 왼쪽 점은 같은 회차의 鶯,
隹의 오른쪽 위 짧은 획은 같은 회차의 壅, 亠의 첫 점은 [1급 19차](../hanja-g1-batch19-2026-09-20/README.md)의 稟과 같다.

부수 유사성으로 승인하지 않았다. 쉰 글자의 사전 전체 필순을 순서대로 보고,
색으로 나눈 25% 진행 구간에서 방향·펜 떼기·획 경계·완성 자형을 대조했다.
[direction-probe.mjs](direction-probe.mjs)가 표시한 15자 35획은 교환·보정·후보 교체로 모두 해소했고,
각도 검사가 놓친 繳의 糸 순서는 끝점 배정 검사가 잡았다.
공개한 순서·경로로 다시 재면 60°를 넘는 획이 없다.
45~60° 구간은 다섯 획(袪 1, 褰 1·11, 鶊 1, 黥 13)이고, 이전 회차와 같은 기준으로 허가된 기하 그대로 뒀다.
