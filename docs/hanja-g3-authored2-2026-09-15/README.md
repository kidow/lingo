## 경로의 출처

고정 MM·Ja·Ko 후보 목록에는 두 글자가 없어 **20획 모두 직접 작성**했다. 이 사실은 고정 후보의 범위에 한정하며 인터넷 전체에 경로가 없다는 뜻이 아니다.

- [proposals.json](proposals.json): 영상의 전체 자형에 맞춰 작성한 중심점.
- [authored.json](authored.json): 직접 작성한 20개 경로와 경로·영상 해시.
- [review.json](review.json): 전체 필순 검토 기록.
- [candidate-paths.json](candidate-paths.json): 실제 적용 데이터와 직접 작성 출처 메타데이터.

기존 직접 작성 경로 처리기를 재사용했다. `geometrySource`는 작성 기록의 해시, `geometryAuthored`는 기록 ID다. `sourceStrokeIndices`는 모두 `null`이며 외부 후보의 획 번호나 차용 출처를 만들어 넣지 않았다.

이는 **출판사 자료와의 Codex 시각 대조**이며 시험 주관 기관이나 전문가의 애니메이션 인증이 아니다. 경로는 교육용 움직임을 나타내는 중심선으로, 교재 붓글씨의 외곽선을 복제하지 않는다. 원본 영상·캡처·XLSX 파일은 저장하지 않았으며 [serve.py](serve.py)는 원본과 디코딩 프레임을 RAM에서만 처리한다.
