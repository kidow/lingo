## 확보한 자료

[동양북스 공식 도서 페이지](https://dongyangbooks.com/book/book_view.asp?goods_code=979&menu_1=hanja&menu_2=han_hanja)가 공개한 『암기박사식 한자 능시 3급』 쓰기노트다. 도서는 박원길·박두수·박정서, 동양문고, 2008-07-11, ISBN 9788983005991이다. 아래 페이지는 **480쪽짜리 도서가 아닌 165쪽짜리 PDF 부록의 페이지**이며, 해당 인쇄 쪽수와 PDF 쪽수가 일치한다.

[공식 부록 다운로드](https://dongyangbooks.com/book/download.asp?no=352&bsno=6414)의 ZIP은 77,040,295바이트, 내부 PDF는 77,369,148바이트다. 원본은 RAM에서 읽고 후보 페이지를 확대 확인했다. 저장소에는 원본이나 페이지 이미지를 재배포하지 않고 출처·페이지·해시·판정을 기록했다.
