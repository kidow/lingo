## 출처 판단

[회사소개](https://www.moyaland.com/_new/hanja/content.php?co_id=company)의 실제 이미지에서 한자 교육제품 개발·생산 및 교재·전자책 발행 이력을 확인했다. [이용약관](https://www.moyaland.com/_new/sub.php?mNum=10&sNum=2)은 제공 콘텐츠의 범위를 디지털 한자 이미지로 특정하고 사이트 콘텐츠의 회사저작권을 주장한다. 발행 서지와 개별 한자 제공 페이지까지 연결한 판단이며, 일반 저작권 문구 하나로 자작 여부를 단정한 것은 아니다.

담당 검토에 더해 root가 소개 이미지 2개, 약관, [笛](https://www.moyaland.com/_new/hanja/item_01.php?it_id=1426582068)·[蹟](https://www.moyaland.com/_new/hanja/item_01.php?it_id=1427357210)·[稚](https://www.moyaland.com/_new/hanja/item_01.php?it_id=1407917080)의 전체 번호도해를 직접 확인했다. 별도 검토자도 이 출처 분류를 재검토했다.

이 자료를 **시험 주관기관의 공식 필순으로 표시하지 않는다.** 개별 최초 창작자·제작일·정확한 인쇄교재 쪽수는 미확인이다. 국내 출판 주체의 정적 순서와 별도로 검토한 공식 방향 자료를 결합하는 기존 기준을 적용했으며, 한국 동영상이나 인쇄책 쪽수를 새 보편 요건으로 추가하지 않았다.

## 17개 상태 대조

세 번호도해의 파일 해시는 기존 핀과 일치했다. 각 번호의 획 역할과 위치를 [상태별 매핑](source-matrix.json)에 기록했다. 앞서 검토한 MM 후보를 그대로 사용해 [17개 누적 후보](review-states.svg)를 렌더링하고 실제 열람했다. 보라색은 해당 단계에 더해지는 획, 검정은 앞선 획이다.

이 SVG는 허용된 공개 후보 경로의 검토용 표현이며 출판사 누적 원문이 아니다. 부수에서 순서를 추정하거나 원본 도해·공식 XML의 좌표를 따지 않았다. [42획 기하 검토](../hanja-g3ii-paths-42-2026-09-13/README.md)의 蹟·稚 보정안과 [63획 순서·방향 검토](../hanja-g3ii-crosscheck-63-2026-09-13/README.md)는 그대로 참조한다. 정적 번호 관찰을 이번의 새 방향 검증으로 세지 않았다.
