# JLPT 46.7%는 진도가 아니다 — 등급이 안 붙는 낱말 3,209개 감사

확인일: 2026-09-08. 대상: `pnpm coverage`의 "등급이 붙은 낱말" 줄과
`.cache/jlpt.json`.

`pnpm coverage`가 **JLPT 2,812/6,021 (46.7%)**를 찍는다. 절반이 비어 보이므로
"더 조회하면 오르나"를 물었다. 답은 **아니다**이고, 이 문서는 그 셈이다.

## 결론

| 물음 | 답 |
| --- | --- |
| 아직 조회 안 한 낱말이 있나 | **0개.** 6,021개를 다 물었다 |
| 조회했는데 등급이 없는 것 | **3,209개.** Jisho(JMdict)에 태그가 없다 |
| 더 나은 출처가 있나 | 없다. 시험이 2010년 개정 뒤로 **공식 단어표를 안 낸다** |

**46.7%는 우리 진도가 아니라 출처가 우리 콘텐츠를 얼마나 덮는지다.**
`scripts/coverage.ts`가 그 줄에 이미 적어 두었다 — "분모가 목록이 아니라 우리
콘텐츠다". TSL·HSK·TORFL처럼 목록 대비로 읽으면 안 된다.

## 조회는 다 끝나 있다

`pnpm levels`는 낱말마다 Jisho에 한 번 묻고 결과를 `.cache/jlpt.json`에
적는다. **등급이 없다는 답도 적는다** — 안 그러면 매 실행마다 3,400번을 다시
묻는다(scripts/cache.ts).

```
캐시 항목 6,027개 · 그중 "등급 없음"으로 적힌 것 3,212개
우리 ja 낱말 6,021개 · 캐시에 없는 것 0개
```

**미조회가 0이므로 `pnpm levels`를 다시 돌려도 숫자는 안 움직인다.**

## 등급이 안 붙는 3,209개의 갈래

| 갈래 | 개수 | 보기 |
| --- | ---: | --- |
| 한자 복합어 | 1,186 | `かき混ぜる` · `味付けする` · `貼り付ける` |
| 가타카나 외래어 | 824 | `インフルエンザ` · `ガーゼ` · `カプセル` |
| 여러 낱말·구 | 433 | `線を引く` · `洗濯物を干す` · `鍵をかける` |
| 그 밖 (한 낱말) | 589 | `挽く` · `一歩` · `足首` · `肝臓` |
| 가타카나 + する | 177 | `ダウンロードする` · `スキャンする` |

품사로는 명사 2,563 · 형용사 290 · 동사 223 · 상황 표현 133이다.

**가타카나가 1,001개(31%)로 가장 눈에 띈다.** spec.md §7이 예상한 그대로다 —
JMdict의 태그는 구 출제기준(2010년 이전)에 기반하고, 그 목록은 외래어를 거의
안 실었다. `インフルエンザ`(독감)는 일본어 학습자가 N5 수준에서 만나는 말인데
태그가 없다.

**구와 복합어 1,619개(50%)는 태그가 붙을 수 없는 꼴이다.** JMdict는 표제어
하나에 태그를 다는데 `洗濯物を干す`는 문장에 가깝다. 우리가 개념을 그렇게
잡았기 때문이지 낱말이 어려워서가 아니다.

**남은 589개는 그냥 목록 밖이다.** `足首`(발목)·`肝臓`(간)처럼 평범한 낱말인데
구 출제기준의 8,000낱말 안에 없었다.

## 붙은 2,812개는 어디에 있나

```
N5 509 · N4 378 · N3 834 · N2 512 · N1 579
```

N3이 가장 많다. 우리 콘텐츠가 일상 사물 중심이라 초급 낱말이 많을 것 같지만,
N5·N4의 기초 낱말은 이미 다 들어와 있고 새로 넣는 것은 대개 중급 이상이다.

## 할 수 있는 것과 없는 것

**없다 — 더 나은 출처.** 현행 JLPT는 단어별 등급표를 공개하지 않는다. 시중의
"N2 단어장"은 교재사 편집물이라 공개 레포에 못 쓴다(§7의 기준). Jisho/JMdict는
그 기준을 통과하는 유일한 자료다.

**있다 — 숫자를 다르게 읽기.** 이 줄은 진도가 아니므로 올리려 애쓸 자리가
아니다. `pnpm coverage`가 이미 TSL·HSK와 다른 표에 두고 있고, 이 문서가 그
이유를 낱말 수로 뒷받침한다.

**있다 — 카드가 빈칸을 감당하는지 확인.** 등급은 카드 좌하단에 그대로 나오고
없으면 그 줄이 빠진다(§4). 3,209개가 그 상태이므로 **빈 줄이 정상**이다.
학습자가 "왜 이 카드만 등급이 없나"를 묻는다면 답은 "시험이 목록을 안 낸다"다.

다시 세지 않게 하기 위해서다.
