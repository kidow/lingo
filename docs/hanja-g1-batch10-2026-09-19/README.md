# 1급 徙~搔 50자 검토 — 50자·642획 반영

2026-09-19 · **50자 반영, 보류 없음**

[1급 9차 腑~娑](../hanja-g1-batch9-2026-09-19/README.md)의 `next-batch.json`에 고정한 후보 50자를
같은 방식으로 대조했다. 첫 대조에서 37자가 일치했고, 13자는 보정 후 전체 획을 다시 확인했다.
허가된 중간선 621획을 유지하고 21획을 국소 보정했으며, 7자의 획 순서를 바꿨다.
MM 원본 43자, Ja 원본 7자에서 출발했다.

## 보정

| 보정 대상 | 변경 |

같은 회차의 珊처럼 冊의 긴 가로가 이미 마지막인 글자와,
澁·壻·遡·逍·疎(Ja 원본), 塑·殲·醒처럼 순서와 방향이 모두 같은 글자는 그대로 뒀다.

부수 유사성으로 승인하지 않았다. 각 글자의 사전 전체 필순을 순서대로 보고,
색으로 나눈 25% 진행 구간에서 방향·펜 떼기·획 경계·완성 자형을 대조했다.
보정 13자는 변경 획뿐 아니라 전체 획을 재대조했다.

[direction-probe.mjs](direction-probe.mjs)가 60°를 넘는 획 39개(12자)를 표시했고,
12자 모두 보정으로 이어졌다. 표시만 되고 그대로 둔 획은 없다.
搔는 표시되지 않았지만 시트에서 叉의 긴 파임과 두 점의 순서가 사전과 달라 획 끝점 좌표로 확인한 뒤 재배열했다.
세 획 모두 방향이 비슷해 프로브가 잡지 못한 자리이며, 같은 叉를 가진 瘙는 왼쪽 점 방향 차이로 표시됐다.
冊·角·嗇·肅처럼 덩어리로 얽힌 자리는 획 끝점 좌표를 숫자로 확인한 뒤 대응을 맞췄고,
簫·蕭의 肅은 열 획의 대응을 하나씩 짚어 같은 재배열을 적용했다.
45~60° 구간의 방향 차이는 10개였고, 그중 嗇·簫·蕭의 넷은 재배열로 대응이 바뀐 자리다.
나머지 여섯은 사전이 세로로 긋고 허가 원본이 기울여 쓰는 짧은 점으로,
이전 회차와 같은 기준으로 임계 아래는 허가된 중간선을 그대로 뒀다.
蕭의 원문은 가로 이동 `translate(12, -y)`를 쓴다. 이동은 방향 벡터를 바꾸지 않는다.
