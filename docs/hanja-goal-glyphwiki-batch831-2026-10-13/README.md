# 鏘 19획 검토·적용 완료

국내 사전 19획 순서·방향과 전체 원본 2종을 브라우저 패널에서 확인했다. 국내 10획의 세로→가로 원본 접속을 먼저, 11획의 아래 가로획을 다음에 재생하도록 순서를 교환했다.

10획 세로 원본의 사각형과 상단 삼각형을 전체 범위의 아래 방향 마스크로, 가로 원본을 오른 방향 마스크로 같은 획 안에서 나눴다. 원본 46개 다각형·좌표·전체 범위·획 가중치 36.21을 유지해 완료 순간의 끝부분 누락을 해소했다. 19획·21마스크,171프레임,곡선12획 확대 경계,10획 확대 경계,10·18획 마스크 전이와 실제 재생을 통과했다.

원본 아카이브·8개 엔진·국내 메타데이터 대조와 로컬 등록 검사,변경 대상 테스트3개가 통과했다. 빌드·전체 테스트·모바일 검증은 실행하지 않았다.
