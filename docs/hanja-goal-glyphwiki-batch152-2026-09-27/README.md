# 芿 8획 적용 — batch152

특급II 芿(새풀싹 잉)의 전체 원본 u82bf-k@8 및 선언된 의존 4개를 국내 사전 필순과 교차검토했다. 시험기관 공식 승인을 뜻하지 않는다.

- 8획 방향·누적 자형과 72개 진행 프레임 확인. 국내 순서에 맞춰 긴 삐침을 7획, 복합 꺾임을 8획으로 묶었다.
- 원본 4개 이차곡선, 기울어진 직선 및 모든 다각형 보존. 새 점·연결선·부품 교체 없음. 불완전한 백업 원본은 적용하지 않았다.
- 고정 엔진 8파일 재현, 테스트 238파일/1,060개 통과. 격리 빌드·타입 검사·정적 7페이지 생성 통과.
- 모바일 소개/쓰기 자동재생·다시 재생·8/8 완료, 오버레이 비중첩, 캔버스 0→1→0 및 시트 고정 확인.
- JEV는 보조 분류이며 런타임 승인 권한 없음. 비공개 그래픽은 RAM에서만 사용.
- 적용 5,038/5,978자(84.3%), 미적용 940자. 다음 후보 芯 8획.
