# 5급까지 획 애니메이션 대조 기록

대조일: 2026-09-07. 대상은 한국어문회 최초 읽기 배정 급수 기준 8급부터 5급까지 누적 500자다.

기존 99자에 7급부터 5급까지 대조를 통과한 386자를 추가했다. 총 485자는 소개·검색 상세·쓰기 연습에서 기존 재생기를 사용한다. 보류한 15자는 정적 SVG와 자유 쓰기만 제공한다.

> 후속 적용: 性을 보정해 5급까지 486자, 回·瓦·臼를 포함해 전체 489자로 확장했다. 아래 수량과 보류 사유는 최초 대조 시점의 기록이다. 현재 상태는 [추가 적용 기록](hanja-stroke-review-supplement.md)을 따른다.

## 근거와 방법

- 공식 자료: 한국어문회 [기타자료](https://www.hanja.re.kr/kccpt/exam/otherData.do?search_option=subject&search_text=%ED%95%84%EC%88%9C)의 「필순 정정 및 500자 필순」, `f37.hwp`, 2010-03-22 판본.
- 원문 SHA-256: `4e191bbee54edd6db595f16fc83a15b9929eba0e3e01095da1e828c70e10760c`.
- 후보: [AnimCJK 한국어 중심선](https://github.com/parsimonhi/animCJK/blob/ec5e17cca76c87587790bcbce5ea0b4d4fb753d6/graphicsKo.txt), 커밋 `ec5e17cca76c87587790bcbce5ea0b4d4fb753d6`.
- 후보 SHA-256: `7e703f34df54080281252a5c87a7106b85034b81fdbf93d37c07009a1448202e`.
- 원문 20개 GIF의 25행씩을 색인하여 중복 없는 500자와 현재 급수별 목록의 일치를 검사했다. 위치 색인 자체는 재생 승인 목록이 아니다.
- 추가 대상 400자를 `scripts/hanja-stroke-review.py`의 `/batch/0`부터 `/batch/66`까지 전부 열어 첫 획부터 끝 획까지 누적 도해와 후보 중심선을 시각적으로 대조했다. 마지막 묶음은 4자다. 각 단계의 추가 위치, 획 연결·분할, 순서와 총획을 확인했다.
- 후보를 그대로 정규화해 사용할 수 있는 386자만 등록했다. 획 추가·분할·재배열이나 이체자 치환으로 불일치를 자동 수정하지 않았다.
- `性`은 단독 원문으로 재확인했다. 공식 2획은 오른쪽 점, 3획은 세로획인데 후보는 반대다. 같은 忄가 있는 `情`도 자체 도해를 확인했으며 해당 후보는 공식 순서와 일치한다.
- 정규화는 모든 점과 획 경계를 유지하고 Y축 반전, 균일 비율 80단위 배치, 중심 정렬, 소수 한 자리 반올림만 수행한다. 완성형 Noto SVG를 획으로 나눈 데이터가 아니다.

시각 대조는 Lingo 구현 검토이며 시험기관의 앱 인증이나 원문과 픽셀 단위로 같은 자형을 보장하지 않는다. 공식 래스터 도해만으로 연속 경로의 모든 순간을 자동 인증하거나 손글씨를 채점하지 않는다.

## 데이터와 재현

- `public/hanja-strokes/g7-reviewed.json`, `g6-2-reviewed.json`, `g6-reviewed.json`, `g5-2-reviewed.json`, `g5-reviewed.json`: 추가 386자의 경로, 원문 이미지·행, 검토일, 원본 해시.
- `scripts/hanja-stroke-locations.json`: 공식 500자 위치 색인. 등록된 전체 485자의 위치를 테스트에서 이 색인과 교차 확인한다.
- `public/hanja-strokes/README.md`, `ARPHICPL.txt`, `COPYING.txt`: 수정된 전체 중심선 소스, 라이선스와 원저작자 고지. 공식 이미지는 배포하지 않는다.
- `lib/hanja-strokes.test.ts`: 누적 500자 중 승인된 485자의 정확한 집합·총획·위치·좌표와 보류 15자의 비활성화를 검사한다.
- `node scripts/hanja-stroke-audit.ts`: 원본 해시와 정규화 좌표를 다시 검사한다. 전체 5,978자 중 후보 누락 5,456자, 획수 불일치 15자, 미승인 후보 40자, 등록 후보 467자다. 자체 경로 18자는 별도로 더해져 앱 재생 485자가 된다. 이 도구는 승인 작업을 하지 않는다.

대조 서버는 원문과 후보를 메모리에 읽어 로컬에서만 보여준다. Python Pillow·xlrd 환경에서 `python3 scripts/hanja-stroke-review.py --port 5865`로 실행하고 `http://127.0.0.1:5865/batch/0`을 연다. 기존 개별 경로 `/BIN002A.gif/21/性`와 전체 위치 색인 `/index`도 유지한다.
