## 경로 확보와 작성

고정 MM·Ja·Ko 자료에는 정확한 玆 항목이 없다.
[animCJK](https://github.com/parsimonhi/animCJK/tree/ec5e17cca76c87587790bcbce5ea0b4d4fb753d6)와 [KanjiVG](https://github.com/KanjiVG/kanjivg/tree/422b5538595676da918c288a4230cb5e22a1ee7e)의 전체 파일 목록도 다시 확인했다.
각각 16,968개·11,681개 경로를 담은 Git 트리 응답은 잘리지 않았으며, 정확한 코드포인트의 경로 파일은 없었다.
이는 확인한 자료 범위의 결과이며 모든 외부 자료에 없다는 뜻은 아니다. 상세 출처·커밋은 [candidate-search.json](candidate-search.json).

10획 모두 `viewBox100`의 단순 중앙선으로 별도 작성했다.

- 왼쪽 5획 다음 오른쪽 5획을 그린다.
- 각 부분은 오른쪽 아래 점, 오른쪽으로 가는 가로, 왼쪽 아래로 내려와 짧게 오른쪽으로 꺾이는 획, 더 길게 내려와 오른쪽 위로 꺾이는 획, 오른쪽 아래 마무리 순서다.
- 오른쪽 5획도 해당 원문 구간에서 각각 확인했다. 玄을 복제한 것만으로 승인하거나 茲·滋를 대체 글자로 쓰지 않았다.
- `authoredPathIndices`는 1–10, `borrowedParts`는 빈 배열이다. 공개 `sourceStrokeIndices`는 모두 `null`이다.
- 원문에서 확인한 대로 8획의 짧은 끝을 9획과 연결하도록 보정했다. 양쪽 가로 사이와 점 아래 간격, 좌우 몸통의 분리, 아래 마무리와 가로의 접합을 폭 5로 다시 대조했다.

## 근거와 관찰

[비상교육 고등 한문 교재](https://text.vivasam.com/detail/186)의 [기초 한자 필순 뷰어](https://viewer.vivasam.com/qrviewer/viewer.html?qrcode=106502_171p_25_ST&teacher=false), 정확한 **1223행 / 1223 이 자.mp4**를 사용했다.

- 원본 길이 14.815초, 486,606바이트.
- 전체 SHA-256: `db5ed20c28011a619e3b59cbc584d340d58e9b7fdab460126c333e9635c71fac`.
- 전체 0–14.5초를 2fps로 확인하고, 2.4–7초·6.6–9.2초·9.2–14.6초를 5fps로 확대했다.
- 획별 완료 표본: 1 / 2.4 / 3.8 / 5.8 / 6.8 / 7.8 / 9.2 / 10.8 / 13 / 14.4초. 정확한 펜 이탈 시각을 뜻하지 않는다.
- 최종 10개 누적 경로의 시작·끝 표시와 확대 완성 자형을 모두 대조했다.
- 동영상·프레임은 RAM에서만 처리했다. 저장소·공개 경로에 복제한 출판사 영상·이미지는 0개다.

**필순 근거는 출판사 영상이고, 배포 경로의 작성 출처는 로컬이다.**
영상의 붓 외곽을 복제하거나 경로가 외부 corpus에서 왔다고 표시하지 않았다.
교재와의 시각 대조이며 시험 주관 기관의 개별 경로 인증이나 별도 전문가 감수가 아니다.
