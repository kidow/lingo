# 藝 19획 검토 — 2026-09-14

4급II 藝(U+85DD)의 19획 전체를 대조하고, 보류했던 오른쪽 윗부분의 간격을 확인했다.
대조 출처는 [e-hanja 藝 필순](http://img.e-hanja.kr/hanjaSvg/aniSVG/8500/85DD.svg)이다.
국내 민간 사전 대조이며 한국어문회나 교육부의 필순 인증을 뜻하지 않는다.

| 대상 | 확인·보정 |
|---|---|
| 1–4획 | 원본 사전의 가로→세로 순서에 맞춰 MM 후보를 2, 1, 4, 3으로 재배열 |
| 9획 | 사선 점을 아래로 내려간 뒤 오른쪽으로 꺾는 한 획으로 보정 |
| 11획 | 아래 土의 세로획을 위 가로획과 분리하고 아래 두 가로획과 연결 |
| 13획 | 오른쪽 위 십자와 丸의 시작 사이 간격 유지 |
| 나머지 16획 | 정규화된 원본 MM 경로의 모든 점 보존(재배열 4획 포함) |

사전의 원래 CSS·JS를 메모리에만 두고 브라우저에서 각 획의 20%·80%·100% 시점,
총 57개 프레임을 관찰했다. 원본의 획 노출은 75%에서 끝나므로 80%에서는 색상
전환 중인 완성 경로를 볼 수 있다. 연속 재생 전체를 관찰했다는 주장이 아닌,
시점별 정지 프레임 검토다. 원래 후보 19개 및 보정 후 19개 누적 상태도 확인했다.

실행 경로는 고정된 Make Me a Hanzi 원본과 직접 작성한 보정 3획으로 재구성한다.
원본 필순 SVG·윤곽·중심선·CSS·JS·스크린샷은 저장하거나 배포하지 않았다.
교과서의 이전 보류 기록과 출처 확보 당시 상태는 변경하지 않았다.
이번 승인은 藝에만 해당하며 艺·芸에 전이하지 않는다.

- `observations.json`: 실제 관찰 시점, 19획 방향, 원본 의존성 해시
- `originals.json`, `prior-candidate-paths.json`: 허가된 MM 원본과 보정 전 경로
- `corrections.json`, `candidate-paths.json`: 재배열·보정 및 전체 수정 소스
- `review.json`: 검토 범위와 승인 해시
- `serve.mjs`, `review.html`: 원본을 디스크에 저장하지 않는 대조 화면
- `verify.mjs`: 기록·실행 데이터 대조, `--online` 지정 시 출처 해시 재확인

검증 결과는 `verification.json`에 기록했다. 관련 테스트 15개, 한자 전체 테스트
220개, Next.js 16.3.3 프로덕션 빌드와 TypeScript 검사가 모두 통과했다.
원본 SVG와 연결된 CSS·JS도 HTTP 200 및 고정 바이트 수·SHA-256 일치를 확인했다.
기존 사전 대조 21자의 실행 데이터는 그대로 보존했다.

현재 8급부터 3급II까지 1,500/1,500자에 애니메이션이 적용된다. 전체 카탈로그는
1,501/5,978자 적용, 4,477자 미적용이다. 다음 권장 작업은 3급 신규 배정자
317자의 출처·획수 후보 정리다. 이번 검토는 로컬 반영 및 검증이며 배포를 뜻하지 않는다.
