## 대조와 보정

각 글자의 전체 실행 단계와 누적 자형을 직접 대조했다. 총획수나 부수 이름만으로 분할·승인하지 않았다.

- 礪·膜의 초두는 후보 3획·사전 4획이다. 사전의 왼쪽 가로→왼쪽 세로→오른쪽 가로→오른쪽 세로 순서에 맞춰 분리했다.
- 礪는 돌석변·안쪽 네모의 가로를 양옆 세로에 연결하고, 초두와 바깥 지붕·아래 구조가 붙지 않도록 조정했다. 18획 관통 세로와 19획 올림획의 접촉은 원본 외곽선도 RAM에서 확인했다.
- 遼의 사전 책받침은 **점 2개→가로·세로 꺾음→마지막 파임**이다. 누락된 두 번째 점을 허용된 점 경로에서 작성하고, 굽이진 후보 경로를 사전의 한 번 꺾는 획으로 보정했다. 마지막 획은 오른쪽 위로 진입해 앞 세로 끝에 닿은 뒤 오른쪽 아래로 펼치도록 했다. 이 진행은 원본 애니메이션 경로에서도 확인했다.
- 遼의 윗가로 범위와 오른쪽 파임의 위치, 안쪽 네모의 연결도 보정했다. 3획과 7획의 오른쪽 위 접점은 원본 외곽선에서 경계가 맞닿는 것을 확인했다.
- 膜는 月과 안쪽 네모의 가로 양끝을 연결했다. 초두·긴 가로와 이웃 구조의 간격, 마지막 두 삐침의 시작점도 바로잡았다.
- 작성·보정한 최종 경로는 **39개**(礪 15·遼 12·膜 12), 그대로 유지한 최종 경로는 **12개**다. 변경한 획과 세 글자의 완성 자형을 다시 대조했다.
- 재생 선폭 5에서 분리되어야 하는 획의 간격도 확인했다. 결과는 허용된 손글씨 중심선에 기반하며 정적 명조 SVG의 외곽선을 그대로 재현하지 않는다.

## 출처와 보관 범위

[e-hanja 礪](http://img.e-hanja.kr/hanjaSvg/aniSVG/7900/792A.svg), [遼](http://img.e-hanja.kr/hanjaSvg/aniSVG/9000/907C.svg), [膜](http://img.e-hanja.kr/hanjaSvg/aniSVG/8100/819C.svg)의 주소를 실제 상세 페이지 iframe에서 재확인했다. 사전 표시 획수·실행 단계·카탈로그는 각각 20·16·15획으로 일치한다. XML 배치 순서가 아닌 실행 지연 시간 순으로 검토했다.

고정 버전 Ko·Ja·MM을 NFKC 호환문자까지 검색했지만 목표 획수와 일치하는 대체 후보는 없었다. 경로는 기존 Arphic Public License 출처와 고정 해시를 유지한다. 국내 민간 사전 대조 결과이며 시험 주관 기관의 공식 인증으로 표시하지 않는다. 런타임 출처는 `ehanja-crosschecked`다.

사전 SVG·HTML·이미지·화면 캡처는 저장하지 않았다. 원본은 RAM에서 처리하고 URL·해시·실행 메타데이터·직접 작성한 관찰 및 허용된 후보·보정 경로만 남겼다. 모호한 접점은 원본 곡선을 표본화해 경계 간 거리를 확인했으며, 파생 결과만 기록했다.

## 검증과 파일

한자 테스트 **55개 파일·322개**와 TypeScript 검사를 통과했다. 새 회귀 테스트 8개는 48개 원본 획에서 51개 승인 획의 재현, 초두 순서·간격, 네모 내부 연결, 礪 관통 세로, 遼 두 점과 마지막 획의 위쪽 진입, 주요 접점, 획 사이 간격, 변경된 출처·경로·검토 기록의 거부를 확인한다. 기존 전체 등록부 검사에도 이번 묶음을 추가했다.

- `originals.json`·`acquire.mjs`: 고정 버전 후보와 읽기 전용 출처 재확인.
- `source-checks.json`·`initial-observations.json`·`observations.json`: 전 획 근거와 전후 관찰.
- `proposals.json`·`corrections.json`·`candidate-paths.json`·`review.json`: 명시적 획 대응과 보정 이력.
- `prepare.mjs`·`verify.mjs`·`checks.json`: 재생성·공개 데이터·진행 현황 검증.
- `progress.json`·`next-batch.json`: 현재 런타임 집계와 다음 검토 목록.
- `serve.py`: 출처를 디스크에 저장하지 않는 임시 로컬 검토 화면.
