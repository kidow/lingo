# 珝 10획 검토·적용

2026-10-03에 확보를 시작했고 2026-10-04에 검토·적용을 완료했다. 특급II 珝의 정확한 전체 u73dd-k 별칭 u73dd와 선언된 u738b-01·ufa1e만 사용했다. 2016년 공개 GlyphWiki 백업 전체 SHA256을 확인했다. 최신 개별 리비전은 백업에 없으므로 만들지 않았다. 백업은 GlyphWiki 데이터의 사본이며 독립 국내 근거나 시험기관 공식 승인이 아니다.

국내 e-hanja 전체 10획의 순서·방향·누적 자형과 90개 진행 상태를 Codex 브라우저 패널에서 대조했다. 국내2/3은 가운데 가로획·세로획 순서이므로 원본을 [[0],[2],[1],[3],[4,5],[6],[7],[8,9],[10],[11]]로 재배열했다. 원본의 7개 이차곡선·다각형·좌표·엔진 기본값을 보존했다. 5획의 접점118.65,30·118.65,172와 8획의 접점176.61,30·176.61,172는 연속이다. 새 좌표·연결 경로·잘라내기·부품 교체는 없다.

집중 테스트3개, 전체 한자 테스트264파일·1138개, 원본 엔진8파일 재현, 타입 검사와 정적7페이지 빌드, 공개3파일 내보내기 바이트 비교가 통과했다. 빌드 중 테스트 메타데이터 접근의 타입 오류를 고쳤고, 수정된 스냅샷에서 테스트·빌드를 다시 통과했다.

모바일430×932에서 소개·쓰기 자동재생 및 다시 재생을 각각1/10→10/10으로 확인했다. 쓰기 오버레이 이미지0개, 애니메이션SVG1개, 캔버스0→1→0획, 시트 위치·스크롤 유지, 해당 화면 콘솔 오류0개도 확인했다. 재생 구현과 기존 속도는 바꾸지 않았다.
