## 보정과 출처 기록

- 순서·방향 변경, 연속 획 분할, 여러 획 병합, 누락 획 작성, 부품 사이 간격을 글자별로 기록했다.
- 稅는 윗부분의 八 방향과 口 주변 간격을 보정했다. 餘는 食 하단을 직선 세로와 별도 가로 두 획으로 고쳐 15획 원본에서 16획을 출력한다.
- 원본의 특정 한 획으로 대응시킬 수 없는 경로는 `sourceStroke: null`과 명시 좌표로 기록했다. 해당 출력 위치는 器10·難4·殺7·賢6·餘9다. 賢6은 여러 원본 획을 합쳐 별도로 작성한 경로다.
- null 대응에 좌표가 없거나 잘못된 획 번호·좌표가 들어오면 거부한다. 원본 영상·기하 데이터·원본 median·보정 recipe·최종 경로의 해시를 고정한다.
- 보정 좌표는 로컬에서 작성한 중심선이며 출판사가 제공한 공식 SVG 좌표가 아니다. 원본 영상은 검토용 임시 프레임에만 사용했고 앱 자산으로 포함하지 않았다.
- Make Me a Hanzi를 사용한 稅·餘가 공개 데이터에 추가되어 출처 메타데이터와 `MAKEMEAHANZI-COPYING.txt`를 포함한다. 기존 AnimCJK 고지와 `ARPHICPL.txt`·`COPYING.txt`도 보존한다.

구현 파일: `scripts/hanja-stroke-textbook-corrections.ts`, `scripts/hanja-stroke-textbook-corrections.json`, `scripts/hanja-stroke-textbook-frames.py`, `scripts/hanja-stroke-textbook-review.json`, `public/hanja-strokes/textbook-reviewed.json`.

## 남은 4급II: 교과서 직접 일치 후보 4자, 전체 9자

전체 급수 기준으로 4자만 남았다는 이전 표기를 정정한다. 교과서 원문과 직접 일치하는 아래 4자 외에 **兩·連·液·衛·砲 5자**가 미적용이므로, 앱의 4급II 250자 중 적용241자·미적용9자다. [전체 급수별 집계](hanja-stroke-coverage-2026-09-08.md).

- **藝**: 상단 획 분리·순서 보정 초안을 전체 영상과 비교했다. 丸 점이 왼쪽 획에 과도하게 붙는 문제는 확인했으나, 상부 오른쪽 십자와 丸 내림획 시작의 실제 잉크 연결은 원본 해상도 및 12.3~13.0초의 0.1초 표본에서도 확정하지 못했다. 임의로 연결하거나 분리해 승인하지 않았으며, recipe와 공개 경로를 등록하지 않았다. 더 선명한 해당 자형의 필순 자료가 필요하다.
- **豊**: 목록의 豊13획과 연결된 영상의 豐18획이 다르다. 다른 글자의 영상으로 승인하지 않는다.
- **硏·鄕**: 현재 조사한 고정 원본에 정확한 문자 키의 재사용 기하 데이터가 없다. 대체 글자의 경로를 가져오지 않았다.
