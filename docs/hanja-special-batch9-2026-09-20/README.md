방향도 순서도 아니고 **획 자체가 다르다.** 국소 보정은 허가된 획의 범위 안에서
방향만 바꾸는 것이므로 점을 가로로 늘릴 수는 없다. 그래서 **닫는 쪽으로 보류**했고,
[verify.mjs](verify.mjs)가 두 글자를 다음 회차 후보에서도 빼 둔다.
賣의 四·罒, 靑·青, 兪의 巜·刂를 보류한 것과 같은 기준이다.

耰의 역방향은 [7차](../hanja-special-batch7-2026-09-20/README.md)의 肫에 이어 둘째 사례다.

끝점 배정 검사는 濰의 糸 순서를 더 찾았고, 窬와 异에도 교환을 제안했지만
이득이 0.8과 3.4라 **잡음으로 보고 그대로 뒀다.**

부수 유사성으로 승인하지 않았다. 쉰 글자의 사전 전체 필순을 순서대로 보고,
색으로 나눈 25% 진행 구간에서 방향·펜 떼기·획 경계·완성 자형을 대조했다.
[direction-probe.mjs](direction-probe.mjs)의 60° 초과 표시는 후보 교체·교환·보정으로 해소했고,
남은 둘은 자형 차이라 보류했다.
공개한 순서·경로로 다시 재면 60°를 넘는 획이 없다.
45~60° 구간은 다섯 획(窬 1·12, 夤 4, 袵 1, 衽 1)이고, 이전 회차와 같은 기준으로 그대로 뒀다.
