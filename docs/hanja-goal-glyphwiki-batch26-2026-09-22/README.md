- [이용 조건](https://glyphwiki.org/wiki/GlyphWiki:データ・記事のライセンス@18)은 사용·변경·재배포를 허용하는 자체 조건이다. CC0로 표기하지 않으며 원문 인용 자료의 별도 권리를 구분한다. [고지](../../public/hanja-strokes/glyphwiki/NOTICE.md)를 함께 배포한다.
- [KAGE 형식 설명](https://glyphwiki.org/wiki/GlyphWiki:KAGEデータ仕様@2)은 사이트 기여자가 엔진을 해석한 설명이다. primitive와 실제 한 획은 항상 일치하지 않는다. 이번 芥는 선·이차곡선·선+이차곡선의 8개 primitive가 각각 한 획임을 전체 대조했다.
- 원본에 선언된 성분 사각형 변환과 200→100 정규화만 사용했다. 임의 좌표·방향 반전·획 분할·병합은 없다. 국내 草의 순서에 맞춘 순열은 `[1,2,4,3,5,6,7,8]`이다.
- 원본 8획과 보정된 8개 누적 상태·완성형을 모두 검토했다. 선폭 4는 草의 두 가로획 사이와 아래 두 세로획을 분리한다. [findings.json](findings.json)에 획별 관찰이 있다.

## 庾 보류

`koseki-106330@6`는 이전 후보의 윗 점·아래 두 가로획 문제를 개선한다. 하지만 전체 12획 대조 결과 중앙획이 广에 닿고, 마지막 획의 시작 위치와 초반 방향이 국내 형태와 다르다. 13개 primitive 중 같은 꺾임의 두 선을 연결한 12획은 검토 전용이며 런타임에 넣지 않았다. 배정표 11획도 그대로다. 동일 원본의 별칭과 대안 차이는 [source-leads.json](source-leads.json)에 기록했다.
