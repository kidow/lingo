# 교과서 필순 6차 검토 — 4급II 잔여 후보

2026-09-08. 직전 미해결 4급II 65자를 대상으로 진행했다. 신규 47자와 기존 보류 16자, 중복 없는 **63자·764개 실제 획 완료 표본**을 원본 영상과 대조했다. 나머지 硏·鄕 2자는 원본 영상의 응답과 해시를 확보했으나 정확한 기하 후보를 찾지 못해 전체 필순 대조·재생 적용을 하지 않았다.

## 적용 결과

- 신규 무보정 일치 **8자**: **破 布 限 血 協 惠 好 希**.
- 기존 보류 보정 후 일치 **16자**: **認 田 絶 精 程 祭 際 尊 準 衆 創 處 請 總 侵 統**.
- 이번 추가 **24자·258획**. 교과서 재생은 **179 → 203자**, **1,976 → 2,234획**이다.
- 한국어문회 도해 검증 503자와 합해 전체 재생 **682 → 706자**. 전체 5,978자 중 미적용은 **5,272자**다.
- 검토 대장 **242자 = matched 203 + conflict 39**, pending 0. 이번 직접 대조 63자는 matched 24 + conflict 39다.

63자에 대해 전체 0.5초 진행과 필요한 0.1초 구간, 매 획 완료 표본, 모든 후보 획을 직접 확인했다. 획 완료 표본은 펜을 떼는 정확한 시각이 아니라 해당 획이 완성된 것을 확인한 상한이며 다음 획 일부가 보일 수 있다. 영상 URL·SHA·크기·길이, 원본 기하 SHA, 보정 SHA와 원본 획 대응, 최종 경로 SHA를 기록했다.

검토자는 Codex이며 인간 전문가 감수 또는 한국어문회 개별 승인으로 표시하지 않는다. 교과서 발행사 영상에 대조한 로컬 벡터 보정은 발행사가 제공한 SVG가 아니다.

## 이번에 확인한 중요한 차이

### 같은 획수라도 남은 15자

| 글자 | 보류 근거 |
|---|---|
| 包·港 | 내부 상자의 왼쪽 위 변 누락 |
| 票 | 영상에 없는 중앙 세로의 갈고리 |
| 解·虛·驗·戶·確 | 내부 획 또는 부품 순서 차이 |
| 暴·航·香·呼·貨·興 | 실제 재생 선폭5에서 원본과 다른 획/부품 접합 |
| 豊 | 목록은 豊13획, 실제 연결 영상은 豐18획으로 자형·획수 불일치 |

豊의 18개 실제 완료 표본을 13개로 줄이지 않았다. conflict 기록에 `observedStrokeCount: 18`과 실제 시점을 보존해 원문 목록/영상 연결 문제를 드러냈다.

검토용 후보 그림의 선폭도 수정했다. 기존 220px 셀의 5px 선은 실제 SVG `viewBox 0 0 100 100`의 `strokeWidth=5`보다 얇았다. 이제 같은 셀에서 11px와 둥근 끝·연결을 사용한다. 신규 23자는 영상 최종 자형과 실제 재생 선폭을 나란히 확인했고 접합 차이가 있는 글자는 보류했다.

### 획수가 다른 22자

각 글자의 영상을 별도로 대조했다. 부수 모양이나 일본어 후보의 획수만으로 자동 보정하지 않았다.

| 다음 보정의 주된 유형 | 글자 |
|---|---|
| 연속 경로 분할 | 極 達 導 城 盛 誠 逆 造 退 吸 |
| 분할/병합과 순서 변경 | 毒 進 賢 |
| 상단 가로 분할·중앙 간격 복원과 순서 변경 | 權 藝 蓄 護 |
| 누락된 점/가로 추가 | 器 難 殺 |
| 구성 또는 방향 재작성 | 送 視 |

賢은 원본 15획/후보16획으로 병합이 필요하다. 視는 원본 示5획/후보礻4획, 送은 상단 八/丷 방향 차이도 있어 단순 분할 문제가 아니다. 이 분류는 작업 후보이며 나열한 차이가 보정 전의 모든 기하 차이를 소진한다는 뜻은 아니다.

### 추가 원본 稅·餘와 미보유 硏·鄕

고정 Make Me a Hanzi 원본에서 稅12획·餘15획을 확보했다. 실제 영상을 전체 대조한 결과 稅의 6·7획 방향과 자형, 餘의 식변 하단과 16/15획 차이로 두 글자 모두 conflict를 유지한다. 별도 교차 검토에서 餘13획 완료 표본을 14.0초에서 **14.2초**로 정정했다.

신규 출처는 SHA별 독립 색인으로 읽고 각 글자의 명시적 출처와 전체 영상 대조가 있어야 생성한다. 기존 Ko/Ja로 대체하거나 미검토 후보를 자동 승인하지 않는다. 현재 공개 번들에는 Make Me a Hanzi 경로가 0개다. 원본 라이선스 고지는 `MAKEMEAHANZI-COPYING.txt`에 보존했다.

전체 미보유 22자 중 추가 벡터 후보는 13자를 찾았고, 이번 稅·餘 외 11자는 아직 개별 영상 대조 전이다. 세 기하 코퍼스에서 여전히 찾지 못한 9자를 포함한 근거는 [추가 원본 조사](hanja-stroke-textbook-batch6-additional-sources-2026-09-08.md)에 정리했다.

## 기존 보류 16자 보정

195획 전체를 원본 영상과 다시 대조했다. 필순·방향·분할·자형을 모두 확인한 명시적 recipe를 추가하고, 수정한 전체 후보를 실제 선폭5로 재검토했다.

- 程9획은 실제 잉크의 오른쪽→왼쪽을 반영했다. 侵5획은 왼쪽→오른쪽을 유지했다. 회색 커서의 이동을 획 방향으로 간주하지 않았다.
- 絶은 왼쪽 세로와 오른쪽 위 7·8획, 請은 위쪽 가로·가로·세로와 아래쪽 관통 자형을 수정했다.
- 衆은 11/12획 접합을 보정한 뒤 교차 검토에서 발견한 6/7획 사이 간격도 복원했다.
- 精·準·處·際·尊 등은 실제 선폭에서 생긴 불필요한 접합을 원본 영상과 다시 비교해 수정했다.

최종 보정 recipe는 원본 median·영상·recipe·출력 경로 SHA와 원본 획 대응을 함께 고정한다. 기존 공개179자의 객체 전체와 순서는 변경하지 않았다. 기존179자 `JSON.stringify(characters)` SHA-256은 `d48b54c45c2fe15c8eba0d4702b81e43508245753ed2d6ef977ed598e85fb069`다.
