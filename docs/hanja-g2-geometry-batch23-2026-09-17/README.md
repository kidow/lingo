## 출처와 재현

- Ko·Ja·Make Me a Hanzi·ZhHans·ZhHant 고정 버전을 다시 조회했으나 세 글자의 완성 경로는 없었다. 출처·해시·부품 경로는 [originals.json](./originals.json).
- e-hanja 실제 상세 페이지의 iframe을 새로 조회. 제목·획수·타이밍·클립 수와 전체 방향 확인 결과는 [source-checks.json](./source-checks.json).
- [compose.ts](./compose.ts)는 공개 부품의 지문을 검사하고 명시한 배치 영역으로 변환한다. 전체 부품 묶음과 개별 글자 묶음의 해시도 따로 검사한다.
- 최초 관찰 → 보정안 → 재검토: [initial-observations.json](./initial-observations.json), [proposals.json](./proposals.json), [observations.json](./observations.json).
- `node docs/hanja-g2-geometry-batch23-2026-09-17/verify.mjs`로 기록·경로·배포 데이터의 동일성, 적용 집계와 다음 후보를 검증한다.
