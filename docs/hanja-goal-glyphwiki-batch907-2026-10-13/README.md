# 巑 22획 보류

브라우저 패널에서 국내 자형과 전체 원본2종을 대조했으며 자형은 호환된다. 원본25raw·27draw·50다각형을 보존하면 연속 경계[1,2]·[18,19]로 최소23획이다. 숫자22 후보는 貝의 세로 raw17과 바닥 가로 raw22를 비연속 폐합하며 사이 raw18~21은 실제 그리는 획이다. 국내22획과 맞추려고 비연속 경로를 합치거나 좌표를 만들지 않으며 방향·진행·확대·재생은 미검토다.

브라우저 패널에서 전체 원본 2종과 전체 자형을 대조했다. 국내 방향은 미검토다. 완료하지 않은 진행 프레임·확대 경계·재생은 승인하지 않았다. 고정 원본·엔진·국내 메타데이터 검증은 통과했으며, 기존 런타임에 이 후보가 포함되지 않음을 확인했다.
