# Batch707 · 孼19획 보류

특급II 孼(서자 얼),배정표·국내 사전19획. 공개 전체형7종(기본,g,k,VS0–3)을 브라우저 패널57에서 전부 관찰하고 한국형19개 사전 정적 방향과 누적 자형을 대조했다.

기본·VS0·VS2는 상단 가운데 세로가 긴 왼쪽 곡선으로 이어져 국내 형태와 다르다. g형은 辛 위가 세로가 아닌 점이다. k·VS1·VS3의 짧은 삐침은 상단 가로에서 떨어지고,辛의 아래 세로 끝이 子의 상단 꺾임과 접한다. 국내16획은 子와 간격을 남긴다. 두 접합 조건을 함께 만족하는 전체 원본이 없어 런타임에 적용하지 않았다.15기록·7전체형·과거 리비전3개를 보존하고 출처 해시·리비전과 원본 윤곽을 재검증했다.

임의 좌표·윤곽 보정,부수 혼합,새 연결선은 만들지 않았다. 방향19개 관찰은 애니메이션 승인과 다르며,순차 프레임 승인0개다. 런타임5361/5978(89.7%)·미적용617은 그대로,누적 보류146자. 남은 급수1급64·2급1·특급II91·특급461.

보류 해제: 국내 두 접합 조건을 만족하는 재사용 가능한 전체 원본 또는 기존 이체형을 인정하는 독립 국내 자료 확보 후19방향·171프레임·확대·재생·앱 검증. 비공개 사전 그래픽은 RAM에만 대조했다.
