# 帨 시작 게이트 자연 재생 보류

새 렌더러의 10획을 자연 재생할 때 2.68000000%에서 시작부에 흰 틈과 분리된 세로 부분이 보였다. 같은 프레임의 기존 렌더러는 연속적이다. 완료 상태가 같아도 이 결함 때문에 적용하지 않는다.

전체 자형, 국내 자료의 10획 순서·방향, 각 획 9단계 진행 화면, 위험 획 4개의 완료 직전·완료, 다중 마스크 5·10획의 전환 경계와 초기/95%, 대상 마스크 2개의 전체 포함 범위는 통과했다. 5획 자연 재생은 2.8125%부터 100%까지 확인했다. 10획은 실패를 확인한 뒤 이미 진행 중인 재생의 완료 상태만 기록했다. 자세한 실제 관찰 범위와 수치는 `hold.json`에 남겼다.

전용 Python 서버 PID 80881·포트 64336은 종료했고 종료 코드는 143이다. 앱·원본 경로·필순·레지스트리·기존 보류 기록은 변경하지 않았다. 빌드는 실행하지 않았다. 현재 전체 적용 수 5,732자, 미적용 246자는 그대로다.

다음 검토는 원 기하를 유지한 별도 표시 정책의 시작 원 밖 조기 노출 가능성이다. 이 기록을 성공으로 바꾸거나 다른 글자의 승인·실패를 추정하지 않는다.
